The DIFIMPHOT package is dedicated to generating and analysing difference
images (hereafter dimages). It can substantially enhance variable source
detection as well as astrometric and photometric measurements in moderate
to extremely crowded fields where conventional algorithms fail (e.g.  
ground-based images of external galaxies).

DIFIMPHOT builds on the IMMATCH package in IRAF and has the following
features:

 - automated registration of a time-series of images
 - optimal image stacking 
 - dimage generation (including spatially variable PSF)
 - dimage source detection using dimage statistics
 - dimage photometry for optimal flux extraction using dimage statistics
 
Also available in the package is extensive documentation including an
illustrated introduction to the technique, detailed discussion of all
processing steps, discussion of image undersampling, atmospheric
dispersion and other issues with dimages, as well as an manual for the
DIFIMPHOT package.

All this is accessible from the DIFIMPHOT main page:

 http://www.astro.washington.edu/austin/dip/DIFIMPHOT.html

which includes installation instructions:

 http://www.astro.washington.edu/austin/dip/install.html

and the software which can be downloaded from:
