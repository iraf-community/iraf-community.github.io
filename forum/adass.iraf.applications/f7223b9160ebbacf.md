# want image center in WCS units

**Blaise Canzian** wrote on Aug 21, 2004

<pre style="background: transparent; box-shadow: none; border: none;">
I have an image with a correct WCS in the header.  I would like to know 
if there is an IRAF application or series of applications that will 
provide a centroid of an image and return the answer to me in the WCS 
frame (RA and Dec), not pixels.  Or if, having computed the cetroid in 
pixel units, I can feed that coordinate to an application that returns 
(RA,Dec) based on the image WCS.  Thanks.

-- Blaise Canzian
    blaise@nofs.navy.mil
</pre>

Hello Blaise,

Whether tasks report coordinates in world units rather than pixels 
depends on the application.  However, a very useful task, which answers 
one of you questions is WCSCTRAN.  This converts between &quot;world&quot; (which 
is whatever is in the header such as RA/DEC) and &quot;logical&quot; (which means 
pixels).  So if you collect a series of pixel coordinates in a text file 
you can easily convert them to RA/DEC as defined in the image header 
with this task.
