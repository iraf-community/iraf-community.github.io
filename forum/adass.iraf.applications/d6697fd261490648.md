+++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++

    HST uses a small set of NIR standards: four white dwarfs and
    three solar analogs. The absolute calibrated spectra of these 
    standards (IRAF STSDAS table format) and their pedigree can be 
    retrieved from one of the STScI WEB pages:
    
    http://www.stsci.edu/ftp/instrument_news/Observatory/cdbs/calspec.html

    The names of the files containing the near-infared spectra are:


     White dwarfs                         Solar Analogs
    
     G191B2B_MOD_002                        P041C_001
     GD153_MOD_002                          P177D_001
     GD71_MOD_003                           P330E_001
     HZ43_MOD_002    


    Coordinates, finding charts and detailed information about the spectra
    can be found in Bohlin, Colina &amp; Finley 1995, AJ 110, 1316 for the
    white dwarfs and in Colina &amp; Bohlin 1997, AJ 112, 307 for the solar
    analogs.


-L. Colina

+++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++


To the reader:

This information does not actually tell you how to use the NOAO/IRAF
flux calibration routine STANDARD with this data.  One would have to
convert the above standard star data into the format used by STANDARD
which is a list of central bandpass wavelengths, bandpass fluxes in
magnitude units, and bandpass widths.  Some time someone should do
this.  At this time we have not done this and I don&#x27;t know anyone who
has.

Frank Valdes
NOAO/IRAF Group
