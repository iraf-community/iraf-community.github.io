## RVSAO 2.0 beta available for testing

**Doug Mink** wrote on May 15, 1998

<pre style="background: transparent; box-shadow: none; border: none;">

A major revision of the IRAF external package RVSAO is available for
testing.  This package contains tasks which measure redshifts of spectra
using cross-correlation and automatic emission line identification, as
well as tasks to created cross-correlation templates.  It is designed
to run with minimal user interaction and has been used on many large
redshift surveys.  A paper describing RVSAO 2.0 will be published in
PASP in August 1998.  This beta version is quite stable, but we would
like to know that it works outside of SAO before making a formal
release.

The software is available for anonynmous ftp at

    ftp://cfa-ftp.harvard.edu/pub/iraf/rvsao-2.0b.tar.Z

Compiled binaries for IRAF 2.11 and IRAF 2.10.4 for Sparcstations
running
Solaris and Alphas running Digital Unix are available at the same site.

Documentation, with examples, is available on the World Wide Web at

    http://tdc-www.harvard.edu/iraf/rvsao/

-Doug Mink
</pre>
