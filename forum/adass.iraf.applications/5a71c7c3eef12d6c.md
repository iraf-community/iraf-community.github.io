Dear,

The &#x27;order&#x27; of equation in IRAF means the number of terms (or coefficients) in the equation.
So the real order of equation is {(&#x27;order&#x27; of IRAF&#x27;) - 1}.  
For example, y = ax^2 + bx + c (ORDER: 3 in IRAF, 2 in mathematics).
If you set the xoder = 4, yorder = 3, the number of coefficients will be 4 x 3 = 12.
