## RSPECTEXT: Dispersion units in 2.11

**Frank Valdes** wrote on Sep 24, 1998

<pre style="background: transparent; box-shadow: none; border: none;">
Q:  If I read in artificial spectra using RSPECTEXT:

cl&gt; rspectext input_file output_file dtype=interp

and try and cross-corelate with FXCOR, I get an error message:

ERROR: Cannot convert to specified units

It used to work with rspectext header- in 2.10, but the &#x27;upgrade&#x27;
to rspectext seems to have stuffed something up.



A:  It is true that the logic that tries to figure out dispersion units when
not present in the header is not able to deal correctly with the output
of RSPECTEXT.  Actually the header from RSPECTEXT was updated and it is
this different header that causes the problem.  This will be addressed in
the next release.

There are two simple solutions.  One is to add the unit information to
header with:

cl&gt; hedit &lt;images&gt; wat1_001 &#x27;wtype=linear label=Wavelength units=Angstroms&#x27;

The other is to delete the new keywords which will let a default of
Angstroms be assumed:

cl&gt; hedit &lt;images&gt; wat* del+
</pre>
