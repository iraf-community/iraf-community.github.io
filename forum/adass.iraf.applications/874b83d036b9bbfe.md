## CCDHEDIT: Getting the right keyword type

**Frank Valdes** wrote on Jun 02, 1998

<pre style="background: transparent; box-shadow: none; border: none;">

Q:  It seems the task CCDHEDIT insists on writing any header keyword
as a string even though I specify type=real....

    NOAO PC-IRAF Revision 2.11.1 EXPORT Mon Jan 26 13:32:19 MST 1998


A:  If you are adding/creating a new keyword then the type specification
works fine.  However, it is a quirk of IRAF that you cannot change
an existing string type keyword to a numeric keyword.  The same
behavior also applies to HEDIT.  So you should delete the keyword
you want to set to a real value and then use CCDHEDIT.
</pre>
