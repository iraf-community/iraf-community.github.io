# Fitting a power law continuum to 1D spectra

**Frank Valdes** wrote on Mar 19, 1998

<pre style="background: transparent; box-shadow: none; border: none;">

Q:  I have some spectra from the 2.1m which have flux calibration problems
redward of ~7500A.  I want to try to fix those calibration problems
by fitting the spectram blueward of this and then extrapolating redward.
My objects are BL Lacs, which are simply a power-law spectrum.  My data
are in units of f_lambda vs. wavelength; I&#x27;d like to convert it to f_nu
vs. frequency, plot it as log f_nu v. log nu, and the fit this power
law (with &#x27;continuum&#x27;?).  Can you explain how I could do this?


A:  You can use SPLOT to convert to log F-nu.  Use the &#x27;n&#x27; key to convert
from F-lambda to F-nu.  Then use &#x27;f&#x27; to enter function mode and then
&#x27;l&#x27; to take the log.  Type &#x27;q&#x27; to exit function mode and use &#x27;i&#x27;
to save the modified spectrum.

To convert the dispersion to log-nu use DISPTRANS.

cl&gt; disptrans &lt;inspec&gt; &lt;outspec&gt; &quot;log hertz&quot;


You can also do everything with SPLOT and not actually change the
data.  The sequence would be:

        cl&gt; splot spec
        n                               # Convert to F-nu
        f                               # Enter function mode
        l                               # Take log
        q                               # Exit function mode
        :units log hertz                # Convert dispersion to log-nu
        t                               # Do fitting
        f                               # Do fit
        q                               # Quit fit (when done using ICFIT)
        :units angstrms                 # Convert back to angstroms
        f                               # Enter function mode
        d                               # Take anti-log
        q                               # Exit function mode
        l                               # Convert to F-lambda
        i                               # Save result
        
        
The t key in SPLOT calls the same ICFIT routines used by continuum.
</pre>
