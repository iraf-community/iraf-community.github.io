# APEDIT

**Frank Valdes** wrote on Feb 23, 1998

<pre style="background: transparent; box-shadow: none; border: none;">

Q:  An IRAF question, concerning APEDIT. The task often chooses a
cosmic-ray hit (or some other artifact) as aperture #1. By using
keystroke &quot;n&quot;, one can then choose the intended aperture, now named #2,
which contains the stellar spectrum. Is there any easy way to relabel
the latter aperture as #1, while simultaneously removing all reference
to the original aperture #1 ? Or, to permit, originally, a manual
choice of the stellar spectrum as aperture #1 ?


A:  The easiest thing in the situation you describe of manually fixing
a single aperture is to type &#x27;d&#x27; to delete the bad aperture and then
type &#x27;n&#x27; to mark the new aperture.  Note that you can indeed renumber
an aperture with &#x27;i&#x27;.  Another hint to pass along is that if you
have lots of problems with cosmic rays you can use a negative value
for &quot;nsum&quot; where the absolute value specifies the number of lines
and the negative means use a median instead of an average.
</pre>
