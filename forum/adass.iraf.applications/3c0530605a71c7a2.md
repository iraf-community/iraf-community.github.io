## Cursor mode and metacode help for SPLOT (:.help)

**Frank Valdes** wrote on May 12, 1999

<pre style="background: transparent; box-shadow: none; border: none;">
This question is more general and posted to remind people about how
to get help on the cursor mode options from any graphics tasks.  FV



Q:  It would be rather helpful if the ``:.&#x27;&#x27; commands were also listed in
the SPLOT help files (or whereever applicable). Eg, I can never remember
how one is suppose to generate a metacode file (and there is no help to
be found with the other tasks which operate on the metacode files) so
it would help that one can spot the `:.write file&#x27; in the help pages.
A separate on-line help page which sums up the methods with which one
can generate the metacode files and work on them would be very helpful
as well, as indicated.


A: I don&#x27;t agree that the information belongs in the SPLOT help
page since then it really should be in every help page that has graphics.
What I have done is add the following to the SPLOT help page and the
run-time &#x27;?&#x27; help page:


:/help  Get help on GTOOLS options
:.help  Get help on cursor mode options


So to refresh yourself on the cursor mode options simply type &quot;:.help&quot;
(this is available from all graphics tasks).  Note also that when
help is paged by a task with &#x27;?&#x27; if you type &#x27;q&#x27; and then &lt;space&gt;
(i.e. finish the task help and then instead of &#x27;q&#x27; to return to the
cursor you type &lt;space&gt;) you also get the cursor mode help.

&gt;From IRAF there is the &quot;help cursors&quot; which discusses the cursor mode
options.  Your suggestion about a quick guide to doing things with
metacode files is a good one.  We just have not had the staff to do
more of the general quick guides that we would like.  Maybe someday...
</pre>
