## MXTOOLS 1st release (17MAR2000)

**Ken Mighell** wrote on Mar 17, 2000

<pre style="background: transparent; box-shadow: none; border: none;">
FROM: mighell@noao.edu
  TO: adass-iraf-applications@iraf.noao.edu

This announcement is the first public release of my MXTOOLS package for IRAF.

Currently, the main task in the package is MXQDPHOT which is a new fast CCD 
stellar photometry task which does quick and dirty photometry.  MXQDPHOT is 
designed for applications where speed matters and every second is important.  
MXQDPHOT currently detects and photometers stars present in two aligned CCD 
images with critically-sampled stellar images [i.e. FWHM of 2--3 pixels].
MXQDPHOT typically takes just a few seconds to analyze a single CCD of
two aligned WFPC2 observations in two filters [e.g. 2--3 seconds on a 
200 MHz Sun Ultra1 workstation].  MXQDPHOT is suitable for producing 
on-the-fly instrumental color-magnitude diagrams at the telescope console 
in the few seconds between CCD readouts.  MXQDPHOT has proven to be an
excellent data mining tool for finding high-quality stellar observations 
amongst gigabytes of archived data.

MXTOOLS uses the CVOS library in STSDAS.  If you do not have STSDAS, it will
have to first be installed in order for the tasks in MXTOOLS to compile
properly.  I have tested the 17MAR2000 version of MXTOOLS on Solaris,
SunOS, and Redhat Linux machines.

Once MXTOOLS is installed, the following IRAF command

  cl &lt; mxtools$src/mxqdphot/verify/ngc362.cl

will do MXQDPHOT photometry on two HST WFPC2 observations of the globular 
cluster NGC 362 in a few seconds for both the F439W and F555W WF3 observations.


Further information about MXTOOLS can be found at the following website:

http://www.noao.edu/staff/mighell/mxtools/

Any comments/suggestions and bug reports would be greatly appreciated.
