## SPLOT: Overplotting with a solid line

**Frank Valdes** wrote on Jan 21, 1998

<pre style="background: transparent; box-shadow: none; border: none;">

Q;  I am asking about how to overplot the spectrum with a solid line
when I use a task &quot;splot&quot;.

What parameter should I set in &quot;splot&quot;?


A:  SPLOT increments the line type number when it overplots (it also
increments the color if you have a color graphics window such as
XGTERM).  The primary plot is with line type 1 which is a solid line.
The first overplot uses line type 2 which is a dashed line.  In SPLOT
you can change the line type with the command &quot;:/line &lt;number&gt;&quot;  (see
&quot;help gtools&quot; or use the command &quot;:/help&quot; for more information about
the the gtools commands).  So you can trick SPLOT into using a solid
line for overplotting as follows.  First make the primary plot.  Then
reset the line type to zero with &quot;:line 0&quot;.  Now make the overplot
which will use line type 1.  THEN MAKE SURE TO RESET THE LINE TYPE BACK
TO 1 OTHERWISE YOUR NEXT PLOT WILL BE INVISIBLE!

You might be interested in the task SPECPLOT.  This was designed to
make good plots of stacked and overplotted spectra.  It has many
features for setting the attributes of each spectrum plotted.  It
may be more suited for what you want to do.
</pre>
