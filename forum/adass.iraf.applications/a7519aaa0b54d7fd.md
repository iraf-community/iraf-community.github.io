## HEDIT: Adding the right keyword type

**Frank Valdes** wrote on Jun 02, 1998

<pre style="background: transparent; box-shadow: none; border: none;">

Q:  I can&#x27;t seem to add a sexigesimal number to a keyword with HEDIT.
How do it force HEDIT not to convert my number to a decimal value?


A:  When HEDIT adds a new keyword it determines the keyword value type
from the value.  In IRAF sexigesimal numbers are recognized as numbers
and not strings so a real value keyword is created and the input number
is converted to decimal.  There is a trick to forcing a string value
type with HEDIT which relies on the fact that HEDIT will not change
the type of an existing keyword.  The trick is to use a dummy value
to first force a string type keyword to be created and then change
the value.  Below is an example.

    cl&gt; hedit pix newtime dummy add+ verify- show- upate+
    cl&gt; hedit pix newtime &quot;1:20:30&quot; verify- show- update+
</pre>
