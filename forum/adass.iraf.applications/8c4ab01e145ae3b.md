## CCDPROC - undoing flat field corrections

**Frank Valdes** wrote on Dec 03, 1997

<pre style="background: transparent; box-shadow: none; border: none;">

Q:  I used the wrong flat field for some frames - how do I effectively undo
this?


A:  I assume you are asking how to undo the CCDPROC flat fielding in a
corrected image rather than returning to the raw data.  In the simple and
usual case where the incorrect flat field and the object image are the
same size you can use IMARITH.  The steps are to multiply by the
incorrect flat field, divide by the scaling factor given in the flat
field header, and remove the header keyword flagging the operation
as being done.  You can then return to CCDPROC again to apply the correct
flat field.

	cl&gt; imarith obj * wrongflat objcor
	cl&gt; imarith objcor / &lt;ccdmean&gt; objcor
	cl&gt; hedit objcor flatcor del+ verify-

where obj is the image you want to uncorrect, wrongflat is the
incorrect flat, &lt;ccdmean&gt; is the value of the CCDMEAN keyword in the
flat field image header, and objcor is the fixed image.  You could do
the above steps &quot;in-place&quot; (i.e. modify the original object image) by
using the same image name for output as for input.  You can also do a
set of images using @lists for the input and output.

Let us know if you have questions about this.
</pre>
