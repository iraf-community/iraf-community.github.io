===== 2001SEP20 RELEASE NOTES =================================================

The latest release of MXTOOLS features several new tasks including 

  psfprep - Convert a PSF image into the MATPHOT PSF format.
   psfobs - Simulate a CCD stellar observation using a MATPHOT PSF file.
   psfg2d - Create a MATPHOT PSF file with a 2-d Gaussian PSF.
  psfdelx - Compute the X partial derivative of a MATPHOT PSF file
  psfdely - Compute the Y partial derivative of a MATPHOT PSF file
    
which are support tasks for the MATPHOT digital-PSF stellar photometry
algorithm which I will describe at the ADASS XI meeting oral session
on Science &amp; Analysis (Tuesday, October 2).
