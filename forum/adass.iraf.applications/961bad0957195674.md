1.0 Revised version of the HRI Calibration Report

The current version of the Cal report on our website and in our
anonymous ftp area is dated 1 June 1999.  It contains a short
discussion of the aspect timing bug found in SASS earlier this year.
We have also analyzed both the original HZ 43 data used in determining
the analytical approximation to the on-axis point response function
(PRF), and the data corrected for the timing bug.  The radial profiles
agree to within the errors so it appears there is no need to revise
the original profile and the PROS routines that generate PRFs.

2.0 Plans for the next PROS release.

IRAF has released a beta test version (IRAF 2.11.2) which contains all
the fixes necessary for Y2K compliance as well as other bug fixes and
enhancements.  STScI will test their TABLES package and make any
changes necessary and we will follow thereafter.  Thus there could be
a new PROS release for IRAF 2.11.2 by 1999 September.

3.0 ROSAT data from the WFC tracker era.

As most of you know, the main star tracker for ROSAT aspect
determination failed in 1998 April.  MPE staff had a backup plan to
use the Wide Field Camera (WFC) tracker, and some data were obtained
during the period 1998 May to 1998 September when the HRI detector was
critically damaged.  These data are now being processed and
distributed to PIs.  There is little doubt that the effective PRF will
be significantly larger than for previous data.  Therefore, we
strongly urge you to be mindful of the observing date if you receive
new data.
