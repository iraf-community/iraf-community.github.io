	Sorry for the late reply, I was hoping other would chime in with
what they found most useful and then I forgot about the posting.  The
first thing to look at is the draft Beginner&#x27;s Guide which is available
as
	ftp://iraf.noao.edu/pub/beguide.ps.Z

Our FAQ (http://iraf.noao.edu/faq) is mostly system stuff but will help
you through most installation, image display, etc problems.  All of the
documentation we have is available from our web pages, these include
various cookbooks to help you through reducing various kinds of data.
Lastly, there are exercises available to help you get started from
ftp://iraf.noao.edu/iraf/misc as exer211.tar.Z, see the readme file for
details.
	All of this material is available from the UK mirror site at
ftp://star.rl.ac.uk/pub/iraf or http://star-www.rl.ac.uk/iraf as well.
Hope this helps, if you still have problems or questions feel free to
post here or write iraf@noao.edu.

Cheers,
Mike Fitzpatrick
</pre>
