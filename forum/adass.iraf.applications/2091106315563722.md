## Tool available for translating IRAF help pages into LaTeX and HTML

**Klaus Elmquist Nielsen** wrote on May 21, 1999

<pre style="background: transparent; box-shadow: none; border: none;">
I would like to announce the availability of iraftex, a tool for
translating IRAF online help pages into LaTeX and HTML.

Iraftex is available from the following location:

        ftp://iraf.noao.edu/contrib/iraftex-0.15.tar.gz

The current version is written in awk (GNU awk recommented) and supports
most (but not all) help pages.

For more information please refer to the README file in the distribution.

Cheers,

        Klaus Elmquist Nielsen
        klaus.elmquist@get2net.dk
</pre>
