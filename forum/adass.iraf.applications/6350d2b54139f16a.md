# SPLOT - formatted output from splot

**Frank Valdes** wrote on Dec 01, 1997

<pre style="background: transparent; box-shadow: none; border: none;">

Q:  I need the central wavelength of several spectral lines, and I would
like to measure it fitting gaussian profiles using &#x27;splot&#x27;. I need an
accuracy of 1 tenth of miliangstrom, but the default listing uses only
three digits after the dot (so, 1 miliangstrom accuracy). How could I
change the format of the output to the logfile (splot.log) as I need?


A:  Unfortunately there is no easy way to extend the precision of the SPLOT
formated output.  We will take this problem into account in a future
version of the software.  The suggestion I would make would be to
modify the wavelength solution to subtract a zero point.  For instance,
if your spectrum is around 4000 angstroms but with miliangstrom
resolution then you could subtract 4000 from the wavelengths and gain
some precision.  You would then just add 4000 to measurments to get the
full Angstrom wavelength.  How to do this depends on the image header
format.  It may be as easy as using HEDIT to change the value of CRVAL1
(or CRVAL2).  If you can&#x27;t figure out how to do this then send me a
listing of a spectrum header and I will advise you.
</pre>
