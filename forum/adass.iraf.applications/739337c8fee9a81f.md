## converting FITS table to imh image

**Phil Hodge** wrote on Jun 02, 1999

<pre style="background: transparent; box-shadow: none; border: none;">
&gt;  Do you have a new tool in IRAF to use for transfering FITS binary table
&gt; to IRAF .imh/pixal in only one step?

Perhaps tomultispec (in the stsdas.hst_calib.ctools package) will do what
you need.  Tomultispec reads wavelengths and fluxes from one or more rows
of a table, fits a curve to the wavelength array, writes the fluxes to an
output image, and adds info about the fit to the output header.  The image
that is created is an imh/pix image in multispec format.

There are other tasks in the tables.ttools package that may be helpful in
working with tables.

Phil
</pre>
