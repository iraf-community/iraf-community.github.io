# Measuring profiles non-interactively

**Frank Valdes** wrote on Jun 26, 1998

<pre style="background: transparent; box-shadow: none; border: none;">

Q:  I am in the process of measuring equivalent widths and FWHMs for around
150 diffuse interstellar bands (DIBs). Can you tell me whether there 
is a way to do this automatically, eg put the central wavelengths and a 
specified continuum in a file and ask Iraf to do it in one batch? 
Clicking on each individual DIB is time-comsuming, as you can 
imagine, especially if one has 10 or 15 program stars.


A:  There are three suggestions you might consider.  There is a task called
SBANDS in the ONEDSPEC package which may be of use.  This does bandpass
photometry including equivalent widths.  It does not measure FWHM.

The second is the noninteractive version of SPLOT called BPLOT.  Basically
this runs SPLOT but instead of typing with the cursor you set up a
file of the cursor keys you would use.  The x coordinate is wavelength
so if you know the wavelength edges you can do the usual thing.  This
may be difficult to do since there are so many prompts for the deblending.
For the single line fitting this should be straightforward.

The code used by SPLOT for line fitting is also implemented in a separate
noninteractive task for just such a purpose.  The task is FITPROFS.

Note that if you want to have more control over the continuum you may
find it better to first continuum normalize your spectra with CONTINUUM.
Then you would be able to force the continuum to be one in some of these
tasks.
</pre>
