# CCMAP: WCS in fits header

**Eduardo A. Gonzalez Solares** wrote on Mar 09, 2000

<pre style="background: transparent; box-shadow: none; border: none;">
Hi all,

I am working on the astrometry of 4K x 2K images and I am using ccxymatch and
ccmap to calculate an astrometric solution for each frame. Since there are
some important field distortions on the edges of the frames I need to apply a
high order general fit with CCMAP in order to get correct astrometry for the
sources at the edges. My problem is that ccmap only puts in the header of the
image the linear term of the fits, this is, the CD matrix. I can use cctran to
transform appropiately from x,y to ra,dec since the output of ccmap is a
database file with the general astrometric solution. My question is if anybody
knows a way to introduce the general astrometric solution in the header of the
fits image, so that IRAF can understand it and I do not need for an aditional
database file.

Thanks a lot,

Eddie.
</pre>

To record the higher order terms in the image header set the ccmap projection
parameter to &quot;tnx&quot; instead of &quot;tan&quot;. Both ccmap and ccsetwcs will then
update the headers with the full solution, i.e. you will see CTYPE1=&#x27;RA---TNX&#x27;
and CTYPE2=&#x27;DEC--TNX&#x27; in the header and there will be terms of the form
lngcor=&quot;....&quot; and latcor=&quot;...&quot; in the WAT1_# / WAT2_# keywords. BY default
ccmap only records the best fit linear part of the solution because the TAN
projection is a defacto FITS standard that most other software will understand.
IRAF code understands the TNX projection but other software probably won&#x27;t. 

If you have saved your database file you don&#x27;t actually have to repeat the
fits. Just change all the references to &quot;tan&quot; to &quot;tnx&quot; in the database
and run ccsetwcs.

I hope this answers your question.
