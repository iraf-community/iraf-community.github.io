**Mike Fitzpatrick** wrote on Jun 09, 2001

<pre style="background: transparent; box-shadow: none; border: none;">

&gt; I have a question in PSF  &amp; ALLSTAR package in IRAF/DAOPHOT.  The
&gt; parameter &quot;maxnstar&quot; (maximum number of star to fit) has a limitation as
&gt; 50,000 while I already got about 90,000 stars founded in DAOFIND &amp; PHOT
&gt; package.  How can I change this value up to 100,000?

	In this case the limit is set by a maximum value set in the
DAOPARS parameter file which defines the &#x27;maxnstar&#x27; parameter, but users
can raise the limit by simply resetting the max field of the parameter.
For example,

	cl&gt; = daopars.maxnstar.p_max
	50000
	cl&gt; daopars.maxnstar.p_max = 100000
	cl&gt; = daopars.maxnstar.p_max
	100000
 
The only real limits are the resources and configuration of the machine
and the setting will stay in effect until you unlearn daopars or daophot.
Similar fields you might want to change include &#x27;p_min&#x27; (minimum value),
&#x27;p_mode&#x27; (&#x27;q&#x27; for query, &#x27;h&#x27; for hidden, etc), or &#x27;p_prompt&#x27; (to change
the wording to something more to your liking).

	Note that while the parameter limits can always be raised in this
way if they are imposed in the parameter file, it might not work as
intended due to contraints on the application (e.g. artificially raising
the number of frames allowed in the DISPLAY task will not get you 100
frames in the display server, you could exceed some array size in the
task, etc).  Check the help page or write back if you have questions about
a particular task.

-Mike
</pre>
