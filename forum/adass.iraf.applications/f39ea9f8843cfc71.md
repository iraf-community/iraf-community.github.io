# Creating IRAF echelle format from individual order spectra

**Frank Valdes** wrote on Jun 26, 1998

<pre style="background: transparent; box-shadow: none; border: none;">

Q: I am dealing with files which have been reduced at the 
observatory using Midas. This resulted in 67 separate fits files, each 
one representing one order. I can view each order separately on Iraf but 
I wish to merge them all in one file (but with separate orders), just 
like the result one gets from the DOECSLIT package (the .ec.imh file), so 
that I can move from one order to the other at the touch of a button. Can I 
also do this using SCOMBINE, and if so what parameters must be specified?


A:  Yes you should be able to make a &quot;.ec&quot; type of file from separate 1D
order spectra.  For this you would use SCOPY with an output format of
&quot;multispec&quot; and a command like:

	cl&gt; scopy @orders mydata.ec format=multispec renumber+
	
The file orders would contain the names of the individual order spectra
in the correct order.  The renumber option will then assign different
sequential aperture numbers for each order (it is a requirement that
each spectrum in a multispec file have different aperture numbers).

The only warning is that if you were to try and use ECIDENTIFY for
doing wavelength solutions the beam numbers would have to be setup
properly.  Since I expect you are not going to do this but have already
wavelength calibrated data then I won&#x27;t describe this step.
</pre>
