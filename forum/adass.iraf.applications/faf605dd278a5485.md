## SPLOT: question about splot labels

**Frank Valdes** wrote on Sep 10, 1998

<pre style="background: transparent; box-shadow: none; border: none;">
Q: I am using splot and in my graphics window I can turn off the banner, create
my own title, label the axes, etc.  

How can I turn off the numerical values for units on an axis which appear by 
each of the tick marks.  In other words, I want the tick marks to be present,
but no numbers or anything else on the x an y axis.


A: Unfortunately there is no way for you to turn off the axis numbering
or modify things like ticks in SPLOT.  SPECPLOT does allow you to have
nothing on the y axis.  If you want more control over the appearence
of spectrum graphs you will have to use IGI (the Mongo-like STSDAS tool for
general graphics) or non-IRAF software.  Just for your information, I
have been working on a new spiffier SPLOT type of task which will have
control over almost everything the IRAF graphics system does but this will
not be available for some time.
</pre>
