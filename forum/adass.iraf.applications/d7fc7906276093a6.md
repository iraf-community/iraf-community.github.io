1.0 REVISED VERSION OF THE PROS USERS GUIDE

Aside from a few minor corrections and some updated material dealing
with PROS 2.5, the major additions are a new chapter on simple
AXAF/MARX tools and a new section in the HRI chapter describing
methods of ex post facto improvement of the HRI spatial resolution for
observations for which poor aspect degraded the effective PRF.
Following information provided by G. Hasinger a year ago, the SAO/RSDC
undertook development of a PROS installation which operates on the
basis of phase binning (of the 402 second wobble period).  The methods
described are still being refined but we and our &#x27;beta testers&#x27; (in
Bristol) have had enough success to warrant a general dissemination of
the method.  What is required for this method is the presence of a
reasonably strong source which is unresolved and not too far off axis.
We believe that a count rate of 0.1 count/s is sufficient; it is
possible that in some circumstances weaker sources can be used.  IRAF
scripts can be downloaded from our anonftp area; cd to
pub/rosat/dewob.

2.0 LINUX PORT

Thanks to a user who allowed us to use their PC and to M. Fitzpatrick
of NOAO, we have now been able to provide binaries for linux.  If you
want to install PROS 2.5_p1 under linux, be sure to read the
appropriate README file in the directory
&quot;/pub/pros/pros_2.5_p1/linux_data_src/&quot; from our anon ftp.

3.0 UPDATED SCC_TO_UTC 

We have downloaded from MPE the latest fits file for scc_to_utc.
Coefficients there are valid through day 67 of 1998.  cd to
pub/rosat/calfiles and get the file scc_to_utc.fits.

4.0 HRI CALIBRATION REPORT

We have made a few changes to the HRI Calibration Report such as 
updating the gain table and plot and including characteristics of
hotspot #3.  cd to pub/rosat/docs/hri_report98 and get either the
postscript file or the compressed version.  The web version will
be updated in the near future.


ABOUT HINTS &amp; POINTERS
As the provider of the PROS software package (&quot;xray&quot; in IRAF), the
ROSAT Science Data Center (RSDC) at SAO distributes HINTS &amp; POINTERS
to PROS Users via email.  When we find answers to often asked
questions, or when we have implemented new software solutions to
longstanding problems, we will send this information directly to our
users.  These messages will also be available via anonymous ftp*, but
to receive the email version, you should register with us. If your
username is the one associated with your site registration, you are
already registered for &quot;HINTS &amp; POINTERS&quot;, but we encourage other
users (even at the same sites) to register.

Mailings will be sent as the need arises.  If you would like to
suggest items for future issues of H&amp;P or add your name to our
distribution list, please contact us at the following address:
