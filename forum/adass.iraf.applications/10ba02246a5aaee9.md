# ECHELLE.DOFOE - Works both with a single fiber and dual object/arc fibers

**Frank Valdes** wrote on Nov 21, 2000

<pre style="background: transparent; box-shadow: none; border: none;">
Q: I have fiber fed echelle spectra.  There is a single fiber feeding the
spectrograph producing images with many orders where the order profile
is defined by the fiber.  Can I reduce this data with DOFOE which has the
desired features of flatfielding in 1D?

A: The DOFOE task was written for a spectrograph that is fed by two fibers
where one fiber is for the object and the second fiber feeds a simultaneous
arc with the object exposure.  The documentation prior to V2.11.3 talks only
about this two fiber mode.  However the task was actually written with the
idea that there might only be a single fiber producing a single set of
orders.  To use this task with just a single fiber the parameter &quot;arcaps&quot;
is simply set to &quot;&quot;.  In the next release of this task the documentation
has been revised to describe how this task is used both for a single fiber
and with the second simultaneous arc fiber.
</pre>
