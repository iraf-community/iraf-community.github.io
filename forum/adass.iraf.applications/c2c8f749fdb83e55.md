## DOSLIT: ERROR: No reference arcs

**Frank Valdes** wrote on Jun 02, 1998

<pre style="background: transparent; box-shadow: none; border: none;">

Q:  While using the doslit script for reducting spectra.
after I finished to edit the aperture and trace the spectra, I got
the following error message:

ERROR on line 58: No reference arcs
    doslit (mode=h)

The only difference between this run of doslit and other I had
done in the past, is that I am working on spectra from telescope
that I did not work before, and the header keywords are not the
same like before.

Could you help me with this problem?


A:  The message you get can occur if you don&#x27;t give any arcs in the
&quot;arcs&quot; parameter even if you don&#x27;t intend to do any dispersion correction.
However, from what you say it sounds like the problem is that DOSLIT
does check if the type of data is identified as a comparison arc.
What you need to do is add the keyword IMAGETYP with a value of
&quot;comp&quot; or &quot;comparison&quot; (lower or upper case is ok) to your arc comparison
images.  This &quot;feature&quot; is useful for data that is taken with systems
that provide this keyword but we should probably consider a way not
require it for data from other sources.
</pre>
