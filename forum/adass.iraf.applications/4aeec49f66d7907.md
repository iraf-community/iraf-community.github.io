## ellipse

**Sergio Cellone** wrote on Jan 15, 1998

<pre style="background: transparent; box-shadow: none; border: none;">

Hi.

 I have found very useful the new version of the &quot;isophote&quot; package
 (STSDAS Version 2.0); however, I want to point out a minor problem:

 When using the &quot;ellipse&quot; task with fixed elliptical parameters (i.e.,
 &quot;hcenter=yes hellip=yes hpa=yes) I have noticed that, if the parameter
 &quot;geompar.recenter&quot; is set to &quot;yes&quot;, the initial X0 and Y0 do not
 remain fixed at their initial values; instead the ellipses are
 &quot;recentered&quot;.

 The main problem is that the new X0 and Y0 are integer, so they can be
 nearly 1 pix displaced from the desired values. For example, I have
 run &quot;ellipse&quot; with: x0=193.43 y0=252.91 ellip0=0.2257 pa0=71.15
 recent=yes hcent=yes hellip=yes hpa=yes, and I obtained X0=194 Y0=252
 ELLIP=0.2257 and PA=71.15 for every SMA.

 Everything works as wanted with &quot;recenter=no&quot;, however, this is not
 evident from the help pages. I think that this should be explicitly
 said in the &quot;controlpar&quot; help pages.

 Thank you very much.
 Best regards.
