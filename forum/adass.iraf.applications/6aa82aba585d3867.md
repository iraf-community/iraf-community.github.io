## FAQ: "No images to combine" (COMBINE, FLATCOMBINE, ZEROCOMBINE, etc.)

**Frank Valdes** wrote on Mar 17, 1998

<pre style="background: transparent; box-shadow: none; border: none;">

Q:  I would like to know the nature of the following problem,
I&#x27;m trying to combine bias, skyflats, etc, and I get the error messages
ERROR on line 46: No images to combine

when I execute zerocombine or flatcombine, but the images are there!!!
I did everything but with no success.
Could you tell me what I&#x27;m doing wrong?


A: This message always means that image types of the input images do not
match the &quot;ccdtype&quot; parameter; i.e. zerocombine will by default only
look for zero images and flatcombine will only look for flat images.
If your data does not have the information to identify the type of
image then you should set &#x27;ccdtype=&quot;&quot;&#x27;; i.e. no value.  Then these
tasks will use whatever images you give them.  To determine what
image types the CCDRED package things you have you can use CCDLIST.
For more on this type &quot;phelp ccdtypes&quot;.
</pre>

When I&#x27;ve seen this error it has always been because I haven&#x27;t run
&quot;setinstrument&quot; properly.  If this isn&#x27;t set for, e.g., &quot;kpnoheaders&quot;
then the various CCDRED routines can&#x27;t interpret the CCDTYPE
parameter, even though it is clearly in the image header.
