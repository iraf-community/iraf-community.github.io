**Frank Valdes** wrote on Sep 10, 2003

<pre style="background: transparent; box-shadow: none; border: none;">
Hi Erika,

There are two simple ways this confusing behavior could occur.  The first
is what Simon indicated.  If the header contains the keyword DISPAXIS then
this takes precedence over the parameter setting.  So changing the
parameter would have no effect on what you see when extracting.

The second is that since the tasks apall/apsum appear in several packages
you have to be sure to set the parameter in the package from which you
are running the task.  For instance if you load SPECRED and then edit
&quot;dispaxis&quot; in the APEXTRACT package parameters this won&#x27;t change the
behavior of APALL in the SPECRED package.  If you do epar on APALL it will
show you the package; say specred.  Then do &quot;epar specred&quot;.

Yours,
Frank Valdes
