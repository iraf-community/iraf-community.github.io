# Setting ICFIT parameters

**Chris Simpson** wrote on May 05, 1999

<pre style="background: transparent; box-shadow: none; border: none;">
Several IRAF tasks, such as CURFIT and COLBIAS, call ICFIT. These tasks
have in their psets a few parameters which are passed on to ICFIT, such
as the function to be fit and its order. Is there some way to set the
initial values of other ICFIT parameters, such as &quot;grow&quot;?

			Cheers,
				Chris Simpson
</pre>

---

**Frank Valdes** wrote on May 05, 1999

<pre style="background: transparent; box-shadow: none; border: none;">
Hi Chris,

Unfortunately there is not.  This was poor design of these tasks.  They
really should have all the parameters but instead they pass defaults to
ICFIT.

COLBIAS is an extremely old task.  Bias subtraction is normally done with
CCDPROC where the ICFIT parameters are all available in the pset.

Cheers,
Frank Valdes
