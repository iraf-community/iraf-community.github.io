        I believe this was fixed in the TABLES 2.0 release, but the cause
is in the tables$pkg/ttools/copyone/puttabdat.x file where the ctod()
function is declared as double instead of int.  The FPE comes about when
trying to do the type conversion.  If you modify this file and rebuild
the package the problem should go away, if not it&#x27;s probably best to
contact help@stsci.edu since they would know if it was resolved.
