This announcement describes the 2001DEC27 release of the MXTOOLS package 
for IRAF.

The following files have been placed on the IRAF anonymous FTP contribution 
web site:

ftp://iraf.noao.edu/contrib/mxtools.README        # installation instructions
ftp://iraf.noao.edu/contrib/mxtools-generic-tar.Z # main tar file (no binaries)
ftp://iraf.noao.edu/contrib/mxtools-bin.sparc-tar.Z  # SPARC binaries tar file
ftp://iraf.noao.edu/contrib/mxtools-bin.ssun-tar.Z   # SunOS binaries tar file
ftp://iraf.noao.edu/contrib/mxtools-bin.redhat-tar.Z # Redhat binaries tar file
ftp://iraf.noao.edu/contrib/mxtools-bin.alpha-tar.Z  # Alpha binaries tar file
ftp://iraf.noao.edu/contrib/mxtools-bin.hp700-tar.Z  # HP700 binaries tar file

The installation instructions are given for (1) IRAF managers for system-wide 
installation of the MXTOOLS as a standard IRAF package, and (2) individual 
users who want a private installation of MXTOOLS for their personal use.

Any comments/suggestions and bug reports would be greatly appreciated.

MATPHOT (CCD stellar photometry with digital Point Spread Functions):

       matphot - CCD stellar photometric reduction using a MATPHOT PSF file.
       psfprep - Convert a PSF image into the MATPHOT PSF format.
       psfstar - Add a star to an image using a MATPHOT PSF file.
      psfshift - Shift a MATPHOT PSF file.
       psfdelx - Compute the X partial derivative of a MATPHOT PSF file.
       psfdely - Compute the Y partial derivative of a MATPHOT PSF file.
        psfg2d - Create a MATPHOT PSF file with a 2-d Gaussian PSF.
        psfobs - Simulate a CCD stellar observation using a MATPHOT PSF file.


QDPHOT (Data mining tools which quickly to CCD stellar photometry):

        qdphot - QDPHOT (Quick &amp; Dirty CCD stellar PHOTometry)
    demoqdphot - The QDPHOT demonstration script
       qdwfpc2 - QDPHOT analysis of 2 HST WFPC2 images
	         Demo: Type &quot;qdwfpc2&quot; and accept the default parameters
    wfpc2color - Transform QDWFPC2 instrumental magnitudes to standard colors
demowfpc2color - The WFPC2COLOR demonstration script
         qdcmd - Show WFPC2COLOR results as a color-magnitude diagram


MX Application Programming Interface (Simplifies writing IRAF tasks in C):

        mxdemo - A simple peak detector written in C using the MX &amp; CVOS APIs


===== 2001DEC27 RELEASE NOTES =================================================

The latest release of MXTOOLS features my MATPHOT stellar photometric 
reduction program which I briefly described in my contributed talk 
&quot;The MATPHOT Algorithm for Digital Point Spread Function CCD Stellar 
Photometry&quot; on October 2, 2001 at the ADASS XI conference in Victoria, B.C.
(O-13 at http://cadcwww.hia.nrc.ca/adass_2001/oral.html ).  My contribution
to the ADASS XI conference proceedings is available at the following
web site: http://www.noao.edu/staff/mighell/matphot/adass11.ps 

I will also be presenting a poster paper on MATPHOT at the 199th AAS meeting
in Washington, D.C. on Thursday, January 10, 2002 where I will demonstrate
how MATPHOT can produce very accurate stellar photometry (millimag or better)
and astrometry (millipixel or better) with bright stars described by ugly
PSFs.

More information about MATPHOT may be found at the MATPHOT web site:

  http://www.noao.edu/staff/mighell/matphot
