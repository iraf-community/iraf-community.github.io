# Guide Star Catalogue access in STSDAS -- help!

**Carrie M. Rowland** wrote on Aug 10, 1998

<pre style="background: transparent; box-shadow: none; border: none;">
Hello!

     I am trying to use the stsdas-analysis-gasp package to convert x-y
pixel coordinates to equatorial coordinates.  So far I have used the
stgindx task to copy the catalog index to a STSDAS table, I have used
sgscind to search the guide star catalog index, and now I would like to
use the extgst task, which is supposed to take the output from sgscind.
This task looks at the output of sgscind, which is essentially a list
of tables that will have stars in my field, and is then supposed to
extract the information that I need from those tables.  Problem is,
extgst keeps looking for things with extension .tab, when in reality
the files are .gsc.  So, to iraf, the files I need do not exist.  Is
there anyone out there who has sucessfully used the gasp package for
astrometry?  Is there any useful documentation for this package?  I
feel I am reinventing the wheel.

Many thanks,

carrie
