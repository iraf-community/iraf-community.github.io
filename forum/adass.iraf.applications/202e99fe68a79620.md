## New CRUTIL package vs older tasks

**Frank Valdes** wrote on Jul 02, 1998

<pre style="background: transparent; box-shadow: none; border: none;">

Q: Are the routines cosmicrays (etc) in noao.imred identical to those
in the external package crutil, and is the latter superseded?


A: The new CRUTIL package has some new tasks as well as versions of
old tasks.  COSMICRAYS is essentially the same except in two regards.
The first is removal of the image type selection feature common to
the tasks in the CCDRED package.  This is really not of too much use
with this task.  The second is that the new version outputs a real
pixel mask rather than a text file.  This reason is pixel masks are
becoming more important and this output can then interface more
easily with other tasks.  But the algorithm in COSMICRAYS is exactly
the same.

The other tasks are fairly simple and are related to other tasks
(IMEDIT, FIXPIX, IMCOMBINE, MEDIAN).  As with COSMICRAYS the most
important feature is better integration of pixel masks.  They also have
more convenient input and output for the purpose of cosmic ray
removal.

One purpose of this package is to bring various tools together in one
package.  In future I would expect to add other tasks (sometimes as
just links to tasks from other packages).  I recommend you use the
tools in this package but if you are just wondering if you need to
install this package to use COSMICRAYS rather than in CCDRED then
the answer is that you don&#x27;t have to.
</pre>
