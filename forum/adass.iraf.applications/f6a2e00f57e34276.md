      Shel,
      
      &gt; I take images of stars from a file and write down their coordinates
      &gt; and some info using imexamine by hand!
      
      You could run a star finder routine like IRAF&#x27;s daofind.  Then you 
      could use this list as input to other programs in the
      noao.digiphot.apphot package.  These programs can give you all the 
      information you could want from a star&#x27;s image. 
      
      As far as the programming goes, once you decide what it is that you
      want to fo repeatedly, a simple terminal script would be the way to
      go.  A terminal script is a list of commands that you have in a file,
      that are sequentially executed until the end of the file is reached.
      
      Start by using the task &#x27;mkscript&#x27; which will create the command in 
      the form you want it in; with all the parameters defined.  Go from 
      there.  
      
      Once you have mastered this, you can worry about trickier things.
      
      Good Luck,
      
      Eric, STSDAS Sr. Data Analyst
