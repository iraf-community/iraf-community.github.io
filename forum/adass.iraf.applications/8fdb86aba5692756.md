Hello Eric,

The approach I am familiar with for matching coordinate lists is based
on finding similar triangles.  The method is described in various places.
My implementation of this idea in FOCAS (a package for catalog generation
and analysis) is described at

F. G. Valdes, L. E. Campusano, J. D. Velasquez, and P.B. Stetson, 1995,
PASP, 107, 1119.

This method is, I believe, similar to what is in DAOPHOT from Peter Stetson
(though I don&#x27;t know this for a fact).  IRAF has a algorithm like this.
However I don&#x27;t know the name and the author of this is on vacation.
You could write Lindsey Davis (ldavis@noao.edu) asking about matching of
two lists of coordinates.  These methods assume the transformation is
linear with offsets, rotations, and possibly flips.  If there is some
additional significant distortion no general algorithm is likely to work.
Since this is WFPC data you can ask Help@stsci.edu about registering
WFPC data at different roll angles.

Other than that it may require interactively matching things.



Concerning your medical imaging question I can answer with IRAF tasks
that do a general unwarping.  The tasks are GEOMAP (to make the
transformation map) and GEOTRAN.  These task describes things in terms
of star positions but if you can measure fiducial points between the
two images that would be equivalent.  The transformations are expected
to be describable by 2D functions so there has to be some degree of
smoothness; i.e. no kinks and discontinuities.  However, the medical
case described might well be done this way.  If someone attempts this I
would also point out that measuring the fiducial points might best be
done using the task RIMCURSOR which simply reads the image display cursor
(the image data would have to be converted to a format that can be
displayed with IRAF display servers XIMTOOL or SAOIMAGE such as FITS
and displayed) and returns the pixel coordinates of marked points.
