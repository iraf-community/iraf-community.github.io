**Frank Valdes** wrote on Nov 22, 2000

<pre style="background: transparent; box-shadow: none; border: none;">
Hello Jianjun,

The factor I think you are missing is that in the SPECRED package
(I assume this is the package you load to run DOFIBERS) you have to
do &quot;epar specred&quot; and set the parameter &quot;dispaxis&quot; to 1 if the spectra
are horizontal when displayed or 2 if the spectra are vertical.  The
way the software determines the dispersion direction is to first look
for a keyword DISPAXIS in the header (so you could use HEDIT to add it)
and if it is not there it uses the &quot;dispaxis&quot; package parameter.

Rotating or transposing the image can be made to work but there are
tricks that have to be done.  The simplest is to clear the coordinate
system after the rotate with &quot;wcsreset &lt;image&gt; wcs=world&quot;.  I&#x27;m not
sure but you might also need &quot;wcsreset &lt;image&gt; wcs=physical&quot;.

Let us know if you have further questions.  As you see your newgroup
message reaches us.  Alternatively you can write directly to us
at iraf@noao.edu.

Cheers,
Frank Valdes

After rotating spectral images using by the task &#x27;rotate&#x27;, some header informations would be

produced and modified. Then you have to edit the image headers properly the header informations.

The newely formed header parameters by the task &#x27;rotate&#x27; are &#x27;ltv1, ltv2, ltm2_1, ltm1_2&#x27;, and

 modified parameters &#x27;ltm1_1 and ltm2_2&#x27;. Compare the header parameters before and after

 rotating. Set zero or none for the newely formed header parameters and same values of images before

rotating for the modified parameters.
