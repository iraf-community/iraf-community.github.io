The thing to understand is that DARKCOMBINE is a simple script intended for
the most common operations.  It calls CCDPROC if the data needs to be
processed before combining and COMBINE to do the actual combining.  While
CCDPROC does not easily work on a cube, the COMBINE task is well suited
for what you want to do.  So if you want to take a cube of dark exposures
and make a master combined dark then use COMBINE with the &quot;project&quot; option.
This option in the COMBINE tasks, also in IMCOMBINE, combines pixels
across the highest dimension.  So for a 3D cube each 2D plane of the
cube is treated as an image and the combined result (using all the
other options such as rejection, scaling, etc) produces a 2D image.  So
I think the answer to your questions is that you just need to use COMBINE
with project=yes.
