**Mike Fitzpatrick** wrote on Sep 01, 2016

{% raw %}
<div>
<br>
                Type "echo $IRAFARCH" to print any value that is already set, then look in your<br>
<br>
    $HOME/.login   $HOME/.cshrc   $HOME/.bashrc  $HOME/.profile<br>
<br>
files to see if it is set there.   If not, then the 'cl' command may be deriving that your architecture *should* be set to linux64 and is constructing the path that way but you only have the linux binaries installed.  In that case, you cat set IRAFARCH as<br>
<br>
    setenv IRAFARCH   linux     (for .login and .cshrc)<br>
<br>
    export IRAFARCH=linux       (for .bashrc and .profile)<br>
<br>
to force the path, or else reinstall IRAF with linux64 binaries.<br>
<br>
</div>
{% endraw %}
