<div>
<br>
<br>
I don't have an xubuntu 16.04 system to test/debug, but the window resizing problem has been seen at various times in the past and was caused by problems with the window manager and/or desktop system.  The fix back then, was to open the system preferences panel and under some form of "Window" or "Window Behavior" panel (the name varied by platform/version) you needed to disable the option that would "Display content when resizing window".  If indeed this is a library compatibility issue, and you did your own install of X11IRAF (or used a distribution not from NOAO), then try using the statically linked binary available at<br>
<br>
    ftp://iraf.noao.edu/pub/fitz/xgterm.STATIC                    # and similar for 'ximtool.STATIC'<br>
<br>
This is the same binary that comes with the stock IRAF v2.16.1 release and is installed on the system from the iraf$vendor/x11iraf/bin.linux directory.  Note X11IRAF is a 32-bit binary but it doesn't sound like the errors are complaining about missing libraries on your 64-bit system.<br>
<br>
Development of X11IRAF is essentially frozen due to the amount of work required to upgrade it to be 64-bit compatible as well as current with the recent X11 systems.  XTerm is always the (ugly) fallback, it would be nice to be able to replace the XGterm graphics with something more modern at some point.<br>
