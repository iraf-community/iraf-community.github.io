<div>
The system should run using pre-built binaries, however compilation isn't supported under 64-bit systems.  For Gentoo you'll need to install the binaries in a 'bin.linux' directory, but you'll want to download the 'redhat' binaries.  A complete summary of the installation is in the example at the end of the install guide, see <a href="http://iraf.net/">http://iraf.net/</a> docs/pciraf/ for details.  Post back if you still have problems.<br>
<br>
Cheers,<br>
-Mike
