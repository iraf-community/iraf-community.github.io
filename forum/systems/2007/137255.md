Packages are defined in the hlib$extern.pkg file and specifically the 'helpdb' string defines a list of help databases to be searched.  This message either means thos packages aren't installed, or the definition of e.g. the 'mscred' directory path is wrong (such as missing a trailing '/').  If you edited this file, be sure the last line of the file is the 'keep' statement.<br>
