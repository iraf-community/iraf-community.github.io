**Mike Fitzpatrick** wrote on May 17, 2007

{% raw %}
<div>
Fuyan,<br>
<br>
We don't have a specific set of binaries for Debian, the files you'll need are as.pcix.gen.gz (all the sources), ib.rhux.x86.gz (core binaries) and nb.rhux.x86.gz (NOAO binaries).  These binaries are for Redhat but should still run, however you'll need to install them in a 'bin.linux' directory instead of bin.redhat, i.e. /iraf/irafbin/bin.linux (for IB) and /iraf/irafbin/noao.bin.linux (for NB).  The complete installation process is described in the installation guide (i.e. <a href="http://iraf.net/irafdocs/pciraf/)">http://iraf.net/irafdocs/pciraf/)</a><br>
<br>
Cheers,<br>
-Mike
