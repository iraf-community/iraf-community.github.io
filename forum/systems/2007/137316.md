**fgrise** wrote on May 05, 2007

{% raw %}
<div>
Finally, I found the problem.<br>
The fact is when you install the python packages with "python setup.py install --with-f2c=&lt;path_to_f2c&gt;", it does not install the packages present in the subfolders.<br>
<br>
You have to go inside each subfolder and install each module ... and it works.<br>
I use Multidrizzle and it works fine !
</div>
{% endraw %}

I had the same /usr/lib/libf2c.so.2 problem on a x86 debian etch system using iraf 2.13-BETA2, TABLES Version 3.7, STSDAS Version 3.7 and STSCI PYTHON 2.5<br>
