**Mike Fitzpatrick** wrote on Jan 17, 2007

{% raw %}
<div>
The patched FITCOORDS binary (i.e. x_longslit.e) is available for a number of platforms from <a href="http://iraf.net/ftp/pub">http://iraf.net/ftp/pub</a>.  Download and install in the appropriate noao$bin.&lt;arch&gt; directory and be sure to rename as 'x_longslit.e' and set the execute permissions (e.g. "chmod 755 x_longslit.e").  The GEMINI V1.9.1 patch contains only updates to CL scripts, help pages and calibration data, so there are no binaries to update.  Binaries for most external packages, including GEMINI, are available in <a href="http://iraf.net/ftp/iraf/extern">http://iraf.net/ftp/iraf/extern</a> or from the Downloads link above.<br>
<br>
As for "living on the edge", the V2.13 release may still be called a Beta (so is GMail for that matter) but it is very stable.  Final work pending is still just new features and enhancements and packaging.  The system is very well supported at this site, questions about how quickly something will be dealt with should be answered by the GEMINI developers.   In any case, I wouldn't be expecting an update to the V2.12 releases any time soon.<br>
<br>
Cheers,<br>
-Mike
