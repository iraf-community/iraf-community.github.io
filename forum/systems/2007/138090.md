**Mike Fitzpatrick** wrote on Aug 30, 2007

{% raw %}
<div>
hi Phil,<br>
<br>
The 'no imtool configuration file' means there isn't a /usr/local/lib/imtoolrc link pointing to dev$imtoolrc.  This is normally done by the install script (I'm not sure how Scisoft handles it though), an alternative is to copy the dev$imtoolrc file to ".imtoolrc" in your home directory.  That should fix the imt8192 problem.<br>
<br>
As for the other message, I've never seen it before.  Do you get the same message using 'ximtool' rather than 'ximtool-alt'?  The alt version is the same binary but uses a different GUI file to provide the menubar.  The message is in the part of the code that simply defines the widgets to be used which makes me think the offset in the script to the GUI file is wrong, i.e. if you look at the script there is a 'SKIP' parameter that is the number of lines in the script before the start of the GUI.  Either that number is wrong, or the 'tail' command isn't working.  Newer versions of 'tail' require it be used as "tail -n +$SKIP $0" instead of the command (w/out the -n) in the script now, although I've never see it on Mac being a problem.  Anyway, hope this helps.<br>
<br>
Cheers,<br>
-Mike
</div>
