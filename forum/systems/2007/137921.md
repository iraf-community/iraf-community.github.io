<div>
The v2.13b2 system doesn't contain the HSI binaries (MKPKG, XC, etc) in the iraf$unix/bin.suse directory by default.  To fix this, copy (do not 'mv') the contents of iraf$unix/bin.redhat to iraf$unix/bin.suse and re-run the install script.  Write back if you still have problems.<br>
<br>
-Mike
</div>
{% endraw %}
