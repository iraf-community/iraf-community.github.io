Hi Kathleen,<br>
<br>
What compiler and platform is complaining about this?  Anyway, the fixes are simple:<br>
<br>
fits_read.x:<br>
        Line 226 fnroot used as subroutine, should be int func()<br>
<br>
t_tpeak.x:<br>
        Line 109/179 sscan() declared as int func(), should be subroutine<br>
<br>
The most common errors you'll see are these sorts of mixed uses of functions and subroutines as well as mixed use of int/bool variables (e.g. an int used in a conditional or a bool set to YES instead of TRUE).  Most all of these have been weeded out of the core system by now.<br>
<br>
Cheers,<br>
-Mike
