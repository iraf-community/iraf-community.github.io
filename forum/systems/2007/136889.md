<div>
I had this same problem with Fedora Core 6.  What I did that fixed it was to edit the cl.csh file (in /iraf/iraf/unix/hlib/).<br>
<br>
In that file under the section where it determines your architucture  you need to add  the line set os_mach = linux (see below).  There may be another way, but this worked for me.<br>
<br>
Jessica<br>
<br>
# Determine platform architecture.<br>
if ($?IRAFARCH) then<br>
    if (-e $iraf/bin.${IRAFARCH}/${cl_binary}) then<br>
        set MACH = $IRAFARCH<br>
    endif<br>
endif<br>
<br>
if (! $?MACH) then<br>
    if (-f /etc/redhat-release) then<br>
        if (`uname -m` == "ppc") then<br>
            setenv mach linuxppc<br>
        else<br>
            setenv mach redhat<br>
            set os_mach = linux    #### ADD THIS LINE<br>
        endif
</div>
