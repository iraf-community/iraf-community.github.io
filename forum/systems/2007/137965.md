**Mike Fitzpatrick** wrote on Aug 09, 2007

{% raw %}
<div>
Try starting as<br>
<br>
<pre><code>% xgterm -display :0.0</code></pre><br>
<br>
I suspect your DISPLAY may not be being picked up properly.  If that doesn't work, then try both of<br>
<br>
<pre><code>% xgterm -ls
% xgterm +ls</code></pre><br>
<br>
These start the window as a login shell, and then as just a plain shell respectively.  Something in your .login file or other startup may be causing the system to wait for something, the latter command will ignore your .login so if that works but the first one doesn't, please post your .login file (if you have one).  Either way, let me know if these change anything.<br>
<br>
-Mike
