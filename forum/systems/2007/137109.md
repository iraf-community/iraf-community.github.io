The v1.3.2 was never an "official' version but you can find the source in <a href="ftp://iraf.noao.edu/pub/fitz">ftp://iraf.noao.edu/pub/fitz</a>  Note however that a 10.4 OSX system won't properly  compile this because of gcc/glibc changes.  A better thing would be to get the X11IRAF v1.5-dev sources/binaries from  <a href="http://iraf.net/ftp/iraf/x11iraf/">http://iraf.net/ftp/iraf/x11iraf/</a><br>
