I don't read Turkish and can't make sense of the distribution home page, but it appears to be a variant of Gnu/Linux and so at least the V2.13beta2 release from this site, if not earlier releases, should run on this system.  I'd suggest you use the 'Redhat' binaries (i.e. the RHUX distribution) but where the installation instructions tell you to install these in a 'bin.redhat' directory you instead use a directory named 'bin.linux'.  The 'bin.linux' dirs is the generic linux binary architecture and since IRAF checks for a /etc/redhat-release file to define the architecture, the absence if this file would mean that the system would look for a bin.linux directory.<br>
<br>
Redhat binaries for external packages should work just as well, again so long as you install them in a 'bin.linux' directory of the package.  If you have any problems with the installation please post explicit error messages.  Hope this helps.<br>
<br>
Cheers,<br>
-Mike
