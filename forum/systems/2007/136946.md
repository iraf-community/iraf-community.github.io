<div>
The error means you don't have the C-shell interpreter installed (i.e. /bin/csh or /bin/tcsh) and so none of the iraf scripts like 'mkiraf' or 'cl' will run (there aren't any bash equivalents in the system).  Go back to the Ubuntu setup an install the tcsh package (don't know quite what they call it) and this problem should go away.<br>
<br>
Cheers,<br>
-Mike
