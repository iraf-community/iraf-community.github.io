# IRAF on KNOPPIX CD

**Varol Keskin** wrote on May 26, 2007

{% raw %}
<div>
For 3 years, I'am using IRAF for astronomical image reduction at the computer lab at the Ege University Astronomy Department. It is very difficult to make IRAF exercises with more than 40 students connecting to a server. Because, too many connections to a server using X-window make high network traffic. To solve this problem, I have installed IRAF on KNOPPIX (ver 5.1.1) live CD so that every student now can boot this CD on individual computer and use IRAF personally. They also can use the same CD at home for IRAF exercises.<br>
<br>
Because KNOPPIX live CD is limited, I have removed some software from CD in order to have enough space for IRAF. I obtained IRAF rpm packages for Fedora Core 6 prepared by Tim Pickering (Thanks Tim :) ). These rpm packages can be obtained from<br>
<br>
<a href="http://caliente.as.arizona.edu/~tim/RPMS/fedora/">http://caliente.as.arizona.edu/~tim/RPMS/fedora/</a><br>
<br>
I have converted these rpm packages to deb format and installed on live CD. The ISO image of this CD can be obtained from <br>
<br>
<a href="http://astronomy.ege.edu.tr/KNOPPIX-IRAF-2007.ISO">http://astronomy.ege.edu.tr/KNOPPIX-IRAF-2007.ISO</a><br>
<br>
or<br>
<br>
<a href="ftp://astronomy.ege.edu.tr/pub/astro/IRAF/KNOPPIX-IRAF-2007.ISO">ftp://astronomy.ege.edu.tr/pub/astro/IRAF/KNOPPIX-IRAF-2007.ISO</a><br>
<br>
sha1sum b022d4d608e6513ef8a34a44267ac1c2cac4093b<br>
md5sum afeeae26d9a86e94a6875a1756eccfc5<br>
<br>
This KNOPPIX-IRAF CD is not perfect but it is very useful for IRAF users. It can be used on any computer which can boot from CD. In fact, it is possible to install this CD on bootable USB stick but I have not try this alternative solution yet.<br>
<br>
I hope this helps for IRAF users.<br>
<br>
Varol Keskin<br>
Ege University Observatory<br>
Izmir, Turkey

<div>
Varol,<br>
<br>
Thanks very much for your posting, this is indeed the type of community involvement we like to see.  I was finally able to download the ISO and have just a few comments:<br>
<br>
-  The ECL wouldn't start due to a missing libtermcap.so.2 reference.  To fix this I simply did a "ln -s /usr/lib/libtermcap.so /usr/lib/libtermcap.so.2" as root.<br>
<br>
- The external packages are normally installed in a separate /iraf/extern directory.  I realize this may be an artifact of the RPM installation.<br>
<br>
- You can recover &gt;60Mb of disk space by stripping the binaries and removing the core system and package sources.  I can send you more information about this if you like.<br>
<br>
- The /iraf/irafbin/lib*_p.a libraries are unneeded and can be removed as well.<br>
<br>
- If you use the v2.13 release several of the external packages can also be eliminated since they (and the ECL) are part of the core system.  Specifically packages like:  ARED, CRUTIL, IMMATCHX, SPPTOOLS, XCCDRED, and you only need either DIMSUM or XDIMSUM (I forget which is more recent).<br>
<br>
Otherwise I was able to boot the ISO using Parallels on a MBP and run IRAF with no problems.  A Knoppix CD has been on the to-do list for a while but I never got around to it.<br>
<br>
If you don't object, I've copied the file to <a href="http://iraf.net/ftp/iraf/contrib/KNOPPIX-IRAF-2007.ISO">http://iraf.net/ftp/iraf/contrib/KNOPPIX-IRAF-2007.ISO</a> to provide a faster download for some users (it took me &gt;2hrs to get it from your site).  I'd be happy to host any updated versions of this you make available as well, just drop me a line.  Good luck on this project and let us know if we can help.<br>
<br>
Cheers,<br>
-Mike

Dear vogt31337,<br>
<br>
There are some other problems with iraf config. For example, user do not have write permission with the current config due to the read-only CD file system. You should change the path in login.cl file for gaining write access.<br>
<br>
There are equivalent keys for "special keys" and you can find them with a little practice.<br>
<br>
If you prepare a convenient login.cl file and load this file (for example, from your personal web page or from local hard disk) whenever you start the CD, you will have much less problem with iraf.  <br>
<br>
I could not find enough time to publish a corrected version of this CD. Sorry for these problems.
