**Mike Fitzpatrick** wrote on Oct 01, 2007

{% raw %}
<div>
You initially logged in as 'cheng' but then su to 'iraf' to run the tasks.  Cheng owns the desktop and needs to give 'iraf' permission to display windows there, so in another window owned by cheng just type the command 'xhost +' to do this.  The 'iraf' account isn't necessary to run IRAF so you can just start DS9 and xgterm as yourself in most cases and avoid this entirely.<br>
<br>
Cheers,<br>
-Mike
