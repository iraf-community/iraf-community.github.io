<div>
It depends on exactly what the error message is:  A 'cannot open connected subprocess' usually means an installation error where the binaries were unpacked in teh wrong directory.  A 'cannot open device' means either the DS9 isn't running, or the task cannot connect to it properly, or it could be something to do with the data itself. <br>
<br>
Please post the exact error message, and the version of IRAF you're using.<br>
<br>
-Mike

**Mike Fitzpatrick** wrote on Nov 18, 2007

{% raw %}
<div>
Then check that you've got an x_tv.e file in the $iraf/bin.suse directory (normally this will be /iraf/iraf/bin.suse/x_tv.e), and that the binary is executable.  If you downloaded a new binary the permissions may have been lost and will need to be restored. The x_tv.e binary should be in the same directory as the cl.e, so since you're able to login to the CL I'm assuming the files were otherwise unpacked in the proper place.<br>
<br>
-Mike
