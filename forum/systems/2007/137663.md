<div>
The 'tail' command has changed in recent linux systems.  The post you reference means that you need to edit the ecl_install_linux.csh script to add a '-n' flag to the 'tail' command on line 401 of that file, i.e. it should read:<br>
<br>
<pre><code>tail -n +$SKIP $0 &gt; /tmp/_ecl.$$/_ecl      # unpack the files
</code></pre><br>
<br>
If you then encounter a problem about an unresolved termcap library you should download the binary at <a href="http://iraf.net/ftp/pub/fitz/ecl.e">http://iraf.net/ftp/pub/fitz/ecl.e</a> and manually install it in the $iraf/bin.linux directory.  Note that if you're using the v2.13 release from this site the ECL is already included in the distribution as the default.<br>
<br>
Cheers,<br>
-Mike
