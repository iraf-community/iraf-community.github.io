<div>
Pedro,<br>
<br>
I'd have to see your help database files to comment specifically, but in general there are 4 files you need to create a helpdb for a package.   For your package I'd image they would look something like:<br>
<br>
dracs$lib/root.hd<br>
<br>
<pre><code>
# Root help directory for the CTIO packages.  This dummy package is necessary
# in order to have `ctio&#x27; appear as a module in some package, so that the user
# can type &quot;help ctio&quot; (with the `ctio&#x27; given as a task).

_drace           pkg = dracs$lib/rootdracs.hd
</code></pre><br>
<br>
dracs$lib/rootdracs.hd<br>
<br>
<pre><code>
# Root task entry for the CTIO package help tree.  Defines `ctio&#x27; as both a
# task and a package in the ctio help database.

ctio            men  = dracs$dracs.men,
                hlp  = dracs$dracs.men,
                sys  = dracs$dracs.hlp,
                pkg  = dracs$dracs.hd,
                src  = dracs$dracs.cl
</code></pre><br>
<br>
dracs$dracs.men<br>
<br>
<pre><code>

           task1 - complex reductions
           task2 - easy reductions
               :                  :
</code></pre><br>
<br>
dracs$dracs.hd<br>
<br>
<pre><code>
# Help directory for the DRACS package.

$src             = &quot;dracs$src/&quot;
$doc            = &quot;dracs$doc/&quot;

task1          hlp  = doc$task1.hlp,          src = src$task1.cl
task2          hlp  = doc$task2.hlp,          src = src$task2.cl
   :                                :                                         :
</code></pre><br>
<br>
The dracs$lib/root.hd is what you pass to the MKHELPDB task, the dracs$dracs.men is the help menu you see when you ask for help on a package name.  From the error I suspect some of the definitions in the root$.hd files are in your main dracs$dracs.hd file??<br>
<br>
<blockquote>By the way, could you tell me how to script a package that has interactive prompting (like for instance, the response task, which you cannot use in non-interactive mode) and make it read the answer to the interactive prompting<br>
from a file or so?</blockquote><br>
<br>
I think what you're referring to here is redirecting the cursor input, see "help cursors" for more infomation.<br>
<br>
Cheers,<br>
-Mike
