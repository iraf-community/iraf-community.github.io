**Mike Fitzpatrick** wrote on Feb 28, 2007

{% raw %}
<div>
Jonathan,<br>
<br>
Try something like:<br>
<br>
<pre><code>
ecl&gt; hselect wpix date-obs yes | scan (s1)
ecl&gt; hedit wpix new-date substr(s1,12,19) add+
ecl&gt; hedit wpix new-date str(substr(s1,12,19)) add+
</code></pre><br>
<br>
The first command pulls out the value of the DATE-OBS keyword to the  's1' variable, the second adds a new NEW-DATE keyword using the substring to pull out just the time.  The last command is optional but converts the keyword value back to a sexagesimal string (it was added as a floating point number the first time).<br>
<br>
Cheers,<br>
-Mike
</div>
{% endraw %}
