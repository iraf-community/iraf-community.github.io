The arrow keys in V2.12 only work when editing task parameters using EPAR, or to sroll through the history list after typing "ehist" at the CL prompt.  A new version of the CL, called the ECL, fixes this and is part of the standard V2.13 release, but is available as an add-on to earlier systems (see <a href="ftp://iraf.noao.edu/pub/ecl_install_linux.csh">ftp://iraf.noao.edu/pub/ecl_install_linux.csh</a> to install it, also note the message <a href="http://iraf.net/phpBB2/viewtopic.php?t=86117">http://iraf.net/phpBB2/viewtopic.php?t=86117</a> in case you have problems).<br>
