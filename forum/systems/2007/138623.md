**Mike Fitzpatrick** wrote on Nov 29, 2007

{% raw %}
<div>
You install DS9 simply by putting the binary in a directory such as /usr/local/bin, or any other directory in your path.  When you execute it using a '!' escape from the CL, a shell is created to execute the command.  If you get a 'command not found' message it means the shell created doesn't contain a path that contains the directory where you installed DS9.  This usually happens if you define the path in your .login file instead of your .cshrc file.<br>
<br>
Note that starting with something explicit like 'cl&gt; !/usr/local/bin/ds9 &amp;' will also work.<br>
<br>
Cheers,<br>
-Mike
</div>

**Mike Fitzpatrick** wrote on Nov 29, 2007

{% raw %}
<div>
If you're getting a 'memory corrupted' from every task it is almost always a sure sign of the 'stacksize problem'.  Before you login to the CL, type<br>
<br>
[code]% limit stacksize unlimited              # for C-shell<br>
or<br>
% ulimit -s unlimited                 # if you use Bash<br>
[code] <br>
<br>
You can put this command in your .cshrc file or .profile/.bashrc to make it permanent.  The 'cl' command should do this automatically as well, however it depends on the IRAF version you're using.<br>
<br>
-Mike
</div>
