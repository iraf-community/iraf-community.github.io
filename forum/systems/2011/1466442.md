**Mike Fitzpatrick** wrote on Apr 25, 2011

{% raw %}
<div>
The message typically means that files in the $hlib or $iraf/unix/bin.&lt;arch&gt; directory are missing from the distribution or can't be found because of an incorrect environment variable setting.  For 32-bit Fedora your IRAFARCH should be 'linux' and your $iraf/unix/bin.linux directory should contain the files being checked for.<br>
<br>
If you tell me which distribution file you used I can verify whether they are correct, otherwise you can get <a href="ftp://iraf.noao.edu/iraf/ftp/v215/PCIX/hs.pcix.gen.gz">ftp://iraf.noao.edu/iraf/ftp/v215/PCIX/hs.pcix.gen.gz</a> and unpack in $iraf/unix if you find files are missing.
</div>
{% endraw %}
