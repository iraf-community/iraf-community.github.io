<div>
The iraf.net extern package directory currently contains binaries for those packages build for v2.15.  There aren't generally Cygwin binaries available on either iraf.net or iraf.noao at the moment, however I plan to build the v2.15 Cygwin system this weekend so they will be available shortly.  Until then, you'll need to compile the package locally from the source distributions (e.g. ctio-src.tar.gz).  See the e.g. ctio.readme file for installation and build instructions.
