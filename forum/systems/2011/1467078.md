**emma** wrote on Dec 21, 2011

{% raw %}
<div>
Hello sebastian, charly,<br>
<br>
If you are using IRAF v2.14, I would recommend using the external packages from <a href="http://iraf.noao.edu/iraf/ftp/iraf/extern-v214/">http://iraf.noao.edu/iraf/ftp/iraf/extern-v214/</a> except for fitsutil, which can be downloaded from <a href="http://www.gemini.edu/sciops/data-and-results/processing-software/requirements/fitsutil-iraf-v214">http://www.gemini.edu/sciops/data-and-results/processing-software/requirements/fitsutil-iraf-v214</a>.<br>
<br>
The gmisc binaries mentioned in this thread are for IRAF v2.15 (i.e., they are located in <a href="http://iraf.noao.edu/iraf/ftp/iraf/extern-v215/">http://iraf.noao.edu/iraf/ftp/iraf/extern-v215/</a>). This version of gmisc contains a version of nhedit that conflicts with the nhedit version found in fitsutil for IRAF v2.14. This is why it is recommended to use the links provided in the first paragraph to download the v2.14 external packages when using IRAF v2.14. Please see <a href="http://www.gemini.edu/sciops/data-and-results/processing-software/requirements">http://www.gemini.edu/sciops/data-and-results/processing-software/requirements</a> for more information.<br>
<br>
The macintel binaries for gmisc can be compiled by following the installation instructions (<a href="http://iraf.noao.edu/iraf/ftp/iraf/extern-v214/gmisc.readme">http://iraf.noao.edu/iraf/ftp/iraf/extern-v214/gmisc.readme</a>). If the v2.14 external packages are used, you will find that the errors you were getting (ERROR: Iraf Main: Unknown task name (nhedit)) will disappear.<br>
<br>
Also, please note that there are help files provided for every task distributed in the Gemini IRAF package (type "help &lt;taskname&gt;" at the IRAF prompt). There are also example reduction scripts available in the package (type e.g., "gmosexamples" at the IRAF prompt).<br>
<br>
sebastian, please read the help file for gmosaic to learn more about the chip gaps (type "help gmosaic" at the IRAF prompt). There is a parameter called fl_fixpix, which is set to no as default. If this parameter is set to yes, gmosaic will interpolate over the gaps between the detectors. If fl_fixpix=no, the gaps will remain in the output (mosaiced) image.<br>
<br>
As a reminder, for Gemini specific issues, questions can be submitted to the Gemini HelpDesk (<a href="http://www.gemini.edu/sciops/helpdesk/">http://www.gemini.edu/sciops/helpdesk/</a>).<br>
<br>
I hope that answers everyone's questions :)<br>
<br>
Happy new year!<br>
<br>
Emma :)
</div>
