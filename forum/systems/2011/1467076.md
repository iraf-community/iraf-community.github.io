<div>
The 'stacksize' limit is only changed on linux systems, since you use 'sudo' this may mean that the root account environment is mis-defined but you don't need to use sudo anyway.<br>
<br>
To trace what the 'cl' command is doing, run it as<br>
<br>
<pre><code>
% csh -x /usr/local/bin/cl
</code></pre><br>
<br>
Otherwise, do you perhaps have a loginuser.cl file that might be trying to change directories?
</div>
{% endraw %}
