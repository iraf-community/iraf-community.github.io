<div>
Hi Emma,<br>
<br>
Thanks for the heads up, but the distribution is as intended.  The AS file is meant to be All-Source, but in the past it included the HSI binaries and was simply Part 1 of an unnecessary three-part file install.  The idea now is that it really is the bare minimum source, since there is now also a toplevel makefile that allows a full sysgen to be done easily with a 'make' command.  In the next release the F2C binaries will also be part of the sysgen build and won't need to be distributed within AS either.<br>
<br>
Most users still appear to be downloading the one-file "iraf-&lt;arch&gt;.tar.gz" files and I can see where the AS/IB/NB files will eventually fade away entirely.<br>
<br>
Cheers,<br>
-Mike
