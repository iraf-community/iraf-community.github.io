Is there some way to make the lines in a contour plot thicker?<br>
<br>

Hi Deidre,<br>
<br>
&gt; Is there some way to make the lines in a contour plot thicker?<br>
<br>
	Sure, but you need to make a special graphcap entry for it.<br>
&gt;From your description of the problem it sounds like you're overlaying<br>
the contour on the image display so you'll need to modify the 'imd'<br>
device entry.  First make a private copy of the graphcap file using<br>
<br>
	cl&gt; copy dev$graphcap home$mygraphcap<br>
	cl&gt; edit home$mygraphcap<br>
<br>
Then add a device entry such as<br>
<br>
	imdr_thick|                :CI#204:LO#2:tc=imd:<br>
<br>
near the top of the file (so you can find it easily, it can go anywhere).<br>
Next type 'gflush' to reinitialize the graphics and try it out using<br>
<br>
	cl&gt; display dev$pix 1<br>
	cl&gt; contour dev$pix dev=imdr_thick<br>
<br>
The ":LO#2" is what doubles the default line thickness but you can change<br>
this to be larger if needed.<br>
<br>
&gt; Another question:<br>
&gt; <br>
&gt; Is there some way to make the lines in a "contour" plot plotted<br>
&gt; to the ximtool window black?<br>
<br>
	Do the above except add the ":LO#2" to the 'imdblack' entry<br>
(on about line 262 of a V2.12.2 graphcap file) or else modify the :CI<br>
color index to be 202.<br>
<br>
Cheers,<br>
Mike Fitzpatrick<br>
