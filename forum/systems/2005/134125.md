<br>
	A quick explanation would be that /home/mreed is not readable by<br>
you on the machine (as is the default case for some linux systems) and<br>
so when you declare the task the CL simply can't read the file.  Check<br>
and perhaps reset the permissions on the directory or else move the script<br>
to a public directory where you have access, a quick check of this is that<br>
you should be able to PAGE or TYPE the script file, if not it's either a<br>
permissions problem or something wrong with the path (e.g.  an nfs mount<br>
point).<br>
	Hope this helps.<br>
