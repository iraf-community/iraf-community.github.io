<br>
&gt; 1-  I downloaded DS9 to visualize images, but I do not arrive at <br>
&gt; launching the application from the language of iraf "Cl".  For example,<br>
&gt; when I try to trace contours on images, that does not give anything on <br>
&gt; DS9.  <br>
<br>
	DS9 is not an IRAF task and must be started manually before you<br>
use the display (e.g. either on the commandline before you type 'cl'<br>
or from within IRAF using  "cl&gt; !ds9 &amp;" to run it in the background).<br>
Once the DS9 is running you should be able to display images, however <br>
overlaying graphics requires a special device name be specified.  See<br>
the CONTOUR task help page example, but briefly you can use something like<br>
<br>
	cl&gt; display dev$pix 1 fill+<br>
	cl&gt; contour dev$pix  fill+ perim- dev=imd<br>
<br>
will display the standard test image and overlay a contour.<br>
<br>
&gt; 2-  And I can't install GRASP, although I have the packages of GRASP. <br>
<br>
	GRASP is the GONG external package and like all packages needs to<br>
be declared in the $iraf/unix/hlib/extern.pkg file using something like<br>
<br>
reset   grasp           = /shared/iraf/extern/grasp/<br>
task    grasp.pkg       = grasp$grasp.cl<br>
<br>
To use the package you must first load it by typing "grasp" at the cl<br>
prompt.  I believe that GRASP may still be tied to IRAF V2.11 and it may<br>
not work under V2.12, but you'll need to contact the GRASP package authors<br>
about that.  <br>
	Note there is a similar package called GASP in STSDAS, is this <br>
what you were referring to?  Hope this helps.<br>
