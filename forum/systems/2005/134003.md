Hi Sue,<br>
	You can either make the file executable with the command<br>
<br>
	% chmod 755 ecl_install_redhat.csh<br>
<br>
and execute as per the instructions, or interpret it with the csh<br>
directly using<br>
<br>
	% csh -f ./ecl_install_redhat.csh<br>
<br>
Either will work, let us know if you still have problems.<br>
