	Sorry for the slow reply, I've been successful at ignoring<br>
my mail these last few weeks.  The tape density problem is something<br>
that should have occurred to me earlier, we don't get many tape questions <br>
any more.  There used to be a way to configure this and the mode <br>
automatically if you built your own kernel, or you can simply set the<br>
variable block mode in the /etc/rc.local file as part of the boot process.<br>
The IRAF alloc/dealloc isn't strictly required to access the tape but <br>
should take care of the permission/ownership automatically  (if you<br>
don't see an error about the ownership of the alloc.e process then this<br>
should be working correctly).  Once you've reset the density it should<br>
remain that way until it is changed again, I'm not aware of any behavior<br>
that will reset it automatically.<br>
	Hope this helps.<br>
