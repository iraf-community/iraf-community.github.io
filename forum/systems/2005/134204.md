**Mike Fitzpatrick** wrote on Dec 20, 2005

{% raw %}
<div>
The V2.12.2a patch was necessary to support a GEMINI package release<br>
that needed certain bug fixes.  They had no specific need for a SuSE<br>
distribution so one was simply never compiled under the assumption <br>
there would be a full V2.12.3 patch "soon" after.<br>
<br>
In any case, the Redhat binaries (rhux) will probably work so long as you<br>
install them under a bin.suse directory.  The 'linux' arch is meant to be<br>
compiled statically so it'll run on most "other" linuxes but the reason for<br>
having separate linux archs has long past and it is time to (at least attempt)<br>
to unite them all into a single linux iraf system.  This would likely mean a<br>
V2.13 release to avoid patch update problems with having only a single<br>
arch, but if we're going to do all that we might as well move the G77 for<br>
the compiler since the original gcc/f2c reasons have also long gone.<br>
<br>
See the Projects page here for more, it's all in the plans if not quite on <br>
a schedule yet.<br>
<br>
Cheers,<br>
-Mike
</div>
{% endraw %}
