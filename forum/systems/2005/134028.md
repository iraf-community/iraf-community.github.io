<div>
Ubuntu is like recent Debian: the RHUX distribution works fine, one just has to modify some of the scripts so that the presence of /etc/debian_version causes the "redhat" architecture to be selected.<br>
<br>
I haven't tried LNUX on Debian or Ubuntu recently, but there used to be incompatibilities when compiling packages from source. This was with IRAF 2.11.3, and if I remember correctly the libc.5 vs. libc.6 issue was part of the problem; I'd expect that the IRAF 2.12.x LNUX builds no longer suffer from that particular problem. In any case: RHUX works on Debian (2.2, 3.0, 3.1) and on<br>
Ubuntu (5.10 amd64, with the caveat that I haven't tried compiling on amd64).
