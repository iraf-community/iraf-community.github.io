	The code change looks correct.  Some of the newer GCC compilers <br>
are now throwing errors at argument mis-matches like this where before <br>
they were ignored as warnings.  Most of the similar problems have been<br>
removed from the core system long ago but beware you may encounter similar<br>
problems in other external packages in the future (I believe TABLES/STSDAS<br>
have similar issues).  If possible using pre-compiled binaries will <br>
generally work, most commonly 'redhat' binaries are available but will run<br>
under newer SuSE so long as you unpack them in the package 'bin.suse' <br>
directory.<br>
