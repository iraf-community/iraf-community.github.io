**Mike Fitzpatrick** wrote on Nov 11, 2005

{% raw %}
<div>
Will,<br>
    From the '-Bstatic' flag it appears the Makefile hasn't been modified for<br>
the proper linux flags.  I was able to compile on a RH9 with no problem <br>
after editing the makefile to uncomment the first CC/TERM flags for Linux.<br>
The cbind.c defines the procedures correctly but it you're using a GCC 4<br>
compiler it might not have worked properly (can't test it directly just now).<br>
In any case, I've put the binaries I compiled at <a href="ftp://iraf.noao.edu/pub/fitz/focas-bin.redhat.tgz">ftp://iraf.noao.edu/pub/fitz/focas-bin.redhat.tgz</a> in case it helps.<br>
<br>
Cheers,<br>
-Mike
