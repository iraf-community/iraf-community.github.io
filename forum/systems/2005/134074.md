Hi Henry,<br>
	Sorry for the slow reply.  We don't have a graphcap specifically<br>
for those devices, but the default PS device can still be made to work.<br>
You can either configure a working 'lpr' command on the machine and the<br>
default device should work, or else simply modify the 'g-lpr' graphcap<br>
entry so the DD string uses the 'lp' command rather than 'lpr'.  Be sure<br>
to type 'gflush' after modifying the graphcap so any changes are picked<br>
up and let us know if you still have problems.<br>
