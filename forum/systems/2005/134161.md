<br>
	The "requirement" for a C-shell lies in the fact that the 'iraf'<br>
user account login directory distributed with IRAF (i.e. the iraf$local<br>
directory) is pre-configured to define the environment using the standard<br>
.login/.cshrc files.  This is actually only needed to allow an iraf<br>
user account to use the pre-defined environment to make IRAF and external<br>
package updates easier, however generic user accounts can use bash or <br>
most other shells easily.<br>
	It is easy enough to install tcsh on the system before IRAF that<br>
you might consider it so you can follow the install directions more easily 	<br>
but since the install script and others are also C-shell scripts you may<br>
need to do this anyway to avoid doing all the install steps by hand.<br>
<br>
	Assuming you've install the tcsh RPM, proceed with the install<br>
instructions normally.  I can send you details for completing the install<br>
manually, but believe me that adding a csh is far easier.  Also have a<br>
look at<br>
<br>
	<a href="ftp://iraf.noao.edu/pub/nvoss/README">ftp://iraf.noao.edu/pub/nvoss/README</a> <br>
<br>
for an alternate install procedure that should set you up with a complete<br>
system trivially (but *does* require csh first).  Hope this helps.<br>
