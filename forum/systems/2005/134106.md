	Sorry for the slow reply, I was travelling when you last wrote.<br>
The modified graphcap looks right assuming that at the unix level you<br>
can pipe a PS file to the "lp" command and have it appear on the printer<br>
you want (i.e. if you need to say "lp -d tek" instead then those flags<br>
also need to appear in the DD string).  It's important to remember that<br>
you need to type "gflush" after modifying a graphcap file to reinitialize<br>
the system,  and after doing the snap so the plot is produced.<br>
	The DD string is executed in a spawned sub-shell so variables like<br>
PRINTER/LPDEST need to be defined in your .cshrc file and not just .login<br>
to be found.  Otherwise it looks like it should work, let me know if you<br>
still have problems.<br>
