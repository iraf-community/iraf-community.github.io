<br>
	The message is familiar on some Linux 2.6 kernel systems, but I'm<br>
confused as to why you would see this on a SuSE v6 system.  The quick <br>
answer is that this is normally fixed using the command<br>
<br>
        limit stacksize unlimited               # for csh<br>
        ulimit -s unlimited                     # for bash<br>
<br>
either in your .cshrc/.bashrc or on the commandline before logging in.<br>
In V2.12.2 this should be done automatically in the CL startup script<br>
but you can issue the commands at the terminal before logging into the<br>
CL.<br>
	If that doesn't work, please verify that you're indeed using the<br>
V2.12.2 system, e.g. <br>
<br>
	cl&gt; head hlib$motd nl=2 <br>
and	cl&gt; dir bin$cl.e long+<br>
<br>
should both indicate dates from at least Jan2004, any earlier and there<br>
may have been a problem with the installation.<br>
	Hope this helps, let us know if the problems continue.<br>
