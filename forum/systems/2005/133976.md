Hi Ray,<br>
	It sounds as if the install script wasn't run (either not as <br>
'root' or only with the '-n' no-op flag).  The CL 'command not found'<br>
can sometimes mean only that the 'local bin directory' where you installed <br>
the commands isn't in your path, or you need to type 'rehash' to pick<br>
it up, but the missing /usr/include/iraf.h makes me think the install<br>
script wasn't executed properly.  Please try running it again as the <br>
root user and verify that the iraf.h link was made in /usr/include.<br>
Hope this helps.<br>
