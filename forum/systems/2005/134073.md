Hi Stephenson,<br>
	Sorry for the slow reply.  Garbage characters almost always<br>
mean that the iraf terminal type is set incorrectly (e.g. it's set<br>
to 'xgterm' instead of 'xterm'), so the first thing to try is to<br>
manually reset the terminal type with <br>
<br>
	cl&gt; stty xterm ; flpr ; gflush<br>
<br>
The 'flpr' and 'gflush' will reinitialize everything, and assuming<br>
you're using an xterm window the graphics should then appear.  <br>
	I can't test the new xterm directly at the moment but it is<br>
also possible that the escape sequence used to put it into graphics<br>
mode has changed.  If so this may require a new graphcap entry.  It<br>
is also possible this is a bug in the xterm itself and you should look<br>
for another patch or similar problem reports on the net.  Let us know<br>
if you've verified the iraf terminal type and things still don't work.<br>
An XGterm for Fedora is available from our homepage that, as far as<br>
we know, still works.  Hope this helps.<br>
