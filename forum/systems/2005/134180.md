<div>
You can get the installation files from the following FTP site:<br>
<br>
<a href="ftp://iraf.noao.edu/iraf/v212/PCIX/">ftp://iraf.noao.edu/iraf/v212/PCIX/</a><br>
<br>
For SuSE, you should retrieve the following three files: <span style="color: blue">ib.suse.x86.gz</span>, <span style="color: blue">nb.suse.x86.gz</span>, and <span style="color: blue">as.pcix.gen.gz</span>; this last file contains all the sources (including the .cl scripts to run the various tasks).<br>
<br>
After doing so, please go to <a href="http://docs.iraf.net">http://docs.iraf.net</a>; click on "Installation and Site Manager's Guides", then click on one of the three links associated with "PC-IRAF V2.12 Installation Guide" (the link on the title is the link to image copies of the documentation, while the two at the end are in PDF format, or compressed PostScript format).<br>
<br>
Hope that helps.
</div>

**Mike Fitzpatrick** wrote on Dec 15, 2005

<div>
The 'cl' and 'mkiraf' commands are unix commands installed in your "local bin directory" (typically /usr/local/bin).  A "Command not found" error means these commands aren't in your path, try a "rehash" to see if you can pick them up once they're installed, a "which cl" to see if it can be found at all, or edit your path to include the directory where you installed them.<br>
<br>
To run either command, simply type the command name at the linux prompt -- *something* should happen and if its an error message post it here.<br>
<br>
-Mike
