<div>
Garbage characters always mean a mismatch between the terminal you<br>
are actually using and the one you told IRAF you're using (e.g. using <br>
an XGterm but set for an Xterm), or you're not using a graphics<br>
capable terminal (a gnome-terminal, kterm, rvxt, etc).  If you're using<br>
an XGterm window you can manually set it on the 'cl&gt;' prompt with<br>
<br>
   cl&gt; stty xgterm<br>
<br>
or set the default when you do a MKIRAF.  Same goes for Xterm which<br>
is about the only other choice in graphics terminals.<br>
<br>
-Mike
