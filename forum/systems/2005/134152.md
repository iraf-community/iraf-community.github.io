No, the bug is still present in the current code.  You can create the<br>
pipes as root using the commands<br>
<br>
	mkfifo /dev/imt1o /dev/imt1o<br>
	chmod 666 /dev/imt1o /dev/imt1i<br>
<br>
or to make a permanent personal change you can either set the 'input_fifo'<br>
resource to be 'none' or simply alias the command to use the -unix_only<br>
flag.<br>
