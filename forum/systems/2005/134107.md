Hi Frederic,<br>
	The "HDR$" syntax is an iraf logical directory telling the system<br>
to put the image .pix file in the same directory as the header, the '$'<br>
at the end of the variable is correct in that case.  However, the imdir<br>
value is defined when the iraf install script is run and normally defaults<br>
to something like /iraf/imdirs.  If you really want HDR$ to be the imdir<br>
then a better solution is to edit the default hlib$login.cl file to read<br>
on line 8<br>
<br>
	set  imdir = "HDR$"<br>
<br>
and leave the mkiraf.csh imdir at some dummy path.  Since the U_IMDIR<br>
won't then be found in the default login.cl the mkiraf script won't edit<br>
it and you're left with HDR$ as the imdir.<br>
	The site manager may have changed these values by hand earlier,<br>
but use of $HDR is certainly wrong, and use of HDR$ should be changed as<br>
above.  Hope this helps.<br>
