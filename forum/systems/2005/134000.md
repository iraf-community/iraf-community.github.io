Hi Jonathan,<br>
	It sounds like you're using an 8-bit display (the only thing<br>
XImtool supports) but are using one of a number of window managers that<br>
don't properly give XImtool the colormap focus.  The first thing to do<br>
is to check that this isn't a window-focus problem by clicking on the<br>
ximtool window to select it (i.e. don't assume moving the mouse into <br>
the window will give it the focus).  If you can then move the mouse into<br>
the window and see grayscale you'll need to change the mouse focus policy<br>
in the linux control panel, if not then it really is a colormap focus <br>
issue and you should try a different window manager.  If you can get<br>
the grayscale image but can't change the contrast be sure the NumLock key<br>
isn't enabled (this changes the event mask and keeps the contrast scale<br>
and menu selection from working).  What you should see is the colormap<br>
flash as you move in-out of the window.<br>
	Since desktops like Gnome/KDE and their applications use most of<br>
the available 8-bit colors the flashing is almost unavoidable.  Most users<br>
end up using DS9 as the display server in 24-bit mode (see<br>
<a href="http://hea-www.harvard.edu/RD/ds9)">http://hea-www.harvard.edu/RD/ds9)</a>, it works as a display but has a <br>
different feature/problem set (e.g. it won't display real image <br>
coords/pixels when images are displayed from IRAF).  SAO is aware of these<br>
problems and we still hope to upgrade XImtool to 24-bit mode at some <br>
point.<br>
	Hope this helps, let us know if the problems continue.<br>
