# Bug in the mkiraf script ?

<div>
Hello,<br>
<br>
I think I might have found a bug in the mkiraf script. When attempting <br>
to run it on my Mandriva 2006-based system, the following message <br>
appears :<br>
<br>
son ~ $ mkiraf<br>
Illegal variable name.<br>
<br>
(I have installed V2.12.2 recently, and my csh seems to be in fact <br>
tcsh-6.14-1mdk)<br>
<br>
I have investigated this problem and found that it comes from line 9 :<br>
<br>
set	imdir	= "HDR$"<br>
<br>
I note that in a previous release of iraf (2.11.3) which is still <br>
installed on another system here, this line is<br>
<br>
set     imdir   = "$HDR"<br>
<br>
.. which sets imdir's value to "", as I understand it, because there is <br>
no shell variable named $HDR at this point ! I remember I had to set the <br>
imdir variable manually in my loginuser.cl file.<br>
<br>
Presently, my workaround is to replace line 9 by<br>
<br>
set 	imdir 	= ""<br>
<br>
and then edit the login.cl file.<br>
<br>
I hope this will be useful, I would be pleased to give further <br>
precisions if needed.<br>
