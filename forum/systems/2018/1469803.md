On (normal) Linux, this would be a big problem: Since 2004, IRAF has a very dirty hack to workaound a bug in its memory management system that requires to set the stacksize to unlimited. However, you don't use Linux, but "something" that looks like Linux, and this may behave differently...<br>
<br>
<blockquote>I'm not too sure if my system is 'special', because I'm using the windows ubuntu shell, I suppose that falls under special as it wouldn't surprise me if it didn't behave like typical ubuntu. <br>
<br>
</blockquote><br>
<br>
That makes it clear. Probably (please check that yourself) the LInux kernel emulation in WIndows does not emulate 32 bit system calls; then you just are out of luck here.<br>
<br>
<blockquote>Is there some test I can perform to check if I can run 32-bit x86 binaries?<br>
<br>
</blockquote><br>
<br>
You could try to install a 32-bit package with a program and see whether it runs. <br>
