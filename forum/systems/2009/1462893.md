Not easily.  Your best bet is to write a small wrapper script for the task and have it write the result to a file you then read from the C program.  Tasks which update their parameters do so by talking to the CL which manages the parameters/uparm directory, there is no easy interface that replicates this functionality from plain C code.<br>
