Hi Patrick,<br>
<br>
I'll trade you for a Fabry-Perot IRAF external package 8-)<br>
<br>
Seriously, the only thing really missing from the obm/Tcl/Imakefile was to set the CFLAGS options to include "-DUSE_STDARG".  This does most of the work and you can easily get the 24-bit ximtool to compile, however XGterm's lineage of Xterm code means that it is a deeply painful process to sort through the flags needed to get a working XGterm.<br>
<br>
Thanks to the kinds folks at NSO I was able to find a machine for this and I'm working on the xgterm code, but it might be a day or many before I get it sorted.  In any case I'll let you know when a full X11IRAF package is ready, if you want the ximtool binary before then let me know.<br>
<br>
Cheers,<br>
-Mike
