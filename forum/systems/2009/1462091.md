**Mike Fitzpatrick** wrote on Jul 17, 2009

<div>
Shared libraries are no longer used in the V2.14 system (we don't have enough machines to build against all possible versions of Solaris)and thus libshare.a is no longer used.  The S*.e files are still distributed so they're available for older binaries but also aren't used in the current code.<br>
<br>
Which package are you compiling?  Is the libshare.a referenced explicitly?  If not, you may be picking up an old version of the iraf compiler.<br>
<br>

**Mike Fitzpatrick** wrote on Jul 17, 2009

{% raw %}
<div>
I admit I didn't pay much attention to the .login/.cshrc file for this release, I just kept whatever was there already.<br>
<br>
MKPKG just runs a command called "xc".  If you need the irafuser.csh alias to get the correct version then it probably means that either the installed version of the 'xc' command is pointing to an older iraf release, or else the path (defined in .cshrc) is pickup up the older version before a more recent one.  If you have multiple versions of IRAF around keep in mind that only one is technically "installed" at a time, i.e. 'cl' command link in say /usr/local/bin will point to the script in a particular IRAF version.  The same goes for xc, mkpkg, mkiraf, et al.<br>
<br>
-Mike
