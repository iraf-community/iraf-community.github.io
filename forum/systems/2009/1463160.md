<div>
The first step is to do the photometry on the sources, see some of the cookbooks available under the Docs link to get started on this.  Then you'll need to identify the same source in multiple images and arrange them by date.  Tasks like PDM in the ASTUTIL package can help you find periodicity, there are tasks both in the photometry package as well as the TTOOLS package in TABLES to help you manage table.  If you have specific questions, write back.
