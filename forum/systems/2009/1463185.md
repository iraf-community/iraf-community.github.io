You can use something like<br>
<br>
<pre><code>
fname = &quot;foo.fit&quot;
len = strlen (fname)
extn = substr (fname, len-2, len)
if (extn == &quot;fit&quot;) {
    ....something
} else if (extn == &quot;txt&quot;) {
    ....something else
}
</code></pre><br>
<br>
Another way to handle it is just to have separate parameters for images and text files and key off of whether the parameter is set.<br>
