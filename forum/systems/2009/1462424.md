**Doug Mink** wrote on Sep 10, 2009

{% raw %}
<div>
It turns out that Snow Leopard defaults to 64-bits and you need to add the -m32 flag to hlib$fc.csh and hlib$mkpkg.incjust like you have to for 64-bit Linux:<br>
<br>
In fc.csh:<br>
<br>
After this:<br>
# Scan the argument list and concatenate all arguments.<br>
set args = ""<br>
while ("$1" != "")<br>
    set args = "$args $1"<br>
    shift<br>
end<br>
<br>
Add this:<br>
if ($MACH == "macintel") then<br>
    print ("MACINTEL: -m32 flag set")<br>
    set args = "$args -m32"<br>
endif<br>
<br>
in mkpkg.inc:<br>
$else $ifeq (MACH, macintel) then<br>
$set    XFLAGS          = "-c -w -m32"       # default XC compile flags<br>
$set    XVFLAGS         = "-c -w"       # VOPS XC compile flags<br>
$set    LFLAGS          = "-Nz -m32"         # default XC link flags
</div>
{% endraw %}
