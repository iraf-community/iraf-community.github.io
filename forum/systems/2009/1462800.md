**Mike Fitzpatrick** wrote on Nov 01, 2009

{% raw %}
<div>
You can change the shell for a user from a terminal window using a command such as<br>
<br>
<pre><code>% sudo chsh -s /bin/csh iraf</code></pre><br>
<br>
The 'chsh' will "change shell".  Strictly speaking an 'iraf' user isn't required, you can unpack the files as yourself.  Just be sure to run the install script using the 'sudo' command so you can make links in the system directories.[/url]
</div>
{% endraw %}

**Mike Fitzpatrick** wrote on Nov 01, 2009

{% raw %}
<div>
The distribution files can be unpacked using any shell.  The C-shell for the iraf user is recommended because it will have a specific environment defined that may help with building packages and such, but iraf commands which are C-shell scripts can still be run by a user (e.g. you) who's default shell is still bash.  <br>
<br>
Anyway, you don't need to delete the unpacked files, just proceed with the install.
</div>
