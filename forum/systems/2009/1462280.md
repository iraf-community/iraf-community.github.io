<div>
If you want to pass an @file into the task that uses a script variable name, then you need to use string concatenation to form the parameter, e.g.<br>
<br>
<pre><code>imcombine (&quot;@&quot;//s1, ......)</code></pre><br>
<br>
None also that when using the "program mode" syntax like this, the string params need to be quoted  so they won't be confused with variables, e.g.<br>
<br>
<pre><code>imcombine (&quot;@&quot;//s1, combine=&quot;median&quot;, reject=&quot;none&quot;, ,,,,,,)</code></pre><br>
<br>
-Mike

**Mike Fitzpatrick** wrote on Aug 14, 2009

{% raw %}
<div>
A more general approach might be to 1) create a list of unique exposure times, and 2) create lists of images that have each of those exposure times.<br>
You can do this using the HSELECT task in the following ways, e.g.<br>
<br>
To create a list of unique exposure times:<br>
<br>
<pre><code>hselect (&quot;*.fits&quot;, &quot;EXPTIME&quot;, yes) | sort (&quot;STDIN&quot;) | uniq (&quot;STDIN&quot;, &gt; &quot;exptimes.txt&quot;)</code></pre><br>
<br>
The file 'exptimes.txt' then contains a list of all the unique exposure times for all the files in the directory.  So, if you have a 100 files but the only EXPTIMES are 300 or 600 seconds, this file will have just those two values.<br>
<br>
The next step is to find those images that have each exposure time, e.g.<br>
<br>
<pre><code>
list = &quot;exptimes.txt&quot;
i = 1
while (fscan (list, tim) != EOF) {
    hselect (&quot;*.fits&quot;, &quot;$I&quot;, &quot;exptime?=&#x27;&quot; // tim // &quot;&#x27;&quot;, &gt; &quot;flist&quot;//i)
    i = i + 1
}
</code></pre><br>
<br>
This scans the file and for each exposure time calls HSELECT to print out the image name if the EXPTIME matches the value read.  This may look a little advanced (e.g. the '?=' string comparator, see the HSELECT and HEDIT help pages), but you'll end up with a series of files starting with the string 'flist' that each have the same exposure time.  From there you could likewise loop over each of these files to call IMCOMBINE on that list.<br>
<br>
Hope this gives you an option.<br>
-Mike
</div>
