<div>
Two things:  There is a quirk of the CL that an 'if' statement sometimes needs to be followed by a semicolon to avoid expecting an 'else'.  For example,<br>
<br>
<pre><code>
while (..) {
   if (...) {
   }
   ;
}
</code></pre><br>
<br>
Another problem is the 'copy' command where the literal path needs to be concatenated with the 's1' variable, i.e.<br>
<br>
<pre><code>copy (s1, &quot;/home/morrison/Solar_analogs/Darks/biastemp/&quot; // s1)</code></pre><br>
<br>
-Mike
