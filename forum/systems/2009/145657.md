<br>
This is because you were setting the value to a null string, which is not a legal boolean value.  If you need to reset the value to something other than yes/no to indicate it isn't set, you can use INDEF, e.g.<br>
<br>
<pre><code>answer = INDEF
if (isindef (answer)) {
     ....set the value
} else {
     ....do something with it
}
</code></pre><br>
<br>

Is this a procedure script or are you running it as e.g. "cl&lt;script.cl" ? I was simply trying to show how to set a boolean variable to INDEF, and then how to detect that within the script.<br>
