# Installing IRAF to eee PC 701

**cngeow** wrote on Feb 11, 2009

{% raw %}
<div>
I've tried to install IRAF to eee PC 701 (Linux version). Here are the steps:<br>
<br>
mkdir bin<br>
sudo apt-get install tcsh<br>
wget <a href="http://geco.phys.columbia.edu/~rubab/iraf/ldso_1.9.11-15_i386.deb">http://geco.phys.columbia.edu/~rubab/iraf/ldso_1.9.11-15_i386.deb</a><br>
sudo dpkg -i ldso_1.9.11-15_i386.deb<br>
wget <a href="http://geco.phys.columbia.edu/~rubab/iraf/libc5_5.4.46-15_i386.deb">http://geco.phys.columbia.edu/~rubab/iraf/libc5_5.4.46-15_i386.deb</a><br>
sudo dpkg -i libc5_5.4.46-15_i386.deb<br>
wget <a href="http://geco.phys.columbia.edu/~rubab/iraf/termcap-compat_1.2.3_i386.deb">http://geco.phys.columbia.edu/~rubab/iraf/termcap-compat_1.2.3_i386.deb</a><br>
sudo dpkg -i termcap-compat_1.2.3_i386.deb<br>
sudo adduser --system --home /iraf iraf<br>
sudo adduser --group iraf<br>
<br>
change the last line in /etc/passwd (using kwrite) from<br>
iraf:x:103:65534::/iraf:/bin/false<br>
to<br>
iraf:x:103:65534::/iraf/iraf/local:/bin/csh<br>
<br>
cd ../../<br>
( make sure is in the / directory using: pwd<br>
/&gt;pwd<br>
/<br>
)<br>
<br>
sudo chown -R iraf:iraf /iraf<br>
sudo chmod -R 777 iraf<br>
sudo mkdir /iraf/iraf<br>
sudo mkdir /iraf/iraf/local<br>
sudo mkdir /iraf/irafbin<br>
sudo mkdir /iraf/irafbin/bin.linux<br>
sudo mkdir /iraf/irafbin/noao.bin.linux<br>
sudo mkdir /iraf/x11iraf<br>
sudo mkdir /iraf/extern<br>
cd /iraf/iraf<br>
<br>
[download as.pcix.gen.gz from IRAF homepage]<br>
<br>
sudo tar -zxf as.pcix.gen.gz<br>
cd /iraf/iraf/unix/bin.redhat/<br>
sudo mv * ../bin.linux/<br>
cd /iraf/irafbin/bin.linux<br>
<br>
[download ib.lnux.x86.gz from IRAF homepage]<br>
<br>
sudo tar -zxpf ib.lnux.x86.gz<br>
cd /iraf/irafbin/noao.bin.linux<br>
<br>
[download nb.lnux.x86.gz from IRAF homepage]<br>
<br>
sudo tar -zxpf nb.lnux.x86.gz<br>
csh<br>
setenv iraf /iraf/iraf/<br>
cd $iraf/unix/hlib<br>
source irafuser.csh<br>
./install -n<br>
<br>
(When setting the location bin, set to /home/user/bin)<br>
<br>
sudo ./install<br>
sudo mv /home/user/bin/* /usr/local/bin/.
</div>
