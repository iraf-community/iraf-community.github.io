**Mike Fitzpatrick** wrote on Oct 05, 2009

{% raw %}
<div>
<blockquote><br>
rspectext(image10)=output </blockquote><br>
<br>
This is an invalid statement, I think you meant<br>
<br>
<pre><code>
image20=output
rspectext(image20)
</code></pre><br>
<br>
You didn't say what error you were seeing specifically.  Since the task has parameters (i.e. anything declared between the 'procedure' and the 'begin') you'll need to declare the task as <br>
<br>
<pre><code>cl&gt; task askchan = /path/askchan.cl</code></pre><br>
<br>
If you want the input/output parameter to be supplied on the command line you'll need to declare them as part of the procedure statement,i.e.<br>
<br>
<pre><code>procedure askchan (input, output)</code></pre><br>
<br>
-Mike
</div>
{% endraw %}
