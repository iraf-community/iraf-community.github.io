<div>
If all you did was delete some files in the system the you don't need to fully uninstall, you can just unpack the distribution files in the same place again.  You DO need to rerun the install script if your $iraf is something other than /iraf/iraf since this path is edited into system files.   Depending on the files deleted, sometimes rerunning the install script is enough.  The usual 'bin directory' is /usr/local/bin but couldv'e been reset in the install script.<br>
