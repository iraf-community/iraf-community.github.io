**Mike Fitzpatrick** wrote on Jan 26, 2008

{% raw %}
<div>
The links are resolved when the system is configured for development (i.e. a "mkpkg linux" that resets the 'bin' link to point to 'bin.linux').  Most packages are declared to install any libraries in a 'lib' directory, but there is also a search path of sort that finds them in 'bin.&lt;arch&gt;' directories.  The unresolved links are normal for a generic system.<br>
<br>
-Mike
</div>
{% endraw %}
