**Mike Fitzpatrick** wrote on Oct 04, 2008

{% raw %}
<div>
The patch file updates the sources only (i.e. new parameter files, help pages, etc) and should be unpacked in the $iraf root directory.  To complete the upgrade you will also need to re-install the IB (core iraf) and NB (NOAO package) binary distributions in the $iraf/bin.&lt;arch&gt; and $iraf/noao/bin.&lt;arch&gt; directories respectively.  In your case, '$iraf' will be the directory in the scisoft distribution tree, on most systems this may also be found as /iraf/iraf.  The patch and distribution files are compressed tar files you can unpack with the command, e.g.<br>
<br>
<pre><code>tar zxvf patch1.tar.gz</code></pre><br>
<br>
-Mike

"Somewhere in your home directory" is not good enough, it MUST be done in the iraf root directory (in your case, /scisoft/share/iraf/iraf) because what it does is unpack the compressed iraf source tarball in whatever directory you're in.  You need to do this in the iraf root so the parameter files, help files, etc are overwritten with the new version to have any effect.<br>
<br>
<blockquote><br>
Are the directories below correct?<br>
/scisoft/share/iraf/iraf â $iraf root directory<br>
/scisoft/share/iraf/iraf/bin.redhat â $iraf/bin.&lt;arch&gt;<br>
/scisoft/share/iraf/iraf/noao/bin.redhat â $iraf/noao/bin.&lt;arch&gt;<br>
</blockquote><br>
<br>
Assuming your scisoft installation has $iraf as /scisoft/share/iraf/iraf, then, yes.<br>
<br>
<blockquote><br>
Therefore, am I supposed to âtar zxvf patch1.tar.gzâ in /scisoft/share/iraf/iraf directory?</blockquote><br>
<br>
Yes<br>
<br>
<blockquote>Can you explain in more detail how to âre-install the IB (core iraf) and NB (NOAO package)â in the last two directories? </blockquote><br>
<br>
By this I mean you need to download and install the ib.rhux.x86.gz (the IB file) and nb.rhux.x86.gz file (the NB file) and unpack them with the same 'tar zxvf &lt;file&gt;' command in the /scisoft/share/iraf/iraf/bin.redhat and /scisoft/share/iraf/iraf/noao/bin.redhat directories respectively.<br>
<br>
Upgrading v2.14 to v2.14.1 is a matter of applying the source patch and reinstalling the binaries, if you do a fresh install of IRAF from the latest downloads (i.e. from the archive/iraf.net site and not the current SciSoft distro) this is already at v2.14.1.<br>
<br>
