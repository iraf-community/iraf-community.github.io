The error may just mean you're using a really old version of the binaries that were compiled for a pre-10.4 system.  Try using the binaries in <a href="http://iraf.net/ftp/iraf/x11iraf/x11iraf-v1.5DEV-bin.macosx.tar.gz">http://iraf.net/ftp/iraf/x11iraf/x11iraf-v1.5DEV-bin.macosx.tar.gz</a> and post back if you still have problems.<br>
