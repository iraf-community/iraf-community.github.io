Hi Naz,<br>
<br>
Looks to me like you've defined the iraf user's home directory to be inside another user's home directory (your own), which isn't normal. Since only one of those users can own the directory, I'm guessing you have a file permission problem. If you're installing IRAF as root, you should probably put the installation in a system-wide directory, eg. /usr/local/iraf or just /iraf. Otherwise, if you're installing in your personal directory, I think you don't want an IRAF user. Probably easiest to install it system wide if you can.<br>
<br>
Cheers,<br>
