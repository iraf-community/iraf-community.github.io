<div>
The problem has to do with how newer compilers are now dealing with functions declared as 'extern' but which appear in the same source file.  In any case, I've put modified source and prebuilt binaries for the package in the download area (i.e.  <a href="http://iraf.net/ftp/iraf/extern/">http://iraf.net/ftp/iraf/extern/</a> ).  You can pick up the new source and build locally of else just install the binaries, beyond this the package has been pretty frozen for a while.<br>
<br>
-Mike
