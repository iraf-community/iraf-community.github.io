# gawk script to detect problems in IRAF help files

**Jason Quinn** wrote on Jun 04, 2008

{% raw %}
<div>
Fitz, at one time you expressed interest in having a script that checks the formatting of IRAF's help files. I wrote a script that helps detect and prevent bad markup. It parses tags and reports the total number of open tags, close tags, their "sum" (technically difference), and the maximum and minimum depth of nesting. It can be ran on a bunch of files at once. The script is written for gawk. It only checks one pair of tags at a time and it doesn't tell you <em>where</em> any problems it detects are. I have another script that does that but it's not very good yet. The parsing script is fairly robust but occasionally reports false positives like when a filename just happens to have the tag characters in it. The script doesn't "know" troff; it just looks for tags and counts them and so is more generally usual and works on HTML files and so on. Here is what a typical run looks like for IRAF help files:<br>
<br>
<pre><code>
jquinn@aries&gt;gawk -f parse.awk -v starttag=.ls -v endtag=.le *.hlp

<br>
There's only a handful of pairs of tags needed to check most of IRAF's help files. Generally, I move into a "doc" directory and run the following four commands:<br>
<br>
<pre><code>
gawk -f parse.awk -v starttag=.help -v endtag=.endhelp *.hlp
gawk -f parse.awk -v starttag=.ls -v endtag=.le *.hlp
gawk -f parse.awk -v starttag=.nf -v endtag=.fi *.hlp
gawk -f parse.awk -v starttag=\fI -v endtag=\fR *.hlp
</code></pre><br>
<br>
As always in UNIX, you have to be very careful about special characters being interpreted by the shell for commands. If your starttag or endtags have these, you may need to use escapes and shell quoting. The last line of the script output tells the user exactly what strings were used for the start and end tags because of this issue. The last example above has potential shell quoting problems because of the slash. If you run into trouble with them, one way to protect them in tcsh would look like this:<br>
<br>
<pre><code>
gawk -f parse.awk -v starttag=&quot;\\fI&quot; -v endtag=&quot;\\fR&quot; *.hlp
</code></pre><br>

Here is the full "parse.awk" source:<br>
<pre><code>
#gawk -f parse.awk -v starttag=value1 -v endtag=value2
#original author Jason L. Quinn
#version 1.01 04-June-2008
#----added maxfilenamesize for prettier output
#----changed output formating slightly
#USER NOTE: getting past the shell for certain characters may require quoting and escaping.
BEGIN {
nf=(ARGC-1)
if ( nf==0 )
	error(&quot;Usage: gawk -f parse.awk -v starttag=value -v endtag=value filename(s)&quot;)
if ( starttag==&quot;&quot; || endtag==&quot;&quot; )
	error(&quot;ERROR: You must set the starttag and endtag variables.&quot;)

if ( starttag==endtag )
	error(&quot;ERROR: starttag and endtag were identical.&quot;)

maxfilenamesize=0

#This just gets the length of the longest inputfile name for pretty output
for ( kf=1; kf&lt;=nf; kf++ )
	{
	file=ARGV[kf]
	if ( length(file)&gt;maxfilenamesize )
		maxfilenamesize=length(file)
	}

#Read in the input files.
for ( kf=1; kf&lt;=nf; kf++ )
	{
	n=0
	numopen=0
	numclose=0
	maxdepth=0
	mindepth=0
	file=ARGV[kf]
	while ( (getline&lt;file) &gt; 0 )
		{
		for( i=1;i&lt;=length($0);i++ )
			{
			if ( substr($0,i,length(starttag))==starttag )
				{
				n++
				numopen++
				if ( n&gt; maxdepth )
					maxdepth=n
				}
			if ( substr($0,i,length(endtag))==endtag )
				{
				n--
				numclose++
				if ( n &lt; maxdepth )
					mindepth=n
				}
			}
		}
	printf(&quot;%&quot;maxfilenamesize&quot;s opentags=%3g closetags=%3g sum=%3g maxdepth=%3g mindepth=%3g&quot;,file,numopen,numclose,n,maxdepth,mindepth)
	if ( n&lt;0 || n&gt;0 || maxdepth&gt;1 || mindepth&lt;0 )
		printf(&quot;\n%&quot;maxfilenamesize&quot;s WARNING: &quot;,&quot;&quot;)
	if ( n&lt;0 )
		printf &quot;Possibly too many close tags. &quot;
	if ( n&gt;0 )
		printf &quot;Possibly too many open tags. &quot;
	if ( maxdepth&gt;1 || mindepth&lt;0 )
		printf &quot;Check tag nesting.&quot;
	printf &quot;\n&quot;
	}
}

END {
printf(&quot;\nSearched for starttag=\&quot;%s\&quot; and endtag=\&quot;%s\&quot;.\n&quot;,starttag,endtag)
}

function error(msg)
	{
	print msg
	exit 1
	}
</code></pre>
