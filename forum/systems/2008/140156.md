**Francisco Valdes** wrote on Aug 29, 2008

{% raw %}
<div>
I suspect this is due to a bug in the FITS header handling.  In some circumstances the addition and deletion of header keywords can put the FITS END card in the wrong place resulting in this message.  These problems are expected to be fixed in the next release and some were fixed in the current version.<br>
<br>
The approach to try and avoid this is to use HEDIT to add a few dummy keywords.  Doing an IMCOPY first and working on the copy may also workaround the problem.<br>
<br>
If you can seem to avoid this problem send us the IRAF version you are using and we can try and give you further workarounds.<br>
<br>
Yours,<br>
Frank Valdes
</div>
{% endraw %}
