After the first run, the 'imglist' pointer is at the end of the file and remains there.  What you need to do is effectively close the file using the command<br>
<br>
<pre><code>imglist = &quot;&quot;</code></pre><br>
<br>
and before the inner while loop 'open' the file anew wth e.g.<br>
<br>
<pre><code>imglist = &quot;myfile&quot;</code></pre><br>
<br>

-Mike
