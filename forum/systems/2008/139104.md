**Mike Fitzpatrick** wrote on Mar 05, 2008

{% raw %}
<div>
First verify that the binaries in the /iraf/iraf/bin.linux directory all have the execute permissions set.  Next try starting as "cl -old", this will invoke the old /iraf/iraf/bin.linux/cl.e   I suspect this will work and that the problem is that the ecl.e is missing a dynamic library dependency, i.e. the libtermcap.so.2  <br>
<br>
You can confirm this by running "ldd" at the unix prompt on the binary.  If indeed libtermcap is missing then you need to either install the 'ncurses' package on ubuntu or else get a statically linked ecl.e binary from<br>
<br>
<a href="http://iraf.net/ftp/pub/fitz/ecl.e">http://iraf.net/ftp/pub/fitz/ecl.e</a><br>
<br>
Download in binary mode, reset execute permissions and install in /iraf/iraf/bin.linux.<br>
<br>
-Mike
</div>
{% endraw %}
