While this could at least potentially be done with imexpression I strongly prefer to do it with an imfort routine of my own. In this context:</blockquote><br>
<br>
Since your intent is to create complex masks, you might also look as MSKEXPR, MSKREGIONS or TEXT2MASK in the PROTO package.<br>
<br>
<blockquote>1. Does the "buf" variable above have to have the same dimensionality as represented by the 4 following parameters?<br>
That is, suppose I wanted to write a common value P to all pixels between (x0,y0) and (x1,y1). How could I<br>
achieve this with imps[123]r? I have tried virtually everything and nothing works.</blockquote><br>
<br>
The 'buf' variable just has to be large enough to hold the section you want to write, this can then be placed anywhere in the image even if the image is larger.  Attached is a test program to demonstrate.  Note that a section such as [100:200,100:200] is actually 101x101 and not 100x100 pixels.<br>
<br>
As for why you might be having problems:  Was the image opened with write permissions (e.g. mode=3 for WRITE_ONLY or mode=2 for READ_WRITE)?  Are the pixels you're trying to set all zero or was there some error message?<br>
<br>
<blockquote>2. Related, how do I specify the (x0,y0) to (x1,y1) range in imps2r, as x0,x1,y0,y1 or x0,y0,x1,y1 (where of course<br>
x0,x1,y0,y1 are all integers)? I have tried both without success. </blockquote><br>
<br>
The arguments are specified as "x0,x1,y0,y1"<br>
<br>
Cheers,<br>
-Mike<br>
<br>
<pre><code>
        program imptest

        character*80    image, errmsg
        integer         im, ier, axlen(7), naxis, dtype
        integer         i
        real            pix(10000)

c --- Set dimensions and type (6 is TY_REAL)
        image = &quot;test.imh&quot;
        axlen(1) = 1024
        axlen(2) = 1024
        naxis    = 2
        dtype = 6

c --- Create the image.
        call imcrea (image, axlen, naxis, dtype, ier)
        if (ier .ne. 0) goto 91

c --- Open the image for writing, mode &#x27;3&#x27; is WRITE_ONLY
        call imopen (image, 3, im, ier)
        if (ier .ne. 0) goto 91

c --- Create a pixel mask array 100x100
        do 10 i = 1, 10000
            pix(i) = 1.0
 10     continue

c --- Write it to the section at [100:199,200:299]
        call imps2r (im, pix, 100, 199, 200, 299, ier)
        if (ier .ne. 0) goto 91

c --- Close the image and quit.
        call imclos (im, ier)
        if (ier .ne. 0) goto 91

        stop

c --- Error exit.
 91     call imemsg (ier, errmsg)
        write (*, &#x27;(&#x27;&#x27; Error: &#x27;&#x27;, a80)&#x27;) errmsg
        stop
        end
</code></pre>

You need to make sure the first 100 pixels of the buffer are 1019.  The routine will effectively write the section line by line but uses the starting address of the buffer you pass in and does the offset in the image itself.<br>
