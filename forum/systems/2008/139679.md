**Mike Fitzpatrick** wrote on Jun 12, 2008

{% raw %}
<div>
Did you load the IMRED package first?  What exactly is the error message?<br>
<br>
A "task 'ccdred' not found" would mean the IMRED package isn't loaded (perhaps in the old version you did this automatically in your login.cl?), but a "cannot open connected subprocess" might mean there was an error in the installation (e.g. not all of the binaries were unpacked, or the NOAO binaries were unpacked in the wrong place). <br>
<br>
<blockquote>PS. I deleted the source code at the completion of the installation script if this makes any difference.</blockquote><br>
<br>
It might, how did you delete the source (using "mkpkg strip" is the preferred method)?  Note that a skeleton of the system is still required in order to find things like parameter files, online help, etc.<br>
<br>
-Mike
</div>
{% endraw %}
