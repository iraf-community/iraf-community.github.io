# string conversion of INDEF-valued real

{% raw %}
<div>
real tmpx=INDEF<br>
print("The value is "//str(tmpx))<br>

**Mike Fitzpatrick** wrote on Jun 24, 2008

{% raw %}
<div>
The '//' is a binary operator and as a rule expressions involving an INDEF operand are not allowed, so what you're seeing is that the result of concatenating a string with an INDEF is itself an INDEF value.  In v2.14 you can use the isindef() builtin to test for this, e.g.<br>
<br>
<pre><code>
if (isindef (foo)) {
    print (&quot;value is INDEF&quot;)
} else {
    print (&quot;value is &quot; // foo)
}
</code></pre><br>
<br>
Alternatively, use printf() instead:<br>
<br>
<pre><code>
ecl&gt; x = INDEF
ecl&gt; printf (&quot;value is %s\n\n&quot;, str(x))
value is INDEF
</code></pre><br>
<br>
Cheers,<br>
-Mike
</div>
{% endraw %}
