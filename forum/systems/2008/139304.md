<div>
Using the frame buffer values sounds normal when the image cannot be found.  Do you get the warning message when your first start IMEXAM or in response to one of the keystrokes?  Do you specify the image name on the command line or start using just the frame number?<br>
<br>
When IMEXAM runs it should request the WCS from DS9 that will include the path to the file.  This should be enough to let IRAF map the image, the exception though may be with MEF files where you've loaded a single extension or the entire data cube.  Is this what you're doing?  Otherwise you might be sure that your IRAF and DS9 sessions are using the same directory (i.e. if you start DS9 in '/data' the be sure to do a "cd /data" in IRAF) in case it's only the image name being sent.<br>
<br>
Hope this helps.<br>
<br>
-Mike
