**Mike Fitzpatrick** wrote on Jul 09, 2008

<div>
Two problems:  <br>
<br>
To use the TABLES libraries you need to compile using the '-p tables' flag to  import the tables environment, i.e. use the command:<br>
<br>
<pre><code> mkpkg -p aceold -p tables </code></pre><br>
<br>
The second problem is that the $iraf and $IRAFARCH environment variables must be set in your host environment.  Since you're compiling inside of IRAF this means in your .cshrc/.bashrc file, or you can simply compile outside of  the CL as something like:<br>
<br>
<pre><code>
% cd /path/aceold                  # go to package directory
% setenv aceold /path/aceold        # in case you didn&#x27;t edit extern.pkg
% setenv iraf /iraf/iraf/                 # trailing &#x27;/&#x27; required, must be correct
% setenv IRAFARCH macosx      # or &#x27;macintel&#x27; for Intel system
% mkpkg -p aceold macosx          # set package architecture
% mkpkg -p aceold -p tables            # build it
</code></pre>   <br>
<br>
The README file with the package appears to leave out the '-p tables' flag, but see the rest for the environment information.<br>
<br>
Cheers,<br>
-Mike

**Mike Fitzpatrick** wrote on Jul 09, 2008

{% raw %}
<div>
Different two problems:<br>
<br>
1) My message left off the trailing '/' in the definition of the 'aceold' package path, i.e. it should read<br>
<br>
<pre><code>setenv aceold /path/aceold/</code></pre><br>
<br>
The 'aceoldlib' is coming from the missing '/' and trying to resolve the path aceold$lib internally.  In general, a trailing '/' on pathnames is recommended and won't hurt.<br>
<br>
2)  The toplevel mkpkg apparently doesn't have an entry for macintel.  You should edit the aceold$mkpkg file and add the following at the bottom:<br>
<br>
<pre><code>
macintel:                                  # install Mac OSX Intel binaries
        $verbose off
        $set DIRS = &quot;lib src&quot;
        !$(hlib)/mkfloat.csh macintel -d $(DIRS)
        ;
</code></pre><br>
<br>
You'll also need to manually create a 'bin.macintel" directory in the /path/aceold directory, but then a "mkpkg -p aceold macintel" should work.  In the end, the 'bin' link should be pointing to the 'bin.macintel" directory  (bin.generic should always be empty).<br>
<br>
-Mike
</div>
{% endraw %}
