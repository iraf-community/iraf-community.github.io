**Mike Fitzpatrick** wrote on Apr 08, 2008

{% raw %}
<div>
The C-shell is required for running IRAF anyway (e.g. the 'cl' and 'mkiraf' commands use csh).  If it isn't your default shell you can just type 'csh' to start one and then the commands in the installation guide ( <a href="http://iraf.net/ftp/iraf/v214/pciraf.ps.gz">http://iraf.net/ftp/iraf/v214/pciraf.ps.gz</a> ) can be followed.  The last two pages of the installation guide have complete examples of the install process.<br>
<br>
For OpenSuse you'll want to be sure to use the LNUX architecture.  When following the install commands, use 'linux' where you see 'redhat' (e.g. when setting IRAFARCH, creating bin directories, etc).<br>
<br>
Cheers,<br>
-Mike
</div>

If you get a "command not found" message then it may not be installed and you need to install it from the SuSE distribution (it may be in a package called 'tcsh' which is equivalent).  Normally the command is in /bin/csh or /bin/tcsh.<br>
