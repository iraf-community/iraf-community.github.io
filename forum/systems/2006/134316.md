First, if this is Solaris for x86 then the proper architecture name is 'sunos' and you should be using the PC-IRAF distribution, the 'ssun' arch is for Sparc systems.  Assuming that is sorted out, the install script should tell you whether there was a problem with the directory structure and what it should look like.  If you got that message be sure the directories are correct and you unpacked the binaries in the proper place.  <br>
<br>
A 'bin.ssun not there' message sounds like a directory structure problem, if this doesn't help please post the exact error message you got from the install script and confirm this is a Sparc system.<br>
