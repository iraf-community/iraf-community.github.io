I assume we're talking about a CL script?  If so the trick is to use something like the SECTIONS (or FILES if it isn't an image) task to expand the template, e.g.<br>
<br>
<pre><code>
procedure qcont (images)

string  images           { prompt = &quot;Image list&quot; }

begin
    string  imgfile, img

    # Exapnd image template
    imgfile = mktemp (&quot;tmp$qcont&quot;)     # get temp file
    sections (images, opt=&quot;full&quot;, &gt; imgfile)

    list = imgfile
    while (fscan (list, img) != EOF) {
         .....stuff
    }
end
</code></pre><br>
<br>
Note some tasks already take image lists and you can just pass it through, other tasks (or pure sccript code) however don't and you need to loop like this.<br>
<br>
Cheers,<br>
-Mike

<div>
The SECTIONS task will expand file templates and @files automatically, i.e.<br>
<br>
sections foo.fits<br>
sections @flist<br>
sections foo*.fits<br>
<br>
will expand the single file name, the contents of the @file, or the wildcard template.  Note however that<br>
<br>
section flist<br>
<br>
will return just 'flist' and not the expanded contents as if you'd used '@flist'.<br>
<br>
-Mike
</div>
{% endraw %}
