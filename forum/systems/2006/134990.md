<div>
 64-bit systems are not supported for compilation at this time (it is a major future project though).  You'll need to install pre-built binaries and in the case of caos linux just grab the redhat binaries but install in a 'bin.linux' directory of the package.  Write back if you still have problems, I have a caos system setup but didn't test any external packages.<br>
