# ximtool in redhat 9-- twm makes it work!

**Andrew Potter** wrote on Jan 21, 2006

{% raw %}
<div>
My previous posts have complained about ximtool not working properly in RH9.  Fitz suggested that all the colors were used up by the GUI.  So I switched the GUI from Gnome to TWM using switchdesk.  Aha!,  ximtool works just fine in TWM, lots of colors available.  I am quite happy to work in TWM, don't need all those bells and whistles in Gnome.<br>
<br>
But, there is a but.  I can only switch to TWM as root. Switching by any other user looks like it works, but it doesn't really-- I always end up with the Gnome gui when I start up x again as a common user.   I don't want to process iraf data as root.  Is there a way to switch to TWM as root and then change the user to my iraf user?  or is there a way to empower the common user to switch?<br>
<br>
Drew
</div>
{% endraw %}

---

**Andrew Potter** wrote on Jan 21, 2006

{% raw %}
<div>
I can get the TWM gui for a common user by clicking the sessions choice before logging in-- and choosing default  Problem solved.
</div>
{% endraw %}

<div>
Glad to hear you resolved it.  FYI, the /etc/sysconfig/desktop file sets <br>
the default desktop for the machine, but you should be able to select<br>
TWM from the XDM login menu and have it be remembered the next time<br>
you log in, or else start it in your .xinitrc file.  See also the man page for<br>
the 'switchdesk' command, you can 'sudo switchdesk' to change it from<br>
the commandline.<br>
<br>
-Mike
