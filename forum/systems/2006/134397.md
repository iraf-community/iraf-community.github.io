<div>
Almost certainly no plans for RPMs from NOAO, however from this site I'm leaning towards a network-based install to simplify things such as was done for the NVO Summer School last year (see the <a href="ftp://iraf.noao.edu/pub/nvoss/README">README</a> and scripts in <a href="ftp://iraf.noao.edu/pub/nvoss">ftp://iraf.noao.edu/pub/nvoss</a>).  You can Google for RPMs other people have put together (and <a href="http://www.owlnet.rice.edu/~marcosh/iraf/downloads.html">.pkg installers for OSX</a>) but I'd rather avoid having to maintain a number of system-dependent installers.<br>
<br>
Of course, if somebody else wants to put these together we can certainly talk about distributing them as contrib software from here.<br>

-Mike
