<div>
Normally you should just need to type 'cl' to start IRAF and 'ds9' to start DS9, the default connection will be made over a unix socket.  Note this socket is based on the userid and so both command must be run as the same user.  There are other ways to start these (e.g. the XIRAF script from the net, SciSoft has its thing) but try this first.  I'm assuming you haven't got a private graphcap or IMTDEV environment variable that would change the default connection scheme.  Post back if you still have problems.<br>

Cheers,<br>
