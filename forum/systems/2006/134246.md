XImtool still runs unders Solaris, and still has the 8-bit default visual limitation.  DS9 will work on a 24-bit display but has its own quirks (e.g. no<br>
wcs/pixel readout when displayed from IRAF, a DS9 limitation, not an iraf<br>
one).  Search the forums for "BadMatch" and you'll quickly find the standard reply about the 8-bit workarounds.<br>
