<div>
"Command not found" usually just means the local bin directory you installed the IRAF commands in isn't in your $PATH.  If you can run the command explicitly, e.g. as "/usr/local/bin/mkiraf" then the installation is okay and you need to adjust your path to pick up the directory.  If it doesn't work, then be sure when you ran the install script you did it <strong>without</strong> the '-n' (no-op) flag so the commands were actually installed.  <br>
