<div>
The V2.12.2a patch is strictly needed on for the GEMINI package.  The 'patch2a' subdirectory contains complete distributions for certain platforms (unfortunately not SuSE) as well as the 'patch2a.tar' file tat will patch your V2.12.2 source to V2.12.2a (but the binaries would then need to be recompiled locally).<br>
<br>
If you <u>do not </u>need the GEMINI package you're fine now, if you do then a simpler route would be to download is as.pcix.gen.gz and either the of the 'rhux' or 'lnux' binaries (i.e. the IB and NB files) from the patch2a subdirectory.  Install the binaries in a 'bin.suse"  directory as before.<br>

Cheers,<br>
-Mike
