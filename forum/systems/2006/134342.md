<div>
See the FAQ and/or search the forums for similar questions and answers, but quickly:  Tasks like SGRAPH usually have a 'device' parameter that let's you<br>
specify a printer or something like the 'eps' or 'psdump' device to generate a PS file of the plot.  A 'g-gif' device also exists to create a GIF of the plot instead  of the terminal output.<br>
<br>
From the cursor mode you can issue the command ":.snap lpr" to <br>
send postscript to the default printer for the machine, or to the device <br>
named by your unix PRINTER environment variable. With no device name <br>
given it will go to whichever device is named by your 'stdplot' <br>
environment variable, this may already be 'lp' or 'lpr' (these are <br>
equivalent) and a shortcut command for this is to simply hist the '=' <br>
key. Once the plot is generated you may need to issue a ":.gflush" <br>
command to flush the graphics buffer right away. To save the output to a <br>
file for later use try the 'psdump' device to create a file in /tmp call <br>
'irafdmpXXXX.ps' where the XXX is a process id, if you want EPS use the <br>
'eps' device name and it will be saved to the current directory as <br>
'sgiXXX.eps'. <br>
<br>
IMEXAM has two cursor modes, if you want to save a graphics plot be sure to type 'g' to get into graphics mode (or 'i' to get back to image mode) so you can make a snap of a surface plot.  Most of the functions have an equivalent task elsewhere in the system that can use the device param, e.g. to make plots in batch mode from a script.  For tasks like SURFACE that doesn't have a cursor mode, an '=gcur' at the cl prompt will bring one up.  Hope this helps.<br>
