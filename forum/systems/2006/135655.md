**Mike Fitzpatrick** wrote on Aug 08, 2006

{% raw %}
<div>
Be sure you ran the install script, and <strong>without</strong> the '-n'<br>
flag.  It sounds as it the commands weren't actually installed,<br>
or the place they were installed isn't in your path, and that<br>
the /usr/include/iraf.h link doesn't exist or is invalid (i.e. you<br>
didn't run as root or specified the wrong $iraf that the install<br>
script should have warned about).<br>
<br>
-Mike
</div>
{% endraw %}
