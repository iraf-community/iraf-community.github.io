<div>
This is a known problem on RH9 and newer systems that can be fixed by using the X11IRAF V1.3.2 snapshot release available from<br>
<br>
<a href="ftp://iraf.noao.edu/pub/fitz/x11iraf-v1.3.2-bin.redhat.tar.gz">ftp://iraf.noao.edu/pub/fitz/x11iraf-v1.3.2-bin.redhat.tar.gz</a><br>
<br>
As for the "control" problem, be sure the NumLock key is not enabled, this changes the event mask and keeps the contrast stretching and menus from working.<br>
<br>
-Mike
