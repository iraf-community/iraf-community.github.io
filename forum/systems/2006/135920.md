**Mike Fitzpatrick** wrote on Sep 28, 2006

{% raw %}
<div>
This is a coding error:  The call to cm_mask() on line 85 of t_ccdmask.x has 14 arguments but is declared with only 13.  The fix is simply to delete the last argument (i.e. one of the two 'ngood') and try compiling again.  This has been fixed in the master source but the package source hasn't been updated yet.<br>
<br>
-Mike<br>
<br>
P.S.  FWIW, CCDMASK is also part of the IMRED.CCDRED package and in fact this version is more recent than the one in the NMISC package.
</div>
{% endraw %}
