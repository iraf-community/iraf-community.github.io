<div>
A floating point error can sometimes be a coding error and sometimes it is data related.  However, there is a known issue with the V2.13 system in the FPE handling code that I suspect you might be seeing.  A quick way to find out would be to install a new set of STSDAS binaries I've just<br>
uploaded to the <a href="http://www.iraf.net/ftp/iraf/extern/">http://www.iraf.net/ftp/iraf/extern/</a> download area (see stsdas_v3.5-bin.macintel.tar.gz).<br>
<br>
Please let me know whether these work or not.  Somebody else might be able to comment on SPECFIT in  general or you might also try asking the STScI helpdesk (help@stsci.edu).  Good luck.<br>
<br>
Cheers,<br>
-Mike
