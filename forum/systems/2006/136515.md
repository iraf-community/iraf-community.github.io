<div>
IRAF will not build from source the way most Debian systems want, however the existing 32-bit binaries will run on an AMD64.  You'll need to follow the standard IRAF install procedures layed out in the PC-IRAF install Guide (<a href="http://iraf.net/irafdocs/pciraf/)">http://iraf.net/irafdocs/pciraf/)</a> or see a recent thread on installing un Ubuntu (<a href="http://iraf.net/phpBB2/viewtopic.php?t=85799&amp;highlight=ubuntu)">http://iraf.net/phpBB2/viewtopic.php?t=85799&amp;highlight=ubuntu)</a>.<br>
