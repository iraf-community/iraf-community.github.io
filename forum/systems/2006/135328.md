**Mike Fitzpatrick** wrote on Jun 22, 2006

{% raw %}
<div>
There are apparently two issues here, although one is clearly a bug:  In the IRAF kernel code the FPE exception flag was being set using a local flag rather than a pointer to the flag.  The second issue is that between 10.3.9 and 10.4 this flag went from being an "unsigned int" to a "long" and may explain why Colin saw the error on a MacIntel system but not generally elsewhere.<br>
<br>
In any case, I've uploaded patch MacPPC binaries to<br>
<br>
    <a href="http://iraf.net/pub/fitz/ib.macx.ppc.gz">http://iraf.net/pub/fitz/ib.macx.ppc.gz</a><br>
    <a href="http://iraf.net/pub/fitz/nb.macx.ppc.gz">http://iraf.net/pub/fitz/nb.macx.ppc.gz</a><br>
<br>
for you to try on your 10.3.9 system.  I did only some quick tests but these appear to fix the problem.  The same change will need to be made for the Mac/Intel binaries -- I'll wait to decide whether things are close enough for a Beta-3 release to put it off a few days or simply update the Beta-2 binaries with this (fairly critical) bug fix.<br>
<br>
Thanks for the report, let me know if things are fixed.<br>
<br>
Cheers,<br>
-Mike
</div>
