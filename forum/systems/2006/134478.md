<div>
Randall,<br>
    In V2.12.2a the scombine binary was broken out on its own,  prior to that it was part of the ONEDSPEC binary.  The message you report can happen with a system is updated with the source, but not the patched binaries (i.e. the package source now declares scombine to be in a binary that doesn't exist).  Be sure that the dates on the noao$bin.linux files come from about July04 as a first check that you've got the right version.  If there is any doubt you can simply reinstall binaries from<br>
<br>
   <a href="ftp://iraf.noao.edu/iraf/v212/PCIX/patch2a/nb.lnux.x86.gz">ftp://iraf.noao.edu/iraf/v212/PCIX/patch2a/nb.lnux.x86.gz</a><br>
<br>
As for building from source, this is possible but requires that you use "mkpkg -p noao" to load the NOAO package environment so the missing include files are found.  Also be sure to reconfigure the package first, i.e. <br>
<br>
    cl&gt; cd noao$<br>
    cl&gt; mkpkg -p noao linux<br>
    cl&gt; mkpkg -p noao update<br>
<br>
But try the binaries first.... Hope this helps.<br>
<br>
Cheers,<br>
-Mike
</div>
