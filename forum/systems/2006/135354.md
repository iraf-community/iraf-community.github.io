**Mike Fitzpatrick** wrote on Jun 23, 2006

{% raw %}
<div>
Try also 'gcc_select' at the prompt to change the default version of GCC used.  Inside the XC compiler it will use the default 'cc' command, the gcc_select changes this.  Alternatively, you can define<br>
<br>
 setenv XC_CC /usr/bin/gcc-4.1<br>
<br>
(or whatever the path is) in your .cshrc file (so its picked up through the call within mkpkg) and it will specifically use that command.<br>
<br>
-Mike
</div>
{% endraw %}
