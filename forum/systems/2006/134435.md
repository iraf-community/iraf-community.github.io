<div>
"Command not found" usually just means the "local bin directory" you specified when you ran the install script isn't in your path.  If the commands actually exist in /usr/local/bin then follow the link to be sure you can read the path, e.g. try to page the file.  If that doesn't work, check the path of the link is correct, but the install script should have caught this.<br>
<br>
Lastly, are you sure the install script was run <strong>WITHOUT</strong> the "-n" flag?  This is the no-op flag so you can see what happens, but more than one person has forgotten to run the install script without this flag after seeing what happens.<br>
<br>
-Mike
