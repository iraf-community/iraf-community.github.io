**Mike Fitzpatrick** wrote on Dec 21, 2006

{% raw %}
<div>
RPM files put together by users are available on net (just use Google), however I'm not aware of any for the latest V2.13 release.  This is an issue on certain linux platforms where changes in V2.13 are required to do things like compile external packages or local imfort tasks, but for simply using IRAF the V2.12 version will normally work.  Redhat (and Fedora) I think are still the most popular linux systems but Ubuntu is making a strong showing recently as well, the choice is up to you. <br>
<br>
As for otherwise installing, we can talk you through problems here but be sure to read the installation guide (<a href="http://iraf.net/irafdocs/pciraf/)">http://iraf.net/irafdocs/pciraf/)</a> first, the last page contains a complete example of everything you will need.  A simpler network-based installation is planned as part of the final V2.13 release but isn't yet available.<br>
<br>
-Mike
</div>
