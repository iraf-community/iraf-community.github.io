**Mike Fitzpatrick** wrote on May 18, 2006

{% raw %}
<div>
You didn't post specific error messages but it is possible they come about either by not having the proper environment defined (i.e. $iraf and $IRAFARCH) or perhaps a missing package dependency (e.g. GEMINI requires FITSUTIL).  Note the mkpkg file for the package needs to be modified to add cygwin as an architecture.<br>
<br>
In any case, I was able to build these packages with no problem and have uploaded the binaries for CTIO/FITSUTIL/GEMINI to the distribution directory.<br>
<br>
-Mike
