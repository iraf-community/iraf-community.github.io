One of the shortcomings of XTerm is that it is possible for the graphics cursor to "lose sync", usually because you're typing "too fast" (specifically before the cursor is ready for new input).  Steadily typing something like a '0' (zero) repeatedly can help put things back in sync.  You might also try using the 'xtermjh' device name which puts the status line output on the text window rather than overwriting the display.  XGterm avoids the sync problem entirely and the full-screen cursor is generally nicer, it's worth installing.<br>
    Hope this helps.<br>
