<div>
Hi George,<br>
<br>
IRAF is compiled using F2C/GCC and I suspect you're missing the f2c library routines.  These can normally be added with the flags<br>
<br>
    -L$iraf/unix/bin.redhat -lf2c -lc<br>
<br>
but I've never tried the Intel compilers under linux and would need to know specifically which references are being undefined.  Note there is also a "-lcompat" flag sometimes needed, this library is also found with the above -L path flag so jusst add it.<br>
<br>
I'm assuming you've got the correct Intel flags defined and that there are no obvious incompatabilities with the F2C/GCC libs, but if you still have problems please post specific error messages.<br>
<br>
Cheers,<br>
-Mike
</div>
{% endraw %}
