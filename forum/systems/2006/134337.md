**Mike Fitzpatrick** wrote on Jan 20, 2006

{% raw %}
<div>
The cl.csh and irafuser.csh scripts are two different things:  /usr/local/bin/cl should be a symlink to the cl.csh that is actually used to start iraf, the irafuser.csh is an environment definition file that you normally 'source' in your .cshrc file along with other definitions such as <br>
<br>
    setenv iraf /iraf/iraf/<br>
    setenv IRAFARCH redhat<br>
    source $iraf/unix/hlib/irafuser.csh<br>
<br>
Does your /usr/local/bin/cl actually point to irafuser.csh, if so it should be changed.  The cl.csh script is run with the '-f' flag so your .cshrc shouldn't<br>
be read, although I'm still not sure why executing irafuser.csh would create the error, I'd expect it to simply return to the prompt.<br>
    In any case, re-running the install script should fix the links.<br>
<br>
-Mike
</div>
{% endraw %}
