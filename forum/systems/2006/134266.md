<div>
Sounds like you're using the newer and pickier GCC 4.0<br>
compilers.  You can add a "-dv" flag to XC to have it print verbose debug information to try to find out which file is<br>
throwing the error, or else compile them by hand individually.<br>
The flags will also show which sub-parts of XC are being<br>
executed and since the message appears to be a runtime<br>
error from XC it will tell you which of xpp/rpp/F2C etc is<br>
throwing the error.<br>
<br>
Once you find that out also please post your system details,<br>
e.g. OS version, gcc/glibc version etc.<br>
<br>
-Mike
</div>
