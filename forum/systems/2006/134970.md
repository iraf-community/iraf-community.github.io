**Mike Fitzpatrick** wrote on May 08, 2006

{% raw %}
<div>
In this case the message means it isn't finding the v5 library:  If caos has v6 then you can try the same trick of linking libncurses.so.6 to libncurses.so.5, however I suspect it is just a matter than libncurses isn't installed at all.  If you or your sysadmin can install this or verify it is missing (look for an 'ncurses' or 'termcap-compat' package) you should be able to get it working (use 'ldd' to check for other dependencies).   Otherwise, see the X11IRAF source in<br>
<br>
<a href="http://iraf.net/ftp/pub/fitz/x11iraf-new_gcc.tgz">http://iraf.net/ftp/pub/fitz/x11iraf-new_gcc.tgz</a><br>
<br>
and try compiling that instead.  A new source distro of X11IRAF with various platform changes is on the way but not ETA.  Post again if you still have problems.<br>
<br>
Cheers,<br>
-Mike
</div>

**Mike Fitzpatrick** wrote on May 08, 2006

{% raw %}
<div>
I was about to post when your reply came in.  CAOS looked like and odd little system so I configured a virtual machine with it and found as you did that the new source compiled (once you got all the yacc/flex/bison/x11 stuff installed).  In any case, I put a version of the xgterm I got at<br>
<br>
<a href="http://iraf.net/ftp/pub/fitz/xgterm.caos">http://iraf.net/ftp/pub/fitz/xgterm.caos</a><br>
<br>
I mention it here because this is linked statically wrt libncurses and might be useful elsewhere.<br>
<br>
<blockquote><br>
&gt;installing in ximtool/clients...<br>
&gt;make[3]: Entering directory `/fontina/local/iraf/x11iraf/ximtool/clients'<br>
&gt;/bin/sh: ./mkpkg: Permission denied<br>
&gt;make[3]: *** [ism_wcspix.e] Error 1 </blockquote><br>
<br>
This may just mean the 'mkpkg' command either isn't installed, or more likely isn't in your default path.  The system is trying to execute the mkpkg file directly instead of the command (ISM_WCSPIX is a plug-in task that provides the real-time wcs/pixel display for ximtool).  You can ignore this for now, else change the $PATH in your .cshrc/.bashrc file.<br>
<br>
Cheers,<br>
-Mike
</div>
{% endraw %}
