**Mike Fitzpatrick** wrote on Dec 01, 2010

{% raw %}
<div>
<blockquote><br>
Does it matter if I run the extern package updates, installs, etc. as user iraf or root? It seems to work both ways.</blockquote><br>
<br>
The only requirement is that you are able to write to the iraf$extern directory.  Installing as root is fine but keep in mind the files may then be owned by root, and updates done later as 'iraf' will see a permissions problem.  You can change the iraf tree to all be owned by the same iraf user with a command such as<br>
<br>
<pre><code>% sudo chmod -R iraf:users $iraf</code></pre><br>
<br>
The need for an 'iraf' user at all will go away shortly (just didn't have time to make it into this release).
</div>
{% endraw %}
