**Mike Fitzpatrick** wrote on Dec 01, 2010

{% raw %}
<div>
The 'chsh' command is what you would use to change the login shell, or you can just edit the /etc/passwd file directly.<br>
<br>
However,  this is separate from the fact that you need to have a C-shell installed on the machine in the first place.  Details on how to do this depend on the platform, note that a 'tcsh' is equivalent to 'csh'.
</div>
{% endraw %}

{% raw %}
<div>
Here is a Graphical User Interface (GUI) method:<br>
In the main menu (up left of the screen in Fedora) go to <br>
System --&gt; Administration --&gt; Add/Remove Software<br>
In the "Add/Remove Software" window,  search for "tcsh"<br>
In the search results choose the box with: "An enhanced version of csh, the C shell" and click apply.<br>
<br>
The "Add/Remove Software" window explained here is in Fedora 14 and 13, In Fedora 11 it might be located in the Applications menu.
</div>
{% endraw %}
