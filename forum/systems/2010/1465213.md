**Mike Fitzpatrick** wrote on Sep 10, 2010

{% raw %}
<div>
Assuming you're using the X11IRAF v2.0 distribution and not something earlier..... <br>
<br>
Edit the x11iraf$obm/ObmW/Imakefile to reset the CCOPTIONS flags to add a '-DUSE_STDARG' flag.  Specifically, starting at line 24 the code should read<br>
<br>
<pre><code>
#if ((GccMajorVersion &gt;= 3) &amp;&amp; (GccMinorVersion &gt;= 1))
        CCOPTIONS = -DUSE_STDARG
#else
        CCOPTIONS =
#endif
</code></pre><br>
<br>
Note that the test for the GccMajorVersion goes from "== 3" to "&gt;= 3".  Otherwise, try using the prebuilt binaries.
</div>
{% endraw %}
