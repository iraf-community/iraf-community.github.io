**Mike Fitzpatrick** wrote on Apr 10, 2010

{% raw %}
<div>
<blockquote><br>
. system app-defaults directory (none found): <br>
i come up to this part while installing x11iraf v1.3.1 on fedora 12 and don't know what to input here can anyone give me some advice. </blockquote><br>
<br>
    The app-defaults file should normally be in /usr/lib/X11/app-defaults, or perhaps /usr/X11R6/lib/X11/lib on Fedora.  The XGterm defaults file is used mainly to specify the fonts and menus strings to be used, but xgterm will work fine without it.<br>
<br>
<blockquote><br>
2. The next question it is going to ask me is about install CDL, so do I need to install CDL?</blockquote><br>
<br>
    Only if you intend to write applications to display images in XImtool/DS9, otherwise you won't need it.<br>
<br>
More generally,  you'll need to use the X11IRAF v2.0 release in order to use 24-bit image displays, v1.3.1 only supports 8-bit.[/quote]
