The 'unmatched' message usually means there's an unquoted string in a script, but the mkiraf.csh is used on all systems and I can't see any errors in it.  The simplest way to find the error is to execute the script as<br>
<br>
<pre><code>%  csh -x /iraf/iraf/unix/hlib/mkiraf.csh</code></pre><br>
<br>
This will trace the script as it executes and show you exactly where the message is coming from.  If you don't see anything obvious, post the results (or the mkiraf script itself).<br>
