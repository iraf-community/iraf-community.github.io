**Mike Fitzpatrick** wrote on Sep 02, 2010

{% raw %}
<div>
This is a known problem in the ECL (the default CL for v2.13 onward) that will be fixed in the upcoming v2.15 release.  The workaround is to use the "old" CL by invoking the /iraf/iraf/bin.&lt;arch&gt;/cl.e binary directly or with e.g.<br>
<br>
<pre><code>cl -o &lt; $irafscriptdir/daofind.cl </code></pre><br>
<br>
-Mike
</div>
{% endraw %}
