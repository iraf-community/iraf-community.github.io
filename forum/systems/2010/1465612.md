**Mike Fitzpatrick** wrote on Nov 26, 2010

{% raw %}
<div>
A simpler place to start may be in understanding how to fix the "strange results" you see, in some cases these might be related to known bugs or errors in how the parameters were set.  Note that we don't have access to AIX hardware so it won't be possible to reproduce any problems or verify fixes.<br>
<br>
Otherwise what you're describing is a port of v2.15 to AIX.  I can tell you now the v2.15 iraf kernel is completely different than for the AIX v2.11 system and a simple recompilation will not work.  The applications code is portable and the starting point for a port would be to take the v2.15 sources and replace the iraf$unix directory (i.e. the iraf kernel) with that directory from your existing v2.11 port (in a real port we would merge AIX changes into the latest kernel) and try building from that.  You could then use "make sysgen" to try building the entire thing from source, but there's no guarantee that will work and no specific reason to believe it'll resolve your 'strange results' problem.  Details about manually doing a sysgen can be found in the 'Unix Site Manager's Guide' (see <a href="http://iraf.net/irafdocs/unixsmg/)">http://iraf.net/irafdocs/unixsmg/)</a>.<br>
<br>
In the past it has been difficult to support a third-party port of IRAF and AIX isn't used much any more so I don't think we'd be interested in making it a mainstream distribution,  but we'll try to answer your questions.
</div>
