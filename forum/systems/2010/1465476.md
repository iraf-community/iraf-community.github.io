<div>
<pre><code>
procedure foo ()

begin

        printf (&quot;prompt&gt; &quot;)
        scan (s1)

        printf (&quot;You said &#x27;%s&#x27;\n&quot;, s1)
end
</code></pre><br>
<br>
This would be to prompt for e.g. filenames, although in that case using query parameters would do the same thing.  If what you want is something like a keystroke command you would use the 'ukey' CL parameter.  E.g.<br>
<br>
<pre><code>nextcmd:
        printf (&quot;\nCommand? &quot;)
        summary = no

        ch = cl.ukey
        if (substr(ch,1,4) == &quot;\\015&quot;) {
            goto nextcmd
        }

        switch (ch) {
        case &quot;?&quot;:                    
                   {  ....print help info
                   }
        case &quot;t&quot;:                       # Record
            {   printf (&quot;\nService Type? &quot;)
                n = scan (stype)
                if (n == 0)
                    stype = &quot;&quot;
                goto submit
            }
        }
</code></pre><br>
<br>
Note this ignores a &lt;cr&gt; and prints the prompt again, but defines a '?' and 't' keystroke command similar to what you see in graphics tasks.
