**Mike Fitzpatrick** wrote on Mar 22, 2010

{% raw %}
<div>
An 'abnormal termination' message means the binary couldn't start for some reason (wrong binary type, a missing shared lib on your system, etc).  To find out, execute the command outside of iraf as e.g.<br>
<br>
<pre><code>% /iraf/iraf/unix/bin.redhat/x_system.e</code></pre><br>
<br>
You'll either see a host error message (please post it) or a "&gt;" prompt meaning it started up okay (type "bye" to exit).
</div>
{% endraw %}
