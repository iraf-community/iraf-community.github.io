<div>
The needed libraries (both 32-bit and 64-bit) are available in the v2.15 release announced in the main iraf.net site for the linux distribution.   You can either copy the requested libs to your build directory or install the full IRAF release.  Note that the libcompat.a is no longer required and should be deleted from the DAOPHOT makefile as a dependency.
