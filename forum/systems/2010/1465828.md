**Mike Fitzpatrick** wrote on Dec 31, 2010

{% raw %}
<div>
There is an incompatability in the libSystem used by 10.4 and the system used to build the ecl.e binary that causes the error.  Since there is nothing substantially new in the ECL itself, using the older binary will work in almost all cases.  If you haven't still got this around, I've put one at<br>
<br>
<a href="ftp://iraf.noao.edu/iraf/v215/support/ecl.e.v214_macosx">ftp://iraf.noao.edu/iraf/v215/support/ecl.e.v214_macosx</a><br>
<br>
Just download, make executable, and put in your iraf$bin.macosx directory.  Starting IRAF as  "cl -old" to run the old CL should also work.<br>
<br>
The change to the irafarch.csh was made earlier in response to a local user's problem, but in general there's only limited support we can offer for 10.4 PPC systems due to a lack of hardware.
</div>
