I was having the same problem a few days ago and since there was no really easy explanation, I just wrote down every step I did so that I won't have trouble again and it can be useful for others. <br>
<br>
Although this way has given me the "Successfully Installed" prompt, I am still having problems, It would be great if any one could guide me in where I am making a mistake!<br>
<br>
This is how I did it:<br>
Installing IRAF:<br>
1. Install the C language shell: tcsh from the add/remove software secion in System-&gt; Administration.<br>
2. Make the iraf user with /iraf/iraf/local as home address and define it's login shell as /bin/tcsh/<br>
3. Log in as the iraf user<br>
4. Set the environment with: setenv iraf /iraf/iraf/ so that $iraf means /iraf/iraf<br>
5. Download the file from the iraf webpage<br>
6. Unzip the file with cat [filename] | zcat | tar -xpf - in the $iraf file<br>
---------------------------------<br>
For 32bit:<br>
in /iraf/iraf/ make the symbolic link:<br>
ln -s bin.linux bin.redhat<br>
in /iraf/iraf/noao/ make the Symbolic link:<br>
ln -s bin.linux bin.redhat<br>
---------------------------------<br>
7. Go to /iraf/iraf/unix/hlib/<br>
8. write ./install -n in that directory<br>
9. Answer all the questions and install IRAF<br>
10. Log out of IRAF and enter your own ID<br>
11. In your home directory (write âcdâ to go to home directory) write "mkiraf"<br>
12. Write "cl" and IRAF should run<br>
<br>
I tried installing IRAF both on my laptop (32bit) and my desktop (64bit). It is interesting that the 64bit version didn't need the symbolic links while, in my case at least, the 32bit did! <br>
<br>
As you can see, this is for installing IRAF on Fedora, to see how to name the Symbolic links you can just skip that section between the lines and while running step 8, it might prompt you with an error that a file is missing, you can use the name of the missing file as the last argument in the Symbolic links...<br>
