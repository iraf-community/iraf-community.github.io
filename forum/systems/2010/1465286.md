# Scisoft IRAF freezing OS X Leopard systems

**Dr M J Carter** wrote on Oct 05, 2010

{% raw %}
<div>
I've had reports of Scisoft's IRAF (2.14, 32-bit) causing OS X Leopard<br>
to freeze up, but only on certain systems.   Test code, abstracted from<br>
real-life problem case, of form:<br>
<br>
imexpr "a &gt; 1e7 ? 1 : 0" test.fits data/infileNNN.fits[M]<br>
<br>
del test.fits<br>
<br>
.... looping on M (1 to 3) and NNN (1 to 69).  IRAF freezes, and<br>
system has to be power-cycled.<br>
<br>
The only thing in common between the afflicted systems is the hard<br>
drive model: Hitachi HDS721010KLA330.  I can reproduce the fault at will<br>
with IRAF, but nothing else I've thrown at them causes the fault, and<br>
Apple's diagnostics see no problems.  Changing the drive causes the<br>
problem to go away, but we've a seriously large number of iMacs<br>
with this drive model, and I'd rather not void their warranties<br>
quite yet.<br>
<br>
Suggestions, please.  Apologies for any formatting botches above.

<div>
Without having a problem system literally in front of me I'm afraid there's not much I can do.  If this were a single system I would suspect a hardware problem (logic board, bad RAM, bad disk, etc) but if it's across a number of machines it might be something else.<br>
<br>
SciSoft normally just repackages the binaries we produce but creates it's own environment variable.  When you login to the CL and issue a<br>
<br>
<pre><code>cl&gt; !env</code></pre><br>
<br>
Do you see a 'mach', 'MACH' or 'arch' environment variable that is something other than 'macintel' (or '.macintel' for $arch) ??  I'm wondering whether you're somehow using the PPC binaries (e.g. does a 'ps' show 'macosx' in the pathname to x_images.e)?<br>
<br>
As I said, IRAF does basic I/O and computation.  You might try attaching a debugger to the x_images.e once it is running to see if it catches an error, otherwise there's not much more I can offer than to suggest you Google around for similar problems.  Some of the stuff I found in a quick search:<br>
