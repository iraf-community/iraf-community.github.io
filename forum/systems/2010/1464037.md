**Mike Fitzpatrick** wrote on Apr 07, 2010

{% raw %}
<div>
It's possible to do a private installation, although not quite as you describe it.  You shouldn't move login.cl file between machines because they contain specific paths (of where you ran the MKIRAF) that might no be valid.  Likewise, the iraf install script edits the iraf paths into key files and the system needs these to be correct.<br>
<br>
Starting with the normal distribution you can download and unpack in a private directory as you would for a system-wide install.  When you run the install script, use the hlib$install.old version to skip the checks and specify some local bin directory for the commands (something already in your path).  The system should work at this point, if you want to do compilation you'll need to define things like $iraf, $host and $tmp in your environment since you won't have a /usr/include/iraf.h file.<br>
<br>
The final v2.15 release will simply much of this by allowing a personal or system installation option, that work is still in preparation.<br>
<br>
-Mike
