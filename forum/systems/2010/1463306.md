**Mike Fitzpatrick** wrote on Jan 09, 2010

{% raw %}
<div>
Because the CL binary seems to start okay, my guess is that the x_system.e binary is the cause of the 'abnormal termination' message.  This usually means there is e.g. a missing (32-bit compatibility?) shared library or a permissions problem.  <br>
<br>
You should go to the $iraf/bin.redhat directory at the unix prompt and try the following<br>
<br>
<pre><code> 
% ldd x_system.e
% ./x_system.e
</code></pre><br>
<br>
The first command will list the required shared libs, look for 'not found' messages.  The second will run the binary directly, if it works you'll see a '&gt;' prompt (type 'bye' to exit) otherwise the host error message might help.<br>
<br>
-Mike
</div>
{% endraw %}
