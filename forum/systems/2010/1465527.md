**Mike Fitzpatrick** wrote on Nov 02, 2010

{% raw %}
<div>
IRAF for Windows requires that you first install Cygwin (cygwin.com), and in addition to the core cygwin release you'll want to install the 'tcsh' shell and X11 system.  IRAF itself can be gotten from the 'Downloads' link on the banner bar, you'll need the as.pcix.gen.gz source distribution as well as the ib.cygw.x86.gz and nb.cygw.x86.gz binaries.  See the PCIX installation guide for details on how to install it all.  The X11IRAF tools (xgterm and ximtool) are also available, you can get DS9 from <a href="ftp://sao-ftp.harvard.edu:/pub/rd/ds9">ftp://sao-ftp.harvard.edu:/pub/rd/ds9</a>
</div>
{% endraw %}

**Mike Fitzpatrick** wrote on Nov 02, 2010

{% raw %}
<div>
The 'bad interpreter' message definitely means you don't have a C-shell installed, the same is probably true for X11.  In the Cygwin Setup panel there should be a category 'Shells', this is where you can select 'tcsh' for installation.  I believe X11 is a category in itself, just install the runtime stuff.
