**Mike Fitzpatrick** wrote on Dec 21, 2015

{% raw %}
<div>
<br>
                Fundamentally, the problem is that you need to install a C-shell in the OS and for some reason the 'apt-get' command isn't working.  That's an issue for another forum or some Googling on your part.<br>
<br>
IRAF-wise, the 'cl' command is being installed as a Bash script, but it appears that within that script lines 95-98 read:<br>
<br>
<pre><code>
    if [ -e $iraf/unix/hlib/irafarch.csh ]; then
        MACH=`$iraf/unix/hlib/irafarch.csh`
    else
        MACH=$os_mach
 </code></pre><br>
<br>
So instead of sourcing the Bash version of the 'irafarch' command it looks for the C-shell version.  Simply editing this script to change the 'csh' to a 'sh' should fix the problem.  There are similar crossovers between shells where the Bash version calls C-shell in <br>
<br>
ecl.sh  <br>
<br>
vocl.sh <br>
<br>
irafuser.sh <br>
<br>
fc.sh<br>
<br>
These should also be edited to change the 'csh' extension to 'sh'.  All of these files live in the $iraf/unix/hlib directory.<br>
</div>
{% endraw %}
