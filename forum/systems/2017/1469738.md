<div>
<br>
                Ok, I finally got it to work.<br>
<br>
I suspected the issue was because most macports libraries are 64 bit. <br>
<br>
Recompiling them with the +universal flag did the trick e.g.<br>
<br>
sudo port -s -v -n upgrade --force xpm  +universal<br>
<br>
sudo port -s -v -n upgrade --force xorg-libXmu  +universal<br>
<br>
Some of the other X11 packages may also need recompiling, but try these first.<br>
<br>
