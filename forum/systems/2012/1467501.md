**Mike Fitzpatrick** wrote on Sep 05, 2012

{% raw %}
<div>
If you've got an older v2.15 system also installed then it may just be that you're using the old 'xc' binary (i.e. you need to rerun the iraf install script for v2.16).  Otherwise, I'd say that you don't have the Posix threads package installed on the machine.  <br>
<br>
XC should automatically include "-lpthread" on the link line, you can verify this using e.g.<br>
<br>
<pre><code>xc -dv foo.x</code></pre><br>
<br>
If you see '-lpthread' at the end of the linker line but still see the error then your sysadmin needs to install the pthread package for your system.  Otherwise, check whether the 'xc' command points to the v2.16 version.
</div>
{% endraw %}
