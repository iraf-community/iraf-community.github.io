**Mike Fitzpatrick** wrote on Jan 23, 2012

{% raw %}
<div>
I think the problem is in how the iraf.lnux.x86.tar.gz file was built, i.e. it includes only the 'bin.linux' directories and not the 'bin.redhat' symlinks that point to bin.linux.  The install script determines the platform architecture by looking for a /etc/redhat-release file (Fedora is a derivative of redhat), however the 'cl' command script uses the more generic output of 'uname' and so comes up with linux as the architecture.  If the symlinks were present (as in the combined iraf-linux.tar.gz files) then this difference doesn't matter.<br>
<br>
I'll fix the distribution for the next release, until then you can just do<br>
<br>
    ln -s bin.linux bin.redhat<br>
<br>
in the $iraf and $iraf/noao directories.
</div>
{% endraw %}
