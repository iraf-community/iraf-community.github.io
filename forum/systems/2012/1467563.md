**Mike Fitzpatrick** wrote on Oct 29, 2012

{% raw %}
<div>
The first thing I would recommend is that you use the latest v2.16 system instead of the much older v2.14 release.<br>
<br>
The error messages mean that the install script is trying to setup your system for a 'macosx' architecture but isn't finding the binaries (probably because you have the 'macintel' binaries instead.  You can define an IRAFARCH variable to override this in the install script, e.g.<br>
<br>
<pre><code>reset IRAFARCH = macintel</code></pre><br>
<br>
This is the first I've heard of somebody trying to use v2.14 on a 10.8 system (one way or the other) so there may be issues with 10.8 not supporting the PPC architecture any longer and so not recognizing the binaries.
</div>
{% endraw %}
