<div>
The problem is that the 'f2c.h' file cannot be found and so the 'C_f' type definition in vosproto.h isn't valid.  Check that $iraf/unix/bin.linux64 contains an f2c.h, and/or that you are compiling the source with a "-I/iraf/iraf/unix/bin.linux64" flag.<br>
<br>
Are you using XC to compile map.c or calling 'cc' directly?

**Mike Fitzpatrick** wrote on Apr 02, 2013

{% raw %}
<div>
My guess then is that you need to compile this file (and those like it) using the '-Inolibc' flag.  If the source includes things like &lt;stdio.h&gt; then without that flag you're getting the stdio.h from hlib$libc and not the host /usr/include that it usually refers to.  You can add a line such as<br>
<br>
<pre><code>$set XFLAGS = &quot;$(XFLAGS) -Inolibc&quot;</code></pre><br>
<br>
to the mkpkg file to set this flag.
</div>
{% endraw %}
