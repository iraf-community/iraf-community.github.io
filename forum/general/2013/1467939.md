**Mike Fitzpatrick** wrote on Dec 02, 2013

{% raw %}
<div>
<br>
<br>
This is a change in behavior (i.e. prints an error instead of continuing with a NULL file) in the v2.16.1 release due to the fact a NULL file would create a segfault, I'm checking with Frank to see if this was the correct fix.<br>
<br>
Normally you would run SETINSTRUMENT to define the translation file, you might also try setting the 'instrument' parameter to the name of an empty file if you have no translations.<br>

**Mike Fitzpatrick** wrote on Aug 13, 2014

{% raw %}
<div>
<br>
                I believe the solution of the previous poster was that you set the instrument parameter to "ccddb$kpno/camera.dat" as the value in epar (e.g. "cl&gt; epar ccdred").  You can also do this on the commandline using<br>
<br>
    cl&gt; ccdred.instrument = "ccddb$kpno/camera.dat"<br>
<br>
but note that the IMRED package must be loaded first.<br>
</div>
{% endraw %}

<br>
                To correct it do:<br>
<br>
1) &gt; epar ccdred<br>
<br>
2) Bring the cursor at Instrument field of ccdred parameters<br>
<br>
3) Click on space key<br>
<br>
4) Click on arrow below (to leave the instrument field empty as it was)<br>
<br>
5) :q (to quit)<br>
</div>
