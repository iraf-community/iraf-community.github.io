If this is new in v2.16 it may be related to the new image template code but is a behavior I haven't seen before.  To go back to using the old code you can do<br>
<br>
<pre><code>cl&gt; reset use_new_imt = no</code></pre><br>
<br>
You can reset this value permanently by editing the hlib$zzsetenv.def file.  Please let me know if this fixes the problem.
