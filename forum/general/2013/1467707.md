# mkobjects : ERROR: No write permission on file (String\_File)

**Stefano Berta** wrote on Jul 03, 2013

{% raw %}
<div>
Hi all, <br>
<br>
I have been working a bit with ARTDATA and MKOBJECTS and I encountered some issue while running it.<br>
<br>
Basically, when using MKOBJ to add some artificial sources on my science maps, I got the error message <br>
<br>
"ERROR: No write permission on file (String_File)"<br>
<br>
This looks a bit strange to me, because I am using IRAF v. 2.14 at the moment, and seeking this forum it seems that this error message is part of the old Y2K bugs. <br>
<br>
I have no control on the IRAF installation here, as it's all centrally structured onto shared disks, hence I cannot trace if this issue is specific of my local setup. <br>
<br>
Anyway, to make the long story short, switching off the "comment" option makes the trick and all works properly, now. <br>
<br>
I thought I'd report this, in case it's a bug that can be fixed. Also it might be worth having a look if other tasks still have a similar trouble.<br>
<br>
Cheers,<br>
Stefano
</div>
{% endraw %}
