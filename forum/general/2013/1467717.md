# IRAF and SAMP

**Robert Janusz** wrote on Aug 22, 2013

{% raw %}
<div>
When I make "callAndWait" to IRAF via a SAMP Hub, I get immediate return to a Client while IRAF still waits doing for example: "scan x" or "implot dev$pix". Is there any method to send the "c" results of "implot dev$pix" to a SAMP Client?
</div>
{% endraw %}

---

**Mike Fitzpatrick** wrote on Aug 22, 2013

{% raw %}
<div>
The short answer is no.  <br>
<br>
The SAMP client in this case is the CL itself and not the tasks it executes.  Because tasks define their own keystrokes it would require modifying each and every task to have it appropriately respond-to or send a message.  The reason you get an immediate return is that e.g. the 'implot dev$pix' command was started successfully, not that it had completed.  It is probably possible to add a "wait until finished' mtype so that your call wouldn't return until the task had finished but that isn't how it currently works.  Still, I'll look into it for the next release (in prep now).
</div>
{% endraw %}
