**Mike Fitzpatrick** wrote on May 10, 2010

{% raw %}
<div>
<pre><code>
cl&gt; artdata
ar&gt; mkpattern foo.fits pattern=checker v1=0 v2=1 ncols=3040 nlines=2016
</code></pre>
</div>
{% endraw %}

**Mike Fitzpatrick** wrote on May 10, 2010

{% raw %}
<div>
For MKPATTERN the options for the pattern are spelled out in the help page.   Note you can do things like invert the v1/v2 values or copy out image sections (e.g. "<li>" to subsample by 3) to invert the pattern or create an offset.  Otherwise, have a look at the IMEXPR task where you can use the array index in an expression to create some sort of pattern.  You also have the option of copying an image/section into the section of an output image to create an arbitrary repeating pattern.
</div>
{% endraw %}
