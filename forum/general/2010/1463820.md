**Mike Fitzpatrick** wrote on Mar 17, 2010

{% raw %}
<div>
Foreign commands like 'gunzip' are executed in a spawned shell, the environment for that shell comes from your .cshrc or .bashrc file depending on the shell used.  If the gunzip command isn't being found, then the PATH defined doesn't include the directory where the command lives.  You can either edit the file to include a path, or try calling the command explicitly with the path, e.g.<br>
<br>
<pre><code>
!/usr/bin/gunzip *.gz
imstat *.fits
!/usr/bin/gzip *.fits
</code></pre>
</div>
{% endraw %}
