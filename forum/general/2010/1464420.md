# Unable to open Parameter Files

**BuffCyclist** wrote on May 24, 2010

{% raw %}
<div>
Hey everyone,<br>
<br>
I finally decided that I wanted to setup iraf on my home desktop. I'm running Ubuntu 10.04 and have iraf installed, however when I go to do a simple command, I get the following error:<br>
<blockquote><br>
cl&gt; imstat MASTER_FINAL_IMAGE.fits<br>
#               IMAGE      NPIX      MEAN    STDDEV       MIN       MAX<br>
 MASTER_FINAL_IMAGE.fits    981060     70.74      234.    -2833.    39662.<br>
Unable to open parameter file `uparm$imlimstas.par'.</blockquote><br>
<br>
So, I look in my /iraf/uparm folder and find the imlimstas.par file, and when I open it up, this is what it reads:<br>
<br>
<blockquote><br>
images,s,a,"foo.fits",,,"List of input images"<br>
fields,s,h,"image,npix,mean,stddev,min,max",,,"Fields to be printed"<br>
lower,r,h,INDEF,,,"Lower limit for pixel values"<br>
upper,r,h,INDEF,,,"Upper limit for pixel values"<br>
nclip,i,h,0,0,,"Number of clipping iterations"<br>
lsigma,r,h,3.,0.,,"Lower side clipping factor in sigma"<br>
usigma,r,h,3.,0.,,"Upper side clipping factor in sigma"<br>
binwidth,r,h,0.1,,,"Bin width of histogram in sigma"<br>
format,b,h,yes,,,"Format output and print column labels ?"<br>
cache,b,h,no,,,"Cache image in memory ?"<br>
mode,s,h,"ql",,,</blockquote><br>
<br>
I've searched online about what this could be, but am not finding anything. The only possible solution I found was to remake the login.cl file, which I've done several times (selecting both Yes and No to "Initialize uparm?") and it hasn't fixed the problem.<br>
<br>
Any help is greatly appreciated! If no one can help me figure it out, I may just go back through and reinstall iraf from scratch and hope that I just missed a step in the installation process.<br>
<br>
Thanks!<br>
<br>
Alright, I have gotten rid of the problem, but I can't determine how to solve it permanently. When I first open a terminal, I have to do the following:<br>
<br>
<blockquote><br>
luna@luna-desktop:~$ cd /iraf<br>
luna@luna-desktop:/iraf$ sudo -i<br>
[sudo] password for luna: <br>
root@luna-desktop:~# cl</blockquote><br>
<br>
Then, when IRAF opens, and I perform the same imstat on the same file, it no longer gives me the "Unable to open parameter file" error.<br>
<br>
Well, turns out it was a matter of write privileges. I ended up going to the main /iraf folder and "chmod 777 login.cl" and the same for uparm. Now it works perfectly!
</div>
{% endraw %}

{% raw %}
<div>
It looks like your iraf files are owned by the 'root' user and not yourself.  This is fine, however you need to run the MKIRAF task to create a login.cl/uparm directory as yourself outside of the iraf tree and then login from there.  The previous message is because you don't have write permissions on the uparm directory/contents and so can't update the files.
</div>
{% endraw %}
