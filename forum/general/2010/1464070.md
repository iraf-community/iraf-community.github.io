**Mike Fitzpatrick** wrote on Apr 13, 2010

{% raw %}
<div>
Hans,<br>
<br>
    Thanks for the report.  Indeed, there was a bug in the code that wasn't properly saving the modified function value before doing the new fit.  This has been fixed for the next release and if you need a patched binary sooner just let me know what platform you're using.  <br>
<br>
Otherwise, I didn't see a problem with changing the e.g. fitrad/psfrad parameters.  Could you provide an example that demonstrates the problem you were seeing?  Remember, you need to type 'f' manually to refit the psf after changing settings.<br>
<br>
-Mike
