**Mike Fitzpatrick** wrote on May 09, 2010

{% raw %}
<div>
XGterm/Xterm and XImtool/DS9 all take a '-geometry' flag that can be used to position a window on the screen.  If you want to position the plot window of an XGterm you can use the '-G' flag or the '%&lt;geom&gt;' option (e.g. "xgterm %320x640+100+100").
</div>
{% endraw %}

**Mike Fitzpatrick** wrote on May 09, 2010

{% raw %}
<div>
Try starting the XGterm with either<br>
<br>
<pre><code>
xgterm -G +0+300        or        xgterm %+0+300
</code></pre><br>
<br>
IRAF has no way to control the window positioning, this is all done in how you start the graphics/display applications (i.e. the xgterm or the ximtool window) outside of IRAF and before you login to the CL.
