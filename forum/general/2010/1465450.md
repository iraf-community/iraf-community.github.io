<div>
The SLALIB routines are available as a library to compiled code only, the procedures don't have script complements.  There is of course the RVCORRECT task that will compute a Barycentric velocity correction, but for time corrections the closest I could find is the DELAYTIME task in the STSDAS.SOBSOLETE.TIMESERIES package.<br>
<br>
You might try Googling for other possibiities, a good start might be <a href="http://astroutils.astronomy.ohio-state.edu/time/bjd_explanation.html">http://astroutils.astronomy.ohio-state.edu/time/bjd_explanation.html</a>

**Mike Fitzpatrick** wrote on Oct 12, 2010

{% raw %}
<div>
You can declare host programs as 'foreign' tasks assuming they are commands somewhere in your normal search environment, e.g.<br>
<br>
<pre><code>task $foo = $foreign</code></pre><br>
<br>
This is roughly the same as doing e.g. "cl&gt; !foo" from the command line.<br>
<br>
As part of a package you do something similar but need to resolve the package name, e.g.<br>
<br>
<pre><code>printf(&quot;$task $foo = $%s/foo\nkeep\n&quot;, osfn(&quot;pkgbin$&quot;)) | cl()</code></pre><br>
<br>
where 'pkgbin' is the logical variable to your package bin directory.  You can use an explicit path, however this is more general.
</div>
{% endraw %}
