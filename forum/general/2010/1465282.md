<div>
RFITS doesn't handle table extensions, for that you'll need to use the STRFITS task in the TABLES.FITSIO package.  If the table is just wavelength/intensity pairs, you might be better off using something like TPRINT to print the table as text, and then use the RSPECTEXT task to create an image with dispersion keywords that SPLOT would understand.
</div>
