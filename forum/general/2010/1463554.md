<div>
A 'segmentation violation' is a generic memory error message:  It can either mean a coding error in the task or perhaps some combination of parameters or corruption in the data is not being caught properly.<br>
<br>
There are no known issues with the task, if you could post your parameters (e.g. "cl&gt; dpar txdump") and the input file being used it should be straightforward to track down if it can be duplicated.  You can also upload these files to the anonftp archive at <a href="ftp://iraf.noao.edu/pub">ftp://iraf.noao.edu/pub</a><br>
<br>
-Mike
</div>
