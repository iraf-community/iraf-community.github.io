<div>
External packages also need to have the sources installed even if you use the pre-built binaries, this is where the parameter files, help etc all live.  <br>
<br>
A 'no param file' either means the sources weren't installed, or the path to the package defined in the hlib$extern.pkg file is wrong (e.g. missing a trailing '/' ???)
</div>
{% endraw %}
