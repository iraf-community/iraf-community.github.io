**Mike Fitzpatrick** wrote on Nov 17, 2010

<div>
The Msky value is actually just an average of the values calculated for the sky region, however there are several methods by which you can fit the sky region.  The help page for the FITSKY task and FITSKYPARS pset has some information, more detailed information on each algorithm can be found in the specification for the APPHOT package (<a href="http://iraf.net/irafdocs/apspec/)">http://iraf.net/irafdocs/apspec/)</a>.  Note also that the psets used to specify the data parameters (e.g. gain, readnoise, etc in the DATAPARS) also play a part in the fit and may be set inappropriately.<br>
<br>
I don't know how the funtools code works so I can't draw a direct comparison.  Hope this helps.
</div>
