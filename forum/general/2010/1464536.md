**Mike Fitzpatrick** wrote on Jun 08, 2010

{% raw %}
<div>
The message only applies to the image header when you specify the sections in the header and the ccdproc.biassec keyword is 'image'.  I presume you have the section directly to the parameter and there is a syntax error of some kind there.  Could you also please post the "dpar ccdproc" output so I can see the parameters you used.<br>
<br>
Note that in image sections, a ':' is used to delimit a range in each dimension, and a ',' (comma) delimits the dimensions.  For example, "[100:200,1:1024]"
</div>
{% endraw %}

**Mike Fitzpatrick** wrote on Jun 08, 2010

{% raw %}
<div>
See the CCDPROC help file description of the parameters:  'biassec' and 'trimsec' are expected to be a valid image section or the string 'image' to tell it to look in the header (your header does not have these keywords).  The boolean value 'no' is causing the problem.

**Mike Fitzpatrick** wrote on Jun 08, 2010

{% raw %}
<div>
In this particular case the problem is that <strong>either</strong> you need to specify the CCDPROC parameters to have the explicit image sections for the e.g. bias and trim sections, <strong>or</strong> you specify the parameter to be 'image' and the header contains those sections in the keywords.  This behavior is task-dependent, in general the task help pages will explain the required keywords.
</div>
{% endraw %}
