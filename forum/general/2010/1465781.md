<div>
The first thing to try is to see whether it is all FITS images, or just the ones you're using, e.g.<br>
<br>
<pre><code>
cl&gt; imcopy dev$pix foo.fits
cl&gt; imstat foo.fits
</code></pre><br>
<br>
If that shows real pixel values then it may be something local to your data (e.g. multiple BSCALE keywords) in which case I'd ask that you upload a sample image to the anonftp at <a href="ftp://iraf.noao.edu/pub">ftp://iraf.noao.edu/pub</a> so I can have a look.  It's not an installation problem I can think of, if it were the tasks wouldn't run at all.
