**Mike Fitzpatrick** wrote on May 07, 2010

{% raw %}
<div>
This is a long-standing problem with DS9 in that it doesn't make use of the file information sent in the display to open the image to read the WCS or pixel values.  The only workaround is to use the File-&gt;Load menu item to have DS9 load the image directly or use another server like XImtool.
