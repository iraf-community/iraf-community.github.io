I am a french student (living in France) and I am ending a physic master<br>

I worked in a group, with two other students. We studied a RR lyrae with<br>
Baade-Wesselink method.<br>
<br>
We had many difficulties to install and configure IRAF for windows<br>
(using Cygwin) and difficulties to learn how to reduce data with IRAF<br>
itself, for spectroscopy and photometry.<br>
Now that we have succeeded in reducing data and making a good report of<br>
our work, we have decided to write documentaiton to help other people to<br>
reduce data with IRAF.<br>
<br>
Maye docs could find place somewhere on you website here:<br>
<a href="http://iraf.noao.edu/iraf/web/tutorials/tutorials.html">http://iraf.noao.edu/iraf/web/tutorials/tutorials.html</a><br>
<br>
Not only we did this doc, but I realized a software for automatic<br>
installation procedure for Cygwin and IRAF with windows. Documentation<br>
for data reduction is also contained inside.<br>
<br>
So, if you are interested in distributing the doc or/and the software<br>
(freeware) you are welcomed!<br>
Our doc was written in french and I translated it in english (also the<br>
software I made in french and english) so maybe a better translation<br>
could have been done and written english could be not so good sometimes<br>
(or many times!!). But it could be useful I think.<br>
<br>
I have compile two versions of the software:<br>
A version that will download all necessary packages on the net (for<br>
cygwin and IRAF); low weight on disk (3,63Mo):<br>

<br>
A version that will install from a local directory containing all<br>

1.7.1 (for cygwin and IRAF); big weight on disk (284Mo):<br>
