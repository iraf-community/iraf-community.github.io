<div>
i think this problem arises because you have an old version of numpy. npy_math.h is new to numpy 1.3,  and defines NPY_NAN<br>
<br>
check your numpy version via <br>
python -c "import numpy; print numpy.version.version"<br>
<br>
if its an old version try updating. if not, see <a href="http://mail.scipy.org/pipermail/numpy-discussion/2009-July/043787.html">http://mail.scipy.org/pipermail/numpy-discussion/2009-July/043787.html</a>, a similar mac specific bug might be causing you problems.<br>
<br>
hope that helps
