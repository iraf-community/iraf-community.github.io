The problem wasn't with scopy at all.  The user had imdir set to a directory that didn't exist, in a directory that was not writable.  Here is an example, run on a Linux machine:<br>
<br>
ecl&gt; set imdir = "/iraf/imdirs/hodge/"<br>
ecl&gt; noao<br>
ecl&gt; onedspec<br>
onedspec&gt; scopy tomul_Y_1176f.fits o8yg.imh renumber+<br>
ERROR: segmentation violation<br>
 "verbose=verbose)"<br>
    line 29: onedspec$scopy.cl<br>
    called as: `scopy (input=tomul_Y_1176f.fits, output=o8yg.imh, renumber=yes)'<br>
<br>
I set imdir to "HDR$", so I hadn't encountered this problem before.<br>

Phil
