Yes, there is a terminal for doing this right.  Use X11, in tcsh... not bash (the default) and there should be a program called AquaTerm that auto starts to do the displays.<br>
<br>
I use the scisoft distribution from the ESO found at:<br>
<a href="http://web.mac.com/npirzkal/Scisoft/Scisoft.html">http://web.mac.com/npirzkal/Scisoft/Scisoft.html</a><br>
That sets everything up nicely.  It also installs the ds9 viewer.  You can also install ds9 directly from its site:<br>
<a href="http://hea-www.harvard.edu/RD/ds9/">http://hea-www.harvard.edu/RD/ds9/</a><br>
Or you can get AquaTerm directly off Sourceforge.net:<br>
<a href="http://sourceforge.net/projects/aquaterm/">http://sourceforge.net/projects/aquaterm/</a><br>
<br>
That should cover it.  That makes your Mac capable of all the IRAF functions<br>
