**Mike Fitzpatrick** wrote on Nov 20, 2010

{% raw %}
<div>
'Grep' is a so-called foreign command, i.e. a host command declared for use in the system but without iraf parameters.  Within a script the syntax for using it is the same as for any other command, but foreign commands can't be used from MKSCRIPT (just edit it in by hand).<br>
<br>
<blockquote><br>
I want grep for the following type of operation: <br>
imhead *.fits long+ | grep &lt;whatever keyword&gt; | sort | unique<br>
</blockquote><br>
<br>
The task you want is HSELECT, see the help page.
</div>
{% endraw %}
