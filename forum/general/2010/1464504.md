**Mike Fitzpatrick** wrote on Jun 04, 2010

{% raw %}
<div>
The 'imextn' environment variable controls which extensions correspond to which image kernels (e.g. try "cl&gt; show imextn").  This can be set in your login.cl file by first uncommenting the value there and then adding 'fts' to the list of FITS extensions.<br>
<br>
Alternatively, the RENAME task can change the extension to .fits automatically, i.e.<br>
<br>
<pre><code>cl&gt; rename *.fts fits field=extn</code></pre><br>
<br>
If by "lose information in the header" you mean DS9 doesn't see the WCS when you use DISPLAY, this is a separate issue (and a long-time problem that requires a change in DS9 to fix).  The "set fts=fits" thing shouldn't actually do anything to help.<br>
<br>
-Mike
</div>
{% endraw %}
