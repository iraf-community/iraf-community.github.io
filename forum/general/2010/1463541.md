<div>
The 'no param file' usually means:<br>
<br>
1) you installed only the binary distribution, not the the source (needed even if you don't build from them, they contain param files, help etc) as well<br>
2) you declared the package in hlib$extern.pkg but without a trailing '/' in the path name (do "cl&gt; show mscred" to see the current value, make sure it's correct)<br>
3) the last line of your hlib$extern.pkg file is not 'keep'<br>
4) there is a permissions problems and the files aren't readable.<br>
<br>
-Mike
</div>
