<div>
PSELECT actually reads the header stuff in the table and is processing according to the formats specified for the columns.  TVMARK on the other hand is simply writing numbers with no regard to the format in an existing table.<br>
<br>
There no real way to change this in either task.  About the best you could do is write a small script to reformat the tvmark columns and put them in .coo.1 format.
