<div>
If you just want to batch process all your images in CCDPROC, and have no Imagetype, simply leave the field "Image Type" blank. I.e.: write a "space" in it and use a list or the asterisk to "*" process all your files.<br>
<br>
cheers<br>
<br>
e.g.:<br>
<br>
images  =                 GD358*.fits  List of CCD images to correct<br>
(output =                    ) List of output CCD images<br>
(ccdtype=                    ) CCD image type to correct<br>
(max_cac=                 1024) Maximum image caching memory (in Mbytes)<br>
(noproc =                   no) List processing steps only?<br>
<br>
or use lists. ;)
</div>
{% endraw %}

**AnTaR3s** wrote on May 16, 2010

{% raw %}
<div>
Maybe I don't understand what you want to do, but in the "ccdtype" field you write the type of images you want to correct. E.g.: In your Lightframes the Imagetype in the header is set to "Light". The you do the following:<br>
<br>
PACKAGE = ccdred<br>
   TASK = ccdproc<br>
<br>
images  =                 foo*  List of CCD images to correct<br>
(output =                     ) List of output CCD images<br>
(ccdtype=                Light) CCD image type to correct<br>
(max_cac=                 1024) Maximum image caching memory (in Mbytes)<br>
(noproc =                   no) List processing steps only?<br>
<br>
(fixpix =                  yes) Fix bad CCD lines and columns?<br>
(oversca=                  yes) Apply overscan strip correction?<br>
(trim   =                  yes) Trim the image?<br>
(zerocor=                  yes) Apply zero level correction?<br>
(darkcor=                  yes) Apply dark count correction?<br>
(flatcor=                  yes) Apply flat field correction?<br>
(illumco=                   no) Apply illumination correction?<br>
(fringec=                   no) Apply fringe correction?<br>
(readcor=                   no) Convert zero level image to readout correction?<br>
(scancor=                   no) Convert flat field image to scan correction?<br>
<br>
(readaxi=               column) Read out axis (column|line)<br>
(fixfile=           Badpix.lis) File describing the bad lines and columns<br>
(biassec=                image) Overscan strip image section<br>
(trimsec=                image) Trim data section<br>
(zero   =                mBias) Zero level calibration image<br>
(dark   =                mDark) Dark count calibration image<br>
(flat   =              mHAflat) Flat field images<br>
(illum  =                     ) Illumination correction images<br>
(fringe =                     ) Fringe correction images<br>
(minrepl=                   1.) Minimum flat field value<br>
(scantyp=            shortscan) Scan type (shortscan|longscan)<br>
(nscan  =                    1) Number of short scan lines<br>
<br>
...<br>
<br>
With this setup the frames with the name foo* (everything with foo at the beginning) AND imagetype "Light" will be corrected using a badpixel-file, the overscan-region defined in the header, zero- and darkframe, flat-field (the masterframes created before) and finally trimmed...so, your bias subtraction and flattening are done in batch mode.<br>
<br>
cheers<br>
<br>
edit: If you do not write "Light" in the type-field (simply write a "space"), the process will run on every image with the name foo* with the same processes and of course in batch mode.
</div>
{% endraw %}
