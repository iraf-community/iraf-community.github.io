**Mike Fitzpatrick** wrote on Nov 02, 2010

<div>
The current MKIRAF command expects to read input from stdin in response to prompts.  You can deal with this in a C-shell script by providing the input by redirection, e.g.<br>
<br>
<pre><code>
if (-e uparm) then
mkiraf &lt;&lt; EOF_MIRAF1 &gt;&amp; /dev/null
y
xgterm
EOF_MKIRAF1
else

mkiraf &lt;&lt; EOF_MKIRAF2 &gt;&amp; /dev/null
xgterm
EOF_MKIRAF2

endif
</code></pre><br>
<br>
Note that if you have an existing uparm dir you'll be prompted whether to initialize it and so the first case takes care of that, otherwise only the terminal type will be set.<br>
<br>
This seemed a reasonable thing to do so for v2.15 I've added args to the MKIRAF script to do this automatically, e.g.<br>
<br>
<pre><code>
mkiraf -t xgterm -i -q
</code></pre><br>
<br>
where the '-t &lt;term&gt;" sets the terminal type, "-i" will initialize a uparm dir, and '-q' will suppress any output.
</div>
