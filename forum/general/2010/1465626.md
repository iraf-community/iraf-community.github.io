**Mike Fitzpatrick** wrote on Nov 28, 2010

{% raw %}
<div>
Scripts typically have ".cl" file extensions, so you can just browse the system for .cl files.  A more automated way is e.g.<br>
<br>
<pre><code>% cd $iraf
% find . -name \*.cl -print -exec egrep -e ^task {} \; | egrep -e &quot;\.cl&quot; 
</code></pre><br>
<br>
and you'll get a list of all task declarations and the script source name.
