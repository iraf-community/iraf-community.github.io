**Mike Fitzpatrick** wrote on Jul 02, 2010

{% raw %}
<div>
The task is actually a script and there are three temp files created for different reasons, but the message isn't enough to distinguish which of those three files is the problem.  Assuming all is well in terms of writing to the tmp directory, you might also see the message if e.g. the 'fields' param is incorrect for the input file since this is used to create one of the files.<br>
<br>
Two things to try:  Do an "unlearn mscred" to reset all of the package parameters, and/or type "d_trace" before running the task to print out more information about what the script is doing before the message.  If you don't understand the output of the latter then please just post it.
</div>
{% endraw %}
