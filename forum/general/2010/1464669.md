# Problems putting hselect result into variables

**Felipe Navarete** wrote on Jul 14, 2010

{% raw %}
<div>
Hi there!<br>
I'm trying to add the result from hselect into a variable in a cl script. I'm doing it in the following way:<br>
<br>
string object<br>
arquiv="file.fits"   #calls the file which I'm working<br>
hselect (arquiv,"OBJECT",yes) | scan(object)<br>
<br>
The problem comes because the field OBJECT is filled with expressions and not just by a single word. When I print "object", only the first word were recorded.<br>
<br>
For example, the OBJECT content is "Object Filter H2" and the object variable just recorder "Object". Any suggestion for solving it?<br>
<br>
Cheers,<br>
Felipe Navarete
</div>
{% endraw %}

**Mike Fitzpatrick** wrote on Jul 14, 2010

{% raw %}
<div>
Instead of "string object", use "struct object"   This will allow you to store all the words in the value.
</div>
{% endraw %}
