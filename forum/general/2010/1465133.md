<div>
<blockquote>Could it be due to the file size of images? one has around 2.5 gb.<br>
</blockquote><br>
<br>
That would do it.  You'll need the IRAF v2.15 system in order to deal with files &gt;2GB in size and other 64-bit issues.  Prior to that, IRAF is a 32-bit system and so the filesize would be a problem.  Similarly, a "64-bit filesystem" would have inodes that exceed 32-bits and so the files where the inode exceeds 32-bit wouldn't be visible/readable to IRAF.  Another problem might be the machine name, e.g. "Arp's Machine" is a problem in the node!path syntax due to the space in the name.<br>
<br>
In any case, you'll need v2.15 to at least deal with the large files.
