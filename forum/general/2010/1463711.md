<strong>What my script does?</strong><br>
Follwoing procedure script finds std. deviation of each image.<br>

Then pass this variance to a text file.<br>
This is done for all the images in the image-list.<br>

I get the text file containing variances (variance_of_all_images.txt),<br>

<div>
I think the problem is that you're using printf() which is expecting a format string, you should be using print() instead.  For example<br>
<br>
<pre><code>

printf (&quot;%g\n&quot;, sigma, &gt;&gt; &quot;foo.txt&quot;)

or

print (sigma, &gt;&gt; &quot;foo.txt&quot;)
</code></pre><br>
<br>
-Mike
