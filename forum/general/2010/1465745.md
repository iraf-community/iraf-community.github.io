**Mike Fitzpatrick** wrote on Dec 13, 2010

{% raw %}
<div>
The 'missing' parameter was added in v2.14, so specifying it for the version of the task in v2.12 without that parameter is an error.  Assuming you are using the ECL under v2.12.2a (it wasn't the default until v2.13), you can remove the use of 'missing' from the HSELECT calls and add the lines<br>
<br>
<pre><code>
    iferr {
        hselect.missing = &quot;&quot;
    } then {
        ;
    }
</code></pre><br>
<br>
Note however this will be a different syntax error under v2.12 using the old CL.  <br>
<br>
My guess is, simply removing the use of the 'missing' parameter will be good enough.
</div>
