**Mike Fitzpatrick** wrote on Mar 28, 2012

{% raw %}
<div>
Assuming you're on a v2.15 64-bit system, this is a known issue in the FITS kernel caused by the use of BSCALE/BZERO values in the header.   This has been fixed in the recent v2.16 release, but unfortunately if you want to patch a v2.15 system you'll need to relink your system with patched 'libex.a' and 'libvops.a' libraries available from<br>
<br>
<a href="ftp://iraf.noao.edu/iraf/v215/support/&lt;arch&gt;">ftp://iraf.noao.edu/iraf/v215/support/&lt;arch&gt;</a>;<br>
<br>
Relinking should then just be a matter of<br>
<br>
<pre><code>% cd $iraf
% make linux64
% make update</code></pre><br>
<br>
If you still have problems let me know, your image worked fine for me under v2.16.
</div>
{% endraw %}
