<div>
Hi, I believe I have found a solution to the problem.<br>
Some tasks are passing a "NULL" file around. This should be equivalent to "" in iraf, but for some reason iraf searches for an actual file called NULL, and since it can not find it, it crashes with an error. So I just replaced NULL with ""  in the files gemhedit.cl and ggain.cl. These tasks are found in the gemtools package and gmos package within the parent gemini iraf external package.<br>
<br>
After this little "hack" gprepare works alright.
</div>
{% endraw %}
