**Mike Fitzpatrick** wrote on Jul 04, 2012

{% raw %}
<div>
This has been fixed and only affects the new VOCL (background jobs were incorrectly using the ECL binary).  For 64-bit linux you can get a new binary at<br>
<br>
<a href="ftp://iraf.noao.edu/iraf/v216/support/linux64/vocl.e">ftp://iraf.noao.edu/iraf/v216/support/linux64/vocl.e</a><br>
<br>
Just download in binary mode and install in your $iraf/bin.linux64 directory.  Thanks again for the report.
</div>
{% endraw %}
