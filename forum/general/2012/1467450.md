**Mike Fitzpatrick** wrote on Jul 13, 2012

{% raw %}
<div>
Be sure your terminal type isn't set to 'xgterm' if you are in fact using an 'xterm' window.  Use the command<br>
<br>
<pre><code>cl&gt; stty xtermjh</code></pre><br>
<br>
to reset the terminal type,  edit your login.cl file manually, or else do a new MKIRAF to reset the terminal type.  <br>
<br>
The XGterm binary is a separate installation in the X11IRAF tools from<br>
<br>
<a href="ftp://iraf.noao.edu/iraf/x11iraf/">ftp://iraf.noao.edu/iraf/x11iraf/</a><br>
<br>
Be sure to get the x11iraf-v2.0BETA-bin.&lt;arch&gt;.tar.gz appropriate for your machine.
</div>
{% endraw %}
