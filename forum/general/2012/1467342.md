**Mike Fitzpatrick** wrote on May 01, 2012

{% raw %}
<div>
Re: the imdel segfault:<br>
<br>
There used to be a bug caused by the 'cache' environment variable being set to "/tmp" but this should be fixed in the version you have.  In any case, do a "cl&gt; show cache" and make sure 1) it isn't set to /tmp and 2) that the path has a trailing '/' on it.  Do something like "cl&gt; reset cache = uparm$" if you need to reset a /tmp value.<br>
<br>
When you're ready with the login info just send it to admin-at-iraf.net and I'll have a look.  Until then, if you can get a core dump from the error (e.g. do a "limit coredumpsize unlimited" in a C-shell before start IRAF) you can post that to <a href="ftp://iraf.noao.edu/pub">ftp://iraf.noao.edu/pub</a> and I'll see what that tells me on my machine.
</div>
