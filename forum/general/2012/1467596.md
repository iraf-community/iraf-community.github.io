**Mike Fitzpatrick** wrote on Dec 29, 2012

{% raw %}
<div>
Sure.  The extensions are controlled by the 'imextn' iraf environment variable which is set globally in the hlib$zzsetenv.def file, or can be uncommented and reset in your login.cl, or set on the command line.  The default value is<br>
<br>
<pre><code>set  imextn          = &quot;oif:imh fxf:fits,fit plf:pl qpf:qp stf:hhh,??h&quot;</code></pre><br>
<br>
where the 'fxf' refers to the FITS kernel.  By putting the "fit" before the "fits" you'll use ".fit" as default extension for this kernel, e.g. "fxf:fit,fits".<br>
<br>
Note the 'imtype' variable controls the default image type created for filenames without an extension, it will normally says 'fits' but this only indicates the file type, the 'imextn' options will control the actual extension.  For example,<br>
<br>
<pre><code>
cl&gt; set  imextn          = &quot;oif:imh fxf:fit,fits plf:pl qpf:qp stf:hhh,??h&quot;
cl&gt; imcopy dev$pix foo
</code></pre><br>
<br>
will create a 'foo.fit' file.
</div>
{% endraw %}
