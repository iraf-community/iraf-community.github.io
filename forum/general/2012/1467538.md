**Mike Fitzpatrick** wrote on Oct 12, 2012

{% raw %}
<div>
I wasn't able to reproduce the problem with the most recent development version of IRAF v2.16, but could confirm it in the SciSoft release (March2012) and that it is also fixed in the most recent May2012 update to the system.  To fix it on your machine, all you should need to do is<br>
<br>
<pre><code>
% cd /usr/local/scisoft/packages/iraf/iraf/
% make latest
</code></pre><br>
<br>
This should update your IRAF scisoft installation with the May2012 release and fix the problem.  If not, let me know.
</div>
{% endraw %}
