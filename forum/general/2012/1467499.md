<div>
The "if (!defvar("helpdb"))' line isn't part of any of the core IRAF startup scripts, neither is it in anything in SciSoft from what I can tell, so I'm guessing this is either a local loginuser.cl file or some modification to the login.cl file that you've made.<br>
<br>
The syntax error is probably coming from a known CL quirk where an if-statement sometimes needs to be terminated by a semicolon to avoid an ambiguity in determining whether an 'else' is expected.  That is, the code might need to be something like<br>
<br>
<pre><code>
if (!defvar (&quot;helpdb&quot;)) {
   ....some stuff
}
;
</code></pre><br>
<br>
If you still have problems and have a loginuser.cl file feel free to post it (or try moving it temporarily to verify that fixes the problem).
</div>

**Mike Fitzpatrick** wrote on Sep 05, 2012

{% raw %}
<div>
In this case it sounds more like a value of $iraf is being set without the trailing '/', e.g. in your .cshrc you have something like<br>
<br>
setenv iraf   /iraf/iraf<br>
<br>
instead of<br>
<br>
setenv iraf /iraf/iraf/<br>
<br>
Even though you explicitly give a path to a CL binary, the $iraf value is used in constructing other paths in the system, and when those are incorrect you see the  'has no param file' message.  Note that if you don't define $iraf in your .login or .cshrc, it might be defined in e.g. a scisoft 'Setup.csh' that's loaded in there.  If it isn't defined at all, look at the /usr/include/iraf.h to see how it is set there, if its missing the '/' then you should rerun the install script to specify the path *with* a trailing '/'.
</div>
{% endraw %}

**Mike Fitzpatrick** wrote on Sep 05, 2012

{% raw %}
<div>
I found out recently this 'defvar' is coming from a script called 'install_helper' in some STScI distribution of STSDAS/TABLES/STCECF.  The syntax is actually invalid and should be replaced with<br>
<br>
<pre><code>
    if (defvar(&quot;helpdb&quot;) == no) {
              :
</code></pre><br>
<br>
Either make the change in the hlib$extern.pkg file or the template used by install_helper in stsci_iraf_x/release_tools/extern.pkg.proto<br>
<br>
If you're using v2.15 or later the dynamic package installation will do just as well to install STSDAS.
</div>
{% endraw %}
