**Mike Fitzpatrick** wrote on Jun 10, 2012

{% raw %}
<div>
You can startup using the 'ecl' command instead of 'cl' (or change the symlinks or private aliases as needed).  The ECL/VOCL are the same except for the VO-specific features of the VOCL needed to run the VO package, but if you don't want the VO stuff you never have to use it.  Otherwise the only way to change the prompt is to load a package.
</div>
