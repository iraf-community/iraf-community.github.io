**Philip Massey** wrote on Jun 11, 2012

{% raw %}
<div>
This isn't rocket science.  In calculating the error on aperture photometry, you add the relative sources of error in quadrature: the read-noise, the photon noise front he object, and the photon noise from the sky.  With PSF fitting it's a little bit trickier.  This is all well documented in the various papers Peter Stetson has written on daophot.  See, for example,<br>
<a href="http://adsabs.harvard.edu/abs/1987PASP...99..191S">http://adsabs.harvard.edu/abs/1987PASP...99..191S</a><br>
<a href="http://adsabs.harvard.edu/abs/1989HiA.....8..635S">http://adsabs.harvard.edu/abs/1989HiA.....8..635S</a><br>
<a href="http://adsabs.harvard.edu/abs/1990ccd2.proc...71S">http://adsabs.harvard.edu/abs/1990ccd2.proc...71S</a>
