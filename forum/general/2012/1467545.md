<div>
If you're saying the memory used by the x_images.e binary is growing and you eventually get an 'out of memory' error, then this is a new bug I would have to fix.  OTOH, if you're saying the memory usage reported by 'top' or 'free' grows with each image the I would say this is normal in the the sense that the system will try to cache data in memory (and swap out what's unneeded) all the time.<br>
<br>
You can try inserting the command 'flpr 0' (zero, not oh) into your script to force the x_images.e binary to restart, but this won't have any effect on the system memory caching (which you shouldn't worry about anyway).
</div>
