# literal ^ in strings

**Jason Quinn** wrote on Oct 25, 2012

{% raw %}
<div>
I've noticed a issue with literal carets in strings. This arose because I was trying to use the match task in a script. I wanted to do a command like<br>
<br>
<pre><code>match &quot;^1&quot; myfile</code></pre><br>
<br>
to list all lines that begin with the number 1. This however doesn't work. I can escape the caret:<br>
<br>
<pre><code>match &quot;\^1&quot; myfile</code></pre><br>
<br>
and it will work.<br>
<br>
There are several related points. The help for match doesn't suggest the escape needs to be used for the caret. And recalling the command using the up arrow keys starts stripping away escapes until the caret-number combination is interpreted as a history recall. Not sure what the intended behaviour is here.<br>
<br>
The history mechanism does act weird here though.<br>
<br>
Cheers,<br>
Jason
</div>
{% endraw %}
