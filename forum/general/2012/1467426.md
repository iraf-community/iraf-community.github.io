# daofind bug when starmap and/or skymap parameters blank

**Jason Quinn** wrote on Jul 01, 2012

{% raw %}
<div>
For the <strong>daofind</strong> task, if the starmap or skymap parameters are blank (such as a space), daofind will delete the input image and exit with error. (Adding a null prefix equals the input filename, which is the source of the problem.) This could lead to data loss when people try to clear previously set prefixes. I am using IRAF 2.16 64-bit linux. To reproduce, try creating a starmap and/or skymap and then blanking the entry for a second run.<br>
<br>
Cheers,<br>
Jason<br>
