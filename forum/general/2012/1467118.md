<div>
See the COUNT task (similar to unix 'wc'), e.g.<br>
<br>
<pre><code>

count (&quot;/dev/null&quot;) | scan (nlines, nwords, nchars, fname)
if (nchars == 0) {
    # file is empty ....
}

</code></pre>
