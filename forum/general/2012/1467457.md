<div>
Hi Andrej,<br>
<br>
I've just installed IRAF in my iMac, and it's very simple. No special iraf user account is actually required.<br>
<br>
Create the /iraf/iraf/ directory:<br>
sudo mkdir -p /iraf/iraf<br>
<br>
Unpack there the tarfile <br>
cd /iraf/iraf/<br>
sudo tar -zxvf /path/to/iraf.macx.x86_64.tar.gz<br>
<br>
Define the iraf variable<br>
export iraf="/iraf/iraf/"<br>
<br>
Run the install script<br>
sudo /iraf/iraf/unix/hlib/install<br>
The default answers should be fine, I only changed imdir and cache which I set to /tmp/imdir and /tmp/cache.<br>
<br>
After this step is completed, you should have a bunch of IRAF-related executables in /usr/local/bin (this directory should already be in your path, check with echo $PATH).<br>
<br>
Initialize IRAF with:<br>
mkdir ~/iraf ; cd ~/iraf<br>
mkiraf<br>
<br>
Then type ecl to start IRAF.<br>
<br>
Cheers<br>
<br>
Nicola

<div>
I personally prefer the command line to the GUI when installing things. Perhaps when you created the /iraf/iraf/ directory from the GUI it got user's ownership rather than root's, thus the problems with wrong permissions.<br>
<br>
As for xgterm, you need to download the macintel version of the X11iraf package, untar it, and put the xgterm executable in your path. For example<br>
sudo mkdir  /iraf/X11-iraf<br>
cd /iraf/X11-iraf/<br>
sudo tar -zxvf /path/to/x11iraf-macintel-tarfile<br>
cd /usr/local/bin/<br>
sudo ln -sf /iraf/X11-iraf/bin.macintel/xgterm<br>
<br>

<div>
Make sure that you are actually running IRAF in a xgterm.<br>
Type xgterm, and a new terminal window should open up. There, cd to your iraf directory:<br>
cd ~/iraf/ <br>
and then launch IRAF.<br>
At the IRAF prompt, type "stty". The answer should be something like "xgterm ncols=101 nlines=29". If not, reset the terminal by typing "stty xgterm" and try imexamine again.<br>
<br>
As for galaxy photometry, I think that's a whole new subject and perhaps deserves its own thread. Packages that could be useful are phot and analysis (in stsdas). I think there are also several posts in the forum about galaxy photometry.<br>
