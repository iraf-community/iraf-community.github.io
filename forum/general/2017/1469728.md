<div>
<br>
<br>
There are still a number of unresolved 64-bit issues with some DAOPHOT tasks, so if you are on a Mac or 64-bit linux system then the first to to try would be to use the 32-bit binary instead to see if it resolves the problem.  These can be found at<br>
<br>
    ftp://iraf.noao.edu/iraf/v216/support/macosx/x_daophot.e            # to replace your iraf$noao/bin.macintel/x_daophot.e<br>
<br>
    ftp://iraf.noao.edu/iraf/v216/support/linux/x_daophot.e                 # to replace your iraf$noao/bin.linux64/x_daophot.e<br>
<br>
Download the files in binary mode, reset the execute permissions and install in the appropriate directory.<br>
<br>
If that doesn't fix the problem, then please post a sample image header so we can check for possible WCS issues.<br>
</div>
