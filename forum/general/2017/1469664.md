Attached is the wcsdb file used by the current Mosaic3 pipeline.  Is there some reason you don't want to use the NOAO pipeline reduced data?<br>
<br>
Yes mscgetcat has become fragile because it depends on external websites.   I asked our local IRAF systems expert and he remembered this discussion on the IRAF forum:<br>
<br>
http://iraf.net/forum/viewtopic.php?showtopic=1469342<br>
<br>
I tried the suggested fix (for the @noao entries) of replacing references to archive.tuc.noao.edu with r2.sdm.noao.edu in the file catdb.dat in the mscred source directory.  You will obviously need to have permission on the file or find someone who does.  The location is $iraf/extern/mscred/src/catdb.dat where $iraf is the root of the iraf installation.  It should also be possible to use a personal file in your working area but I would have to figure out what would need to be changed to reference it instead.<br>
