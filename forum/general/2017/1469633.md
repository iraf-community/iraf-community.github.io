**Mike Fitzpatrick** wrote on May 09, 2017

{% raw %}
<div>
<br>
                Thanks for the report, the task declaration is incorrect.  The solution is to do<br>
<br>
    cl&gt; sptable                                  # load packages<br>
<br>
    cl&gt; xonedspec<br>
<br>
    cl&gt; copy xonedspec$scombine.par xonedspec$scombine/scombine.par<br>
<br>
You should then be able to do "lpar scombine" or run the task normally.<br>
</div>
{% endraw %}
