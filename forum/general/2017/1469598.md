**Mike Fitzpatrick** wrote on Apr 11, 2017

{% raw %}
<div>
<br>
                The CL (actually the ECL or VOCL depending on your version) is hanging at the "stty xgterm" command in the login.cl file because of the input redirection.  Even if you don't have a login.cl in the current directory, the system may be picking up the global one from your $HOME/.iraf/login.cl file.<br>
<br>
To fix it, you can either create an empty login.cl in the same directory as the script (e.g. "touch login.cl"), comment out the 'stty' command from your login.cl, or else use the original version of the CL that doesn't have this problem.  For example<br>
<br>
    % cl -o <br>
</div>
{% endraw %}
