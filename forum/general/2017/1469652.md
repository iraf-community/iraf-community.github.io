<div>
<br>
                CL is meant to be used interactively, not within a script.<br>
<br>
You can however "abuse" the feature to load an alternative startup script to run a command -- this is the common way to run scripts:<ul><br>
<li> add a line "logout" at the end of your script<br>
<br>
</li><li> run it with "cl -f /home/sap/Script/clean_photo.cl"<br>
 </li></ul><br>
