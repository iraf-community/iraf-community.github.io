<div>
<br>
                Try putting a ';' after the closing '}' of the if-clause and before the closing brace of the 'while', i.e.<br>
<br>
<pre><code>
    while (....) {
        if (....) {
        }
        ;        &lt;------- ADD THIS
    }
 </code></pre><br>
<br>
There is a longstanding ambiguity in the grammar where an if-stmt is looking for a following 'else' clause, adding the semicolon explicitly terminates the 'if' statement.  A dummy "junk = 0" statement would do the same thing.<br>
</div>
