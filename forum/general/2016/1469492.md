# Rebin to simple wcs using output from ccmap

{% raw %}
<div>
<br>
                We have used ccmap to create a database file (.db) containing 3rd order polynomial coefficients to link CCD pixel coordinates to sky RA DEC coordinates using GAIA stars. We now want to use this database file to rebin the image into a linear image with specified pixel scale and simple wcs in the fits header (to allow straightforward over-plotting with other data).  Is there a single task that will do this?  <br>

<br>
The task to use is MSCIMAGE.  This is found either in the MSCRED or NFEXTERN.MSCTOOLS packages (I recommend NFEXTERN as more current).  These can be easily installed if you don't have it.  MSCIMAGE works from the header WCS to some other WCS specified by parameters or by reference to another image to be matched.  So you need to get the CCMAP solution into the header WCS.  This happens automatically if you used the update option of CCMAP on the image.  Alternatively the task CCSETWCS can be used to transfer a CCMAP database solution to an image WCS.<br>
<br>
Let me know if you need more details.<br>
