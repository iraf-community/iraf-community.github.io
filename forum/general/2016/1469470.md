<br>

test 2<br>

(ok)<br>
<br>
(in iraf)<br>

<br>

ERROR: Cannot change directory to 'test 2'<br>
<br>
called as ...<br>

<br>

<br>

**Mike Fitzpatrick** wrote on Oct 18, 2016

{% raw %}
<div>
<br>
                Spaces in directory names aren't supported in IRAF.  The usual workaround is to create a symlink without spaces (e.g. 'Seagate_HD' in your case) and use that in the path name.<br>
</div>
{% endraw %}
