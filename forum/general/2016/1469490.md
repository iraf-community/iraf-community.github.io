<div>
<br>
                The '//' is a string concatenation operator, so the final expression written to the file (assuming the variable n_i=123) would be something like<br>
<br>
    z123 * (nclus == 123) + 1000. * (nclus != 123)<br>
<br>
where I'm guessing 'z123' and 'nclus' are then valid column names in the table.  The trick is that the logical expressions will return either a 0 (false) or 1 (true) value so when 'nclus=123' the expression is just the value of the 'z123' column, otherwise it's a flag value of 1000. <br>
