# fields task keeps asking

**Gabriel** wrote on Nov 04, 2016

{% raw %}
<div>
<br>
                I can't seem to be able to run the 'fields' task without it asking me to input the 'Fields to extract'.<br>
<br>
This happens even with mode='h'.<br>
<br>
Example:<br>
<br>
ecl&gt; fields.mode='h'<br>
<br>
ecl&gt; fields.fields='1,2'<br>
<br>
ecl&gt; fields.lines='1'<br>
<br>
ecl&gt; fields.files='test.dat'<br>
<br>
when I run the task:<br>
<br>
ecl&gt; fields<br>
<br>
I get:<br>
<br>
ecl&gt; Fields to extract (1,2):<br>
<br>
aaa   bbb   <br>
<br>
Why is it not working silently?<br>
<br>
The 'test.dat' file I'm using contains this:<br>
<br>
aaa bbb ccc<br>
<br>
123  456 45<br>
<br>
789  654 66<br>
<br>
</div>
{% endraw %}

**Mike Fitzpatrick** wrote on Nov 14, 2016

{% raw %}
<div>
<br>
                The 'fields' parameter is a query parameter so you need to change the mode of that one parameter, not just the entire task.  For example,<br>
<br>
   cl&gt; field.fields.p_mode = "h"<br>
<br>
will do what you want.<br>
</div>
{% endraw %}
