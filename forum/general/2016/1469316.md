{% raw %}
<div>
<br>
                Try setting:<br>
<br>
    cl&gt; reset use_new_imt = no<br>
<br>
This will by pass the new image template code and use the older version.  You can make the change permanent by setting this in your login.cl file or by editing the system hlib$zzsetenv.def value.<br>
