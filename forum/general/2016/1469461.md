{% raw %}
<div>

<br>
FWIW, it appears that there are NO new issues to report wrt IRAF, X11IRAF or DS9 under the new OSX 'Sierra' release.  It is possible that if upgrading from Yosemite (or earlier versions os OSX) some of the problems experienced with the El Capitan upgrade may resurface (see e.g. http://iraf.net/forum/viewtopic.php?showtopic=1469385) but can likely be resolved with a fresh install of XQuartz.  Overall I'd say the upgrade is pretty painless and my machine even seems noticeably quicker.<br>

                As a followup.... It appears the 'ism_wcspix.e' binary used by XImtool to compute the WCS coords fails under Sierra due to a binary incompatibility and 64-bit issue  The code has been patched and new binaries for affected platforms are available from<br>
<br>
    ftp://iraf.noao.edu/iraf/v216/support/macintel/ism_wcspix.e<br>
<br>
    ftp://iraf.noao.edu/iraf/v216/support/macosx/ism_wcspix.e<br>
<br>
    ftp://iraf.noao.edu/iraf/v216/support/linux64l/ism_wcspix.e<br>
<br>
Download the binary, make it executable and install in the $iraf/vendor/x11iraf/bin. directory.<br>
<br>
An X11 error when closing XImtool using the red window button has also been reported but at this time there is no workaround other than to exit XImtool using the 'Quit' button.<br>
</div>
