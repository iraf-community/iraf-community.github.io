**Mike Fitzpatrick** wrote on Mar 10, 2016

{% raw %}
<div>
<br>
                The are compressed image files but missing the ".fz" extension.  You can add the extension using the command:<br>
<br>
    cl&gt; rename *.fits fz field=extn<br>
<br>
to rename all the files.  After that, the FUNPACK task in the FITSUTIL external package, or the 'funpack' command from the CFITSIO distribution outside of IRAF, can be used to uncompress the files.<br>
</div>
{% endraw %}
