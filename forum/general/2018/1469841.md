**Rob Steele** wrote on May 31, 2018

{% raw %}
<div>
<br>
                If you look into the original 64-bit Linux binary of IRAF, there is x_photcal.e that replaced the 32 bit version. This makes problems if the system cannot run 32 bit executables, for example on the Windows subsystem for Linux (WSL).<br>
<br>
The replacement was probably done because in 2.16.1 x_photcal has a lot of bugs on 64 bits which lead to crashes, f.e. in the "fitparams" task. More information on this is found at:<br>
<br>
https://github.com/iraf/iraf-v216/issues/128<br>
<br>
The problem is fixed in the development version of IRAF (which is f.e. included in Ubuntu 18.04). The fix is in<br>
<br>
https://github.com/iraf/iraf-v216/pull/130<br>
<br>
However, Fitz has "archived" the development repository of IRAF so that no further changes can be made.<br>
<br>
@rjvo: can you try the version that comes with Ubuntu 18.04 and report back if that works for you?<br>
<br>
</div>
{% endraw %}
