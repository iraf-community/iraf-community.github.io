**mlgubolin** wrote on Apr 27, 2018

{% raw %}
<div>
<br>
                Hi guys! How are you? <br>
<br>
After this catchy title I really want to discuss something really serious, which is how old and outdated IRAF's code is.<br>
<br>
I mean, the code itself is excellent, but it was written in a completely different era and a total rewrite my be huge work but I really think that the benefits exceed the problems.<br>
<br>
I have a plan. We should rewrite it in a modern, concurrent language, which REALLY supports modern computers and takes advantage of it. I think the best option is Rust (https://www.rust-lang.org/) that is also a open source language, safe and made by Mozilla to create the new Firefox Quantum (https://blog.rust-lang.org/2017/11/14/Fearless-Concurrency-In-Firefox-Quantum.html).<br>
<br>
The thing is that I cannot do it alone. This is a HUGE project and help will be most accepted <br>
<br>
So, who's in?<br>
<br>
PS: I'm not working with IRAF anymore, since I left academy for a programming job, but I really wanted to use my knowledge of both areas to help astronomers.<br>
<br>

<br>
                First of all, sorry for the late reply. I was starting a new job and I was dealing with all problems related to it.<br>
<br>
@robsteele49 Yes! I've seen pyraf but not this iraf-v216, thanks for sharing <br>
<br>
The idea to port IRAF for several systems is a good one, but I mean a complete rewrite. Well, it is something that I want to do in free time until it gets some momentum and I still need to study some stuff before start.<br>
<br>
@ambrosc I strongly disagree and I'll try to justify it:<br>
<br>
- First, as I said above, my idea was to complete rewrite IRAF, since its code is fundamentally outdated, which wouln't be a problem if IRAF was written in a more "modern" way to say.<br>
<br>
- I'm disagree that Rust is a niche product, by all means. The Firefox's core is written in Rust and Mozilla is strongly supporting it (https://research.mozilla.org/rust/). There's an OS being written in Rust (https://www.redox-os.org/) and a search in Github by Rust returns &gt;30k repositories (which per se don't mean so much).<br>
<br>
- Also, Python is a language that is starting to feel it's age: People use it a lot, but new languages succeed where it failed in terms of compilation, usability and memory control. For example, Rust and Go languages do not give the cue to programmers make mistakes with pointers, what helps A LOT for bug prevention.<br>
<br>
- Rust is made to be reliable and have long-term support. For as long Firefox use it, we can be sure that will be supported and updated.<br>
<br>
Just to conclude: I don't think that we should replace the original IRAF, not right now at least. But rewrite IRAF is an opportunity for expanding its functionality for other uses than astronomy, write a new and revised documentation and to force astronomy community to learn and use more modern languages and softwares.<br>
<br>
I really think that we can't afford to lose the knowledge and work embedded in IRAF just because is "and old tool" and people can't to use it anymore due to incompatibility. <br>
