<div>
From within IRAF you can run UNIX command by escaping them with an exclaimation mark (aka a "bang").<br>
<br>
For example "!ls -l *.fits" would give you a long listing of all the fits files.<br>
<br>
If  you look in your default login.cl file, you'll see some examples of how to define "foreign" tasks. That's probably what you are after.<br>
<br>
Jason

**Mike Fitzpatrick** wrote on Jul 22, 2009

{% raw %}
<div>
Try<br>
<br>
<pre><code>cd (dirname)</code></pre><br>
<br>
Foreign commands pass their arguments directly and the unix 'cd' doesn't know from the iraf 'dirname' value, but if you use "program mode" as above then the CL interprets the value ('tmp') before executing the command.  Note this works with iraf logicals as well, e.g.<br>
<br>
<pre><code>cd (&quot;tmp$&quot;)</code></pre><br>
<br>
will put you /tmp, but if dirname="tmp" it will put you in the 'tmp' subdirectory of where you currently are.<br>
<br>
-Mike
</div>
{% endraw %}

string command
string dirname

command = &quot;cd &quot;//dirname
print(command) | cl

</code></pre><br>

the double slash just means put the string variable after the explicitly defined string. Any variable you want can be put into the command string as follows:<br>
<br>
"......"//variablename//"......."
