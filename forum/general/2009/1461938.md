**Mike Fitzpatrick** wrote on Jul 03, 2009

{% raw %}
<div>
The 'cl' command is actually a C-shell startup script, if what you want is to execute a script from the host level then have a look at <br>
<br>
<a href="http://iraf.noao.edu/iraf/web/new_stuff/cl_host.html">http://iraf.noao.edu/iraf/web/new_stuff/cl_host.html</a><br>
<br>
Alternatively, you can execute the CL binary directly as e.g.<br>
<br>
% /iraf/iraf/bin.redhat/ecl.e &lt; test.cl<br>
<br>
Note that in the first case you can't rely on having a login.cl file to do any package loading or initialization,  in the second case if you do it from a directory with a login.cl it will be read, however you'll lose of of the setup the 'cl' command does which may affect whether you can compile a task, or find some binaries.<br>
<br>
If you have questions, write back with details.<br>
<br>
-Mike
</div>
