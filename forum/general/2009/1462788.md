<div>
There are any number of ways to do it, basically you need to create a string variable for the filename.  You can do this as e.g.<br>
<br>
<pre><code>
cl&gt; fname = &quot;file&quot; // i          # append an integer to a literal string
cl&gt; fname = &quot;flist&quot;              # create a file of image names
cl&gt; file (&quot;foo*.fits&quot;, &gt; fname)
</code></pre> <br>
<br>
an so on.  Once you have the filename, you can read it using the 'list' parameter.  For example, if it is a list of filenames<br>
<br>
<pre><code>
list = fname
while (fscan (list, s1) != EOF) {
    imstat (s1)
}
</code></pre><br>
<br>
If you have specific questions, please post the details of how you need to create the filename and what is in it.<br>
<br>
-Mike
</div>
