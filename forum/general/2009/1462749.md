**Mike Fitzpatrick** wrote on Oct 20, 2009

{% raw %}
<div>
For this task (and others in ARTDATA), if you specify an output image name then it usually means you are modifying an existing input image.  Specifying only the 'input' param will create a new image.<br>
<br>
Anyway, to create a new image, try something like<br>
<br>
<pre><code>
cl&gt; mknoise test gain=3.32 back=0 rdnoise=4 poisson=no ncols=200 nrows=2048
</code></pre><br>
<br>
You shouldn't specify the newline character '\n' for any parameter, you can just leave it blank and if it is required you will be prompted.<br>
<br>
-Mike
</div>
