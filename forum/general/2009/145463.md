<div>
I think the task you're looking for is IMEDIT which has lots of options for replacing bad pixels, however it replaces pixels from another area of the same image.  FIXPIX can be used to interpolate across rows/cols and if you've copied in a region of pixels might be useful to patch the transition region, but you may still have a different background level in the patched region to deal with.<br>
<br>
Another option might be to use IMEXPR to select pixels from one image or the other depending on whether the value is saturated.  For example,<br>
<br>
<pre><code>cl&gt; imexpr &quot;(a &gt; 65000 ? b : a)&quot; fixed.fits a=saturated.fit b=patch.fits</code></pre><br>
<br>
This assumes the images are already registered (see tasks like WREGISTER if not) but will replace only those pixels above a certain value with the corresponding pixel from a second image.<br>
Hope this helps.<br>
<br>
-Mike
