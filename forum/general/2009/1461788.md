**Mike Fitzpatrick** wrote on Jun 15, 2009

{% raw %}
<div>
It's usually a permissions or a path problem, e.g. you typed 'mkiraf' as one user but are trying to login as a different user, or you copied the login.cl/uparm from another machine and the path to the uparm is incorrect (because it's relative to the 'home' which is the directory where you first typed 'mkiraf').  Chances are, typing 'mkiraf' again to recreate the login.cl/uparm directory will fix the problem, otherwise look into the above.<br>
<br>
-Mike
</div>
{% endraw %}
