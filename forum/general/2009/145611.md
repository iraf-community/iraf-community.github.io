The warning about graphics overlay is normal and nothing to worry about.  Not being able to create the .coo file may be a result of reinstalling linux, e.g. you saved the user directories but in the new install the user-id was changed and so you no longer have write permission in the directory.  Likewise, be sure the file doesn't already exist.<br>
