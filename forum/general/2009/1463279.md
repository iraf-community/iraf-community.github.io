# Problem running executables from IRAF command line

**avi** wrote on Dec 24, 2009

{% raw %}
<div>
I am unable to run simple Fortran and C executables from the IRAF command line. They are properly defined in my login.c file. The error I get is:<br>
<br>
ERROR: Abnormal termination of child process '??'<br>
<br>
Those executables run OK when I call them using "!", meaning when they are ran from the shell. For example, when running a simple program that writes "hello" to the screen, I get:<br>
<br>
cl&gt; !./hello<br>
hello<br>
cl&gt; hello<br>
ERROR: Abnormal termination of child process '??'<br>
cl&gt; <br>
<br>
Using ecl gives exactly the same result. I am using IRAF 2.13-BETA2 on a Linux (ubuntu) machine.<br>
<br>
Any helpful ideas would be highly appreciated<br>
<br>
Avi
</div>
{% endraw %}

---

**Mike Fitzpatrick** wrote on Dec 24, 2009

{% raw %}
<div>
How are you declaring the task?  It should be something like<br>
<br>
<pre><code>
cl&gt; task $hello = $foreign
</code></pre><br>
<br>
And the 'hello' command must be in the path declared by your .cshrc/.bashrc file.  The '$foreign' says this is not an iraf command, otherwise the CL is trying to talk to it as a child process and can't.
</div>
{% endraw %}
