<div>
There aren't plans to specifically support new fonts, however XGterm is able to use any of the fonts currently on your system and supported by the X11 server.  The '-fn' commandline flag can be used to name the font, see the 'XTerm' man page for additional flags that control fonts.<br>
<br>
-Mike
</div>
