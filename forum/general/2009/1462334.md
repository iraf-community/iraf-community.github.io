<div>
The access() function takes a single file name, not a template string.  If you want to see whether more than one such file exists, see e.g. the FILES command to expand the list.  You can pipe the output to COUNT then check whether more than one match was found, e.g.<br>
<br>
<pre><code>files (&quot;*left.fits&quot;) | count | scan (nfiles)
if (nfiles &gt; 1) {
    delete (&quot;*left.fits&quot;)
}</code></pre><br>
<br>
-Mike
</div>
