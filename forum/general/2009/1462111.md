<div>
The termcap libs are included in the 'ncurses' package which you should install.  Since there may be version number differences, perhaps the simplest thing is to simply get the statically linked binary at<br>
<br>
<a href="http://iraf.net/ftp/pub/fitz/ecl.e">http://iraf.net/ftp/pub/fitz/ecl.e</a><br>
<br>
Download in binary mode, reset execute permissions and install in the $iraf/bin.redhat directory.<br>
<br>
-Mike
</div>
{% endraw %}
