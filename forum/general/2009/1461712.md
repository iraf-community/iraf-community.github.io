<div>
The IMEXPR task will allow you to write an expression than can effectively invert the values as you describe.  Note you'll need to figure out what are reasonable values for the high/low pixels.  Note there is also the DTOI package under IMRED which was (long, long ago) used for dealing with plate-scanned images.<br>
<br>
The z-scale display algorithm is just a way of picking optimal values to scale the display from 16/32-bit range to the 8-bit display range.  Likewise, IMEXPR could also be used to linearly scale your pixels values to the range<br>
0-200 and you could display then with the params "zscale- zrange- ztrans=none" to display raw pixels.<br>

-Mike
