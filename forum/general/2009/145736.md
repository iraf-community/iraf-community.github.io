In IRAF it is usually required and always a good idea that when a directory must be specified it end with '/' or '$'.  In the latter case of a logical directory the value should resolve to a directory ending with a '/'.  That is why you get something like<br>
<br>
sd93521.datstandards.men<br>
<br>
instead of <br>
<br>
sd93521.dat/standards.men<br>
<br>
Given that this still is wrong.  You should post the parameters from an 'lpar standards" command.  I can not recall immediately if the .men menu file is required, I would have thought it was optional.  I guess it is trying to list the menu file because it did not find the dat file for the star.<br>
<br>
Yours,<br>
Frank Valdes
