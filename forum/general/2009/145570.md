This is a crash in DS9 itself and not specifically an IRAF problem.  The first thing to do is to be sure you are using the latest version available from  <a href="http://hea-www.harvard.edu/RD/ds9/">http://hea-www.harvard.edu/RD/ds9/</a>  If you still have problems you should report them to saord @ cfa.harvard.edu<br>
<br>
Presumably the TEST12 image in your example was loaded from DS9 directly and not thru IRAF?  Does it make a difference if you load from IRAF using the DISPLAY task prior to IMEXAM?<br>
