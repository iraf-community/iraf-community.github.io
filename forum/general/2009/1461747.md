# apall's multispec vs echelle make differing APNUM keywords

**Jason Quinn** wrote on Jun 05, 2009

{% raw %}
<div>
It appears that choosing "multispec" vs "echelle" for the format parameter in the apall task can produce different APNUM keywords in the output headers. I tested this on an image after unlearning apall (actually the imred.kpnoslit apall) and the relevant differences are<br>
<br>
APNUM1  = '1 1 62.37 75.85'<br>
APNUM2  = '2 2 152.79 166.42'<br>
<br>
vs<br>
<br>
APNUM1  = '1 1 62.09 75.53'<br>
APNUM2  = '2 2 153.01 166.66'<br>
<br>
According to the help file, the only difference between the two methods is the file extension. So the first question is why are the different and the second question is if there's a bug in one (or both) of the two calculations.<br>
<br>
I can send the exact file needed to reproduce the error upon request however I suspect it won't be hard to reproduce. <br>
<br>
Jason
