<div>
If by 'associate' you mean you want the flux from one file and the wavelength from the other .....  WSPECTEXT will convert a FITS file to ascii, FIELDS can select a single column from a text table and JOINLINES can be used to paste columns.  Lastly, RSPECTEXT can convert this back to a fits image.  Note however that you need to be careful not to have RSPECTEXT try to apply its own dispersion solution to the header.<br>
<br>
See the help pages for each task for details.
</div>
