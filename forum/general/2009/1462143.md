**Francisco Valdes** wrote on Jul 21, 2009

{% raw %}
<div>
Hello,<br>
<br>
As Mike says, the parameter mechanism is rather tricky.  The answer provided by Mike was close.  You also need to set a second parameter.<br>
<br>
<pre><code>
cl&gt; apparams.ansfind = &quot;NO&quot;
cl&gt; apparams.initialize = no
cl&gt; apsum dummy.fits
</code></pre><br>
<br>
The same logic applies to other parameters.  Note that other tasks in the package may use different hidden parameter sets.  In particular, the "all-in-one" version of the various operations is APALL which uses the parameter set APALL1.  But the logic is the same; set initialize to no so that it doesn't reset the ansXXX parameters that you want to set.<br>
<br>
Yours,<br>
Frank Valdes
</div>
{% endraw %}
