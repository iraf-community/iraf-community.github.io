<div>
Doing a new MKIRAF in your iraf login directory will probably fix this since it creates the uparm directory and defines the correct path to it.  Most times, this message is caused by copying a login.cl from another machine and so the paths don't match, or else using the login.cl of another user and so you don't have write permission in the uparm directory.  The tasks still run, the parameters just aren't saved between sessions.
