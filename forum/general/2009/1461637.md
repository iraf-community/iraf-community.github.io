**Mike Fitzpatrick** wrote on May 26, 2009

{% raw %}
<div>
Does the image look reasonable if you display it?  If there aren't as many pixels in the file as you give for the dimensions you'll end up with zero values, and perhaps also a skewed image or a band of blank pixels.  Note the unix 'wc' command can give you a count of words in a file, if you have just ascii pixel values that number should match your dimensions.  You don't need to explicitly put a period on the values, unless you have "strange" representations of the numbers it should pick out the type and set it appropriately.<br>
<br>
If you still have problems upload the ascii file to the anonftp at <a href="ftp://iraf.noao.edu/pub">ftp://iraf.noao.edu/pub</a> and I'll have a look.<br>
<br>
-Mike
