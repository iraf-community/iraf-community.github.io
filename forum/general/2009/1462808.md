<div>
You can download pre-built binaries from <a href="http://iraf.net/ftp/iraf/extern/mscred-bin.macintel.tar.gz">http://iraf.net/ftp/iraf/extern/mscred-bin.macintel.tar.gz</a><br>
<br>
Assuming you downloaded this file to the /tmp directory, you would install them using<br>
<br>
<pre><code>
% cd /Users/iraf/iraf/mscred
% tar zxvf /tmp/mscred-bin.macintel.tar.gz
</code></pre><br>
<br>
This will create a 'bin.macintel' directory in the mscred package dir with the binaries.<br>
<br>
-Mike
