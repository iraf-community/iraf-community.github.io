**Mike Fitzpatrick** wrote on Jul 13, 2009

{% raw %}
<div>
Check your hlib$extern.pkg file for any indication of a misplaced '/'.  This file is read at startup automatically and is often the cause of syntax errors like this.  If you don't see anything obvious, you could also put the command "d_trace" at the top of your login.cl file, the last screen full of info around the error might provide a clue about where this is happening.  <br>
<br>
I seem to remember a similar report but not that it was ever resolved.  Are you using SciSoft or a distribution/installation from this site?<br>
<br>
-Mike
</div>
{% endraw %}
