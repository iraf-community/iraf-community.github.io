<div>
It's nothing peculiar to APALL, the message just means that you have a Multi-Extension FITS file and so need to specify the image extension to use, e.g.<br>
<br>
<pre><code> cl&gt; imstat mef.fits[1]</code></pre><br>
<br>
You can read more about the FITS kernel usage at  <a href="http://iraf.net/irafdocs/fits_userguide/">http://iraf.net/irafdocs/fits_userguide/</a><br>
<br>
-Mike
