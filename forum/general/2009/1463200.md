We have a directory we want to get to from within IRAF that has a space in its name: "Macintosh HD" - which can't be changed because of all the other things that address it... anyway, we are finding it impossible to cd into this directory  - we tried single and double quotes, etc. UNIX doesn't seem to have trouble, but ecl can't manage it. **Mike Fitzpatrick** wrote on Dec 11, 2009

{% raw %}
<div>
Spaces in directory/filenames aren't currently permitted, but I'll add it to the list of features for the next release.  The usual workaround is to create a symlink at the unix level to get you past the problem area, e.g.<br>
<br>
<pre><code>
% sudo ln -s /Volumes/Macintosh\ HD/  /data
</code></pre><br>
<br>
In iraf then just e.g. "cl&gt; cd /data/Users/....."<br>
<br>
-Mike
</div>
{% endraw %}
