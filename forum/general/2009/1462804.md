<div>
The paths in the extern.pkg file must be the actual paths on the machine and not just the example paths in the readme file. I.e. try changing your "/local/mscred/" to "/Users/iraf/iraf/mscred" if that's where you actually unpacked the package.<br>
<br>
-Mike
