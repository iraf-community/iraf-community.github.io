<div>
If I understand correctly, you just want to use a foreign command from within a script and redirect some input.   To use the command you simply need to declare it as a foreign task in your login.cl/loginuser.cl file as e.g.<br>
<br>
<pre><code>task $foo = $foreign</code></pre><br>
<br>
This assumes the command 'foo' is already in your unix path.  You can then use if from a script as e.g.<br>
<br>
<pre><code>
printf (&quot;1\n2\nyes\nno\n&quot;) | foo ()

or 

type (&quot;myinput&quot;) | foo()

or

foo (&lt;&quot;myinput&quot;)
</code></pre><br>
<br>
Does this answer it?
</div>
