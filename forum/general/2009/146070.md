<div>
Variables can't be created dynamically as you are doing (i.e. you only declare 'variable', not 'variable1', 'variable2', etc).  If you have some small number of things to read (e.g. 3-5) then the simplest thing is something like<br>
<br>
<pre><code>
list = &quot;myfile&quot;
fscan (list, variable1)
fscan (list, variable2)
    :
</code></pre><br>
<br>
Another way is to use an array of values, e.g.<br>
<br>
<pre><code>
    string var[5]

    list = &quot;zin&quot;
    for (i=1; fscan(list,s1) != EOF; i=i+1)
        var[i] = s1
    
    for (i=1; i &lt;= 5; i=i+1)
        print (var[i])
 </code></pre><br>
<br>
Note arrays are 1-indexed and you cannot scan into them directly.  You'll also have to know how many strings to expect so you can declare the array with some max value.  <br>
<br>
If the values on the lines have some meaning you might be better off with the first option where you can have meaningful variable names to use in the script.  <br>
<br>
-Mike
