<div>
The FILES or SECTIONS tasks you would normally use to create lists of images don't support descending subdirectories (although that would be an interesting new feature to add).  Instead you can create the file list using the host 'find' command, e.g.<br>
<br>
<pre><code>
cl&gt; find . -name \*.fits -print &gt; flist
cl&gt; hedit @flist foo yes
</code></pre><br>
<br>
The 'find' task is declared as foreign in your login.cl and so doesn't need to be escaped.  Also, are you sure you didn't mean you wanted to use the HSELECT task to get the value, or by 'extract' do you mean delete?<br>
<br>
-Mike
</div>
