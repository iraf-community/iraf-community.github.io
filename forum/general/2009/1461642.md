<div>
It sounds like you want to automatically characterize an image.  This is usually done with a cataloging program such as SExtractor or ACE.  Since you mention IMEXAM, there is a more automated version for characterizing the PSFs in an image call PSFMEASURE.  However, the trick is to define the positions to use.  A task like DAOFIND might be useful.<br>
