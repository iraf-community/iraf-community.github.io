**Mike Fitzpatrick** wrote on Apr 16, 2009

{% raw %}
<div>
Scripts can indeed load packages.  Typically you would use the defpac() function to see whether the package is already loaded, e.g.<br>
<br>
<pre><code>
if (defpac(&quot;ptools&quot;) == no) {
    print (&quot;Loading PTOOLS package&quot;)
    prools
} 
</code></pre>
</div>

Looks like I got it backwards:  defpac() is typically used to determine when a package is NOT loaded so you can print an error and quit, loading the package won't work because of the way the package loading works internally.
