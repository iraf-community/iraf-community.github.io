**Mike Fitzpatrick** wrote on Jan 16, 2009

{% raw %}
<div>
By default, X11 will start an Xterm as the window.  You can use this, but you need to tell IRAF  it;s an xterm.  If you want to use XGterm you generally need to start it explicitly and then login to iraf from that window.  It's certainly not a permissions problem.<br>
<br>
-Mike
</div>
