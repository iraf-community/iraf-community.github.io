# CCD Photometry with very large FWHM

**Gabriel** wrote on Apr 03, 2009

{% raw %}
<div>
Hi everybody,<br>
<br>
I'm working with frames with an unusually large FWHM: around 10-11 pixels. I'm following the 'A user's Guide to Stellar CCD Photometry with IRAF' by Massey &amp; Davis (1992). I'm using a script I wrote, but I can't seem to substract the PSF stars and their neighbours cleanly, no matter what I try to do. Bellow I transcript the steps I follow and the parameter values I use (I've tried several small variations of this parameters values, with no satisfying results):<br>
<br>
1) Input of the following parameters:<br>
<br>
-<strong>smean</strong> = 'Sky mean value' (obtained by: imexa + 'm' key over a clear sky patch. The value I've used is around 16)<br>
-<strong>delta</strong> = sqrt(smean*gain + rdnoise*rdnoise)/gain (Gain = 2.1, Rdnoise = 8)<br>
-findpars.<strong>threshold</strong> = 3.5*delta<br>
-datapars.<strong>fwhmpsf</strong> = 'typical FWHM value' (around 10-11 pixels)<br>
-datapars.<strong>sigma</strong> = 'SSTDEV value' (around 2)<br>
-datapars.<strong>datamin</strong> = smean -3*delta<br>
-datapars.<strong>datamax</strong> = 64000<br>
-datapars.<strong>noise</strong> = "poisson"<br>
-daopars.<strong>psfrad</strong> = 'radius of the larger unsaturated PSF star' (I've used mostly something around 30 pixels)<br>
-daopars.<strong>fitrad</strong> = 'typical FWHM value'<br>
<br>
2) Daofind run<br>
<br>
3) Input of the following parameters:<br>
<br>
-unlearn <strong>centerpars</strong><br>
-unlearn <strong>fitskypars</strong><br>
-unlearn <strong>photpars</strong><br>
-unlearn <strong>psf</strong><br>
-photpars.<strong>apertures </strong>= 'typical FWHM value'<br>
<br>
4) Phot run<br>
<br>
5) PSF stars selection<br>
<br>
6) PSF run<br>
<br>
7) Input of the following parameters:<br>
<br>
-daopars.<strong>psfrad </strong>= psfrad - fitrad ('radius of the larger unsaturated PSF star' - 'typical FWHM value'. I've been useing this values: 30 - 10 = 20)<br>
<br>
8) Nstar run<br>
<br>
9) Substar run<br>
<br>
At this point I should have a 'name.sub.1.fits' frame with no PSF stars or their neighbours (according to Massey's guide), but I don't. The closest I get is a horribly substracted frame. I'm thinking there must be something wrong with the parameter values I use, but I can't figure out which ones.<br>
<br>
Any help will be very much appreciated!<br>
<br>
Gabriel
