**Mike Fitzpatrick** wrote on Jul 14, 2009

{% raw %}
<div>
The newline following the 'end' is required otherwise the input is terminated prematurely.  The default ECL should print correct line numbers in the case of syntax errors and script crashes but this is a different case where the input stream terminates prematurely.  Note if you're still running v2.12 the ECL is an add-on you can get and the old CL will always print the number of lines regardless of where the error happened.<br>
<br>
-Mike
</div>
