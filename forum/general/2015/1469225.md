                What you're seeing the XGTerm GUI code followed by the plot metacode.  The fact you're seeing it means you told IRAF you were using an XGterm window (e.g. when you did the MKIRAF), however you started the CL from some other type of window (e.g. an XTerm which can be used by resetting the terminal type, or something like a rxvt/gnome-terminal which doesn't support graphics).<br>
<br>
Start an XGterm window (it is installed with the rest of iraf so jus type 'xgterm') and login to the CL from that window.<br>
