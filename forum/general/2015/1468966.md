**Mike Fitzpatrick** wrote on Jun 09, 2015

{% raw %}
<div>
<br>
                The FITS file is probably fine then, your problem is that you have a Multi-Extension FITS (MEF) file and need to specify the extension explicity, e.g.<br>
<br>
    cl&gt; imhead trim_18.fits[1] l+<br>
<br>
will list the header of the first extension.<br>
<br>
For a task like IMARITH you would specify the extension of each image, however you should instead be using the MSCRED package to handle the extensions automatically, e.g.<br>
<br>
    cl&gt; mscarith trim_18.fits / flat_hk_mar28_2015.fits trim_data_flat_18.fits<br>
<br>
will automatically expand the extensions and process each.  MSCRED is an external package that must be installed separately.<br>
</div>
{% endraw %}

                It's your data, you tell me what's possible.  Installing MSCRED should also have installed the FITSUTIL package, you can use the FXHEADER command to print out the structure of each file, e.g.<br>
<br>
   cl&gt; fitsutil<br>

   cl&gt; fxheader trim_18.fits<br>

Depending on your IRAF version you might also be seeing a bug in the new image template code, to work around this do<br>
<br>
    cl&gt; reset use_new_imt = no<br>
<br>
before running the mscarith task.  If it works you can make the change permanent in your login.cl file.<br>
