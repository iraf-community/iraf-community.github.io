**Mike Fitzpatrick** wrote on Jul 09, 2015

{% raw %}
<div>
<br>
                Your Flat file has several pixels with values such as 1E-16 which is skewing the output.  You can use the IMREPLACE command to fix these pixels to some known value you like better, e.g.<br>
<br>
    cl&gt; imreplace flat_hk_nov28_2013.fits  0.0 upper=0.01<br>
<br>
would replace all values less than 0.01 with 0.0.  The resulting IMSTAT looks better but depending on your particular application you may want to replace values in the output as well.<br>
</div>
{% endraw %}
