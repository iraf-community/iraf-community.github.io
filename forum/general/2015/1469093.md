                If by 'meta file' you mean the plot metacode then I'm afraid you wouldn't really find anything useful.  The GKIDECODE task can be used to read the file, however the values for the various lines are all plotting device coordinates.<br>
<br>
If you really mean the task FITPROFS (I'm not familiar with 'FITPROS') the see the help page for a desccription of the 'logfile' and 'verbose' parameters, but I'm not aware of a way to get all of the values that make up the plot.<br>
