**Mike Fitzpatrick** wrote on May 12, 2015

{% raw %}
<div>
<br>
                The thing to remember is that there is no standard definition of the RA/DEC header keywords, and that these have no defined relation to the WCS itself.  Depending on the instrument/control system, RA/DEC may refer to the (unprecessed) coordinates of an object in the field, a pointing value for the telescope, the center position of a dither field, etc.  So, before deciding the WCS is wrong, you should test the readout of coords to see whether a cursor put on an object corresponds to some known object or whether there is a systematic offset, and necessarily whether the WCS ties to the RA/DEC keywords in some logical way.<br>
<br>
The astromatic.net forums can be used to discuss SCAMP, for computing a WCS in IRAF see the "Creating a Mosaic WCS" document (http://iraf.net/irafdocs/astrom.php) for an overview, you'll need to adjust this a but for a single-frame image.<br>
</div>
