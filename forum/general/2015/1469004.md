<br>
The EUV package has been frozen for quite a while and was not updated for 64-bit systems, so you're still running the original 32-bit binaries.  The first thing I'd check is whether the detector.tab file can be read at all, e.g. can you do<br>
<br>
    cl&gt; tinfo reference/detector.tab<br>
<br>
    cl&gt; count reference/detector.tab<br>
<br>
The first command would verify the table file itself can still be read (maybe there are byte-swapping issues?), the second would verify the file can be opened as a file.  The latter test is because some 32-bit binaries cannot read files on 64-bit filesystems and I want to be sure this isn't happening here (if it is, try copying the detector.tab file to /tmp and using it from there).  Otherwise, what version of the EGODATA files are you using?  Have you tried accessing the FITS files directly rather than using the converted .tab versions?<br>
