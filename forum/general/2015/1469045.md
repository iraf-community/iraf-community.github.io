**Mike Fitzpatrick** wrote on Jul 16, 2015

{% raw %}
<div>
<br>
<br>
Try using:<br>
<br>
    cl&gt; reset use_new_imt = no<br>
<br>
before running your task to bypass the new image template code in v2.16.  If this fixes your problem you can make the change permanent by either setting this in your login.cl file or editing the system hlib$zzsetenv.def file.<br>
