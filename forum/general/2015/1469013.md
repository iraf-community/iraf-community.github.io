**Mike Fitzpatrick** wrote on Jun 30, 2015

{% raw %}
<div>
<br>
                A segmentation violation is a general error that can be caused by a bug in the code (e.g. a pointer reference out of bounds) or some combination of data and task parameters (e.g. unexpected zero values).  There's not enough information in your post to say specifically what is happening and there are no known open issues.  Could you upload a sample FITS file and the parameters you used (e.g. "cl&gt; dpar daofind") to the anonymous ftp at ftp://iraf.noao.edu/pub so I can try to reproduce the problem?  It would also help to know whether you are using the 32-bit or 64-bit IRAF version (i.e. the 'linux' or 'linux64' architecture).<br>
<br>
Note also that DS9 versions 7.1 and later have issues related to properly reading image cursors, this has been recently fixed in the newest beta version.  I mention this because an improper cursor position may be contributing to the problem.<br>
</div>
{% endraw %}
