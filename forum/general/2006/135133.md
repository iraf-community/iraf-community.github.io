**Mike Fitzpatrick** wrote on Jun 02, 2006

{% raw %}
<div>
A private copy of the observatory database can be used simply by defining an 'obsdb' environment variable giving the path to it.  For example,<br>
<br>
<pre><code>
cl&gt; copy noao$lib/obsdb.dat home$   # make private copy
cl&gt; edit home$obsdb.dat             # add your entry
cl&gt; reset obsdb = home$obsdb.dat   # define the env variable
</code></pre><br>
<br>
and you should be able to use the new entry.  This can be put in your login.cl file for more persistence and doesn't require iraf write permission.  See the OBSERVATORY help page for details.<br>
<br>
-Mike
</div>
{% endraw %}
