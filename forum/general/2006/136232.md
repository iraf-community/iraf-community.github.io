<div>
I have solved the problem<br>
It is due to my $display variable in iraf account.<br>
I have to set permission on iraf account in order to use display<br>
In addition, i have to add this line to the login.cl in order to use ds9 in iraf:<br>
task $ds9 = "foreign"<br>
I don't know why this works, but at least now I can use ds9 to display images now
</div>
{% endraw %}
