**Mike Fitzpatrick** wrote on Sep 06, 2006

<div>
Hi Phil,<br>
<br>
A quick guess would be a missing/incomplete XFILESEARCHPATH environment definition telling the system to look in /usr/lib/X11/app-defaults in the first place.  Try<br>
<br>
irafnet&gt; echo $XFILESEARCHPATH<br>
:/usr/lib/X11/%T/%N%S:/usr/x11R6/lib/X11/%T/%N%S:/usr/local/lib/%T/%N%S:<br>
<br>
If all your friend got was the 'xgterm.fedora' binary then it wouldn't have included the app-defaults file, this was part of the X11IRAF src/binary distributions and assumed you used the install script/makefile to install it.  I believe having the XGterm resource file in the directory where you start the command will also work but I haven't tried it.  In the worst case, the definitions in that file can be put in the user .Xdefaults file.<br>
<br>
Cheers,<br>
-Mike
</div>
