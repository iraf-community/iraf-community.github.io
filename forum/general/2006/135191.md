I'm afraid I don't know the details of a Spitzer .tbl file.  If it is an ascii FITS header followed by text columns the FIELDS trick will still work if you set the 'lines' param to skip the header.  You could also (with such a format) use RTEXTIMAGE to create an image (assuming none of the columns are strings, or perhaps STRFITS to create a table you can plot.  If an image the you can LISTPIX the columns and pipe that to SGRAPH.<br>
<br>

**Mike Fitzpatrick** wrote on Jun 09, 2006

{% raw %}
<div>
Hi Karen,<br>
<br>
Thanks for the sample data file.  It wasn't quite what I was expecting but it can be made to work at least for the limited question you asked, for more detailed analysis with this data obviously some way to convert this to a FITS file with a proper spectral WCS would be better.  In any case, for simply plotting all of col2 vs col3 something like<br>
<br>
<pre><code>
cl&gt; match &quot;[\\\|]&quot; spitz.tbl stop+ | fields &quot;2,3&quot;  &quot;STDIN&quot; | sgraph
</code></pre><br>
<br>
will do it.  The MATCH command effectively skips the headers (which begins with a backslash or vertical pipe, the multiple backslashes are needed to escape through to the CL).  The FIELDS selects the columns for plotting.<br>
<br>
However, I notice column 1 is the spectral order so plotting everything might not make sense in all cases (and for your sample produced stray lines on the plot).  So to select only say order 20 for plotting try<br>
<br>
<pre><code>
cl&gt; match &quot;\^20&quot; spitz.tbl stop- | fields &quot;2,3&quot; &quot;STDIN&quot; | sgraph
</code></pre><br>
<br>
In this case the backslash escapes the ^ from being interpreted by the ECL (if you use the latest 2.13BETA2), and disabling the 'stop' param passes through the lines beginning with a '20' instead of blocking lines beginning with a backslash as above.<br>
<br>
I'm not sure what software there is for converting this to FITS, but I'd be surprised if you couldn't easily find something.  When you do, the earlier syntaxes for selecting the colums should work.  Hope this helps.<br>
<br>
Cheers,<br>
-Mike<br>
