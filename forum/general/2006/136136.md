**Mike Fitzpatrick** wrote on Oct 30, 2006

{% raw %}
<div>
You should always be able to use FITS images directly, what did you do to 'configure' iraf to do this?  If you're only seeing one line of the image then either the display frame buffer you're using is only 1-D (e.g. 1024x1) or your image only has one row.  Please post a header of the image (e.g. "cl&gt; imhead myimage.fits long+") and the frame buffer you're using (e.g. "cl&gt; show stdimage").<br>
<br>
-Mike
