**Mike Fitzpatrick** wrote on Oct 12, 2006

{% raw %}
<div>
Hi Catrina,<br>
<br>
Sorry, the Mac HFS filesystem is case-insensitive so 'Demoflat' and 'demoflat' are seen as the same file in the underlying OS (Note also that ':' can be used as a directory delimiter).  It's possible to format HFS to be case-sensitive in Tiger and later, however it means wiping the partition clean to do it.<br>
<br>
Cheers,<br>
-Mike
</div>
{% endraw %}
