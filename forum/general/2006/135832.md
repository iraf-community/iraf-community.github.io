The installation guide is available at <a href="http://iraf.net/irafdocs/pciraf/">http://iraf.net/irafdocs/pciraf/</a>, the procedures are the same for all platforms, only the names of the binaries differ.  Note this is the "traditional" installation methode and separate from anything done elsewhere with .dmg files or in systems like Scisoft.  An automatic network installation is planned for the final V2.13 release (expected shortly).<br>
