Robert,<br>
<br>
Images can be displayed (on most IRAF systems) using inet sockets, unix domain sockets, or named fifo pipes, the last two are used (in order) by default.  However, cygwin doesn't implement unix sockets and DS9 has an apparent bug in using fifo pipes, so you need to force IRAF to use the inet socket.  The simplest way to do this is to set an IMTDEV environment variable before you start the CL, e.g.<br>
<br>
<pre><code>export IMTDEV=&quot;inet:5137:127.0.0.1&quot; </code></pre><br>
<br>
Then as long as DS9 and X11 are running, and note DS9 needs to be installed separately, you should be able to display images. This has been fixed for the final release to be automatic.  Note also that FITS files can be used directly so converting to .imh images is optional.<br>
<br>
Hope this helps,<br>
-Mike
