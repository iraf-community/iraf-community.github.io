I'm not sure, but the definition of stdimage modes is contained in file imtoolrc, which should be located in /usr/local/lib/<br>
<br>
Here is an excerpt of mine:<br>
<br>
<pre><code>
# IMTOOLRC -- Predefined frame buffer configurations.  The value of nframes
# given is the initial number of frame buffers allocated; more frames can be
# added at runtime.  The configuration numbers may be given in any order but
# must be unique and in the range 1-128.  NOTE - corresponding entries must be
# present in the dev$graphcap file, for use with IRAF.  This file is used by
# both the IMTOOL and SAOIMAGE display servers.
#
# Format:  configno nframes width height

 1  2  512  512         # imt1|imt512
 2  2  800  800         # imt2|imt800
 3  2 1024 1024         # imt3|imt1024
 4  1 1600 1600         # imt4|imt1600
 5  1 2048 2048         # imt5|imt2048
 6  1 4096 4096         # imt6|imt4096
 7  1 8192 8192         # imt7|imt8192
</code></pre><br>
<br>
maybe you can just add a new configuration, and call it, say, imt14000,<br>
then, probably, you should tell to IRAF to use it.<br>
In my login.cl I have a line:<br>
<br>
<pre><code>
#set    stdimage        = imt800
</code></pre><br>
<br>
maybe just uncomment it and set to imt14000. <br>
<br>
Cheers,<br>
Emiliano<br>
<br>
P.S.: maybe, as the imtoolrc file says, you need to edit the graphcap file...?

<div>
Emiliano almost has the complete answer:  Frame buffers are configured by editing <strong>both</strong> the imtoolrc file and the dev$graphcap file.  From the FAQ:<br>
<br>
<blockquote><br>
What do I change to add a custom frame buffer size? <br>
<br>
 There are two files that need to be modified to create your own frame<br>
buffer size, imtoolrc and graphcap.  You will need to restart the display<br>
window to activate these changes.<br>
<br>
  o First you need to copy over the system imtoolrc file into your home<br>
    directory, and then modify the file so it reflects your new frame<br>
    buffer size.  Note the name change during the copy.<br>
<br>
       % cd<br>
       % cp /iraf_path/dev/imtoolrc .imtoolrc<br>
       % vi .imtoolrc<br>
<br>
    Go to the end of the file and add an entry for your particular frame<br>
    buffer following the examples in the file (contrary to what is in the<br>
    file, keep you frame numbers less than 64).<br>
<br>
  o Next, copy over the system graphcap file and edit it in a similar fashion<br>
    following the examples under the "STDIMAGES devices" section.  Now when<br>
    you log into IRAF point to this new graphcap file, and then reset the<br>
    value for stdimage.<br>
<br>
       % cp /iraf_path/dev/graphcap mygraphcap<br>
       % vi mygraphcap<br>
       [restart the display window and log into the CL]<br>
       cl&gt; reset graphcap = /home_path/mygraphcap<br>
       cl&gt; gflush<br>
       cl&gt; reset stdimage = my_new_frame_buffer<br>
<br>
    When editing the graphcap entry be sure to modify the ":cn" (configuration<br>
    number) field as well as the buffer sizes (the :xr and :yr fields as well<br>
    as the DD string).  After resetting the graphcap environment variable be<br>
    sure to type a 'gflush' to reinitialize the graphics system.<br>
</blockquote><br>
<br>
The GDEVICES command will print a listing of the currently available buffers.<br>
<br>
Cheers,<br>
-Mike
</div>
{% endraw %}
