<div>
It is a subtlety of the use of a "list directed parameter", in this case your 'filelist' script variable.  Basically, these parameters return a value from the list each time they are queried, but you only use it in the one imcombine call and so it returns only the first image on the list, and so the input and output image is the same.<br>
<br>
I think what you intended was for this to be an @file, try instead<br>
<br>
<pre><code>imcombine(input=&quot;@left.lis&quot;, output=.......)</code></pre><br>
<br>
or even just<br>
<br>
<pre><code>imcombine(input=&quot;*L.fits&quot;, output=......)</code></pre><br>
<br>
Cheers,<br>
-Mike
</div>
{% endraw %}
