Jihane,<br>
    I assume what you want is a PS file of a plot of the spectrum?  The first step is to generate the plot using something like SPLOT, PROW, GRAPH or a number of others.  See the helps pages for these tasks by entering the task name in the search bar on the banner, or do an 'apropos' search on a string like "plot" or "spectrum".<br>
<br>
    Once you have a graph generating the PS is easy.  This is summarized well in <a href="http://iraf.net/phpBB2/viewtopic.php?t=83718&amp;highlight=psdump">http://iraf.net/phpBB2/viewtopic.php?t=83718&amp;highlight=psdump</a> <br>
which also has a link to the FAQ.  Hope this helps.<br>
