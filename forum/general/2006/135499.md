Assuming there are no errors reported by the install script, be sure it was run as the root user and <strong>without</strong> the "-n" flag.  If you're simply getting a "command not found" message then this is normally a path problem, e.g. you specified /usr/local/bin as the "local bin directory" but this isn't in your $PATH.  Hope this helps.<br>
