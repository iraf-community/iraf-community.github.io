See the TCALC task in the TABLES.TOOLS package.<br>
<br>
If what you have is a file with some numbers and you want to divide each by a constant:<br>
<br>
<pre><code>
list = &quot;numbers.txt&quot;
while (fscan (list, x) != EOF) {
    print ((x / 3.14159))
}
</code></pre><br>
