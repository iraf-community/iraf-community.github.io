Try doing a "cl&gt; !which sgidispatch" to see if you can find the command.  The dispose command in the graphcap is done using a spawned shell and so if your .cshrc file doesn't define a path to the sgidispatch command it might not produce the final file. <div>
Karen,<br>
<br>
The graphcap uses 'sgidispatch' as the command, not the .e binary.  This should be in the same directory as 'cl', 'mkiraf', etc  If a "cl&gt; !which cl" also shows no results then this is still a path problem in your .cshrc/.bashrc file, however if it can find the cl command but not sgidispatch, then check that the link is indeed installed, points to a valid .e file, and that you can run the 'sgidispatch' command at the unix prompt (it should just return the prompt, but no error messages).<br>
<br>
Re-running the install script should fix any issues with links.  BTW, is this a SciSoft installation?<br>
<br>
-Mike
