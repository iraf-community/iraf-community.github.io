<blockquote> 1. is there a single command that would undo the previous installation?<br>
or would the process of installing the higher version automatically<br>
wipe out the older version?</blockquote><br>
<br>
Beginning in V2.11.3 there was an hlib$uninstall script available, however this simply removed the links made into the system by the 'install' script.  Updating a previous installation is covered as part of the installation guide, i.e. what files to backup and merge to retain local definitions, but you need to manually move/rename/delete existing code trees. <br>
<br>
<blockquote>2. this was installed by .rpm files using a single command.<br>
May i know if similar .RPM files are available for v2.12? if so,<br>
where does one find them?</blockquote><br>
<br>
You'll have to Google to find a reference but I know these exist.  I do not think however that a V2.13 RPM has been created yet.  These are done by users and not us.  Note that if you install with an RPM file, the 'rpm -e' command can then uninstall it.<br>
