<div>
At it's simplest, all you need to do is create the one larger image, and then<br>
IMCOPY your four separtate images into it.<br>
<br>
For example ... to create a 1024x1024 image from 4 512x512 images.<br>
<br>
<pre><code>
cl&gt; magnify image1 bigimage 2 2                # Create the larger image
cl&gt; imreplace bigimage 0.                          #  Set the pixels to zero.
cl&gt; imcopy image1 bigimage[1:512,1:512]
cl&gt; imcopy image2 bigimage[513:1024,1:512]
cl&gt; imcopy image3 bigimage[1:512,513:1024]
cl&gt; imcopy image4 bigimage[513:1024,513:1024]

</code></pre><br>
<br>
You should be able to script out what you need from this example.<br>
<br>
NOTE:  You could also use MKIMAGE to make the template image, but you <br>
            need to load  noao.imred.ccdred.ccdtest<br>
