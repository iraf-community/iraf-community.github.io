<div>
I'm not sure what parameter is causing this but it is usually due to some parameter setting.  I would suggest you unlearn splot and then set the parameters again.  Be particularly careful in anything to do with filenames.  Note that " " and "" are different and the second one is what you should use to specify no filename.  The tricky thing is that in epar you cannot see the difference.  But if you do lpar splot you can see if you have a space character.  If this doesn't fix your problem, please post an 'lpar' listing of the splot params.<br>
