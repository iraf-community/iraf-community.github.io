<div>
The standalone ECL installer still has the original release version.  Since then, work was done to improve the tab completion and so the specific example you give now works as expected, this is the version distributed with the V2.13 releases.<br>
<br>
I've put a copy of the Redhat binary of the new ecl.e at <a href="http://iraf.net/ftp/pub/fitz/ecl.e.RHUX">http://iraf.net/ftp/pub/fitz/ecl.e.RHUX</a>  --  Simply download this, rename 'ecl.e', make it executable and put it in your iraf$bin.redhat directory.  You still need to have installed the files from the ecl_install_&lt;arch&gt; file to get the param file.  If you're already running V2.13 this new binary doesn't offer anything new.<br>
<br>
Cheers,<br>
