**Philip Massey** wrote on May 06, 2006

<div>
Someone who actually knows something will have to answer the specific question, but let me note that there might be two alternative ways around this issue for you:<br>
<br>
a) Mark the approximate centers using tvmark:<br>
    unlearn tvmark<br>
    tvmark 1 xyfile interactive+<br>
and just drive around the image display hitting "a" (for "add").<br>
This gives you a file that contains the x and y coordinates of where<br>
the cursor was when you hit a "a".  Then, run center on this file.  To<br>
make sure everything worked to your satisfaction, display the image<br>
again, and overmark the centered coordinates using tvmark again:<br>
    tvmark 1 xyfilecentered interactive-<br>
where xyfilecentered is the output of center.<br>
<br>
b) I'm surprised that you can't take advantage of "daofind" to find the <br>
approximate centers of most of the galaxies. You would have to specify a<br>
very large fwhm, and play around with sigma, round, and sharp, to see what<br>
worked pretty well.  Whatever it missed, you could then add by hand.

<div>
Phil has some good tips on how to alternately use the task, see also the help page examples for using the CONTOUR plot instead of the display.<br>
<br>
That said, I wasn't able to reproduce your problem on an Ubuntu (or any other) setup here, and I can't imagine what would be causing the delay.  Two ideas come to mind however:  From the terminal window define a DEBUG_IIS environment variable before starting ds9, e.g.<br>
<br>
% setenv DEBUG_IIS 2<br>
% ds9<br>
<br>
Then login to iraf in a different window.  When you display or read the cursor you should see the IIS protocol messages being exchanged which will include the redraw of the pixels to make the mark and the cursor read request.  If those requests come almost instantaneously the problem is on the DS9 side and you should be sure you're using the latest version.  If there is a delay and the requests come 15sec later when the mark is drawn let me know.<br>
<br>
The second idea is to simply use the markers in DS9 directly as a workaround, e.g. hit the SpaceBar for the CENTER input and then click the left mouse button to make a mark on the screen.  The circle size/shape can be adjusted using the Edit-&gt;Preferences-&gt;Region menu panel.  Hope this helps.<br>
<br>
Cheers,<br>
-Mike
