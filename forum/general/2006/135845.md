The IMPORT/EXPORT tasks in the DATAIO package are able to convert the PPM file to FITS (import) and then back out to something like a GIF (export) that GIMP could handle.  Note however that FITS doesn't have a color model and so you may need to deal with the RGB planes of the image separately.  You're images are also likely missing a WCS in the header so you'll be dealing mostly with pixel coordinates.  <br>
<br>
You can use the REFERENCES task (or the 'Apropos' search bar above) to look around for tasks that might help 'register' or 'shift' your images by various means.  If you goal is to combine the images into a color format at the end, using IRAF for the registration and GIMP for the combination isn't a bad way to go.  There are a number of Windows-based applications for astrophotography that might be easier, using VMware to run them in a windows virtual machine is another option.<br>
<br>
Lastly, see the registration document at <a href="http://iraf.net/irafdocs/reg/">http://iraf.net/irafdocs/reg/</a><br>
<br>
Hope this helps.<br>

-Mike
