<div>
The use of @files only works as you're expecting in the case where there is an output (list) parameter for the task.  In the case of TPRINT there can be multiple input files but the '&gt;' will redirect ALL output from the command (as it would in unix).  If you want to split the output you'll need to process each input file in turn in some sort of loop.<br>
