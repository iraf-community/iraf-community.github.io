For Linux 2.6 kernels and IMFORT tasks you need to specify that the 'stacksize' is unlimited in order to work around changes in the memio system.  For example<br>
<br>
<pre><code>
linux%  limit stacksize unlimited     [for c-shell]
linux% ulimit -s unlimited    [for bash]
</code></pre><br>
<br>
Put this in your environment file or on the commandline before running the task.  The normal CL startup command does this for you automatically, however imfort tasks are normally declared as foreign commands and so the above should go in your .cshrc/.bashrc file.<br>
