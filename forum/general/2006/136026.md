<div>
If <strong>every<strong> task throws a memory corruption error then the stacksize limit is the proper fix so long as it's done in your .cshrc file or the hlib$cl.csh startup script.  However, the error can also simply be a coding error in the task, a bug triggered by the data or perhaps a weird combination of parameters.  If it's only the ELLIPSE task then this is probably the latter.  The ST helpdesk can be reached at help@stsci.edu and this may be something familiar to them, otherwise be sure you're using the latest version, unlearn parameters or try different data to see if you can isolate the problem.  Hope this helps.<br>
