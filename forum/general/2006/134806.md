Hi Doug,<br>
<br>
Pixel lists are more a data structure than a file format even though they are available through the standard IMIO interfaces.  So, there is no document on the format other than the sys$plio interface itself, but see the README file and PLIO.hlp in that directory for more info.  Also see the imio$iki/plf image kernel code (and the imio routines referenced in the README there).  I'm not sure whether CVOS will read .pl files, but it may be a solution.<br>

Cheers,<br>
-Mike
