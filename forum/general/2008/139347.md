Hopefully this will be an easy question to answer if nobody minds taking a few minutes to read. I'm writing a little IRAF script and have a little problem, which essentially boils down to the following.<br>
<br>
I have the variables <em>image</em> and <em>coofile</em>. I have set image to be <em>sa95.fits</em> and want coofile to be <em>sa95.fits.coo</em> , with the sa95.fits part coming from the <em>image</em> variable and the .coo bit being just text. Basically, my question is how do I set the value of a variable to be that of another variable, plus some text?<br>
<br>
<pre><code>
string image
string coofile

image = &quot;sa95.fits&quot;

coofile = image #want this to be image.coo

</code></pre><br>
<br>
Thanks a lot!<br>
<br>
Sam

<div>
Try:<br>
<br>
<pre><code>
image = &quot;sa95.fits&quot;
coofile = image // &quot;.coo&quot;
</code></pre><br>
<br>
The '//' is a string concatenation operator.<br>
<br>
-Mike
