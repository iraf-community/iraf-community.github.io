What, if any, error message do you get?  A 'command not found' means the 'ds9' command is not in any directory defined by your path.  Also,  how is your alias defined?  Can you execute the file by specifying the full path directly?  Does the binary have the execute permissions set?<br>
<br>
<blockquote><br>
IMPLOT<br>
When attempting to run implot the display window ceases to load and instead I get a paragraph or more of nonsense writing in my terminal. such as @#$qw!@Y#%KO@WQ$#@!%. Anyone know how to address these issues? </blockquote><br>
<br>
Garbage in the screen always means a mismatch in the terminal type, e.g. you aren't really running an Xterm window but an rxvt, gnome-terminal, etc (these do not support graphics).  The terminal type is set in your login.cl and can be reset on the commandline or by doing a new MKIRAF.<br>
