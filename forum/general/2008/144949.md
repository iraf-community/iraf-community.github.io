**Mike Fitzpatrick** wrote on Nov 26, 2008

{% raw %}
<div>
Because the task has parameters (i.e. arguments in the procedure declaration, more generally, anything before the 'begin'), you must declare it without the '$', e.g.<br>
<br>
<pre><code>task markit = /path/markit.cl</code></pre><br>
<br>
As for the syntax error, I think notepad may have put some control characters in the file that are causing the problem, the script runs fine for me (file created with 'vi').<br>
<br>
-Mike
</div>
{% endraw %}
