<div>
What is the value of your 'arch' CL environment variable (i.e. "cl&gt; show arch") and what kind of Linux system are you using?  The Redhat binaries are appropriate for systems like Fedora, CentOS, RH Enterprise, and (I think) Scientific Linux, but all other platforms should have 'arch' set to '.linux'  and so you would need to mv the package 'bin.redhat' directory to 'bin.linux' for them to be found.<br>
<br>
Finding the executable in the current directory is a last resort for the system, the fact you're getting the error means that the binaries are installed in 'bin.redhat' but the system is expecting them to be someplace else (probably bin.linux).  <br>
<br>
Cheers,<br>
-Mike
</div>
