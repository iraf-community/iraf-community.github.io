<div>
1)  This error occurs in scripts when there is a parameter which matches a variable with a minimum match.  One solution is typically to declare a dummy parameter in your script "string flat" even if you don't use it.  I can't tell more without the whole script.<br>
<br>
2) It is hard to spot the problem.  Send the result of listing all the parameters right before you execute the task:<br>
<br>
<pre><code>
cl&gt; lpar ccdproc
cl&gt; ccdproc
</code></pre><br>
<br>
Yours,<br>
Frank Valdes
