<div>
Let me guess: You use emacs?<br>
<br>
The script is syntactically fine, however emacs users sometimes get into a mode where the file is missing and EOF or a newline at the end of the last line.  I can run your script correctly but can also reproduce the error if I remove the '\n' after the "end" statement.  "Parser gagged " in this case means the interpreter saw the EOF before the newline terminating the last statement.<br>
