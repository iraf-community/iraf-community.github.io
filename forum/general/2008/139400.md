# flushing parameter changes

**Tom Duvall** wrote on Apr 17, 2008

{% raw %}
<div>
I have some batch iraf jobs that use the same uparm directory as my normal foreground iraf.  Sometimes I have occasion to change a task parameter in the foreground iraf, like "task.param = 41".  I would like for this to be reflected in the parameter file in the uparm directory.  If I do 'flprc', this doesn't do it.  If I logout of the foreground job, that does it.  I'm looking for a 'less drastic' way to flush these parameter definitions.<br>
Tom
</div>
{% endraw %}

---

**Mike Fitzpatrick** wrote on Apr 17, 2008

{% raw %}
<div>
'flprc' is short for 'flprcache' which refers to the process cache.  To update the parameters on disk see the 'update' command and its help page.  Note that if you want the parameters used by background tasks to be independent, you can always just reset the 'uparm' environment variable.<br>
<br>
-Mike
</div>
{% endraw %}
