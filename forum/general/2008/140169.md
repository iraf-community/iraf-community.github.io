<div>
IRAF parameters have 7 attributes:<br>
<br>
name,type,mode,value,min|dictionary,max,prompt<br>
<br>
The type may be<br>
<br>
integer(i)<br>
real(r)<br>
string(s)<br>
parameter set (pset)<br>
<br>
In addition a preceeding * means it is "list structured".  The value is a file name and each request for the parameter reads the next line for the value:<br>
<br>
e.g. *r will read a real value from each line.<br>
<br>
The mode may be<br>
<br>
a for automatic<br>
q for query<br>
h for hidden<br>
<br>
Anyway,  what you are looking for is "pset" in order for a parameter whose value points to a file or task containing a set of parameters.<br>
<br>
To read more on the IRAF parameter mechanism do<br>
<br>
<pre><code>
help parameters
</code></pre><br>
<br>
The reason for the pset paper is that this was feature added after the basic IRAF parameter system was in place.<br>
<br>
Yours,<br>
Frank Valdes
</div>
