The usual way to extract 1D spectra from 2D data is with the twodspec.apextract package.  Admittedly this is a fairly sophisticated package with lots to learn for the novice.  But it may be good for you to learn about it and look over the documents of spectral reductions in the docs area of the iraf.net site.<br>
<br>
The simplest way to do a simple column or line sum of a 2D spectrum is with the task SCOPY in the ONEDSPEC package.<br>
<br>
<pre><code>
cl&gt; onedspec
cl&gt; onedspec.dispaxis=2    # 1=spectrum along rows, 2=spectrum along cols
cl&gt; onedspec.nsum=10      # Number of rows/columns to sum
cl&gt; scopy spec2d spec1d aper=50
</code></pre><br>
<br>
In the ONEDSPEC package tasks which work on 1D spectra automatically convert 2D spectra using dispaxis, nsum, and aperture.  The "aperture" parameter is the row or column in the 2D spectrum which is the center of the spectrum you want to extract.  Note that instead of using SCOPY you could use SPLOT to do the conversion internally and get a graph of the spectrum.<br>
