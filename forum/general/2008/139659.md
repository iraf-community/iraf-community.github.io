**Mike Fitzpatrick** wrote on Jun 05, 2008

{% raw %}
<div>
The answer all depends on the format of the input table:  The FIELDS task can extract columns from a table and the JOINLINES task can merge two files by joining the lines.  Similarly, the TSELECT task in the TABLES external package can select rows and cols from a table, or TDUMP/TPRINT can output selected entire columns.  The TMERGE or TJOIN tasks could then be used to join the tables/rows.<br>
<br>
Cheers,<br>
-Mike
