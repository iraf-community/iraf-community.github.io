The normal Mac Terminal.app cannot be used for graphics.  If you're using XGterm then you just need to tell IRAF that's the terminal type, i.e. either reply 'xgterm' when asked the terminal type when running MKIRAF, or at the CL prompt type the  command:<br>
<br>
<pre><code>cl&gt; stty xgterm</code></pre><br>
<br>
If you see a bunch of gibberish on the screen it means the terminal type is set incorrectly, or you aren't really running an xgterm.<br>
<br>
Cheers,<br>
-Mike
</div>
