I used the daophot task "psf" to compute a psf for my crowded starfield.  I selected by hand 10 stars that were isolated and which had average fwhm values.  I then generated the image.mag file with phot and the image.pst file by hand using the information in the image.mag file.  <br>

The output image "image.psf.fits" I got, has a funny dark shape in the middle although my stars had close to perfect Gaussian shapes.  This is bothering me.  Isn't this image that "psf" generates supposed to be like a top-view of the light curve and therefore must be the brightest in the centre with a circular shape? <br>

Hello Lientjie,<br>
<br>
You may have figured this out since this reply is rather late.  The DAO PSF model consists of an analytic function (e.g. a gaussian) and an empircal residual image.  The .psf file header has information about the analytic function and the image raster has the residuals.  It is very normal to see the pattern you describe as well as a dark ring with a bright peak.  To see the actual PSF you should run the task SEEPSF which creates a PSF image you can display.<br>
<br>
Yours,<br>
Frank Valdes

<div>
Johan,<br>
<br>
Getting a good PSF and subtraction is sometimes as much an art as science.  It depends on the data, whether there is a position dependent PSF variation (e.g. distortions) and maybe the right selection of PSF template stars.  So it is normal to get some problems such as you describe.  The only thing you can do is iterate until you get the best result you can.<br>
<br>
Yours,<br>
Frank
