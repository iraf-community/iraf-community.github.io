<div>
Distribution files are compressed tar files and can be unpacked as e.g.<br>
<br>
<pre><code>
% cd /iraf/iraf
% tar zxf /path_to/as.pcix.gen.gz
</code></pre><br>
<br>
For the binaries you would run similar commands on the appropriate IB or NB distribution files in /iraf/irafbin/bin.&lt;arch&gt; and /iraf/irafbin/noao.bin.&lt;arch&gt; respectively.  <br>
<br>
See the installation guide for a complete example and details.<br>
<br>
-Mike
