**Francisco Valdes** wrote on Jul 11, 2008

{% raw %}
<div>
Since you have only one reference spectrum there is no need to do much to assign a reference spectrum to an object spectrum.  You could use "select=match" in refspec or you could add<br>
<br>
hedit scispec refspec1 'comb58_62' add+<br>
<br>
That is, add a keyword REFSPEC1 to the science spectrum, scispec in the example, whose value is the reference spectrum file name.<br>
<br>
All the other choices for the refspec.select parameter depend on having a keyword in the header to sort against.  The default is JD which is why you got the message.  Your header doesn't really have any keyword that would be suitable for selecting a reference.<br>
<br>
Yours,<br>
Frank Valdes
</div>
{% endraw %}
