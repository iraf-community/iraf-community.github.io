<div>
In V2.14 the default imtype was reset to 'fits' meaning that all new images would be FITS.  To explicitly use 'imh' you need to either specify the file extension when creating the image (e.g. "imcopy dev$pix foo.imh"), or you can <br>
<br>
<pre><code>cl&gt; reset imtype = &quot;imh&quot; ; flpr 0             # zero, not oh</code></pre><br>
<br>
This can also be done in your login.cl file.<br>
<br>
Note that FITS images can be used directly provided they have an extension.  The tutorial images don't have an explicit extension, but you can add one using something like<br>
<br>
<pre><code>cl&gt; rename fsp* fits field=extn</code></pre><br>
<br>
With that done, you can use the FITS files directly in the exercises.<br>
<br>
Cheers,<br>
-Mike
