**Mike Fitzpatrick** wrote on Apr 15, 2008

{% raw %}
<div>
<blockquote>Doing a "grep -n WORD FILE" works out fine, but do you know how I'd go about sticking it in a script? Is that possible? </blockquote><br>
<br>
Grep is declared (along with many others) as a foreign command in your login.cl file.  You can extend the list of available commands by editing that file or simply using the '!' shell escape.  <br>
<br>
To answer your specific question: For foreign commands you simply use the "program mode" syntax, i.e.<br>
<br>
<pre><code>grep (&quot;-n&quot;, &quot;word&quot;, &quot;file.txt&quot;)</code></pre><br>
<br>
where cmdline args like '-n' become literal arguments, and filenames like 'file.txt' could just as easily be script variables.  If grep wasn't a foreign command you'd just create the command string and pipe it to the CL, e.g.<br>
<br>
<pre><code>print (&quot;!grep -n myword &quot; // fname) | cl()</code></pre><br>
<br>
-Mike
</div>
