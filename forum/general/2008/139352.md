**Mike Fitzpatrick** wrote on Apr 10, 2008

{% raw %}
<div>
DS9 (or XImtool) need to be running before you try to display an image.  The message simply means that IRAF can't find a display server running.  There can be other explanations so if you still have problems, let me know what platform you're using.<br>
<br>
<blockquote>Also, I can use ds9 to display the images just fine, so do I even need to worry about IRAF's native display capabilities?</blockquote><br>
<br>
That's up to you, however some tasks require interaction with the image display and things can be simpler if IRAF displayed the image in the first place.<br>
<br>
Cheers,<br>
-Mike
</div>
