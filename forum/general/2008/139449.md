**Mike Fitzpatrick** wrote on Apr 24, 2008

{% raw %}
<div>
Use the 'min' and 'max' parameter attributes, e.g.<br>
<br>
<pre><code>
procedure test (range)

int     range                   { prompt=&quot;range&quot;, min=80, max=98 }

begin
    print (range)
end
</code></pre><br>
<br>
Cheers,<br>
-Mike
</div>
{% endraw %}

It's just a matter of resetting the parameter attribute 'p_max' , e.g.<br>
<br>
<pre><code>
ecl&gt; =display.frame.p_max
4
ecl&gt; display.frame.p_max=23
ecl&gt; =display.frame.p_max
23
</code></pre><br>
<br>
There is likewise a 'p_min' attribute for the minimum value.<br>

**Mike Fitzpatrick** wrote on Apr 24, 2008

{% raw %}
<div>
Because '1' is the starting character for 10, 11, 12, etc  It is a string type and so abbreviations are permitted so long as they are unique.<br>
<br>
Additionally, the first character of the enum string should be the delimiter not the first value, i.e. use "enum="|1|2|..." not "enum='1|2|...."<br>
<br>
<blockquote>Also, what is the parameter attribute for enum? p_enum doesn't seem to work. </blockquote> <br>
<br>
Enumerated values are store in the parameter 'min' field, i.e. the p_min attribute.<br>
<br>
Cheers,<br>
-Mike
</div>
{% endraw %}
