I'm not sure if one of the DIGIPHOT packages, say APPHOT, has the option for uncentered sky regions.  The most likely task would be polyphot but my quick reading of the help file doesn't suggest this is possible.<br>
<br>
The task that will do this is in the external GUIAPPS package.  The subpackage XAPPHOT is for photometry and the tasks XGUIPHOT or XGPHOT allow independent skies.  The GUI task can be quite useful for complex interactive photometry situations such as you are dealing with.<br>
