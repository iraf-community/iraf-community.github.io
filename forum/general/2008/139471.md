<div>
You're correct that the string replaces only up to the same number of chars that are currently permitted for the column.  this is enforced by the TABLES library code and not the task so there is no way to change this behavior other than to modify the table to the solumn is e.g. 7 chars wide instead of 5.<br>
<br>
Cheers,<br>
-Mike
