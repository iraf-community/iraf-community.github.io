**Mike Fitzpatrick** wrote on Jun 30, 2008

{% raw %}
<div>
If you're going to be overwriting files in IRAF, you need to set the 'clobber' environment variable, by default the system protects from overwrite.  E.g., try<br>
<br>
<pre><code>cl&gt; reset clobber = yes
cl&gt; listpix .....
</code></pre><br>
<br>
-Mike
</div>
{% endraw %}
