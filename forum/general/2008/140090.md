**Mike Fitzpatrick** wrote on Aug 20, 2008

{% raw %}
<div>
If it is the same region for all the images, then you can do it directly using an image section, e.g.<br>
<br>
<pre><code>cl&gt; imstat *.fits[100:200,300:400]</code></pre><br>
<br>
and the specified section will be used for each image.  Is this what you needed?<br>
<br>
Cheers,<br>
-Mike
</div>
{% endraw %}
