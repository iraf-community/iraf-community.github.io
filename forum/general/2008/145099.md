Siti,<br>
<br>
I've verified that histogram mode works in the latest v2.14.1 release, but you don't actually see the histogram unless you zoom in (e.g. use the 'z' key repeatedly).<br>
<br>
The ":hist" command should indeed report that if you've set the "option=histogram" on the commandline that it is yes, but if you've literally typed ":hist [yes]" (where the brackets are the problem) this might confuse the setting.  Also, was 'histogram' the only setting or was this in combination with something else?<br>
<br>
-Mike
