**Mike Fitzpatrick** wrote on Apr 03, 2008

<div>
Steve,<br>
<br>
This may be related to your earlier problems with the 'imdir' setting, be sure that this was reset if needed and is still valid.<br>
<br>
Otherwise, since this is a temp file there may be a conflict between the setting of your 'imtype' variable (which sets the default image type for new images if not explicitly set with an extension), and the explicit .imh extension you are using.  Do a "show imtype" to see the current value, and if it is something like 'fits' reset it to 'imh' with the command<br>
<br>
<pre><code>cl&gt; reset imtype = imh
cl&gt; flpr 0                                              # zero, not oh
</code></pre><br>
<br>
Cheers,<br>
-Mike
</div>
