<div>
The 'task has no param file' message usually means that either the path to the task/script is incorrect, or that the task really doesn't have any parameters but was declared as if it did. <br>
<br>
For scripts, parameters are anything declared before the 'begin' statement in a procedure script (command scripts don't have parameters by definition).  If your variables are all declared after the 'begin' then the script has no parameters and should be declared with a '$' before the task name, i.e.<br>
<br>
<pre><code>task $ircombbin = /path/ircombbin.cl</code></pre><br>
<br>

<div>
You'll need to rename the script file to 'ircombbin.cl'.  When looking for the parameter file a filename is being constructed internally based on the task name (with a '.par' or a '.cl' extension).  An alternative is to create an 'ircombbin.par' file to explicitly hold the parameters,  if you did this it would look like:<br>
<br>
<pre><code>
refimg,s,h,,,,
shiftfile,s,h,,,,
coordfile,s,h,,,,
outfile,s,h,,,,
continue,s,h,,,,
ink,s,h,,,,
inj,s,h,,,,
inh,s,h,,,,
refk,s,h,,,,
refj,s,h,,,,
refh,s,h,,,,
date1,s,h,,,,
one,s,h,,,,
imglist,*struct,h,&quot;&quot;,,,
mode,s,h,&quot;ql&quot;,,,
</code></pre><br>
<br>
-Mike
