Hi Steven,<br>
<br>
I wouldn't claim to be an expert in these things (especially Mac), but it sounds like a hardware problem to me. Whatever IRAF does wrong, it should not be able to crash your computer unless you have an OS bug or a hardware error. Can you also crash the machine by doing something CPU intensive, such as compiling code? In any case, there should be no problem reducing NIRI data in IRAF with 2Gb of RAM.<br>
<br>
Since you have already tried changing the RAM, maybe there could be some problem with the processor or a cooling fan, for example? You can probably download a hardware diagnostics program from the Web that will boot from a CD and run continuous tests for a few hours to look for possible failures. If you find errors that way, you can presumably send the machine back. Alternatively, it might be worth searching the Web for known problems with your version of Apple's software such as the X server.<br>
<br>
Someone else might be able to tell you where to look on a Mac for information such as kernel error messages or CPU temperature.<br>
<br>
Cheers,<br>
<br>
James.
