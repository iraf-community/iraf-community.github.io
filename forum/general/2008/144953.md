<div>
It depends on the type of conversion being done, e.g. a clgetb() will complain if you enter anything but 'yes' or 'no', but a clgeti() will simply truncate a floating point value.  Internally in SPP people have use YES/NO instead of TRUE/FALSE and for some compilers this is fine, but recent GCC will complain about a type mismatch.  There is a coerce() function to morph pointers (mainly by changing alignment), otherwise things are done using the normal type casting functions like 'int()'.<br>
<br>
Short answer, you'll know if you broke something, and don't try to push the limits.<br>
<br>
-Mike
