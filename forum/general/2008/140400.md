<div>
Try searching the forum using keywords like echelle and tilt.  Basically the solution is to divide up each order into a number of narrow apertures (~1 pixel), extract them, wavelength calibrated them, and then combine them back together in wavelength space.  It is a little complicated because of bookkeeping but it will address the problem.<br>
