<br>
The spectral packages, such as onedspec, have heuristics that try and handle units and recognize various keywords for the dispersion units.  In your case you should be able to add a keyword CUNIT1 (or whatever axis is the wavelength) with a value of 'micron'.  Note that CUNITn is not standard FITS though its meaning would be quite clear.<br>
<br>
Once the software knows the units there are ways to change the units in various tasks.  Note that SPLOT will plot in angstroms by default.  There is a parameter in SPLOT to specify the desired default units.  Note also the ":units" command to change units.  This also appears in other tasks.<br>
