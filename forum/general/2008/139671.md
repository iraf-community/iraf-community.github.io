Hi Paul,<br>
<br>
    For fitting gaussians the first task that comes to mind is the NGAUSSFIT task in STSDAS.FITTING, although I admit I'd need to play with it to know whether it could be used if given only data in the wings.  Perhaps more promising is the NFIT1D task in the same package that sports a 'function' parameter, one of the allowed values being<br>
<br>
<blockquote> galaxy brightness profile (bulge and disk), </blockquote><br>
<br>
You might need to reformat the histogram data into a table but might also be able to use this to fit the entire thing.<br>
<br>
    Lastly, you might google around for more specific bulge-disc decomposition tasks (tasks like GIM2D and GALMORPH come to mind. can't remember whether GALFIT was iraf based or not).<br>
<br>
Cheers,<br>
-Mike
