**Mike Fitzpatrick** wrote on Apr 29, 2008

{% raw %}
<div>
Since what you want is to redirect the output of one task into the values of two separate parameters, then no, this cannot be done.  Some tasks *can* be chained together using pipes and specifying the input/output params to be STDIN/STDOUT respectively, but not in this case.<br>
<br>
That said, things can be made a lot simpler.  For example, the FIELDS task can be used to select columns from the output, and in the case of a single object you could pipe this to scan() to save the results to local variables.  For example<br>
<br>
<pre><code>cl&gt; imcentroid input.fits ref.fits coords.txt verbose- | fields STDIN &quot;2,4&quot; | scan (x,y)
cl&gt; imshift  input.fits output.fits xshift=x yshift=y
</code></pre><br>
<br>
For multiple objects you would save the intermediate file and loop over the result.<br>
<br>
Cheers,<br>
-Mike
</div>
