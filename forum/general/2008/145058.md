# Creating text files in scripts

Hello there! This is my first post, but I've been reading the forum for weeks. You guys have been great helping me to understand IRAF.<br>
<br>
My problem has to do with having my cl script output a package's results to a text file. When not in a script, I often use syntax such as:<br>
<br>
imheader imlist=fitsimage lo+ &gt; headerinfo.txt<br>
<br>
which will create a text file named headerinfo.txt. If I wish to do the same in a cl script (since I must use program langauge) I would type something like:<br>
<br>
imheader (imlist="fitsimage" longheader="yes" ) &gt; headerinfo.txt<br>
OR<br>
imheader (imlist="fitsimage" longheader="yes" &gt; headerinfo.txt)<br>
<br>
but both of them yield syntax errors. Any help on how to create a text file from the output of a package? Imheader puts out many many lines of data and i want to put it all in a text file.<br>
<br>
Thanks so much!

**Mike Fitzpatrick** wrote on Dec 10, 2008

{% raw %}
<div>
<blockquote>imheader (imlist="fitsimage" longheader="yes" &gt; headerinfo.txt) </blockquote><br>
<br>
This is the closest to what you want, but you need to remember that the various parameters are separated by commas in 'program mode', and since you're using a literal filename you need to enclose it in quotes.  Try e.g.<br>
<br>
<pre><code>
imheader (imlist=&quot;fitsimage&quot;, longheader=&quot;yes&quot;, &gt; &quot;headerinfo.txt&quot;) </code></pre><br>
<br>
Note the comma before the redirection (which is considered as another argument to the task).<br>
<br>
If your intent is to extract specific header keywords then you may want to consider using HSELECT and "scan from pipe", e.g.<br>
<br>
<pre><code>hselect (&quot;dev$pix&quot;, &quot;object&quot;, yes) | scan (objname)</code></pre><br>
<br>
where 'objname' is a local script variable.<br>
<br>
-Mike
</div>
