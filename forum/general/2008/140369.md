<div>
You'll want a newline ("\n") to end the printf and don't just pipe the output of printf to the variable but use a scan call.<br>
<br>
<pre><code>
      :
begin
   string str
   int n
   for(n=1;n&lt;=5;n+=1)
       {
          printf(&quot;left_%d.fits\n&quot;, n) | scan(str)
          print(str)
       }
     :
end
</code></pre><br>
<br>
But the way I would do it would be like this:<br>
<br>
<pre><code>
     :
begin
   string str
   int n
      :
   for(n=1;n&lt;=5;n+=1)
       {
          str=&quot;left_&quot;//str(n)//&quot;.fits&quot;
          print(str)
       }
     :
</code></pre><br>
<br>
I also hate any n=n+1 type constructs and changed it to n+=1. I prefer even more n++ but IRAF doesn't have an increment operator.<br>
<br>
Jason
</div>
