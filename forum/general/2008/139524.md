'/bin/bash: routine.e : command not found' .<br>
The routine.e is present in the same directory from where iraf was launched, it was compiled using 'fc routine.f' and it created the excecutable 'routine.e'.<br>

<div>
The '!' executes the command in a spawned shell, the 'command not found' is telling you the command isn't included in your $PATH.  You can either adjust your path, or else run it as "!./routine.e" to force the execution of the file in the current directory (or else add the '.' directory to your PATH).<br>
<br>
Cheers,<br>
-Mike
