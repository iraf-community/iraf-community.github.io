**Mike Fitzpatrick** wrote on Nov 28, 2008

{% raw %}
<div>
If you see a lot of garbage on the screen, then it means you either have your terminal type set incorrectly or you aren't actually using an XGterm window to login to iraf. You can set the terminal type when you first do a MKIRAF or on the commandline as "cl&gt; stty xgterm" so long as you are actually using an XGterm window.<br>
<br>
The alternative is perhaps that XGterm no longer works properly on Fedora 10 (a system I haven't tried).  There haven't been any similar reports of problems, but I would assume that an Xterm window still works.<br>
<br>
-Mike
