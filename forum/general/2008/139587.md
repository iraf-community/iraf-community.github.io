Hi,<br>

I'm afraid you will have to find a workaround for this because the resources needed to reproduce and then debug this are not available here.  You could combine in smaller groups and then combine the groups.  The maxmemory feature can help with some problems but not all.  It is not likely to help with the memory corruption error since mostly it helps when the error is "out of memory".  You could try it and change the value down by a factor of 10 and then 100.<br>
<br>
If we get more reports, particularly with something that is easy to reproduce, this will get fixed in a future release.<br>
<br>
