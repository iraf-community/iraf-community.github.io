<blockquote>The output of the script will be , first make master bias using zerocombine and then using CCDPROC subtract the master bias from science and flat images.<br>

<br>
I suspect the problem is that you are passing in the name of the file containing the image list, but without the '@' preceeding it.  For example, if 'images.txt' is a list of images to reduce you would call your script as e.g.<br>
<br>
<pre><code>cl&gt; reduction bias.fits @images.txt</code></pre><br>
<br>
<blockquote>Second thing I like to ask ,if I want declare ZEROCOMBINE and CCDPROC as parameter (before begin) how to declare it? how my script will look and work? </blockquote><br>
<br>
I don't understand what you're asking:  You cannot declare tasks as parameters.  If what you want is to define some of the task parameters as a separate step then you would do something like<br>
<br>
<pre><code>
zerocombine.combine=&quot;average&quot;
zerocombine.reject=&quot;minmax&quot;
   ... and so on

zerocombine (input=l_bias, output=&quot;mbias.fits&quot;)
</code></pre><br>
<br>
If you want e.g. the 'reject' parameter to ZEROCOMBINE to also be a parameter to your script you would declare it as such and then set it as above.<br>
<br>
-Mike
