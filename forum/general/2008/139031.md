**Mike Fitzpatrick** wrote on Feb 15, 2008

<div>
Tracy,<br>
<br>
You can eliminate any question of path permissions problems by seeing whether you can view the file from the CL directly, e.g.<br>
<br>
<pre><code>cl&gt; type onedstds$blackbody/standards.men</code></pre><br>
<br>
If this fails then start checking individual paths, "cl&gt; dir onedstds$" etc to see where the problem is.<br>
<br>
Are you running the STANDARD task directly from the CL prompt or from a script?  If the latter then this could be a problem with running out of file descriptors.  This can happen when e.g. a script opens a 'list' variable inside a loop but doesn't effectively close it with a<br>
<br>
<pre><code>list = &quot;&quot;</code></pre><br>
<br>
statement.<br>
<br>
We're not aware of any problems with the task or file permissions so something else must be going on.  Hope this helps.<br>
<br>
Cheers,<br>
-Mike
</div>
