# make error beep

**Jason Quinn** wrote on Aug 01, 2008

{% raw %}
<div>
The new error function is nice but it is silently thown. I prefer to have scripts beep when they encounter an error (frequently I'm on another desktop while a script is running). I end up using code like this in my scripts<br>
<br>
<pre><code>if ( error condition )
         {
         beep()
         error(1,&quot;an error occured&quot;)
         }
</code></pre><br>
<br>
when I'd rather be able to do something like<br>
<br>
<pre><code>if ( error condition )
         error(1,&quot;an error occured&quot;, beep+)
</code></pre><br>
<br>
Is it possible to add a feature like this to error?<br>
<br>
This would be a worthwhile extension and could be done without breaking existing code.<br>
<br>
Jason
</div>
{% endraw %}
