{% raw %}
<div>
The error usually means just that either your 'uparm' directory doesn't exist, or you don't have write permissions in it (e.g. you are logging in through the 'iraf' user account as yourself and can't write to the uparm directory owned by 'iraf).  Uparm directories are created when you do a 'mkiraf' (which you only need to do once in a directory), then login using the 'cl' command.  You should not be using the 'iraf' account as the login, just do a MKIRAF yourself in your home directory.<br>
<br>
-Mike
