<div>
In v2.14 we switched to the ECL as the default, this uses the readline interface to permit the history editing and fix the backspace problem, but has a side-effect with host scripts such as this.  Specifically, if the current directory contain a login.cl file the 'stty xgterm' command is causing the problem.<br>
<br>
Try running the script *without* a login.cl file in the current directory, or to get the old CL execute using<br>
<br>
<pre><code>% cl -old &lt; /tmp/cl.reduce$$ &gt; /tmp/cl.logreduce$$</code></pre><br>
<br>
Otherwise, I wouldn't expect your script to work since the '@objectlist' would require a CL variable 'objectlist' to be present.  Since you say 'relevant part of the script' I'll assume for now this is set elsewhere.  Anyway, hope this helps.<br>
<br>
Cheers,<br>
-Mike
