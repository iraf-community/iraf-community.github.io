# imcombine - sigma image with median stack

{% raw %}
<div>
How is the sigma image calculated when you median combine a stack of <br>
images with imcombine?
</div>
{% endraw %}

---

**Francisco Valdes** wrote on Nov 05, 2008

{% raw %}
<div>
The sigma image is always the the reduced RMS (root mean square corrected for a finite population by using N-1) of all non-rejected values about the output value at each pixel.  So for a median the RMS is about the median value.<br>
