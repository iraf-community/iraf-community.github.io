<br>
Installing Cygwin is just a matter of getting the setup program from cygwin.com and running it on your machine.  In general, just using the default installation is enough to run IRAF, but you may want to also select the development tools, C-shell, and X11 environments as well.  The program will download and install all you need, then just select the  Cygwin icon to bring up a terminal window you can use to install IRAF.  Note you'll need X11 so you can run Xterm (or XGterm) as a graphics terminal and a display server like DS9.<br>
