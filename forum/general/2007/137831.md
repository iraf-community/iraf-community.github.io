<div>
The "Scale Parameters" option at the bottom of the DS9 'Scale'  menu should let you set the z1/z2 values manually, I don't believe there are any XPA access points or command-line options that would let you do this automatically.  The menu on that popup panel will also let you control some parameters used in the DS9 zscale algorithm which is the old version.  IRAF currently uses (by default) 1000 points evenly grid over the image to compute the z1/z2, the old version (i.e. DS9) uses 600 points on 120 lines and so the sampling and resultant values will be slightly different.<br>
<br>
How are you overlaying the WFPC aperture?  Tasks like WCSCTRAN and SKYCTRAN can help you convert between image and sky coordinates.  The COMPASS task in STSDAS.GRAPHICS.SDISPLAY can overlay a compass for you.<br>

-Mike
