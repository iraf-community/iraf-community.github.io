<div>
The 'x86' is a generic cpu architecture naming convention, the current v2.13 Redhat (RHUX) binaries will work fine under Fedora.  Note the system is still only 32-bits and compilation (external packages or local tasks) under 64-bit isn't supported at this time.  A user in Japan has been working on a 64-bit system and appears to have made some progress (see  <a href="http://www.ir.isas.jaxa.jp/~cyamauch/iraf64)">http://www.ir.isas.jaxa.jp/~cyamauch/iraf64)</a>.  For external packages and such it is best to install pre-compiled redhat binaries, if you still have problems or questions let us know.<br>
<br>
The X11IRAF v1.5DEV sources from the download area <em>should</em> build, if you ahve problems with XGterm try the prebuilt binary at <a href="ftp://iraf.noao.edu/pub/xgterm.fedora">ftp://iraf.noao.edu/pub/xgterm.fedora</a>.<br>
<br>
Cheers,<br>
-Mike
