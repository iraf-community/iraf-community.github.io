**Mike Fitzpatrick** wrote on Dec 19, 2007

{% raw %}
<div>
SIMPLE=F means, according to the FITS standard, that the file is NOT FITS standard.  IRAF (both the FITS kernel and the RFITS task) check this field and simply punt if it isn't true, the CFITSIO code used in DS9 may be more lenient.  In practice many files put SIMPLE=T even if they use non-standard conventions (e.g. the ESO HIERARCH keywords) and the tasks read them fine.<br>
<br>
I think your options are to change the value, or look at something like the IMPORT task to read the image as a raw raster file.  If the file really isn't conforming then changing the value may still be an error.  What's the origin of these files?<br>
<br>
-Mike
</div>
{% endraw %}
