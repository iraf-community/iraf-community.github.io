**Mike Fitzpatrick** wrote on Sep 17, 2007

{% raw %}
<div>
The V2.13 release doesn't include binaries for the iraf kernel routines by default.  Try copying the contents of $iraf/unix/bin.redhat to $iraf/unix/bin.linux to fix this and then re-run the install script.<br>
<br>
Cheers,<br>
-Mike
</div>
{% endraw %}
