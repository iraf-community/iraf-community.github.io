# Problem with Match in .cl script

**Elden Paul Iverson** wrote on Jul 10, 2007

{% raw %}
<div>
I have been having trouble using the match command.  Below is a portion of the script I am using.<br>
<br>
hselect BYU*.fits $I,FILTER yes &gt; "datalist1"<br>
match U\# "datalist1" &gt; "datalistU"<br>
<br>
I want the script to pull out the filename and filter field from each header and delete the images taken in the U filter.  Unfortunately it recognizes the U in BYU as matching the U(whitespace) that should be found in the filters field.  The same problem happens in with the B portion.  For some reason the \# is not recognized as whitespace like the help files said it should be.

<div>
Not recognizing the '#' may be a bug in the system, I need to look into it further.  Otherwise you can use the end-of-line metachar to do what you want, e.g. to select all lines *except* those with the U filter:<br>
<br>
<pre><code>cl&gt; match &quot;U$&quot; datalist1 stop+</code></pre><br>
<br>
Note the 'stop' param inverts the sense of the match.<br>
<br>
- Mike
