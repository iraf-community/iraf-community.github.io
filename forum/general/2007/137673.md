I assume this was an installation from an RPM file of some kind?  Which one?<br>

The 'mkiraf' command is a symlink to the $iraf/unix/hlib/mkiraf.csh file; The /iraf/iraf part of the path is  the standard value of the iraf root directory, but this could be anything.  Without knowing how the RPM file setup the system, I can't say whether it installed the system someplace else, failed to make the proper link, or perhaps was built missing some files.
