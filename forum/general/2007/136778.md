The exact reason won't be known until you find the bug, generically it just means you corrupted a pointer in your program somewhere.  Compiling with the '-g' flag will enable debugging output, and memory tools like Valgrind or ElectricFencec (Google for references) can help as can the MALLOC_CHECK_ environment variable (see the 'malloc' man page).<br>
<br>
This doesn't appear to be any sort of IRAF program though so this probably isn't the best forum for solving the problem.<br>
