The 'sgidispatch' command is a link created by the install script that points to the hbin$sgidispatch.e executable (where hbin$ is $iraf/unix/bin.&lt;arch&gt;).  If you're on a system like SuSE or Debian that may be using the Redhat binaries (and where the hbin$bin.linux dir is empty) it will be expecting to find the sgi2uapl.e translator in the hbin$bin.redhat directory and not the hbin$bin.linux directory that would be correct for your platform.  A common error is to 'mv' the contents of the bin.redhat to bin.linux instead of copying them.<br>
<br>
Otherwise, something like an invalid $iraf defined in your .cshrc file could be causing the sgidispatch to look in the wrong place.  If you still have problems please post your IRAF version and platform.<br>
