# Problem with Display in .cl script

**Elden Paul Iverson** wrote on Jul 10, 2007

{% raw %}
<div>
A buddy and I are working on automating our reduction/phot process but are being hung up.  In the example portion below we want the script to walk through our flatB images, throw the images 1-by-1 to ds9, and ask if we want to keep or discard it.  We are having trouble a the display command.  It asks if we want to display img with flatB<em>whatever</em> as the default (i.e. img(flatB-000126.fits): ).  If we do a carriage return the script moves on and displays the image and then prompts us whether or not we want to keep it (i.e. post-cr it acts as it should).  We want to remove the verification img(flatB<em>whatever</em>) prompt.<br>
<br>
___________________________________________________________________<br>
int temp<br>
<br>
sections flatB*<br>
if (sections.nimages &gt; 0){<br>
	hselect flatB* $I yes &gt;&gt; datalistB<br>
	list = "datalistB"<br>
	while (fscan(list,img) != EOF){<br>
		display (img, 1)<br>
		print ("Keep this flat? (0 if no, 1 if yes)")<br>
		scanf ("%d",temp)<br>
		if (temp == 0)<br>
			del (img)<br>
	}<br>
}<br>
;<br>
<br>
del datalistB<br>
________________________________________________________________

**Mike Fitzpatrick** wrote on Jul 10, 2007

{% raw %}
<div>
It's only a code snippet, but from what you posted I can imagine a number of scenarios that might cause the problem, and may depend on whether this is part of a procedure script or one you run using redirection (e.g. "cl &lt; myscript.cl"):<br>
<br>
1) The line using HSELECT to generate the file list should have the file 'datalistB' in quotes so that it won't be interpreted as a script variable.<br>
2) Purely stylistic, but you should use SECTIONS or FILES to get the file list<br>
3) If 'img' isn't declared as a string variable you'll get a prompt for it each time it is referenced.  Same if 'img' is declared as a query parameter (i.e. in the arg list for a procedure script). <br>
4) I'm not sure what to make of "img(flatB-000126.fits)", are the parens really part of the prompt in some way??  How are you running this?  Is 'img' declared as a string variable of some kind?<br>
<br>
-Mike
