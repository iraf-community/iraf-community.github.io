<div>
Image display requires that you have a display server (Ximtool or DS9) running before you try to display.  DS9 is available from <a href="ftp://sao-ftp.harvard.edu/pub/rd/ds9">ftp://sao-ftp.harvard.edu/pub/rd/ds9</a> and supports 24-bit displays, XImtool is available from the downloads section of this site and still requires an 8-bit display.  Note that XGterm is an improved graphics terminal (e.g. color graphics) that is part of the same X11IRAF distribution as ximtool, so you might want to get both downloads in any case.<br>

-Mike
