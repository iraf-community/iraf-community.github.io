<div>
The WAT keywords are an IRAF convention, and from the look of them it wouldn't appear as if you have a WCS in the image at all (i.e. the 'system=physical' implies only a pixel coordinate system).  The CTYPE keywords are only part of a WCS, you also need CRVAL, CRPIX, and sometimes a CD matrix to define the reference value, reference pixel, and scale/rotation matrix respectively.  Please post the entire header (e.g. "imhead image.fits long+") if you think there should be a WCS in the image.<br>
<br>
The WCSEDIT and WCSRESET tasks can help, if you're running a recent V2.13 release see also the MKCWCS and MKCWWCS tasks in the IMCOORDS package.<br>
<br>
Cheers,<br>
-Mike
