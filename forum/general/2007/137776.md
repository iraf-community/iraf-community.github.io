<div>
Frank is of course the authority, but a quick idea worth trying (I think anyway) is to use FITPROFS to do the profile fitting and save the fit to an output file.  Then you can use e.g. IMEXPR to write a new image using either the non-zero pixels  indicating the fitted regions or the pixels from the original spectrum, e.g.<br>
<br>
<pre><code>cl&gt; imexpr &quot;(a ? a : b)&quot; newspec.fits a=fitted.fits b=original.fits</code></pre><br>
<br>
The reference image should probably be set to the original spectrum to preserve the WCS.  There may also be something clever you could do with SARITH as well.<br>
<br>
-Mike
</div>
