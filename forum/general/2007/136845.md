**Mike Fitzpatrick** wrote on Feb 17, 2007

{% raw %}
<div>
The output looks normal.  The NOAO package is defined in the extern.pkg file, but if that is empty an error about loading imred is expected.    Before reinstalling everything, it may be simplest to just recreate the extern.pkg file.  There is an 'extern.pkg.DEF' file in hlib you can start with.  The installer may have done something to the current file when it failed (I don't know exactly what it does).  Th e unix command  <br>
<br>
<pre><code> % od -c $hlib/extern.pkg</code></pre><br>
<br>
can reveal any hidden control chars/nulls in the file and verify that there is indeed a \n on the last line.<br>
<br>
-Mike
