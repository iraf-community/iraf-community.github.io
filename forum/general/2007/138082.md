<div>
The problem is that the FITS file itself is corrupt:  The header extends one 80-char line past the magical 2880-byte block boundary and so what you're see is the data shifted in the display.  The proper fix is to edit the header so it's the right size, e.g. delete one of the empty comments.<br>
<br>
Cheers,<br>
-Mike
</div>
{% endraw %}
