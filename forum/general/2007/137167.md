**Mike Fitzpatrick** wrote on Apr 10, 2007

{% raw %}
<div>
The COUNT task can tell you how many lines are in a file, but you still can't use this within a script to declare an array based on the value (i.e. that's what I meant by 'variable sized' arrays.  The best  you can do is declare an array to be some number larger than you expect to use, and then perhaps use COUNT to make sure you won't overflow it.  Optimally though you'd write your script so that you wouldn't need to store the file as an array internally in the first place.<br>
<br>
-Mike
</div>
