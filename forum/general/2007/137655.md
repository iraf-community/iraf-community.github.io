**Mike Fitzpatrick** wrote on Jun 28, 2007

{% raw %}
<div>
The default terminal type is set is your login.cl and created when you first do a MKIRAF.  If you truly are running an xterm window (and not something like a gnome-terminal that cannot do graphics at all), then when prompted for the terminal type enter 'xtermjh' (to put the status line on the text window) or 'xterm'.  You can reset this anytime on the command-line using<br>
<br>
<pre><code>cl&gt; stty xtermjh</code></pre><br>
<br>
Using XGterm is the same:  Start up the xgterm window (you can get the binary from the Downloads area and install it someplace like /usr/local/bin)<br>
but use 'xgterm' as the terminal type when doing an 'stty' or MKIRAF.<br>
<br>
Cheers,<br>
-Mike
</div>
{% endraw %}
