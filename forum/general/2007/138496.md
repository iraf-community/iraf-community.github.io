<div>
Try adding the command<br>
<br>
      limit stacksize unlimited<br>
<br>
to your .cshrc environment (or "ulimit -s unlimited" to your Bash environment if you use that).  This works around some memory changes in recent v2.6 kernels and is done automatically in the CL startup script, but with #!cl scripts it needs to be part of your linux environment. <br>
<br>
Cheers,<br>
-Mike
