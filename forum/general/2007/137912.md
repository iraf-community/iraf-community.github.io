**Mike Fitzpatrick** wrote on Aug 03, 2007

{% raw %}
<div>
PHOTCAL requires the TABLES package for certain tasks.  The error means that you have the TABLES package defined (perhaps/probably because that was left in the hlib$extern.pkg file) but isn't being found properly.  A "show tables" will tell you where it thinks the package is installed (probably /iraf/extern/tables), check that it is indeed there.  Note that even if you installed pre-built binaries for TABLES you'll also need the source in order to get the parameter files.<br>
<br>
Cheers,<br>
-Mike
</div>
{% endraw %}
