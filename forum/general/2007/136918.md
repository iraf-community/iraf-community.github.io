<div>
Ana,<br>
<br>
Try using something other than format=onedspec and you'll get multiple apertures in the same file.  If you're only extracting a single aperture and using the onedspec format, I'm not sure there's a way to force the name, the extension is added for onedspec format images automatically.<br>
<br>
-Mike
