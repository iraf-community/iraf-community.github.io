**Mike Fitzpatrick** wrote on Jun 21, 2007

{% raw %}
<div>
You need to use the "program mode" syntax, i.e. with the parenthesis.  For example,<br>
<br>
<pre><code>
procedure rcur ()

string curfile = &quot;&quot;     { prompt=&quot;cursor filename&quot;      }

begin
    string fname

    # save param to local variable so we&#x27;re not prompted each time
    # we use it.
    fname = curfile

    # Read image cursor, append result to filename.  Delete existing
    # file first.
    if (access (fname) == yes)
        delete (fname, verify-)
    rimcursor (&gt;&gt; fname)
end
</code></pre><br>
<br>
Note the use of '&gt;&gt;' to append results instead of '&gt;' that would overwrite.<br>
<br>
-Mike
</div>

**Mike Fitzpatrick** wrote on Jun 21, 2007

<div>
<blockquote>if I delete the file every time, why I use &gt;&gt; to append? I just create a new file every time... or not?</blockquote><br>
<br>
In this example, the '&gt;&gt;' isn't strictly needed.  In real scripts however, you may be looping over multiple images and marking the same star in each image (so you'd delete the file before this loop).  Anyway, it was just to point out the difference between &gt; and &gt;&gt; for redirection<br>
<br>
<blockquote> <br>
Also I have another question:<br>
if I would like to execute a command outside iraf, but using a variable defined in iraf...?<br>
for example:<br>
I need to open an image in ds9 but I can't use 'disp' because i need the world coordinate, so I'm interested if exists something like this, in a script: </blockquote><br>
<br>
You could create a command string and pipe it to the CL for execution, e.g.<br>
<br>
<pre><code>printf (&quot;!ds9 %s &amp;\n&quot;, filename) | cl()</code></pre><br>
<br>
Note the '&amp;' so it runs in the background and won't block the script.<br>
<br>

**Mike Fitzpatrick** wrote on Jun 21, 2007

{% raw %}
<div>
You can either start DS9 manually before running the script, or else use the sleep() command to wait  a specified number of seconds, e.g.<br>
<br>
<pre><code>
print (&quot;ds9 &amp;&quot;) | cl()          # start ds9
sleep (5)                           # wait for it
rimcur( .....)                      # read the cursor
</code></pre><br>
<br>
Just be sure the sleep is "long enough".....<br>
<br>
-Mike
</div>
