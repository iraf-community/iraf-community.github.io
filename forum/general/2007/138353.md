<div>
Hi,<br>
<br>
Do your file names really have so many zeros? :?<br>
<br>
What I would do is copy the findgain script to my current directory and make a simple edit to have it print out the imstat results.<br>
<br>
<pre><code>
obsutil&gt; copy obsutil$src/findgain.cl .
obsutil&gt; redefine findgain = findgain.cl
obsutil&gt; ed findgain.cl

After the imstat call add:

concat (statsfile)
</code></pre><br>
<br>
Another thing you can do is type "d_trace" right before running your script.  This will be very verbose in dumping stuff to the terminal window.  What you would want to do is look back for the imstat call to see the exact command being executed and then you could try the command manually.  One way to capture the trace info if what you want is too far back to scroll is set the terminal to capture the output (in xgterm you use control-leftbutton to get the menu and select logging.  Note you type d_trace again to turn this output off.<br>
<br>
A mix of the two is if you modify a local copy of findgain you can put d_trace before and after the command to limit the trace to the region of interest though it is often easier to do other things if you have control of the script.<br>
<br>
Frank
