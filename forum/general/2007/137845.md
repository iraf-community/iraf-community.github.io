<div>
I'm not quite sure what your script is trying to do, but in general variables would be passed to script calls using e.g.<br>
<br>
<pre><code>pconcat (s2, s3, s4)</code></pre><br>
<br>
But note there are only two required args to PCONCAT which is why I'm confused!  Otherwise, for tasks that lists you can use @-files with a single call instead of a loop, e.g.<br>
<br>
<pre><code>pconcat (&quot;@&quot;//s2, s3)</code></pre><br>
<br>
would concatenate all the files in 's2' into the 's3' output database.<br>
<br>
-Mike

In that case, try <br>
<br>
<pre><code>pconcat (s2//&quot;,&quot;//s3, s4)</code></pre><br>
<br>
Comma-delimited lists work the same as @-files, the // operator is the CL script string concatenation, the result will be written to the file named in s4.<br>
