Q:      I'm getting the error message:<br>
<br>
        cc&gt; doslit<br>
        List of object spectra (a0134):<br>
        Edit apertures for a0134? (yes):<br>
        ERROR on line 58: Arc reference spectrum not found - a0135<br>
        doslit ()<br>
<br>
        However, the file a0135.fits does exist.  What's wrong?<br>
<br>
A:      This error is usually caused by a mismatch between the image extension<br>
        you have set as the default and the type of your data.  Because<br>
        the installation default is "imh" but now it is more common to use<br>
        FITS files this mostly occurs when imtype="imh".  You can change the<br>
        default imtype value by editing your login.cl, uncommenting the line<br>
        for imtype and changing the value to "fits" (or whatever<br>
        extension you use).<br>
<br>
        This dependence on imtype is a "gotcha".  The task needs to<br>
        manipulate the image names and uses the imtype variable to do<br>
        this.  This is described in<br>
<br>
            <a href="http://iraf.noao.edu/irafnews/apr98/irafnews.1d.html">http://iraf.noao.edu/irafnews/apr98/irafnews.1d.html</a><br>
<br>
        The reason this is not more general is that this program preceded<br>
        the changes which allowed people to use different image types and<br>
        the quick way to modify this complex task was to use the imtype<br>
        variable to tell the script what extensions to look for.<br>
<br>
        I have made a changes to various related task to help with this<br>
        occasional "gotcha".  The new behavior will be to show the full<br>
        name the task is looking for and to add a hint to check the imtype<br>
        variable.<br>
<br>
        kp&gt; doslit<br>
        ...<br>
        ERROR on line 58: Arc reference spectrum not found - demoarc1.imh<br>
        Check setting of imtype<br>
        kp&gt; dir demoarc1*<br>
        demoarc1.fits   <br>
</blockquote><br>
<br>
Note that if you really are using v2.12 on a Cygwin system then this must be the original Chris Burke port.  The change mentioned above was done in 2005 and is part of v2.13.  If you still have problems, post back.<br>
<br>
