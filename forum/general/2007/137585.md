<div>
hello Trillian,<br>
maybe the task "hselect" could be useful. From its manual page:<br>
<br>
 <blockquote><br>
NAME<br>
    hselect - select a subset of images satisfying a boolean expression<br>
<br>
USAGE<br>
    hselect images fields expr<br>
</blockquote><br>
<br>
it prints the required header keywords (field) only for the images for which the expression is true. Here is an example from the manual:<br>
<br>
 <blockquote><br>
            cl&gt; hselect n1.* $I,naxis[12],title 'naxis == 2'<br>
            n1.0001 512     512     quartz<br>
            n1.0002 512     512     "dome flat"<br>
            n1.0005 384     800     "ngc 3127 at 45 degrees"<br>
            cl&gt;<br>
 </blockquote><br>
<br>
Cheers,<br>
Emiliano.

<div>
Sorry for my previous post. It works! <br>
<br>
Here is how I did it: (for others to see) <br>
<br>
hselect 24* $I, OBJECT, COMMENT &gt; info<br>
<br>
This will print ONLY the object and comment information onto a file I called 'info'.<br>
