<div>
The 'minput' parameter was added in the v2.12.2a patch release.  If it isn't being found the first thing to do in an 'cl&gt; unlearn transform' to clear out any old uparm files.  If you still get the error, the problem may be that the source patch wasn't applied but the binaries are from the 2a patch and so expecting the parameter.  <br>
<br>
If this is a Scisoft installation it may be a problem in their distribution, but you can check the file twodspec$longslit.transform.par to verify the parameter is in there.  If it's missing I can send it to you.<br>
<br>
-Mike
