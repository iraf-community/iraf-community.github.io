**Mike Fitzpatrick** wrote on May 02, 2007

<div>
See the NFIT1D task in the STSDAS.ANALYSIS.FITTING package.  It is the only thing I'm aware of that will fit a blackbody but I don't think it'll report a temperature directly.  STSDAS is an external package you'll need to install separate from the core system and also requires the TABLES package.<br>
<br>

-Mike<br>
