<div>
This is a known and long-standing issue with DS9.  From the IRAF display the WCS information is sent as before however DS9 doesn't do anything with the filename sent in order to read the header of the actual image, and so it simply uses the approximate scaling and coordinate values.  When it loads an image in standalone mode, it actually reads the image header and uses a proper WCS.  There is little we can do from the client side, since even if we sent the entire FITS header, DS9 would still need to be modified to use it.<br>
