**Mike Fitzpatrick** wrote on Jul 06, 2007

{% raw %}
<div>
See the help page for examples, but I think you need to use the '@' sign before the quoted keyword so it is interpreted correctly, e.g. @"date-obs"  This is used to de-reference the value, otherwise the '-' is taken as an operator to compute the difference between the values of the 'date' and 'obs' keywords.<br>
<br>
Cheers,<br>
-Mike
</div>
{% endraw %}
