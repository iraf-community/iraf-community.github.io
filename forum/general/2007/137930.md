**Mike Fitzpatrick** wrote on Aug 06, 2007

{% raw %}
<div>
For an overview, see the example at the end of the Installation Guide (<a href="http://iraf.net/ftp/iraf/V2.13-BETA/pciraf.ps.gz)">http://iraf.net/ftp/iraf/V2.13-BETA/pciraf.ps.gz)</a>, details are in the rest of the doc.  <br>
<br>
In either Slackware or FC7 you would use the RHUX binaries, however for Slackware you need to install them in 'bin.linux' directories instead of 'bin.redhat'.  To complete the install, *copy* the files from $iraf/unix/bin.redhat to $iraf/unix/bin.linux before running the install script.<br>
<br>
-Mike
</div>
{% endraw %}
