# image compression

**Tom Duvall** wrote on Mar 09, 2011

{% raw %}
<div>
Our images from the SDO satellite come in a compressed FITS format, described in <a href="http://heasarc.gsfc.nasa.gov/docs/software/fitsio/compression.html">http://heasarc.gsfc.nasa.gov/docs/software/fitsio/compression.html</a>.  Currently, I use an external program to uncompress into a more usual format.  This may not be the most efficient way to proceed and I was wondering if the iraf fits reader can read these files more directly.  Newer versions of ds9 can read these images.<br>
Tom<br>
<br>
ps: I put an example image in <a href="http://sun.stanford.edu/~duvall/Iraf/testfits.fits">http://sun.stanford.edu/~duvall/Iraf/testfits.fits</a>
</div>
{% endraw %}

**Mike Fitzpatrick** wrote on Mar 09, 2011

{% raw %}
<div>
At the moment we have tasks in the FITSUTIL package to compress and uncompress files like this, however there is a new FITS image kernel being developed now that will handle these images directly.  It will be built on top of CFITSIO to handle the compression and is meant to be fully compatible with the existing fits kernel.  We hope to introduce this in a release later this year.
</div>
{% endraw %}
