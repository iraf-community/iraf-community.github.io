**Mike Fitzpatrick** wrote on Feb 23, 2011

{% raw %}
<div>
I think the problem is just that you're using the default imt512 frame buffer so you're only seeing the central 512x512 pixels and the star is being clipped from the display.  Try doing<br>
<br>
<pre><code>cl&gt; reset stdimage = imt800</code></pre><br>
<br>
and then redisplay the image.  Set the DISPLAY task 'contrast' parameter to 0.0 and you'll use the full 8-bit data range in the scaling.
</div>
{% endraw %}
