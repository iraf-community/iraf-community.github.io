<div>
Two ways that come to mind are to use either the MSCOMBINE task in the MSCRED external package since this is designed to work on MEF images, or to use the FXSPLIT task in the FITSUTIL package to split the MEF into separate simple FITS files and then proceed with IMCOMBINE.<br>
<br>
Otherwise, you'll need to explicitly list each extension as a separate image for them to be treated as simple files in a list, e.g.<br>
<br>
<pre><code>
cl&gt; imcombine img.fits[1],img.fits[2],......
</code></pre>
