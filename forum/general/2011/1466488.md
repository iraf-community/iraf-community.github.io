# splot wavelength calibration

**heather** wrote on May 10, 2011

{% raw %}
<div>
I'm looking at spectra which were originally SDSS stellar spectra, rebinned to a linear wavelength scale by IDL code in the SSPP (segue pipeline)<br>
<br>
Looking at the header of the fits file, CRVAL1 = 3850 and CD1_1 = 1. (both Angstroms)<br>
<br>
When I plot the data in splot, the first pixel has wavelength 3851 A. And all subsequent pixels have wavelengths one A more than they should.<br>
<br>
I'm using IRAF 2.14.1 on a Linux box running Redhat Enterprise 5 (64 bit)<br>
<br>
The fits file can be found at<br>
<a href="http://astronomy.case.edu/heather/boss.lineindex.fit">http://astronomy.case.edu/heather/boss.lineindex.fit</a> (spectra in HDU 0) and a plot of the wavelength of the first pixel in splot is at<br>
<a href="http://astronomy.case.edu/heather/4iraf.jpg">http://astronomy.case.edu/heather/4iraf.jpg</a><br>
<br>
Any suggestions would be much appreciated.<br>
<br>
thanks<br>
Heather Morrison
</div>
{% endraw %}

**Mike Fitzpatrick** wrote on May 10, 2011

{% raw %}
<div>
Try adding a CRPIX1 = 1 keyword to the headers to specify the starting pixel.  Otherwise the value is assumed to be zero and since the image index starts at one .......<br>
<br>
Frank may have additional comments about a better set of keywords to add.
</div>
{% endraw %}
