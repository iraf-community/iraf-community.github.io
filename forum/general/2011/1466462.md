**Mike Fitzpatrick** wrote on May 02, 2011

{% raw %}
<div>
Tom,<br>
<br>
You're right, I've verified that with the distributed binaries there is still a problem.  The good news though is that it's apparently already been fixed in the dev system, see <a href="http://iraf.net/phpBB2/viewtopic.php?t=90680">http://iraf.net/phpBB2/viewtopic.php?t=90680</a><br>
<br>
That message referred to columnar access to data but affect higher dimensioned data as well.  You can use the same trick of using the 32-bit binaries or if you want to make the code change it is trivial:  In sys$imio/imggsc.x the code diff is<br>
<br>
<pre><code>

37,38c37
&lt; 	#sz_pixel = pix_size[IM_PIXTYPE(im)]
&lt; 	sz_pixel = sizeof(IM_PIXTYPE(im))
---
&gt; 	sz_pixel = pix_size[IM_PIXTYPE(im)]
</code></pre><br>
  <br>
I.e. you want to use the sizeof() function.  To recompile the change:<br>
<br>
<pre><code>
% setenv iraf /iraf/iraf/                       # define environment
% setenv IRAFARCH &lt;arch&gt;
% source $iraf/unix/hlib/irafuser.csh
% cd /iraf/iraf                                   # go to iraf root
% make &lt;arch&gt;                                # set architecture
% mkpkg ; mkpkg update                   # relink core system
% make update                                 # rebuild everything else
</code></pre><br>
<br>
These are actually more steps than I'd intended, but I'm heading off a likely followup question you'd have if you did just a "make update".  Anyway, let me know if you have any problems.<br>
<br>
Cheers,<br>
-Mike
</div>
