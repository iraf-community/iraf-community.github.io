<div>
Exactly what is in the .reg file you created?  Note that DS9 regions use keywords such as <br>
<br>
<pre><code>circle &lt;x&gt; &lt;y&gt; &lt;radius&gt;</code></pre><br>
<br>
whereas a task like text2mask does simple points or rectangles and expects only center/corner pixel positions.<br>
<br>
There may be other tasks more suited to creating the mask file within IRAF, in general support for DS9 regions files is pretty sparse.  See for example OBJMASK or MSKEXPR or MSKREGIONS (or other tasks listed by a "cl&gt; refer mask" command).
</div>
{% endraw %}
