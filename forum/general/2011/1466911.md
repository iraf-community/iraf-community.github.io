**Mike Fitzpatrick** wrote on Jul 19, 2011

{% raw %}
<div>
The 'gcount' keyword is probably missing from your image.  This is read from the header and scanned into a script variable, but if it doesn't exist you'll typically see the 'undefined local variable' message.<br>
<br>
Since these are non-HST images you should use HEDIT to add the gcount keyword with a value other than 4.
</div>
{% endraw %}
