**Mike Fitzpatrick** wrote on Feb 04, 2011

{% raw %}
<div>
If you're using an XTerm you need to reset the terminal type in iraf first, e.g.<br>
<br>
<pre><code>cl&gt; stty xtermjh
cl&gt; implot dev$pix
</code></pre><br>
<br>
You won't see the full-screen cursor but if the task then works then it looks like it is an xgterm issue.
</div>
