Hi Petr,<br>
<br>
<blockquote><br>
I am confused concerning the 2.15 installation instructions (sorry) <br>
First, the root page of this portal announces the v2.15 and gives links to more details. But the link to Install Guide links to pciraf.ps but version 2.12 ! Should it be obeyed ? </blockquote><br>
<br>
That was the last version of the installation guide, and it still applies since the old-format AS, IB, and NB distribution files are still available for v2.15 in addition to the single file download.  The doc, however, should be augmented with instructions for using the single download, I just haven't had time yet.<br>
<br>
<blockquote><br>
1. V2.15 Installation Instructions <br>
<br>
in case I have already the another IRAF version installation (e.g. 2.12) ? <br>
<br>
I understand it - go directly to <br>
I am installing multiple IRAF versions: </blockquote><br>
<br>
"Multiple versions" refers to e.g. having v2.12 and v2.15 available on the machine at the same time.  This can be a tricky thing to get right since only one version can properly be "installed" (i.e. the iraf.h file, the 'cl' link, etc) as the default although you can define things in the environment to select from multiple versions.  It is also important to the keep the versions in separate directory trees, e.g. /iraf/iraf.v212 and /iraf/iraf.v215.<br>
<br>
If this is actually what you are doing, then just create a new directory for the v2.15 tree and unpack the distribution in there.  Then, decide whether you want this new version to be the default and if so, run the install script with the new 'iraf root directory'.<br>
<br>
<blockquote><br>
so as I am not installing for the first time I am not required to run install script and create iraf directory ? <br>
</blockquote><br>
<br>
The install script MUST be run if either there is no iraf already on the machine OR the iraf root is something other than /iraf/iraf.  The script not only puts links in the system directories, it also edits paths in the iraf files themselves.<br>
So, if the path changes the install script must be re-run.<br>
<br>
Cheers,<br>
-Mike
