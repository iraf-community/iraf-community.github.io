<div>
Is it possible the "missing" keywords were simply moved to the primary header because of inheritence?  There are various rules by which the FITS kernel updates the header and in the case of FXINSERT I forget the particulars, but you might try adding the qualifier "[noinherit]" to the output name to suppress the inheritence, e.g.<br>
<br>
<pre><code>cl&gt; fxinsert in.fits out.fits[3,noinherit]</code></pre>
