<div>
Assuming you ran the IRAF install script properly (as the root user, without the '-n' flag, etc), the message means that either the 'local bin directory' you specified (typically /usr/local/bin) isn't in your $path variable, or else occurs after the /usr/bin directory where the Lisp interpreter 'cl' command is sometimes installed.<br>
<br>
Do an "echo $path" to see if the path is included in your environment, and/or adjust the location of the iraf local bin directory.  To verify it is indeed a path problem, you can also try starting by explicitly using the full path, e.g.<br>
<br>
<pre><code>% /usr/local/bin/cl</code></pre>
</div>
{% endraw %}
