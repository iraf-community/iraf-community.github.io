<div>
You can get a statically link ECL binary and the 'cl' command script to use it from<br>
<br>
<a href="http://iraf.net/pub/fitz/ecl.e">http://iraf.net/pub/fitz/ecl.e</a><br>
<a href="http://iraf.net/pub/fitz/cl.csh">http://iraf.net/pub/fitz/cl.csh</a><br>
<br>
Copy the first file to $iraf/bin.linux (or 'bin.redhat' depending on your system), and copy the second file to $iraf/unix/hlib/cl.csh<br>
<br>
This will make the ECL the default when you run the 'cl' command.  If you have problems or questions, post back.
</div>
{% endraw %}
