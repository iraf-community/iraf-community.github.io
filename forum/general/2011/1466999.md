# IRAF not recognizing SBIG .FIT images

**Jason Smolinski** wrote on Oct 10, 2011

{% raw %}
<div>
Hello all,<br>
I currently have a data set in .FIT format taken using an SBIG ST-L-1001E CCD camera and am trying to reduce it using IRAF.  However, when I try to get IRAF to handle the files, it gives me errors.  For example:<br>
<br>
<pre><code>
ecl&gt; display n01028.FIT 1
ERROR: Cannot open image (n01028.FIT)
</code></pre><br>
<br>
Although the file exists in the current working directory, IRAF doesn't recognize it as an image.  When I try an 'imcopy' I get the same message, and when I open the image using ds9's GUI (which works), doing an 'imexam' causes the whole ds9 to crash and IRAF returns a number of errors.  <br>
<br>
Has anyone else out there experienced any problems handling SBIG's .FIT files with IRAF?  Any thoughts on what might be preventing IRAF from recognizing the files as valid FITS images?
</div>
{% endraw %}

{% raw %}
<div>
Never mind. I realized that the "imextn" arguments in the login.cl file are case sensitive.  Adding "FIT" to that fixed the issue.
