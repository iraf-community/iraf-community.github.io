# FITS headers between iraf and aips

**Michael Gregg** wrote on May 29, 2011

{% raw %}
<div>
Hi,<br>
<br>
I recently read a bunch of data from old exabytes into AIPS, the only method available to me to get the data off the tapes. Using another AIPS task, I then wrote out the data from AIPS format to regular fits files.  The data look fine and I can implot them in iraf and display them.  The trouble is that AIPS has converted most of the header keywords into HISTORY lines by prepending the string "HISTORY" to the start of nearly every header line, as in this example:<br>
<br>
HISTORY TIME    = '         0:59:58.0' / UT TIME<br>
HISTORY EXPOSURE=                    1 / EXPOSURE TIME (SEC)<br>
HISTORY RA      = '         3:50:53.9' / RIGHT ASCENSION<br>
HISTORY DEC     = '       +37:22:40.0' / DECLINATION<br>
etc...<br>
<br>
These header lines originally looked like:<br>
<br>
TIME    = '         0:59:58.0' / UT TIME<br>
EXPOSURE=                    1 / EXPOSURE TIME (SEC)<br>
RA      = '         3:50:53.9' / RIGHT ASCENSION<br>
DEC     = '       +37:22:40.0' / DECLINATION<br>
etc...<br>
<br>
There are about 80 header lines so affected in each fits file, and I have about 2000 of these files.  I am wondering if there is an easy way to restore the headers to their original format in batch so that IRAF (and I!) can easily recognize and read the keywords as keywords.  I can do it manually file by file, and that would take way too long.  The only thing I can think of is to try reading and rewriting the headers in IDL; I am hoping that maybe this problem has already been solved or that there is a simple way in IRAF already.<br>
<br>
Thank you,<br>
<br>
Michael Gregg<br>
U.C. Davis

{% endraw %}

<div>
Have a look at the HFIX task.  Basically, you can use it to drive a 'sed' or an 'awk' script to edit the headers autmatically.  For example,  create a file with all the edit something like<br>
<br>
<pre><code>
s/HISTORY TIME/TIME/g
s/HISTORY EXPOSURE/EXPOSURE/g
      :         :         :
</code></pre><br>
<br>
Then you can edit all of your images with the command<br>
<br>
<pre><code>hfix *.fits command=&quot;!sed -f edits.txt $fname &gt; temp; mv temp $fname&quot;</code></pre>
</div>
