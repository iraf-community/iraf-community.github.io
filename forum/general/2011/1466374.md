<div>
It depends on exactly what's in the .cl file:  If it is just a list of IRAF commands you can run those commands as e.g.<br>
<br>
<pre><code>ecl&gt; cl &lt; myfile.cl</code></pre><br>
<br>
If .cl contains a procedure script, you need to declare it as a task first, e.g.<br>
<br>
<pre><code>ecl&gt; task mytask = /path/mytask.cl
ecl&gt; mytask infile.fits
</code></pre><br>
<br>
See the Script Beginner's Guide (<a href="http://iraf.net/irafdocs/beguide/)">http://iraf.net/irafdocs/beguide/)</a> for additional detail.
</div>
