**Mike Fitzpatrick** wrote on Jul 22, 2011

{% raw %}
<div>
Assuming the apostrophe is done properly in the header (i.e. that a value like "O'Hara" is written as "O''Hara"), the you can use either the same double-apostrophe trick or a '\' to escape the value.  For example<br>
<br>
<pre><code>
ecl&gt; hselect dpix.fits $I,FILTER &#x27;(filter?=&quot;r&#x27;&#x27;&quot;)&#x27;
dpix.fits	&quot;        r&#x27;&quot;
ecl&gt; hselect dpix.fits $I,FILTER &#x27;(filter?=&quot;r\&#x27;&quot;)&#x27;
dpix.fits	&quot;        r&#x27;&quot;
</code></pre><br>
<br>
Note that the "?=" string comparison operator does a substring search, so a simple "filter?='r'" would also work (so long as it is unique).
</div>
{% endraw %}

**Mike Fitzpatrick** wrote on Jul 22, 2011

{% raw %}
<div>
I think the magic combination of parameters you need is<br>
<br>
<pre><code>cl&gt; hedit ...... add- addonly+</code></pre><br>
<br>
The 'add+' will override the 'addonly' param and change the value for existing params, otherwise the 'addonly' is used as the only toggle.
</div>
{% endraw %}
