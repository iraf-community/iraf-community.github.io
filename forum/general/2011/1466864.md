<div>
Almost any OS upgrade will require that at least the IRAF install script is re-run (in order to reset the /usr/include/iraf.h link primarily, commands put in /usr/local/bin are normally left alone).  Whether there are binary incompatibilities remains to be seen (I don't have a preview of Lion):  in the best-case scenario this might require just a relink of the IRAF system/packages locally (which a user can normally accomplish), in the worst case a new IRAF version might be required.<br>
<br>
In any case, Lion will indeed be supported, just don't expect it to be the same day (or anything close) Lion is released.  Support will be added as time permits.
