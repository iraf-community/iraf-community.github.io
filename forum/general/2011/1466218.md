# IRAF file extension

<div>
When using CCDops v5, images are saved as *.FIT images. Although DS9 can open these images without complication, IRAF doesn't open them unless I change the extension to *.fit (all lowercase). Is this supposed to happen and is there any way to change CCDops to save as *.fit or get IRAF to open *.FIT?<br>
<br>
Just to be explicit, the error I get when I attempt to display:: <br>
<br>
<pre><code>ecl&gt;display AutoGrab001.FIT
ERROR: Cannot open image (AutoGrab001.FIT)</code></pre>

**Mike Fitzpatrick** wrote on Mar 04, 2011

{% raw %}
<div>
IRAF uses the 'imextn' environment variable to associate file extensions to a particular type of image (DS9 actually opens the image to read it).  You can uncomment the definition from your login.cl file to add "FIT" as a valid extension for the 'fxf' FITS kernel, or you can simply rename the files with a command such as <br>
<br>
<pre><code>cl&gt; rename *.FIT fits field=extn</code></pre>
</div>
{% endraw %}
