**Mike Fitzpatrick** wrote on Jun 24, 2011

{% raw %}
<div>
Type "help cursors" and have a look at section 3.7 (Alternate Cursor Input).  If I understand your question, you can take the list of positions you have now and create a cursor file containing the keystrokes you would interactively issue at those positions, then just run the task using this file to drive the cursor commands.  <br>
<br>
Note there are other tasks in the DAOPHOT package that automatically process the image and compute a FWHM value in the output file.  Hope this helps.
