**Mike Fitzpatrick** wrote on May 23, 2011

{% raw %}
<div>
See the "help cursors" description of alternate cursor input in section 3.7.  You would need to create a cursor command input file to drive the program as you would interactively and issues the :wccf command.  Batch mode in FXCOR can create a summary plot but doesn't have a way to dump the CCF automatically.
