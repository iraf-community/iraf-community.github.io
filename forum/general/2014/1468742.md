**Mike Fitzpatrick** wrote on Dec 16, 2014

<div>
<br>
<blockquote>(1) How do I create a string array like "first," "second," "third," "fourth"?</blockquote><br>
<br>
Try<br>
<br>
           string foo[4] = "first", "second", "third", "fourth"<br>
<br>
The size of the array must be part of the declaration.<br>
<br>
<blockquote>(2) How do I print the whole string? Like if I do<br>
<br>
string mycustomarray = "first," "second," "third," "fourth"<br>
<br>
How can I use a print command to get<br>
<br>
first, second, third, fourth<br>
<br>
to appear in the Terminal?</blockquote><br>
<br>
You would have to do it in a loop, e.g. <br>
<br>
<pre><code>
   for (i=1; i &lt;= 4; i=i+1) {
       printf ("%s", foo[i])
       if (i &lt; 4)
           printf (",")
       else
           printf ("\n")
    }
 </code></pre><br>
<br>
<blockquote>(3) How do I clear the definition of mycustomarray so that I can define it to be something else later, like<br>
<br>
mycustomarray = "one," "two," "three," "four"<br>
<br>
?</blockquote><br>
<br>
You can't "undeclare" the array, you can simply reuse the elements.  Note this means you can't change the size either.<br>
<br>
<blockquote><br>
<br>
(4) Likewise, how do I clear the definitions of other strings that I create, for example,<br>
<br>
string myvariable = "December2014"<br>
<br>
and redefine it to be<br>
<br>
myvariable = "January2015"<br>
<br>
?</blockquote><br>
<br>
Just exactly like that, i.e. you redefine to the value.<br>
<br>
<blockquote><br>
<br>
(5) Where can I find a tutorial or workshop on how to work with how to set my own IRAF variables? The resources that I located were about parameters within tasks and advanced scripting.</blockquote><br>
<br>
In case you haven't already found it, see the Script Guide at  https://iraf.net/irafdocs/script/  as well as the CL Programmer's Manual at<br>
<br>
ftp://iraf.noao.edu/iraf/docs/clman.ps.Z<br>
</div>
{% endraw %}
