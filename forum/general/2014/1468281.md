<br>
I don't see the error in the standard v2.16.1 release so this must be something peculiar to the distribution itself (which has custom mods of it's own).  The Ureka folks will have to comment on a fix, however you could simply overlay the working MSCRED binaries from the ftp://iraf.noao.edu/iraf/extern directory to continue.  If you still have problems then the error is probably coming from one of the core system tasks and using the standard release is the only option (but again, you can download the main iraf system tarball and simply replace the binaries).<br>
