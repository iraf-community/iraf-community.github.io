<div>
<br>
<br>
The problem is that the spectra are stored as FITS binary tables and not in the spectral format IRAF tasks currently understand.  We are working on tools to make files like this usable directly, however for the moment you'll need to do something like use TDUMP (or other TABLES package tasks) to write out the bintable as wavelength/flux pairs, and then RSPECTEXT to read them into a format the ONEDSPEC tasks can understand.<br>
</div>
{% endraw %}

                I did not find the right procedure to open the dr10 SDSS release with IRAF but with python/pyfits, the right procedure is the following:<br>
<br>
import pyfits<br>
<br>
FitsFile = pyfits.open(FolderName + FileName) <br>
<br>
Spectra = FitsFile[1].data<br>
<br>
Int = Spectra['flux']<br>
<br>
WavelenRange = 10.0**Spectra['loglam']<br>
<br>
FitsFile.close()<br>
