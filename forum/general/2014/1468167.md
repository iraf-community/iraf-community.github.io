**gworthey** wrote on Sep 08, 2016

{% raw %}
<div>
<br>
                Issue solved. <br>
<br>
Apparently, I should use [sci,2,overwrite].<br>
<br>
The integer in there conceptually stands for "the second SCI extension," not HDU #2.<br>
<br>
Reading the kernel description, EXTNAME (e.g., the string SCI) and EXTVER (e.g., the integer 2) can together be used to select the HDU you want. If you omit the EXTNAME, the integer is assumed to refer to the HDU number.<br>
<br>
If anybody knows a place that that is explained/documented, do let me know. <br>
</div>
{% endraw %}
