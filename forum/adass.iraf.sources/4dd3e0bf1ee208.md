	IRAF is distributed with all sources, in this case what you&#x27;re
after can be found by doing

	cl&gt; cd noao$ondespec/splot

The files &#x27;spdeblend.x&#x27; and &#x27;deblend.x&#x27; should be what you need most.
The sources are written in SPP and you&#x27;ll need to write another SPP
task to make use of them.  See ftp://iraf.noao.edu/iraf/docs/sppguide.ps.Z
for an intro to SPP, there is also a guide available from STScI at
ftp://ftp.stsci.edu/pub/software/stsdas/docs/SPPManual.ps.
	I&#x27;m not aware of any single task in IRAF or any external package
that simply fits multiple Gaussians.  Hope this helps.

Cheers,
Mike Fitzpatrick
</pre>
