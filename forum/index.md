## IRAF discussion forum

### Current discussion

The current discussion forum is Github:

[**IRAF Community Discussions**](https://github.com/orgs/iraf-community/discussions)

This is the place for current questions, discussions, bug reports, and announcements.

### Historic discussion channels

Before the current forum, IRAF discussions took place through several public forums

* The `iraf@noao.edu` mailing list.
  This list was active 1987–2005.

* The NNTP newsgroup hierarchy `adass.iraf.*`.
  These newsgroups were hosted at NOAO and distributed world-wide via
  Usenet servers. Here are archived messages (1997–2005):
    - [adass.iraf.announce](adass.iraf.announce/): New IRAF software or facilities. (42 threads)
    - [adass.iraf.system](adass.iraf.system/): System issues and system administration. (106 threads)
    - [adass.iraf.applications](adass.iraf.applications/): Applications discussion group. (188 threads)
    - [adass.iraf.programming](adass.iraf.programming/): Programming discussion group. (19 threads)
    - [adass.iraf.misc](adass.iraf.misc/): Miscellaneous discussion. (11 threads)
    - [adass.iraf.sources](adass.iraf.sources/): Small programs or documents. (6 threads)

* The web discussion forum at `iraf.net`.
  This web forum was run by volunteers at iraf.net 2005–2023. The
  discussions are preserved here:
    - [General IRAF](general/): General IRAF questions, problem reports, suggestions, tips and announcements (1126 threads)
    - [Applications](applications/): Questions about how to use tasks, external packages, or problems with a particular application. (1346 threads)
    - [Systems](systems/): Installation, platform support and/or programming discussions (494 threads)
    - [Misc](misc/): Miscellaneous discussions, IRAF-related or otherwise (46 threads)
