## while loop usage and fscan

**Frank Valdes** wrote on Mar 23, 2000

<pre style="background: transparent; box-shadow: none; border: none;">
Q:  I have a question concerning the while loop in a cl script:

I would like to read a file line by line and save each line as a
different variable. How many lines the file contains and how many
variables are needed (and the names of them) depends on a query
parameter.

therefore i need a loop with a counter, like the &#x27;for&#x27; loop.
but as far as i understood cl, it is not possible to use the &#x27;fscan&#x27;
without a while (!= EOF) loop.

--&gt; does this while loop return a counter? how can i refere to it?

--&gt; &#x27;nscan returns a number&#x27; is written in the help page. can i use
nscan for reading a file? how can i refere to this number? where can i
find a example for the use of nscan?   



A: The fscan does not have to be used in a while.  It returns an integer
giving the number of elements read or EOF.  So you can do something like

for (i=1; i&lt;=maxlines; i=i+1) {
    if (fscan (list, x, y, z) == EOF)
        break
    if (nscan() != 3)
        next
     ...
}


You can use the fscan return value without having to use nscan:


for (i=1; i&lt;=maxlines; i=i+1) {
    j = fscan (list, x, y, z)
    if (j == EOF)
        break
    if (j != 3)
        next
     ...
}
