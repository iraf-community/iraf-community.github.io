**Mike Fitzpatrick** wrote on Jul 16, 1998

<pre style="background: transparent; box-shadow: none; border: none;">
&gt; When I run the task regions (stsdas) I get the messages &quot; Error on line
&gt; 127: Open: file does no exist (scidata$index.tab)&quot; What&#x27;s wrong ?

	You need to first run the STGINDX task in the package to create
the index table, be sure to reset the &#x27;cdfile&#x27; parameter so the path to
the GSC CD-ROM is correct.  If you don&#x27;t have write permission in the
STSDAS tree specify the output table to be e.g. &quot;home$index.tab&quot;, then
change SGSCIND &#x27;index&#x27; param to point to it and you can use a private
version.  If you don&#x27;t have the GSC CD you can pick up a copy of the 
index.tab file (in Sun byte order) from ftp://iraf.noao.edu/pub.

-Mike

Hello, Luisa

you have to do something once to create the file (eg. scidata$index)
on disk.  This is documented in the help on STGINDX.



I apologise for the fact that our documentation is not clear on this topic.
You are certainly not the first to have trouble with this...
 
The missing file is an index file, and will need to be created on disk
once only, you can continue to use this index disk file for subsequent
use of gasp.  It is on the CD, but in a format that is not quite acceptable to
the tasks that read it, so it is translated into a disk file once when you 
install (or start using) gasp.
 
 
Here are some notes that should help you through this...
 
 
.       You&#x27;ll need to create the index file on disk: here is 
.       my &#x27;lpar sgscind&#x27; output which shows how GASP goes for the Northern
.       and Southern CD roms on the moint points  /gsc/vol1 and /gsc/vol2,
.       and the index file at &quot;scidata$index&quot;: 
.

.        
 
 
Creating the required index file is a one-time-only operation that is
done by the gasp task stgindx (type &quot;help gasp option=sysdoc&quot; for more
information about the gasp package):
 
STGINDX (Jul93)           stsdas.analysis.gasp           STGINDX (Jul93)
 
 
 
NAME
    stgindx -- Create an index table.
    
    
USAGE
    stgindx
    
    
DESCRIPTION
    This  task  will  copy  the  guide  star   index   table---in   FITS 
    format--from  the  CD-ROM  to a magnetic disk.  The index table will
    be reformatted to a STSDAS table.  The index table is  used  by  the
    &#x27;sgscind&#x27;  task  to  determine  which GSC regions overlap the user&#x27;s
    field.  This task is required since the index table on  the  GSC  is
    in  FITS  format  and  &#x27;sgscind&#x27;  requires the table to be in STSDAS
    (binary) format.
    
    
PARAMETERS
    
    (index = scidata$index.tab) [file name]
        Output file name for the guide star catalog index table.
    
    
EXAMPLES
    
    
BUGS
    
    
SEE ALSO
    strfits, sgscind
 
 
 
If you have write permission for iraf/stsdas files, then you can create 
this file with the default parameters.  Otherwise use some file name that
you can create, and put that file name into your gasp task parameters that
require this index file.
 
I hope this helps.  Please email me if you need any more help.
