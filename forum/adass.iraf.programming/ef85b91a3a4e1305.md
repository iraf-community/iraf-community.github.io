**Mike Fitzpatrick** wrote on Mar 13, 1998

<pre style="background: transparent; box-shadow: none; border: none;">


&gt; Q1: I&#x27;m using a small &#x27;mkpkg&#x27; file (I include this file in the
&gt; attachments) to compile a Fortran program within IRAF.  I would like to
&gt; compile the Fortran source (&#x27;lijnst.f&#x27;) with double precision (something
&gt; very easy to do in a shell command line) but I don&#x27;t know how to specify
&gt; this option in the mkpkg file .  I&#x27;ve tried it setting a XFLAGS option for
&gt; the XC compiler, but I haven&#x27;t been able to make it work...
	I assume you mean you want to use the -dbl or -r8 flag to the F77
compiler?  To do this you need to define XFLAGS before calling the library
update part of the mkpkg file, and you need to escape the host compiler
command using &quot;-/&quot;.  For example, your XFLAGS definition should look some-
thing like

	$set   XFLAGS = &quot;$(XFLAGS) -/r8&quot;

Put this as the first line in the libls.a or iraflib.a target of your mkpkg
file, or at the top so it&#x27;s always defined.  Tasks are linked with the C
compiler so these flags don&#x27;t make any sense on the link line, but you can
similaryly define LFLAGS to set any link flags you want to use.

&gt; Q2: If I want to use an external Fortran library like say a NAG library,
&gt; to calculate an integration in a program of the &#x27;mkpkg&#x27; file list (say, a
&gt; call in &#x27;lijnst.f&#x27;), how I must specify this in the &#x27;mkpkg&#x27; file? (if it&#x27;s
&gt; possible) and; where this libraries must be located (i.e. if they need to
&gt; be in a different directory from the default one, like in one of the IRAF
&gt; logical directories or it doesn&#x27;t matter).
	It depends on where the library is installed in your system.  If
it&#x27;s in the normal library search path in e.g. /usr/lib just use &quot;-lnag&quot; on
the link line and it should be found.  If it&#x27;s on say /usr/local/lib then
you can either specify the path explicitly, or using the above trick put
a &quot;-L/usr/local/lib&quot; on the LFLAGS, e.g

	$set   LIBS   = &quot;-lxtools -lnag&quot;
	$set   LFLAGS = &quot;$(LFLAGS) -/L/usr/local/lib&quot;

Also, I noticed you make use of some STSDAS libraries.  Rather than use
the explicit path you can import the package environment with the &#x27;-p&#x27;
flag so they will be found automatically.  So for example part of your
mkpkg file could be rewritten as (assuming you use the NAG lib):


lijnst:
	$set LIBS   = &quot;-lxtools -liraf77 -lf77util -lnag&quot;
	$set LFLAGS = &quot;$(LFLAGS) -/L/usr/local/lib -p stsdas&quot;
	$set XFLAGS = &quot;$(XFLAGS) -/r8&quot;
	$update   libls.a
	$update   iraflib.a
	$omake	  x_lijnst.x
	$link	  x_lijnst.o libls.a iraflib.a $(LIBS) -o x_lijnst.e
	;

Hope this helps.

-Mike
