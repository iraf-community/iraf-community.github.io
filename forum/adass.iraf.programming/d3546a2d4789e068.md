Phil, by design, and for reasons of efficiency, IMIO does not permit pixel
values to be INDEF.  Pixel masks should be used to flag bad image pixels.  If
you store an INDEF-valued pixel in an image, IMIO will treat it like any
other pixel value; operations such as type conversion mail fail entirely.  In
general the INDEF value is machine dependent.  The recommended approach is to
replace bad pixels in an image with artifically generated values, and use a
bad pixel mask to flag such pixels and exclude them from most subsequent
analysis.
