## script tricks: pattern matching in strings

**Frank Valdes** wrote on May 23, 2000

<pre style="background: transparent; box-shadow: none; border: none;">
Q:  Is there a way to identify (and constrain a search for) characters
in a string? Eg similar to what is possible in STSDAS table tools?

I need something of the kind:

if( substr(spec,s,i) == &quot;{a-z}&quot;) do this

ie, identify the position of an entry in the string with this range
in characters (and ignore case in the process; for the above syntax).


A:  There is a way to do what you want.  The CL string comparison
operator does not provide &quot;pattern matching&quot;.  So you need to use a
task that does.  The appropriate task is MATCH.  To use it in a script
do something like

str = &quot;&quot;
print (substr(spec,s,i)) | match (&quot;{a-z}&quot;) | scan (str)
if (str != &quot;&quot;) {
   do this
}

Note that str has to be declared as struct if you want to have spaces
in the string.  Read the help for MATCH to find the pattern operators
allowed.  You can also use &quot;printf&quot; but be sure to terminate the format
string with a new line:

printf (&quot;%s\n&quot;, substr(spec,s,i)) | ...
</pre>
