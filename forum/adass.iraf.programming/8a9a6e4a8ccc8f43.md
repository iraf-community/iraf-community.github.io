**Mike Fitzpatrick** wrote on Sep 03, 1999

<pre style="background: transparent; box-shadow: none; border: none;">
&gt; I&#x27;m trying to compile a package under OSF and keep getting a message
&gt; something like:
&gt; 
&gt; 	Can&#x27;t locate file for: -lm_4sqrt
&gt; 
&gt; where do I find this particular library?

	In one of the minor revision updates from the Digital Unix V4.0b
version used to do the IRAF port DEC decided it would be fun to move the
contents of libm_4sqrt.a to the regular libm.a and so it&#x27;s no longer
available on recent DU systems.  The normal workaround for this was to 
download a patched xc.e binary from our /pub as &#x27;xc.e.DU4&#x27; and replace 
you iraf$unix/bin.alpha/xc.e binary, however the recent V2.11.2 patch
release for Alpha also solves this problem by linking that lib only when
it exists.  You can use the first workaround until upgrading.

Cheers,
-Mike
</pre>
