# TABLES/STSDAS v2.0.2 available

**Ellyne Kinney** wrote on Oct 06, 1998

<pre style="background: transparent; box-shadow: none; border: none;">

TABLES/STSDAS v2.0.2 is now available.

Tar files of the source and binaries, as well as instructions for installing them, 
are available on our Web site at:

	http://ra.stsci.edu/Advisory.html

and on our anonymous ftp site at:

	ftp.stsci.edu/pub/software/stsdas/

with installation instructions in the INSTALL file.

Release notes are available on our Web site at:

	http://ra.stsci.edu/stsdas202.html

If you have any questions or problems installing the packages, 
you can contact me at: help@stsci.edu or (410)338-1082.

Ellyne Kinney
</pre>
