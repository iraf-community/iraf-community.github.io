# STSDAS/TABLES v2.1.1 patch release now available

**Perry Greenfield** wrote on Dec 10, 1999

<pre style="background: transparent; box-shadow: none; border: none;">
STSDAS/TABLES v2.1.1 patch release is now available.

This patch release is only to fix problems that surfaced in v2.1.
It does not include any new or updated tasks or packages. The most serious 
problem in the previous release was that acesses of double precision
floating point columns in FITS binary tables were corrupted on PCIRAF and
Tru64. A configuration file problem for Red Hat Linux resulted in some
installations having difficulty building executables for STSDAS. Most of
the other changes involved problems with help files, control-C handling for
C tasks, and cleaning out files that did not belong in the source
distribution (but were otherwise harmless).

One can download the full source or a patch tar to update the v2.1 source.
Binaries are currently available for Solaris and RedHat 6.0 or later.
Binaries for other platforms will be added as they are built. Visit the
STSDAS web page (url: http://ra.stsci.edu) for the latest status on which
binaries are available, to download the source and binaries, and to view
the release notes and installation instructions.
</pre>
