# IRAF V2.11.3b bug fix patch

**Doug Tody** wrote on Sep 18, 2000

<pre style="background: transparent; box-shadow: none; border: none;">
IRAF V2.11.3b limited bug fix patch
September 18, 2000

Patch 3b is a limited patch containing minor fixes to support various
external packages (Gemini, PROS, STSDAS, MSCRED).  If your operations are
not affected by any of the bugs fixed in the patch you don&#x27;t need to install
it, although there is no reason not to do so.  The 2.11.3b patch contains
all FITS kernel bug fixes through August 2000, some buffer size increases,
file descriptor leak fixes, error recovery fixes, isolated fixes to MWCS
and QPOE, a fix affecting apextract performance when extracting large
numbers of spectra, an updated observatory database, and some enhancements
to the networking interface to support an upcoming release of Ximtool.
Nothing was included which would change the normal behavior or interface
of an application.  This is primarily a bug fix patch, and release of
new functionality is being deferred until the upcoming V2.11.4 release.

Since this is a limited patch we are releasing it only for specific
platforms.  Patch files for additional platforms will be considered
upon request.

The currently available patch files are as follows:

    patch3b-sos4.tar.Z		SunOS (sparc architecture) 
    patch3b-ssol.tar.Z		Solaris (ssun architecture)
    patch3b-dunx.tar.Z		Compaq Tru64 / Digital Unix
    patch3b-rhux.tar.gz		RedHat Linux 6.1/6.2
    patch3b-fbsd.tar.gz		FreeBSD

The patch files contain updated executables for the given architecture.
Some source and runtime files are also included; these are duplicated in
each patch file, and will be updated correctly no matter which patch files
are installed or in what order.

To install the patch, merely untar it at the IRAF root.  For example, to
install the patch for the Sun Solaris architecture:

    % cd $iraf
    % zcat patch3b-ssol.tar.Z | tar -xpvf -

More detailed information on installing the patch is given in the README
file in each distribution directory.

NOTE --  Patch3b is an incremental patch for the V2.11.3 release only.
IRAF must already have been upgraded to V2.11.3 before the patch is
installed.  The V2.11.3a patch (Feb 2000) should be installed before
installing V2.11.3b.  The V2.11.3 distribution files DO NOT include patch3b.

For further information on the patch please see the URL

    http://iraf.noao.edu/v2113_patch3b.html

More detailed information and updates on the IRAF software can be obtained
by subscribing to the various mailing lists, e.g. buglog, applications, and
system.  See http://iraf.noao.edu/subscribe.html to subscribe to the various
lists.
