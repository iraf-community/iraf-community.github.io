## TABLES/STSDAS 2.1 now available

**Ramon Williamson** wrote on Oct 04, 1999

<pre style="background: transparent; box-shadow: none; border: none;">

The Science Software Group of the Science Support Division at STScI wishes to 
announce the availability of Version 2.1 of the Space Telescope Science
Data Analysis Software (STSDAS).  Concurrent with the STSDAS release, we
have also released V2.1 of the TABLES external package. Both of these
packages are layered upon IRAF V2.11 as external packages; it is
therefore necessary to obtain and install IRAF V2.11.1 or 2.11.2 (depending on
availability) (from tucana.noao.edu) before installing TABLES and STSDAS.  The TABLES package is intended for sites whose software requires only the binary
tables and FITS utilities (e.g. SAO&#x27;s XRAY package).  


PLEASE NOTE: STSDAS is layered on TABLES, so it is essential to install 
             V2.1 of the TABLES package _before_ installing V2.1 of 
             STSDAS.  


WHERE TO OBTAIN THIS SOFTWARE 

Off-site users may obtain TABLES and STSDAS from our ftp archive on node 
&quot;ftp.stsci.edu&quot;, in the sub-directories under &quot;pub/software&quot;: e.g.
&quot;/pub/software/stsdas/stsdas_v2.1&quot;, &quot;/pub/software/stsdas/tables_v2.1&quot;.  
See the INSTALL file in &quot;/pub/software/stsdas, and the &quot;STSDAS Site Manager&#x27;s
Installation Guide and Reference&quot; (located in the &quot;/pub/software/tables/doc&quot;
directory in the file &quot;InstallGuide.ps&quot;) for retrieval and installation
instructions.  If you choose to get the software electronically, please
send us the electronic registration form **even if you have already
registered for an earlier release of STSDAS** so that we may keep you up
to date regarding revisions to the software and documentation.  Sites
that do not have access to ftp may obtain the V2.1 release by writing to
the STSDAS System Administrator (help@stsci.edu), for a distribution
tape and installation instructions.  

Precompiled binaries also exist for some of the ports supported by NOAO,
including Sun Solaris, Tru64, Red Hat Linux 5.0 and 6.0, Slackware 3.6, and
FreeBSD 2.2.8.  See the INSTALL file above for directions for downloading
those.

We hope that you find STSDAS V2.1 useful, and we encourage your feedback.
Please contact us through e-mail (help@stsci.edu), by telephone at 
(410) 338-1082, or regular mail to the STSDAS Group, at the address below.
