## New IRAF "Tips & Tricks" facility

**Doug Tody** wrote on Jun 09, 1998

<pre style="background: transparent; box-shadow: none; border: none;">


			IRAF Tips &amp; Tricks

A new set of Web pages describing many useful and often overlooked
capabilities of IRAF is now available from

		    http://iraf.noao.edu/tips

If you&#x27;ve ever wondered how to find out what tasks are available for
performing a certain operation, how to edit string parameters without
having to retype the whole string, or how to automatically contol the
position or size of an XGterm graphics window, then this is the page for
you.  A peliminary set of tips includes a number of handy and useful little
items that we have found many users don&#x27;t know about (sometimes even very
experienced ones!).  We encourage you to browse these, and to submit your
own tips and tricks so that others might benefit from what you&#x27;ve learned:
a form for submitting new Tips &amp; Tricks is provided on the tips page.

We would also like to take this opportunity to remind you of other on-line
services provided from the IRAF Web pages (http://iraf.noao.edu):

     http://iraf.noao.edu/iraf-mirrors.html

	    FTP and WWW mirror archives of our site.

     http://iraf.noao.edu/search/searches.html

	    Search the IRAF archives, documentation, archived ADASS
	    newsgroup articles, buglogs, FAQ, or FTP archive.

     http://iraf.noao.edu/iraf-help.html

	    On-line help pages for the NOAO IRAF development system and
	    selected external packages.  Searchable.

     http://iraf.noao.edu/faq

	    Frequently Asked Questions covering installation and display
	    problems, applications, post-install configuration and more.

     http://iraf.noao.edu/iraf/docs

	    All available IRAF documentation, the README file serves as
	    a &quot;Table of Contents&quot;.

     http://iraf.noao.edu/adass_news.html

	    Information about the ADASS newsgroups and associated email
	    exploders.

     http://iraf.noao.edu/irafnews/newslet.html

	    IRAF Newsletters (updated 4/98 with the latest Newsletter
	    covering the IRAF V2.11 release).

     http://iraf.noao.edu/tutorials

	    Excercises and Tutorials for the IRAF system.

     http://iraf.noao.edu/contrib.html

	    Contributed software (STSDAS/TABLES, XRAY, etc).

As always, users who experience problems or want to suggest something or
comment on the system are encouraged to write to iraf@noao.edu.  We hope
the &#x27;Tips &amp; Tricks&#x27; are useful and that you will consider contributing
anything you&#x27;ve found that may be helpful to others.

Thanks goes to the IRAF User Committee for suggesting this feature, and
to Mike Fitzpatrick and George Jacoby (IRAF Project Scientist) for setting
it up.

The IRAF Group
Tue Jun 9 1998
