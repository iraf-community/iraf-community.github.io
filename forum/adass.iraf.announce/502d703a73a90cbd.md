## Problem with FITS table access for STSDAS/TABLES on PCIRAF and Tru64

**Perry Greenfield** wrote on Oct 27, 1999

<pre style="background: transparent; box-shadow: none; border: none;">
A bug has been discovered in the underlying CFITSIO library that TABLES 
uses to access FITS tables that results in serious errors on Intel and
Alpha processors when accessing double precision floating point columns
in FITS tables. This affects all PC-IRAF and Tru64 (Digital Unix) users.
Users of other platforms are unaffected and do not need to do anything.

We will be releasing a patch version of TABLES and STSDAS (v2.1.1) very
soon after the next IRAF patch release (v2.11.3, expected in a couple of
weeks or so). In the meantime, users on these systems can obtain the patched
CFITSIO file from the stsdas web page (see the first news item) with
the instructions for rebuilding STSDAS and TABLES.
</pre>
