## TABLES/STSDAS v2.2 now available

**Edward Colbert** wrote on Aug 18, 2000

<pre style="background: transparent; box-shadow: none; border: none;">

              *****************************************

                   TABLES/STSDAS v2.2 NOW AVAILABLE

              *****************************************

The Science Software Group of the Science Support Division at STScI
wishes to announce the availability of version 2.2 of the Space
Telescope Science Data Analysis Software (STSDAS).  Concurrent with the
STSDAS release, we have also released v2.2 of the TABLES external
package. Both of these packages are layered upon IRAF v2.11 as external
packages; it is therefore necessary to obtain and install IRAF v2.11.1,
2.11.2 or 2.11.3 (hopefully 2.11.3) (from tucana.noao.edu) before
installing TABLES and STSDAS.  The TABLES package is intended for sites
whose software requires only the binary tables and FITS utilities (e.g.
SAO&#x27;s XRAY package).


PLEASE NOTE: STSDAS is layered on TABLES, so it is essential to install 
             v2.2 of the TABLES package _before_ installing v2.2 of 
             STSDAS.  


WHERE TO OBTAIN THIS SOFTWARE 

Off-site users may obtain TABLES and STSDAS from our ftp archive on node 
&quot;ftp.stsci.edu&quot;, in the sub-directories under &quot;pub/software&quot;: e.g.
&quot;/pub/software/stsdas/stsdas_v2.2&quot;, &quot;/pub/software/stsdas/tables_v2.2&quot;.  
See the INSTALL file in &quot;/pub/software/stsdas, and the &quot;STSDAS Site Manager&#x27;s
Installation Guide and Reference&quot; (located in the &quot;/pub/software/tables/doc&quot;
directory in the file &quot;InstallGuide.ps&quot;) for retrieval and installation
instructions.  If you choose to get the software electronically, please
send us the electronic registration form **even if you have already
registered for an earlier release of STSDAS** so that we may keep you up
to date regarding revisions to the software and documentation.  Sites
that do not have access to ftp may obtain the v2.2 release by writing to
the STSDAS System Administrator (help@stsci.edu), for a distribution
tape and installation instructions.  

Precompiled binaries also exist for some of the ports supported by
NOAO, including Sun Solaris 2.5.1, Solaris 2.8, Tru64 5.0a, Red Hat
Linux 6.1, Sun SunOS 4.1.3, HP-UX B.10.20 and SGI IRIX 6.5.  We should
soon have binaries for  Slackware 3.6, and FreeBSD 2.2.8.  See the
INSTALL file on the ftp site for directions for downloading those
files.

We hope that you find STSDAS v2.2 useful, and we encourage your feedback.
Please contact us through e-mail (help@stsci.edu), by telephone at 
(410) 338-1082.
</pre>
