# saord release 1.7.2 withdrawn temporarily

**Eric Mandel** wrote on Jun 05, 1998

<pre style="background: transparent; box-shadow: none; border: none;">


This afternoon we uncovered a bug in the way SAOtng passes certain
FITS images to analysis routines using the command:

	xpaget SAOtng.&lt;filename&gt; raw_data

The raw data passed in this way by SAOtng is used by programs in the
SAOtng Analysis menu and by user programs as well. Although the bug
does not affect SAOtng&#x27;s image display functions, we have decided to
withdraw release 1.7.2 temporarily while we fix the problem.  This
measure will prevent incorrect analysis of data retrieved from SAOtng.

We expect to have a fix in the coming week and to make the release
available soon after that.

Eric
</pre>
