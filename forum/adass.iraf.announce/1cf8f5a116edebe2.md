# PC-IRAF V2.11.1 released

**Doug Tody** wrote on Jan 27, 1998

<pre style="background: transparent; box-shadow: none; border: none;">

PC-IRAF V2.11 RELEASED (patch level V2.11.1)
-----------------------------------------------------------

The initial release of PC-IRAF is now available.  This replaces the old
V2.10 Linux/IRAF release which only supported Slackware Linux.  The new
PC-IRAF is a single version of IRAF, tailored for personal computers,
which supports the various PC platforms as optional architectures within
a single IRAF installation.  A single installation of PC-IRAF on a central
server can be used to simultaneously run IRAF on a variety of networked
PCs, each running a different operating system.

The initial PC-IRAF release supports the following platforms:

    o	Slackware Linux V3.3.

    o	Red Hat Linux V5.0.

    o	FreeBSD V2.2.5.

Support for additional platforms is planned for a future release, in
particular for Solaris x86 and MkLinux (Macintosh).

All of the above are at patch level V2.11.1, the same version of IRAF as
was released for Suns, the DEC Alpha, and HP/UX in late December (plus a
few additional bug fixes we found while testing PC-IRAF extensively in the
latter half of January).

Please see the distribution README file for additional detailed information
on the release, including notes on the different platforms.  This is online
in the distribution directory as

    ftp://iraf.noao.edu/iraf/v211/PCIX/README

As always, please report any problems including any errors in the release
documentation, especially if you encounter problems shortly after a release.

Late breaking news about minor updates, or workarounds for installation
problems, will be found at the end of the distribution README file (which
is updated periodically following a release), or in the adass.iraf.system
newsgroup and mailing list.  This and other IRAF-related newsgroups are
available via email subscription via a form in the IRAF web pages, or by
mail to listproc@iraf.noao.edu.

Tue Jan 27 21:21:26 MST 1998
