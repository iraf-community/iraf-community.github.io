# TABLES/STSDAS 2.1 Beta Release now available on Anonymous FTP

**Ramon Williamson** wrote on Sep 14, 1999

<pre style="background: transparent; box-shadow: none; border: none;">
Dear IRAF, TABLES, STSDAS Users:

I am pleased to announce the availability of the Beta Release of TABLES and 
STSDAS, version 2.1.

I have placed the Beta release version of TABLES and STSDAS 2.1 on our
anonymous FTP site on ftp.stsci.edu (130.167.101.2).  There are
compressed tars in /pub/software/stsdas/beta for both TABLES and STSDAS under
Solaris 2.5 for TABLES and STSDAS 2.1 Beta.  The files are tables21_beta.tar.Z and stsdas21_beta.tar.Z. A README.beta file also exists for these tars.  This file contains basic instructions on how to install the tars.

This Beta release is LOAD and GO for SUN Sparcs and Ultras running Solaris 2.5
under IRAF 2.11.2, which means it has already been compiled under these
conditions, and once the tar is read, you can use the package.  TABLES and
STSDAS should run correctly under IRAF 2.11.1, either under Solaris or
other OS&#x27;s, but the packages will need to be recompiled due to shared
image differences.

Please feel free to contact Ray Williamson at ramon@stsci.edu with questions
on installing the code.

Any bug reports should also be sent to Ray Williamson at ramon@stsci.edu.
We hope to make the final release within a few weeks, so please let us know of
problems.

                                                        Ray Williamson
                                                        STSDAS Administrator
