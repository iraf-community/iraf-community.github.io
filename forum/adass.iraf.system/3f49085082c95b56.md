  I&#x27;m not an expert too, but I guess the problem with your XWindows
  configuration is related to the color bit planes you&#x27;re using.
  I mean: Ximtool only supports 8 bit color squeme (2^8 colors).
  Sometimes XWindows is configured with 16 and sometimes 32 color
  bitplanes. Please check this out.

  If you ran XConfigurator to configure the Xwindows, don&#x27;t let it 
  specify the mode (e.g. 1024x767x16 the typical case) but
  rather tell him you want to choose the display mode.
  Choose the resolution your hardware supports but be sure to
  select it in the 8 bits column.

  Hope it help.
