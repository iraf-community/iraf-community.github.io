Just a warning: there are several PGX cards, PGX-8, PGX-24 and PGX-32.
PGX-8 supports only 8-bit color (default on-board graphics in U5 &amp; U10
when first introduced).  PGX-24 supports both 24-bit and 8-bit color,
but NOT simultaneously, no overlay (new default on-board graphics
in U5 &amp; U10).  PGX-24 is actually an ATI RAGE PRO chip set (not Sun).
PGX-32 supports both 24-bit + 8-bit overlay and is the only one of the
three that is truly a separate PCI card.  PGX-32 is also not Sun and
is actually the Tech-Source Raptor GFXtra card.  I&#x27;ve personally
never used the PGX-32 since Creator3D is not much more in cost (but
significantly better performance), hence I can not comment on its 
default settings/behavior.

True, this works, but is not the best way.  In my experience, there
are only 3 programs left that absolutely can not run under visuals
differring from 8-bit: SAOtng, ximtool, and IRTF viewfits, and will 
find the 8-bit visual if available.   All other programs that I&#x27;ve 
used luckily default to the highest bit visual available.  So, when
at all possible graphics framebuffers should be purchased and then
set to allow something like a 24-bit default visual with an 8-bit
overlay (concurrent 24-bit and 8-bit visuals to support large numbers
of colors for most programs but the 8-bit programs can still find
a colormap to use).  I am glad to see that there is progress being

The factory default for /usr/dt/config/Xservers should look like:
   :0   Local local_uid@console root /usr/openwin/bin/Xsun :0 -nobanner
Notice that there is no specification about which framebuffer to use
or which visual depth.  This is because the rest of the software and 
hardware is set to figure all of that out and the /usr/dt directories
are often shared among many Suns with varying hardware displays. 

Definitely issue the dtconfig -reset command as recommended above
or if all else fails, reboot.  :)

If you do need to modify CDE settings for a computer, it is 
suggested that copies of the relevant /usr/dt files be placed
in /etc/dt and then modified.  The files in /etc/dt over-ride
the files in /usr/dt (although some conflicts do occur). This will
1). keep copies of the original code and 2). allow customization 
for individual computers while sharing the main, large /usr/dt.  
The Xservers file usually only needs modification if you plan to 
use multiple monitors and graphics framebuffers (multi-head) and
you want to order which displays are left, right, above, or below
others.  (If you can afford multiple monitors, they are great and
extremely easy to do!)

Try moving your .xserverrc file to some random file (e.g. .foo )
so that you are hopefully using all the default settings.

In addition, there are some settings that may have been modified for
the Creator3D card.   First, to see the settings, try typing:

	/usr/sbin/ffbconfig -propt -prconf

Or, the all encompassing:
