## PC-IRAF typo in install script

**Doug Tody** wrote on Dec 09, 1999

<pre style="background: transparent; box-shadow: none; border: none;">
Thu Dec 9 1999  -- Install script typo
===========================================================

The V2.11.3 PC-IRAF &quot;install&quot; script (unix/hlib/install) contains a typo.
Line 515, which should look like

    if ($mach == linux || $mach == redhat || $mach == suse || \

contains an extra &quot;or&quot;, as in &quot;|| ||&quot;.  The fix is to either edit the file
and correct the error, or install the updated version provided in the
installation directory:

    ftp://iraf.noao.edu/iraf/v211/PCIX/install
</pre>
