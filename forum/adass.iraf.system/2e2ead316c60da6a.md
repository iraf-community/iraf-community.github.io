**Mike Fitzpatrick** wrote on Nov 21, 1999

<pre style="background: transparent; box-shadow: none; border: none;">
	The message was probably something like a &quot;checksum error&quot; and
a &quot;broken pipe&quot; from the tar command.  These usually indicate that the
file were somehow corrupted (e.g. you didn&#x27;t download in binary mode, a
file is missing, etc).   First verify that you have all the pieces, then
so a &quot;sum as.*&quot; and verify that the checksums produced are the same as
in the CHECKSUMS file that was in each distribution directory.  You&#x27;ll
need to download each file that doesn&#x27;t agree, be sure to use binary 
mode.  IRAF is known to run under Mandrake without problem (so long as
you get the /iraf/v211/PCIX/rhux-6.0 distribution).
	If you still have problems feel free to follow-up here or send
a message to the site support address, iraf@noao.edu.  Hope this helps.

-Mike
</pre>
