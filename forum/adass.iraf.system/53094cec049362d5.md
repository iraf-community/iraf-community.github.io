Subject: IRAF V2.11.3 upgrades on NOAO servers

The next IRAF version, V2.11.3, is in the final stages of testing and we
are planning to install this on the NOAO-Tucson servers this evening
(Friday 5 November).  This is primarily a bug fix patch and should not
affect any ongoing reductions, but as the binaries will be replaced any
IRAF sessions running when the upgrade occurs will probably crash.  Only
the current or default IRAF installation will be affected; &quot;irafo&quot; will
not be changed.  In other words, V2.11.3 will replace V2.11.2 on the
servers.

(Also, for those of you who are running any of the PC-IRAF platforms such
as Linux, a compatible V2.11.3 release for all the PC-IRAF platforms is
in testing now and should be available soon.  This does not yet include
support for the Macintosh running Linux however).
