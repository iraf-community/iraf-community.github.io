	You didn&#x27;t say what system this was for but assuming it&#x27;s a
Solaris machine an entry for a DLT 7000 on SCSI 0 would look something
like:

mtm|mtmhi|                              :tc=mtst0.solaris.dlt-hi:
mtmlo|                                  :tc=mtst0.solaris.dlt-lo:
mtmhic|mtmc|                            :tc=mtst0.solaris.dlt-hicomp:
mtmloc|                                 :tc=mtst0.solaris.dlt-locomp:

mtdlt0|mtst0.solaris.dlt|DLT drive on device 0:\
        :al=0 0b 0bn 0n 0c 0cb 0cbn 0cn 0h 0hb 0hbn 0hn \
        0l 0lb 0lbn 0ln 0m 0mb 0mbn 0mn 0u 0ub 0ubn 0un: \
        :dv=0bn:lk=0:tc=solaris-dlt:
mtdlt0h|mtst0.solaris.dlt-hi|:dv=0hbn:dn=high:tc=mtdlt0:
mtdlt0l|mtst0.solaris.dlt-lo|:dv=0lbn:dn=low:ts#20000000:tc=mtdlt0:
mtdlt0h|mtst0.solaris.dlt-hicomp|:dv=0ubn:dn=compressed:tc=mtdlt0:
mtdlt0l|mtst0.solaris.dlt-locomp|:dv=0mbn:dn=comp (low):ts#20000000:tc=mtdlt0:

solaris-dlt|Quantum DLT-7000 digital linear tape drive:\
        :dt=Quantum DLT-7000 (solaris):tt=DLT-IV:\
        :ts#35000000:bs#0:fb#10:fs#8192:mf:

To change this for a different device number you would need to be sure
to modify the :al (device aliases), :dv (the device actually used for I/O),
and :lk (used to create the allocation &quot;lok file&quot; in /tmp) fields.  There
may be other changes required for other operating systems.
	For further information on tapecap configuration see the last IRAF
Newsletter article on the subject:

	http://iraf.noao.edu/irafnews/apr98/irafnews.1f.html

The :bs is the tape block size which can be set independently at the host
level to be variable or some fixed size.  Use the &#x27;mt -f &lt;dev&gt; status&quot; 
command to see what the current setting is and some systems support an
&#x27;mt&#x27; option to change this or you may need to flip a dip switch on the
hardware.  The Newsletter article should point you to tapecap fields that
might need tweaking or write back.

-Mike
</pre>
