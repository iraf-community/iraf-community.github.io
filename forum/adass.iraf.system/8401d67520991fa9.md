## Using SAOtng on a 16-bit (or higher) display under Solaris

**Eric Mandel** wrote on Jun 18, 1998

<pre style="background: transparent; box-shadow: none; border: none;">


&gt; We have several Suns, but all have 8-bit frame buffers so the question
&gt; has never come up....

Please note that SAOtng will run fine on an X server set up in 24-bit
mode if an 8-bit PseudoColor visual also is supported.  This is the
case, for example, with 24-bit Suns, but not with 16-bit Linux.  No
need to change the server or run Xnest or anything.  So far as we can
tell, Linux is the only system in which the deep frame support doesn&#x27;t
also come with 8-bit PseudoColor support, necessitating the change in
sever depth.

You can see which visuals are supported by executing:

	xdpyinfo

Eric
</pre>

the need to fire up a separate 8 bpp server for ximtool, et al. which
require PseudoColor visuals.  if it&#x27;s a big issue, i think the
commercial Accelerated-X server from www.xig.com supports PseudoColor
visuals in 24 or 32 bpp.  or it at least allows one to Xnest 8 bpp
within 24 bpp. i don&#x27;t recall which, but i have seen ximtool running
in a 24 bpp display using their server.  i&#x27;m not sure if metro-x also
has this capability, but i doubt it.
