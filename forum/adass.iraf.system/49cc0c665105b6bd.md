## PC-IRAF V2.11.1 on Debian Linux

**Doug Tody** wrote on Jan 29, 1998

<pre style="background: transparent; box-shadow: none; border: none;">

&gt; &gt; The initial PC-IRAF release supports the following platforms:
&gt; &gt; 
&gt; &gt;     o	Slackware Linux V3.3.
&gt; &gt; 
&gt; &gt;     o	Red Hat Linux V5.0.
&gt; &gt; 
&gt; &gt;     o	FreeBSD V2.2.5.
&gt; &gt; 
&gt; 
&gt; Does this mean that Debian Linux is NOT supported yet?  I did have
&gt; troubles with PC-IRAF 2.10.4p2 on my Debian 2.0.30 machine -- Mike
&gt; Fitzpatrick helped a lot, but it took some doing.  Will I be likely to
&gt; have similar problems with 2.11? 

We don&#x27;t explicitly support Debian, or any versions of Linux other than
Slackware and RedHat.  On the other hand the new PC-IRAF release is up to
date, and if you are running a recent version of Debian this will probably
eliminate most of the problems you had earlier.  The fact that we don&#x27;t
directly support Debian doesn&#x27;t necessarily mean that it won&#x27;t work.  I
would be surprised if you can&#x27;t install the LNUX (i.e. Slackware)
distribution and have it work under Debian.  Whether compiliation would
work without some tweaking is impossible to say, but I should think the
bin.linux executables would run.  We distribute prebuilt executables for
the major external packages as well, e.g. tables and stsdas, so for some
this will eliminate the need for compilation.

The simplest thing is to just try it; you can keep your old iraf installation
around and just reinstall it (e.g. change /iraf to point to it and/or run
the install script) if there are problems with V2.11.  So far as I know
no one has tried PC-IRAF on Debian yet.  I&#x27;ll bet any problems are minor.
</pre>
