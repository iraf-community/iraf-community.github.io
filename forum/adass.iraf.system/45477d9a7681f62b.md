With the addition of an solaris-exb8200 entry the mta3 tapecap entry below
reads in fine here, so you must have some other problem.  This has nothing
to do with devices/devices.hlp, dev$devices is not used on Unix systems,
and devices$hlp is just documentation.  All that is involved is the tapecap
environment variable, which must point to your tapecap file, the tapecap  
file itself, and the entry therein.  &quot;bad tapecap entry&quot; would appear to
indicate that the system can&#x27;t read the &quot;mta3&quot; tapecap entry, if one exists.

Try &quot;show tapecap&quot; to see if this looks right, and &quot;page tapecap$&quot; to verify
if the file can be accessed as expected.  If that works and you get the right,
file, it must be a problem in the format of the file itself.

A useful way to test *cap files is to use the showcap task:

    cl&gt; reset graphcap = &lt;my-tapecap-file-name&gt;
    cl&gt; showcap
    * set &lt;device-entry-name&gt;

This will print the device entry if it can be read from the file.  (Be sure
to set grapcap back to dev$grapcap when you are done or you will not be
able to find your graphics devices later).
