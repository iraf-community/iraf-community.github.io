# Solaris OS versions (fwd)

**Doug Tody** wrote on Dec 24, 1997

<pre style="background: transparent; box-shadow: none; border: none;">

Here is something to watch out for if you have occasion to relink IRAF on
a Solaris system.  (found while preparing the V2.11.1 patch).

---------- Forwarded message ----------
Date: Wed, 24 Dec 1997 13:06:58 -0700 (MST)
From: Doug Tody &lt;tody@tucana.tuc.noao.edu&gt;
Subject: Solaris OS versions

It turns out that there were problems (&quot;bad arg to system call&quot;) when running
Solaris/IRAF linked under 2.6 on 2.4 and 2.5 systems (data and beet).  I found
this while doing a few basic tests after updating the shared images for these
platforms.  It appears that the fstat system call has changed in 2.6 and
doesn&#x27;t work on older systems.  There could be other similar problems as well.

So we are going back to linking Solaris/IRAF on 2.5 (data).  One would
expect Solaris 2.6 to be able to run 2.5 binaries, and so far as I can
tell IRAF linked under 2.5 works on Solaris 2.4, 2.5, and 2.6 (the shared
images are still linked custom for each platform).
