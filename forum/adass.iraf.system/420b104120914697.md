	Usually when garbage appears in response to a graphics task it 
means that either the terminal window being used does now support graphics
(e.g. an &#x27;rxvt&#x27; window), or you are using an xterm/xgterm window but IRAF
thinks it&#x27;s something else (e.g. you use an &#x27;xterm&#x27; but IRAF assumes an
&#x27;xgterm&#x27;).  You can use the command &#x27;show stdgraph&#x27; to see to current
setting and &#x27;stty xgterm&#x27; or &#x27;stty xterm&#x27; within the CL to reset it.

&gt; Another strange behavior is from the keyboard (Italian): at the CL prompt
&gt; I can&#x27;t delete the last letter I write with any keys (Del, Canc etc.): all
&gt; what appear are meta-characters

	The CL will use whatever backspace key is set at the unix level,
however international keyboards or language settings in the window environ-
ment may reset these.  To set the backspace key you would use

	% stty erase &lt;hit_desired_delete_key&gt;

when setting this in your .login file you would use the same command but
if you use &#x27;vi&#x27; as the editor you&#x27;d type Ctrl-V (verbatim) before hitting
the delete key to use.  Note that tasks like xmodmap can be used to remap
or alias a Delete and BackSpace key and may change the settings.  Does
delete work at all at the host level, if so you need to set that key 
using the above (or similar) stty command.
	Hope this helps, if you still have problems feel free to followup
or reply directly.

Cheers,
-Mike
