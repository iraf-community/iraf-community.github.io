## Whence linuz?

**Doug Tody** wrote on Jan 28, 1998

<pre style="background: transparent; box-shadow: none; border: none;">

[The question is what happened to &quot;bin.linuz&quot; (containing gzip compressed
executables) which was present in Linux/IRAF]

&gt;   I notice that the &quot;linuz&quot; distribution isn&#x27;t present.  Should I 
&gt;   expect any problems if I just go ahead and gzexe the executables?
&gt;   We do a lot of running on laptops and other systems with limited
&gt;   disk space, so this is important to us.

linuz was always a bit odd as it isn&#x27;t a real architecture.  It would have
been awkward this time around since we have half a dozen platforms rather
than one.  So I wanted to drop it.  There should be no problem gzexe-ing
a few executables if you want to (I would leave cl.e and x_system.e unzipped
and maybe one or two others, and gzexe the rest).  Maybe I should add a 
comment to the README about this.

Hi Tony,

In general I think the more traffic in the newsgroups/mailing-lists the
better.  This has the benefit of spreading the expertise around, and
eventually we might even see a discussion which is not so one-sided as it
is now (i.e. in the future we could have expert iraf users helping other
users).  Meanwhile we try to forward stuff to the newsgroups occasionally
to keep them from totally dying from disuse, and because it is undeniably
useful to do so.  For example it is only appropriate to post major stuff
like the announcement of a new IRAF version to the main IRAF mailing list
(adass.iraf.announce, which is forwarded to a zillion people), so we need a
place such as adass.iraf.system to discuss the minor follow up issues that
always come up - things like why don&#x27;t executables linked on Solaris 2.6
always run on 2.5, the Debian Linux support question just posted, and a
hundred other things like that.  Many people no longer read the newsgroups
under USENET due to all the SPAM postings, but all these newsgroups are
gatewayed to moderated mailing lists and an increasing number of people are
subscribing to these, so even a modest level of discussion can be quite
useful.  Plus the newsgroups are archived and searchable via the IRAF web
pages. 

The bottom line is it is up to you.  If the question is directed at a
specific person email is probably best.  General queries can be posted to
either iraf@noao.edu or a newsgroup, but in many cases, the most benefit
will result from using a newsgroup.  In any case, we do encourage people
to post to the newsgroups.  Try to think of them like the mail subscription
services/discussion groups that have become so popular in the past couple
of years.

	- Doug
