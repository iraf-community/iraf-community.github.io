In my WCSTools package ( http://tdc-www.harvard.edu/software/wcstools/ )
there is a program, i2f, which reads any IRAF .imh image written
in either byte order on a system which uses either byte order and
converts it to a FITS file.  The WCSTools programs run standalone
under every Unix on which they have been tested.  There is also an
IRAF package directory into which you can plug the executables at

ftp://cfa-ftp.harvard.edu/pub/gsc/WCSTools/wcstools.iraf.tar

though if this is all you want to do, just grab the WCSTools tar file
and make i2f .  Documentation is on the web site, and options are
printed
if you run the program with no arguments.
