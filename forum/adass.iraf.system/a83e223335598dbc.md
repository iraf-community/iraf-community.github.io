**Mike Fitzpatrick** wrote on Aug 26, 1998

<pre style="background: transparent; box-shadow: none; border: none;">
	Checksums are pretty straightforward things to calculate and you
should have gotten matches on either the BSD or SYSV values in the dist-
ribution.  Since things won&#x27;t unpack and none of the checksums match, I&#x27;d
say all of the files are corrupted and you should try downloading them
again.  Be sure to set binary mode for the transfer, you may prefer to use
the IRAF mirror site in the UK at

	ftp://star.rl.ac.uk/pub/iraf

Hope this helps.

-Mike
</pre>
