	You can change the system default by editing the system
/usr/dt/config/Xservers file to add the arguments 

        ........ defDepth 8 defClass PseudoColor

Or, on the command line start X using something like

        /usr/openwin/bin/Xsun :0 -dev /dev/fb defclass PseudoColor

Note that you can put the above command in a .xserverrc file in your login
directory (see the xinit man page) and just comment it out when you want to
restart in 24-bit mode.
	Hope this helps.

Cheers,
-Mike

&gt; login screen and be able to use ximtool.  However I haven&#x27;t been able to
&gt; figure out how to start CDE in 8 bit PseudoColor.  I have access to other
&gt; machines where this is not a problem, but I&#x27;d like to be able to iraf
&gt; normally without switching offices :)  Any suggestions on configuring CDE
&gt; to default to pseudocolor appreciated! Thanks,

By default Creator3D is a 24-bit plus 8-bit overlay graphics 
system.  This means that if you don&#x27;t change any of the factory
settings for the framebuffer or CDE, then ximtool will run just 
fine because there is already an 8-bit display running 
simultaneously on top of the 24-bit display.  So, you must have
intentionally set the system to run in 24-bit only mode; change 
it back.

I have several Ultra boxes with Creator3D.  Ximtool runs with
no problems in the default 24-bit plus 8-bit overlay mode.


	craig
