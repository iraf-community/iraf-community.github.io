# X11IRAF and Linux RedHat 5.0

**Mike Fitzpatrick** wrote on Dec 29, 1997

<pre style="background: transparent; box-shadow: none; border: none;">

	Several users have reported that the X11IRAF tasks XGterm/XImtool
fail under the Linux RedHat 5.0 distribution when using the prebuilt
binaries from our archive (ftp://iraf.noao.edu/iraf/x11iraf).  This is
apparently due to incompatabilities with the new &#x27;glibc&#x27; library used
with RedHat 5.0.  Users who encounter problems will need to build the
package from source to fix this, the source archive can be found at

	ftp://iraf.noao.edu/iraf/x11iraf/x11iraf-v1.1-src.tar.gz
	ftp://star.rl.ac.uk/pub/iraf/iraf/x11iraf/x11iraf-v1.1-src.tar.gz
	ftp://ecf.hq.eso.org/iraf/iraf/x11iraf/x11iraf-v1.1-src.tar.gz

Once unpacked the system is built using the commands

	% xmkmf
	% make World

New binaries will be created in a &#x27;bin&#x27; subdirectory, simply move these to
wherever you have xgterm/ximtool installed currently.  If you have problems
or questions feel free to contact iraf@noao.edu.  Binaries linked against
the new glibc will either be made available through our archives in the
/iraf/x11iraf directory or by contacting site support.

Mike Fitzpatrick
</pre>
