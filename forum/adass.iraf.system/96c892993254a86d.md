	On some systems it may be necessary to install the f2c.h file from
the bin.redhat (i.e. hbin$) in /usr/include or /usr/local/include, on
other systems this file is present even if the F2C package hasn&#x27;t been
installed.  PC-IRAF is distributed with an F2C binary and library which is
used for compilation, but one oversight of the hlib$f77.sh script used to
drive the F2C/GCC translation is that the hbin directory isn&#x27;t searched as
an include directory.  To fix this you can edit the hlib$f77.sh script so
that the initial CFLAGS definition (on about line 34) explicitly passes
the path to the iraf$unix/bin.&lt;arch&gt; directory in the &#x27;-I&#x27; flag, e.g.

	CFLAGS=${CFLAGS:-&quot;-I${iraf}unix/bin.${IRAFARCH}&quot;}

As it&#x27;s written now it assumes the HSI is configured for the platform arch-
itecture, but the distributed system is configured generically.  We plan
to fix this for the upcoming V2.11.2 patch, until then just ask if you have
problems or other phases of compilation under Linux.

Cheers,
-Mike
</pre>
