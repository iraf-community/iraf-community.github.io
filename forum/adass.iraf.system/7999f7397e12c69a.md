	Is the message &quot;cannot open connected subprocess&quot;?  If so then it
usually means the binaries were installed in the wrong place, e.g. the
NOAO package binaries were installed in the same directory as the core
system binaries.  If this is the case then you should get the message for
all NOAO tasks, and all the time.  Or are you saying that this error just
happens occassionally?  In that case I haven&#x27;t got a quick answer, it could
be that you&#x27;ve defined something in your login.cl or loginuser.cl that is
causing this in which case try doing a fresh mkiraf from a scratch directory
to see if it happens there as well.
	If you still have problems please send me more information (the
exact error message, and a way to reproduce it if possible).

-Mike
