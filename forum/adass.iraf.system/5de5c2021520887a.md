# IRAF networking on Linux systems

**Mike Fitzpatrick** wrote on Mar 31, 1998

<pre style="background: transparent; box-shadow: none; border: none;">

&gt; I tried to edit dev$hosts to have it on the iraf network.  I tried all
&gt; possible combinations I could imagine and it still does not work.  I run
&gt; netstatus and get:
&gt; 
&gt; cl&gt; netstatus
&gt; Local node `&#x27; (0), default node `&#x27;, 5 nodes in local network
&gt; Network interface disabled (no entry for local node in dev$hosts)

	There is a known bug on some Linux distributions (main Red Hat) in
which the gethostname() procedure (used by networking to determine the
local host) will return an error if the length of the hostname is longer
than the string requested by the iraf call, resulting in the local node
showing up as a null string in the NETSTATUS output.  This is usually
because the /etc/sysconfig/network file contains the fully-qualified
hostname (e.g.  zippy.tuc.noao.edu).  Simply edit this file and change the
host name to &#x27;zippy&#x27; and the node should be recognized.  Note you can then
use the shorter name in the dev$hosts file for the node, e.g.

zippy                 : zippy!/iraf/irafbin/bin.redhat/irafks.e
</pre>
