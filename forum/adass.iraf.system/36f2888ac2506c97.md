## CDL Build on Solaris systems

**Mike Fitzpatrick** wrote on Mar 15, 1998

<pre style="background: transparent; box-shadow: none; border: none;">

	The recent V1.6 release of the Client Display Library (CDL) will 
not build correctly on Solaris systems, specifically the VXIMTOOL dummy
server will not build, due to missing library definitions in the Imakefile.
        The top-level Imakefile contains an incorrect target for linking
the VXIMTOOL dummy server, specifically the socket libraries needed by this
task (and any Solaris client) are not included.  To fix this, edit the 
Imakefile vximtool target to read:

vximtool: vximtool.o
        $(RM) vximtool
        $(CC) -o vximtool -DHAVE_CDL vximtool.o $(LDOPTIONS) libcdl.a \
            $(MATHLIB) $(EXTRA_LIBRARIES)

i.e. add the EXTRA_LIBRARIES macro to the link line.  This should
automatically be filled in to use &quot;-lnsl -lsocket&quot;, which are the required 
libraries.  Imakefiles used to build client libraries can similarly include
the $(EXTRA_LIBRARIES) macro to have these libs used when necessary.
	I regret any inconvenience this has caused, anyone still having
problems or questions should feel free to write back.

-Mike
</pre>
