    		     IRAF V2.12.2a Release Summary


	The IRAF V2.12.2a patch is primarily a bugfix release for GEMINI
package developers and is also being made available to resolve problems in
specific applications or with specific platforms.  See below for details on
who should upgrade.

	Existing SunIRAF or PC-IRAF V2.12.2 systems can be upgraded by
applying the patch file (&#x27;patch2a.tar.Z&#x27; in the distribution directory)
from the iraf root directory and reinstalling the IB and NB binary
distributions.  This will update the system sources, HSI binaries, and
core system and NOAO package binaries.  At this time, the default version
available from the iraf archive will remain V2.12.2 and so new
installations will also be required to apply the patch in order to upgrade
to V2.12.2a.  

	Upgrading an older V2.11 installation will require a full install
of IRAF, replacing any older versions. See the README file in each
directory or notes below for patch-update or installation details.

	External packages should continue to work with IRAF V2.12.2a,
however we strongly recommend that all packages be relinked to pick up
system bug fixes.  Precompiled versions of many IRAF external packages are
available from the IRAF archives.


WHO SHOULD UPGRADE?
-------------------

	The IRAF V2.12.2a patch fixes a number of system and platform bugs
found since the recent V2.12.2 release.   

We RECOMMEND this patch for

    o  GEMINI Package Developers
	   The V2.12.2a patch contains system changes needed for GEMINI
	   development.  

    o  Sites which use the FITS kernel heavily
	   A bug introduced in V2.12.2 can have the effect of corrupting
	   the comment field of some FITS header keywords.  While not 
	   usually fatal, this can affect pipeline and archive systems.

    o  Users of the LNUX PC-IRAF architecture
	   The V2.12.2 HSI binaries (mkpkg, xc, hardcopy translators, etc)
	   have a known problem affecting compilation of local tasks or
	   external packages and should be replaced.  This patch fixes the
	   problem, however to fix only the compilation issues a new set of
	   HSI binaries are also being made available the patch directory as
		
	     ftp://iraf.noao.edu/iraf/v212/PCIX/patch2a/hbin.lnux.x86.gz

	   To use this file, simply download in binary mode and unpack in
	   the $iraf/unix/bin.linux directory.  Contact site support with
	   questions.


We DO NOT RECOMMEND this patch for

    o  Sites which require a working GEMINI V1.6 Package
	    Changes in the handling of filenames by certain tasks are not
	    backwards compatible with the GEMINI.NIRI package and will lead
	    to files not being found during processing.  (An upcoming V1.7
	    release of GEMINI will require the IRAF V2.12.2a patch so users
	    should be preapred to upgrade later this summer).

	    Please contact IRAF site support or the Gemini HelpDesk with
	    questions.


Known bugs fixed by this patch can be found in the buglog available from

	ftp://iraf.noao.edu/iraf/v212/bugs.log


UPDATING AN EXISTING V2.12.2 SYSTEM
-----------------------------------

	The IRAF distribution files have been fully regenerated for IRAF
V2.12.2a, but are not the default distribution for each system (which remains
at the earlier V2.12.2 release).  One way to upgrade IRAF to V2.12.2a is to
do a full installation using the AS/IB/NB distribution files found in the
&#x27;patch2a&#x27; subdirectory of each system.  Since this will replace your existing
system, sites should diff/merge selected locally customized files from DEV
(hosts, tapecap, graphcap, imtoolrc, devices.hlp, etc.) and HLIB (extern.pkg,
mkiraf.csh, login.cl, zzsetenv.def) as is recommended in the installation
guide.

	If you have an existing IRAF V2.12.2 system you have the option of
installing the patch2a.tar.Z file and new binaries (the ones found in the
&#x27;patch2a&#x27; subdirectory) to update.  

THE V2.12.2a PATCH WILL OVERWRITE CERTAIN SITE-SPECIFIC FILES. These include:

    dev/hosts
    dev/imtoolrc
    dev/graphcap
    dev/termcap
    unix/hlib/login.cl.def
    unix/hlib/zzsetenv.def

You may want to save copies of these files and diff/merge them with the
new versions after installing the patch.

To install the patch, login as the iraf system manager, go to the $iraf
directory, and untar the patch as follows:

        % cd $iraf
        % zcat patch2a.tar.Z | tar -xpvf -		# Sun/IRAF
or      % tar zxpvf /&lt;path&gt;/patch2a.tar.gz		# PC-IRAF

Then diff/merge the files listed above. Next, go to the archives and
download and install the IB (IRAF core system) and NB (NOAO package)
binaries for the architectures your installation will support. For
example, to install IB.RHUX.X86 (the RedHat Linux binaries for the core
system, with the IB.RHUX.X86 distribution downloaded to the directory
&quot;/ib.rhux.x86&quot; (where is where you created this directory):

    % cd $iraf/bin.redhat
    % pwd
    /iraf/irafbin/bin.redhat       # (you should be here, or somewhere similar)
    % cat /&lt;path&gt;/ib.rhux.x86.gz | zcat | tar -xpvf -

    % cd $iraf/noao/bin.redhat
    % cat /&lt;path&gt;/nb.rhux.x86.gz | zcat | tar -xpvf -

A similar procedure is followed to install each of the other binaries.


UPDATING A V2.11 SYSTEM OR INSTALLING FOR THE FIRST TIME
--------------------------------------------------------

	The procedures for installing IRAF are unchanged from earlier
versions of IRAF. Refer to the IRAF Installation Guide in each of the
archive platform distribution directories for detailed installation
instructions.  A full installation of IRAF replacing all earlier versions,
as for any major release, will be required.  If you are installing IRAF
V2.12 for the first time you DO NOT need to apply the patch file if you
install from the &#x27;patch2a&#x27; subdirectory of the distribution.  You WILL
need to apply the patch, or remain at the V2.12.2 release, if you install
from the main distribution directory.

Currently supported platforms include:

o   The SUN/IRAF V2.12.2 release supports the following platforms:

    Sun/IRAF System               Distribution   Additional Supported Systems
    ---------------               ------------   ----------------------------
    SunOS 4.x                     SOS4
    Solaris 5.5.1 and higher      SSUN

    Distribution directory:  ftp://iraf.noao.edu/iraf/v212/SSOL/patch2a


o   The PC-IRAF V2.12.2 release supports the following platforms:

    PC-IRAF System                Distribution   Additional Supported Systems
    --------------                ------------   ----------------------------
    MacOSX 10.2 and higher        MACX
    RedHat Linux 6/7/8/9          RHUX           Mandrake 7 thru 10
    RedHat Fedora and Enterprise  RHUX
    Slackware V8.x                LNUX/x86       Debian 2.x, all others

    Distribution directory:  ftp://iraf.noao.edu/iraf/v212/PCIX/patch2a
