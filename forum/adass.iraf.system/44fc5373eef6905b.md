        This is a known problem discovered after the last release of
course.  The problem is caused by the -Xs flag used to avoid other
problems when compiling the Gterm code, but is incompatible with the yacc
output in laygram.c.  The solution is to edit the obm/ObmW/Imakefile with
the following:

# Hack to compile under SunPRO V4 on Solaris
#if defined (SunArchitecture) &amp;&amp; HasSunC &amp;&amp; OSMajorVersion &gt;= 5
laygram.o:
        $(CC) $(EXTRA_INCLUDES) -c laygram.c
#endif

This will cause the laygram.c to compile with a simpler command and should
avoid the errors.
