## PC-IRAF V2.11 Installation on Red Hat 4.x Systems

**Mike Fitzpatrick** wrote on Feb 18, 1998

<pre style="background: transparent; box-shadow: none; border: none;">

        The RHUX architecture for Red Hat 5.0 systems makes use of the new
glibc libraries and the PC-IRAF binaries for this architecture will not
run on older distributions of the Red Hat Linux system (resulting in an
error &quot;Command not found&quot;).  However, the IRAF system will still attempt
to use the &#x27;redhat&#x27; architecture since the check made when configuring the
environment isn&#x27;t yet sensitive to the Red Hat version number (this will
be fixed in a later patch and was missed in initial testing). 
        In order for the binaries to be found correctly, and to minimize
problems later when a patch will correctly determine the appropriate
architecture, users on Red Hat 4.2 and earlier systems should proceed with
a normal &#x27;linux&#x27; binary installation.  Once the system is installed the
&#x27;bin.redhat&#x27; links in the $iraf and $iraf/noao directory will need to be
changed to point to the corresponding &#x27;bin.linux&#x27; link.  For example,
while logged in as the iraf user:

    % cd $iraf                                  # go to the iraf root
    % rm -f bin.redhat noao/bin.redhat          # delete links
    % ln -s bin.linux bin.redhat                # reset $iraf link
    % cd $iraf/noao                             # go to the iraf root
    % ln -s bin.linux bin.redhat                # reset $iraf/noao link

Lastly, the HSI binaries must still be found in order to compile external
packages or get hardcopy output.  To do this rename the bin.redhat directory
and create a similar link, e.g.

    % cd $iraf/unix                             # go to HSI directory
    % mv bin.redhat bin.redhat50                # save directory for later
    % ln -s bin.linux bin.redhat                # make link

        Note that when the system is later upgraded to Red Hat 5.x these
bin links will need to be changed and the RHUX binaries installed.  At that
time it may be simplest to just reinstall IRAF from scratch using the normal
RHUX installation procedure.  Any IRAF upgrades which may later be applied
must still use the LNUX architecture binaries.
        Anyone with problems or questions should feel free to contact site
support (iraf@noao.edu).


Mike Fitzpatrick
</pre>
