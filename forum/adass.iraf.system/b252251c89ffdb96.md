# KDE and Xgterm Window Resizing

**Mike Fitzpatrick** wrote on Apr 19, 2000

<pre style="background: transparent; box-shadow: none; border: none;">
&gt; We are having some problems with xgterm here.  We are running under
&gt; RedHat Linux v6.1 with the KDE window manager.  Here are the problems:
&gt; 
&gt; 1) When we resize the window, the plot is not resized unless it gets
&gt; redrawn by executing whatever command generated the plot again.  Should
&gt; the plot in the window be resized automatically as the window itself is
&gt; resized?
&gt; 
&gt; 2) On some machines, any attempt to resize the xgterm window (and only
&gt; the xgterm window) causes the window to shrink to a tiny size, from
&gt; which it can never be resized larger using the mouse.  It&#x27;s almost as
&gt; if the window is fighting the user to stay small.  Any ideas on what
&gt; would cause this?

        I stumbled across the same thing a few days ago and as near as I
can tell it&#x27;s either a bug in the KWM window manager or the Qt toolkit
used.  The workaround is to bring up the KDE Control Panel and get into
the Windows.Properties form.  In the top &quot;Windows&quot; panel disable the option
which says &quot;Display content in resizing windows&quot; and hit apply.  The 
gterm window should then resize correctly.  Your first problem with the
plot not redrawing I&#x27;ve only ever seen once but not since I found this
workaround. 

-Mike
</pre>
