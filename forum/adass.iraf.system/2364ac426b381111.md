Annie,

For your first question, try using &#x27;psidump&#x27; for color plots.  The resulting
postscript file will be in /tmp.

For your second question, it looks like the program &#x27;sgidispatch&#x27; was not
properly installed, or you can&#x27;t find it.  Are you sure you ran the install 
script?  From your host prompt, try doing a &#x27;which sgidispatch&#x27;.  If you get 
&#x27;sgidispatch: Command not found&#x27;, then there are two things to look for.  The 
program should have been installed as a symbolic link in /usr/local/bin.  Make 
sure that it is there.  If it is, then make sure that /usr/local/bin is in your 
personal search path.

Let us know if you still encounter any problems.

Cheers,

Matt Cheselka
</pre>
