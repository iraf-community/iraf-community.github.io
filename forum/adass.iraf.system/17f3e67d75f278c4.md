      The problem is caused by the fact that on line 64 of
ared$quad/qpcalimage.x the boolean &#x27;found&#x27; variable is set to the integer
value NO instead of the boolean FALSE.  You can either change the code and
recompile or there are prebuilt slackware and redhat binaries in
ftp://iraf.noao.edu/contrib, just unpack in the appropriate image
directory.
