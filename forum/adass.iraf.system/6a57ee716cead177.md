## IRAF for Alpha Linux

**Doug Tody** wrote on Jan 13, 1998

<pre style="background: transparent; box-shadow: none; border: none;">

Hi Peter,

&gt; I wonder if there will be an implementation of IRAF for Alpha Linux?
&gt; If yes, when willl it be available.

We don&#x27;t have any immediate plans to support Linux except on PCs and Macs,
as the vendor Unixes for workstation platforms are better supported and
more heavily tested than Linux (on those platforms, not PCs) and are
generally of high quality.  Digital Unix in particular is quite a good
Unix system.  Although we may not support Linux on all possible platforms,
we do plan to support the GNU compilers on *some* workstations since e.g.
the F2C/GCC combination is top quality, and compilers can be a major
expense so using GNU here can save some money.  Currently though, among
the workstation systems we have immediate plans to support the GNU compilers
only on Solaris, mainly so we can use them for s/w development.

Providing all these variations as turnkey supported options takes resources,
we have to look at the expected usage in deciding to support an option.
We are constantly reviewing platform support so the decision to support a
particular option may differ in the future.

Just curious - why do you want to use Linux on the Alpha rather than DU4?

	- Doug
</pre>

support.  It probably wouldn&#x27;t be too hard to port IRAF to it since it

support, but there are always a few nontrivial system things (e.g. floating
point exception handling) that require some customization.      - Doug
