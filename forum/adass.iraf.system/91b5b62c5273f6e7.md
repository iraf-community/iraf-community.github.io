# XImtool Menu Buttons don't work

**Mike Fitzpatrick** wrote on Jan 20, 1999

<pre style="background: transparent; box-shadow: none; border: none;">
&gt; I have a user who can&#x27;t get the buttons on &quot;ximtool&quot; to work. No problem 
&gt; if we log in remotely and display remotely on a Linux/XFree86/olvwm setup,
&gt; but his console doesn&#x27;t run ximtool right.  The menus do drop, but none of
&gt; the options can be clicked on.

	This problem has been reported more frequently but the mystery
wasn&#x27;t solved until I saw at a console myself.  Apparently the solution
is to be sure that the Num-Lock key isn&#x27;t set at the keyboard.  This has
the effect of turning off the &#x27;focus&#x27; attribute of an EnterNotify event and
so the menu widget never gets focus and thus cannot be selected.   In the
systems tested turning off the Num-Lock fixed the problem, please contact
site support if this doesn&#x27;t seem to work for you.

Mike Fitzpatrick
</pre>
