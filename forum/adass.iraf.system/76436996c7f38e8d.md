# X11IRAF on Red Hat 5.0 systems

**Mike Fitzpatrick** wrote on Feb 06, 1998

<pre style="background: transparent; box-shadow: none; border: none;">

&gt; I am running RedHat 5.0 on an Intel 586.
&gt; I have downloaded and unpacked the redhat binaries for iraf and
&gt; the general sources.  iraf/cl seem to work ok.
&gt; 
&gt; But I can&#x27;t get either xgterm or ximtool to work, both crash with a
&gt; &quot;Segmentation fault&quot; error.  I&#x27;ve checked that both binaries are, indeed
&gt; ELF binaries (I didn&#x27;t download the wrong tar file).

        Red Hat 5.0 uses a new version of the C library so you&#x27;ll need a
new version of X11IRAF that uses this.  You can get this from /iraf/x11iraf
as x11iraf-v1.1-linux-glibc-bin.tar.gz.  Try these binaries instead and
let me know if you still have problems.

Cheers,
-Mike
