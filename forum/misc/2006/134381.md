<div>
The FOCAS package in NOAO is simply a stub for long-ago plans to incorporate FOCAS into the system.  FOCAS is however available in two flavors from the <a href="ftp://iraf.noao.edu/iraf/extern">ftp://iraf.noao.edu/iraf/extern</a> archive directory:  as the traditional 'focas' collection of tasks, and as the 'ifocas' iraf-icized version of those same tasks.  See the associated readme files for details and installation instructions, and I'm sure Frank will comment at some point as well.<br>
<br>
Note that the successor to FOCAS is ACE (Astronomical Catalog Environment), parts of which are already installed in the NPROTO package (i.e. detect/objmasks).<br>
<br>
-Mike
