# how to handle CALSPEC fits files

**galtavi** wrote on Aug 29, 2006

{% raw %}
<div>
Dear IRAF expert, I have a problem handling the CALSPEC spectra<br>
(<a href="http://www.stsci.edu/hst/observatory/cdbs/calspec.html)">http://www.stsci.edu/hst/observatory/cdbs/calspec.html)</a> with IRAF.<br>
"Files are in machine independent binary FITS table format".<br>
It's the first time I use them.<br>
SPLOT does not plot them (ERROR: MWCS: dimension mismatch (mw_open))<br>
In order to plot them with SPLOT I make the following: I convert the original fits file into an ASCII table with TDUMP<br>
(tdump file.fits columns="WAVELENGTH, FLUX" datafile="table.dat") <br>
then I go back to fits with RSPECTEXT, with <br>
(dtype  =            nonlinear) Dispersion type<br>
This option generates a huge header (I had to modify the login.cl with this line:<br>
set    min_lenuserarea    = 1000000) in order to avoid the error:"Warning: Out of space in image header".<br>
The problem is that if I want to use SARITH or other tasks with this spectra I get the error : "Warning: MWCS: out of storage for FITS-WCS cards".<br>
I think the problem is the huge header, I was thinking to resample the spectra (the ASCII table) with a costant step before converting them to fits with rspectext<br>
in order to have a "normal header".<br>
Maybe there is a simple way to handle these spectra. Do you have any suggestion?<br>
I also had to increase cmbuflen in the login.cl to print a postscript image.<br>
Thanks!<br>
Giuseppe
