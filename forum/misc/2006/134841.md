<br>
I'll need further information to understand the context of this question well enough to answer it.  STB is a unix daemon (not strictly IRAF, per se) which is executed by a BSD-style line printer queue to write data to tapes or CDs.  This is legacy software that has been retired from operation at KPNO, CTIO and WIYN in favor of a much modified "iSTB" daemon that is responsible for constructing an online, spinning disk, directory structure on terabyte scale data stores as a first step toward incorporation of data products in a scientific archive.  Organizations outside of NOAO have used STB at various points, but we don't support this software for individual use.<br>
