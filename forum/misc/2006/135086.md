**Mike Fitzpatrick** wrote on May 26, 2006

<div>
<blockquote>or a synthetic photometry project I need to read/write STSDAS tables; do you know if there is a C library to read/write STSDAS tables? </blockquote><br>
<br>
The CVOS interface in STSDAS has a tables binding, see stsdas$lib/cvos and the doc subdirectory there.<br>
<br>
<blockquote>By the way: is Starbase format compatible with STSDAS?</blockquote><br>
<br>
Not as far as I know.  Starbase is an ascii table format.<br>
<br>
<blockquote>And where exactly can I find the description for STSDAS tables format , in STSDAS docs? </blockquote><br>
<br>
See tables$doc/fileformat.doc<br>
<br>
Cheers,<br>
-Mike
</div>
