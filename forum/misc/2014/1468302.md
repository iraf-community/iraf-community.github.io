<br>

<br>
output = @image_out<br>
<br>
verbose = yes<br>

<br>
The "image_out" file is a text file containing one line: ouFile.fits<br>
<br>
The message I get is: ERROR: cannot open image (image.fits[111:222,333:444])<br>

What makes it more strange is that if I have "image.fits[111:222,333:444]" as input and "ouFile.fits" as output, i.e. if I don't go through the text files it runs fine. I know I can just skip this step, but the whole thing is part of a script and it is not that easy...<br>
