Hi Pat,<br>
<br>
Sorry your original message wasn't replied to directly.  We don't have a web page with all available tasks, but you can do the search you want using the REFERENCES task, e.g.<br>
<br>
<pre><code>cl&gt; refer gain</code></pre><br>
<br>
would find all tasks with 'gain' in the one-line description of the task.  If you really want a list of all available tasks, use<br>
<br>
<pre><code>cl&gt; references updquick+       # create a  quick-reference file
cl&gt; references usequick+              # tell the task to use if from now on
cl&gt; page uparm$quick.ref            # browse the file
</code></pre><br>
<br>
This lists only what you have installed on your machine.  For that's some 2700 help pages so browsing by hand has limited use 8-)<br>
<br>
Cheers,<br>
-Mike
</div>

<div>
Hi Hanin<br>
<br>
For my experiemnts I used sky-flats, but it is reccomended that u use the flats that u use during observations, i.e. sky or dome flats to get a tru representation of the system performance.<br>
<br>
It is best to use flat frames with an close enough mean data count (for 16 bit between 45000 and 55000, depending on saturation level and exposure times), just so long as the data count is high.<br>
<br>
readnoise is usually in the region of 10 electrons/pixel, depending on the ccd<br>
the gain is usually in the region of 1-3 electrons/ADU, depending on the ccd.<br>
<br>
u might want to determine the dynamic range of the ccd, to get a tru reflection of the system capabilities.<br>
<br>
Hope this helps :D <br>
<br>
Pat
