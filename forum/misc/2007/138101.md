<div>
Real data can be found various places on the net, mostly in archives.  For simply beginning to play with data you can make your own using the ARTDATA package, see esp the MKEXAMPLES task.  If you want FITS files the be sure to do a "cl&gt; reset imtype = fits" before running tasks.<br>
<br>
Otherwise, you can see the Exercises developed long ago for v2.11 from<br>
<br>
<a href="ftp://iraf.noao.edu/iraf/misc/exer211.readme">ftp://iraf.noao.edu/iraf/misc/exer211.readme</a><br>
<a href="ftp://iraf.noao.edu/iraf/misc/exer211.tar.Z">ftp://iraf.noao.edu/iraf/misc/exer211.tar.Z</a><br>
<br>
These haven't been updated in a while, but do contain sample data.<br>
<br>
Cheers,<br>
-Mike
</div>
