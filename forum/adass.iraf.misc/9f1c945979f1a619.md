**Mike Fitzpatrick** wrote on Jun 26, 1998

<pre style="background: transparent; box-shadow: none; border: none;">

&gt; I&#x27;ve tried :.snap eps on some IGI-generated plots, and the postscript
&gt; looks good except for the loss of colour information. Is there a way to
&gt; dump to a postscript file and retain colour?

	The only way to do this is using the PSIKERN Postscript graphics
kernel in STSDAS.  V2.11 comes with psikern entries in the default
graphcap file including a &#x27;psidump&#x27; device to write the output to
&#x27;psidmpXXX.ps&#x27; in the /tmp directory, but to make use of this you&#x27;ll need
to have STSDAS installed on your system.  The resulting EPS file retains
the axis/label/frame colors, but assumes you have a white paper page and
so the plot itself is drawn as a black line on a white background which 
might not always be what you want.
	You can change this by changing the :LG field of the &#x27;psi_def&#x27;
graphcap entry to point to stsdas$lib/tvmark_cmap instead of the invxgterm
file as it does now, this file defines the same LUT used by TVMARK.  If
you want to play with the colors yourself see the psikern system help by
using
	cl&gt; help stplot.psikern opt=sys

and see Examples 10-12 and the info on colors.  
	Note that the choice of colors in the plots is controlled by the
CL &#x27;glbcolor&#x27; environment variable which defaults to a value of
&quot;pt=3,fr=9,al=3,tl=6,ax=5,tk=5&quot; where

        pt - plot title 		fr - viewport frame
        al - axis labels 		tl - tick label
        ax - axis 			tk - tick marks
        gr - grid between tick marks

The color index values refer to the XGterm color[0-9] resource values
which default to

        	0 - black 	5 - cyan
        	1 - white 	6 - yellow
        	2 - red 	7 - purple
        	3 - green 	8 - magenta
        	4 - blue 	9 - darkslategray

This combination of glbcolor and the color[0-9] resources control the
colors you see on the screen, but keep in mind what comes out of the
PSIKERN is the color index specified in the :LG LUT file.
	The reason you don&#x27;t get color from most hardcopy devices is that
the graphics are processed by the SGI (Simple Graphics Interface) kernel
which turns all the graphics commands into simple move/draw instructions
and drops the color attributes, PSIKERN keeps the color information and
generates the postscript directly rather than relying on an SGI translator
the way the psdump/eps devices do.

-Mike
</pre>
