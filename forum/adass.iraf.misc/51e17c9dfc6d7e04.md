**Mike Fitzpatrick** wrote on Aug 05, 1998

<pre style="background: transparent; box-shadow: none; border: none;">
&gt; I suspect this is a trivial question, but searching through the IRAF
&gt; docs I&#x27;ve been unable to find out how to determine (within a CL script or
&gt; SPP program)  the current plot limits (in world coordinates) of a
&gt; displayed plot.

	The answer may best depend on what&#x27;s drawing the plot in the first
places, e.g. if you use GRAPH or IGI to draw the plot your script can
already know the limits since these are set as task parameters or part of
the igi file.  Otherwise, the only way to get the limits from a CL script
is to dump (or redirect) the graphics metacode to a file and then parse
the output of GKIDECODE with the verbose option turned on.  What you&#x27;re
looking for is a line something like

set_wcs nwords=352
	 1 1. 256. 45. 1941.  0.11 0.89 0.15 0.88  0 0 7
	   ^^^^^^^^^^^^^^^^^
The indicated items  the plot (x1,x2,y1,y2).  From an SPP program you
would have to open a graphics pointer in APPEND mode and then make a call
to ggwind(), e.g.

        gp = gopen (&quot;stdgraph&quot;, APPEND, STDGRAPH)
        call ggwind (gp, x1, x2, y1, y2)

The simplest may be to use such an SPP program to get the WCS and print it
out so the script can scan them into local variables, I assume there are
other reasons for not having IGI draw the whole plot itself.
	Hope this helps.

Cheers,
-Mike
