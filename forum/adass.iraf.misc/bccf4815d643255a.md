## Talking to XGterm from another application ??

**Mike Fitzpatrick** wrote on Apr 16, 1998

<pre style="background: transparent; box-shadow: none; border: none;">

&gt; Some Iraf tasks like splot display a spectrum in a Tek window and a user
&gt; can &quot;expand&quot; the plot effectively specifying the wavelength range.
&gt; My question is wthether there is a way to get this wavelength range 
&gt; somehow from another application (my solar atlas).

	Sorry, can&#x27;t be done.  XGterm is not a server in the sense that
XImtool is, the &quot;protocol&quot; used to draw the graphics is simply a set of
escape sequences created by the iraf STDGRAPH kernel and interpreted as
drawing instructions by the Gterm widget.  What you want is a graphics
server accepting commands such as &quot;set axis labels&quot;, &quot;draw vector&quot;, etc
that you could query from a 3rd party source in the same way multiple
clients can connect to XImtool and readback the frame buffer.  I suppose
this is possible but it&#x27;s not a quick hack.  Even writing an OBM
application to query the Gterm widget won&#x27;t provide enough information to
get the axis boundaries.
	You&#x27;re best bet if it&#x27;s just one task would be to take the source
for SPLOT and make a modified version which would update your other
application whenever the axes are redrawn.  

Cheers,
-Mike
</pre>
