Sergei, this sounds like the usual pseudocolor rendering problem encountered
when displaying grayscale data (i.e. a linear range of values) as some
range of RGB color values.  In principle in a case such as you describe
one could try to map a visible wavelength to a color using a physical
color spectrum mapping, but in practice this rarely works well on a
workstation screen for various reasons, and a pseudocolor (nonphysical)
mapping is used instead.  You might want to have a look at some pseudocolor
color tables to see if any will render the data the way you want.  For
example, see the collection of colortables in ximtool/luts in the x11iraf
distribution (this is often installed with ximtool as well).  A separate
copy of this is available as

    ftp://iraf.noao.edu/iraf/x11iraf/imtoolcmap.tar

These are normalized colormaps, you just scale them linearly to fit your
data range.
