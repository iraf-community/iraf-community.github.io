<div>
<br>
                You can rule out permission/file access problems with the file by trying open it with some other task, e.g.<br>
<br>
    cl&gt; type stdimgset<br>
<br>
If that works, or not, you can check for other obscure weirdities like the file doesn't have a proper EOF or a newline on the last line (can sometimes happen with emacs or some OSX editors), or if the path to the file contains a space (e.g. your name is in the directory path and includes a space).  There are know 64-bit issues you can resolve by seeing http://iraf.net/forum/viewtopic.php?showtopic=1469590 but I doubt that is the problem here. <br>
<br>
Otherwise, the task hasn't changed since 2001.<br>
<br>
