**Mike Fitzpatrick** wrote on Apr 18, 2014

{% raw %}
<div>
<br>
                The X11IRAF binaries are (and will remain) 32-bit, but recent versions of Ubuntu (and others) either don't provide the compatibility libs by default or else make it difficult to find.  Depending on the version of Ubuntu you have you can try doing<br>
<br>
    % sudo apt-get install ia32-libs<br>
<br>
to install the compatibility libs, but this is probably a longshot.  Alternatively, you can get statically linked binaries from<br>
<br>
    ftp://iraf.noao.edu/pub/fitz/xgterm.STATIC<br>
<br>
    ftp://iraf.noao.edu/pub/fitz/ximtool.STATIC<br>
<br>
Download in binary mode, make sure they're executable, and then manually copy to e.g. /usr/local/bin/xgterm.<br>
</div>
{% endraw %}

**Mike Fitzpatrick** wrote on Apr 20, 2014

{% raw %}
<div>
<br>
                Make them executable and move to /usr/local/bin with the commands<br>
<br>
    % chmod 755 /path/xgterm.STATIC<br>
<br>
    % sudo mv /path//xgterm.STATIC /usr/local/bin/xgterm<br>
<br>
and likewise for ximtool.<br>
</div>
{% endraw %}
