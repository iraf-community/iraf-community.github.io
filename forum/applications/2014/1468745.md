<br>
                If doing a new MKIRAF in say /tmp and logging in through there fixes the problem (i.e. w/ a brand new uparm directory), then something may have reset which uparm directory you are using (e.g. did you login through another user's account and so an 'unlearn' doesn't have write permission to delete the file).  Do a "show uparm" to see which directory is being used, or try "delete uparm$*" to delete everything.  Does logging out and back in help?  If you set a parameter, does an "lpar reidentify" show that setting was changed?<br>
