<div>
<br>
                This may be a known issue with the new image template code.  To workaround it try doing<br>
<br>
    cl\$this-&gt;_split2($m[0]) reset use_new_imt = no<br>
<br>
before running the task.  You can set this in your login.cl or make a permanent system change in the hlib$zzsetenv.def file if it works.<br>
