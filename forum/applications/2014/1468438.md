                Hi! Obviously I was too tired yesterday, since then answer to my question was in front of my eyes but couldn't see it. You can simply add the filter transmission file in the bandpass file!<br>
<br>
To sum up: <br>
<br>
1. <em>rspectext</em> to transform a standard .dat file to .fits image.<br>
<br>
2. <em>sbands</em> using the produced image (of 1-D spectrum) of standard and a bandpass file, which contains the bandpasses (names, central wavelengths, widths, filter transmission files).<br>
<br>
