<br>
1)compute sum residual[size=9:3f35e9626a]i[/size:3f35e9626a]*residual[size=9:3f35e9626a]i[/size:3f35e9626a], <br>
where i is from 1 to point counts, residual is (input value - function fitted value)  <br>
2) divide this sum to (counts-1)<br>
3) compute sqrt<br>
<br>
expression like this:<br>
sqrt [ sum[size=9:3f35e9626a]i=1,ncount[/size:3f35e9626a](residual[size=9:3f35e9626a]i[/size:3f35e9626a]*residual[size=9:3f35e9626a]i[/size:3f35e9626a]) / (count-1) ] <br>

        # calculate the rms of the fit<br>

                GM_XRMS(fit) = GM_XRMS(fit) + wts<em> * xresid<em> ** 2<br>

            GM_YRMS(fit) = 0.0d0<br>
