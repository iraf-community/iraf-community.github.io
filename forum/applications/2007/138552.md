**Mike Fitzpatrick** wrote on Nov 13, 2007

<div>
There's actually a speed advantage to using imh, but for this question the point is that .imh images use the imdir to store the pixel file, and if that isn't valid you can't create temp or output images properly.  A MKIRAF will create a new uparm directory and so you'll use the default parameters the first time you run a task, this is normal.<br>
<br>
One thing to try is to run your command directly in the CL and see if you get the expected results (with your parameter settings).  This will separate whether its an Astro::CL thing or something in how you're calling the task.<br>
<br>
-Mike
</div>
