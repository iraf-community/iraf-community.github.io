<div>
As far as I know, Pyraf doesn't use the standard IRAF graphics kernel.  In the CL/ECL this is builtin and when running from an XGterm window is able to make use of the OBM to run a GUI.  Starting the GUI by hand won't do any good since it isn't connected to the client IRAF application, however you should still be able to run SPECTOOL without the GUI as a normal graphcis app (although I won't say it definitely would work under pyraf in that way).  Unless the pyraf folks can offer some advice, you may need to run the GUI apps under the CL only.<br>

-Mike
