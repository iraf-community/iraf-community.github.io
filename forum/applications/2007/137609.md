**Mike Fitzpatrick** wrote on Jun 19, 2007

<div>
Please post your IRAF version and the type of platform you're on, as well as whether this happens with any other tasks.  There is no known issue with DAOFIND, however there was e.g. a known FPE problem on the earlier macintel ports affecting all tasks.<br>
<br>
You can rule out parameter problems by unlearning the task parameters or doing a MKIRAF and logging in through some scratch directory to use the default params (e.g. run one of the help page examples).  If it happens only with this image and not another that would also be good to know.<br>
<br>
-Mike
