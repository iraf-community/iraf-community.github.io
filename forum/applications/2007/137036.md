<div>
It may be that the original FITS file was corrupted, decompressing the file wouldn't normally corrupt the file.  The header should be a series of 80-char 'cards' padded with blanks, it looks as though your header might be padded with NULL or else terminated early.<br>
<br>
There's no task to fix this specifically, however see the HFIX task for a way to execute an arbitrary command on the header file.  Assuming you can write and awk/sed/perl/whatever script that puts each keyword on a line you can use this task to apply it to the header.  If you have only one image to edit, the default HFIX command will simply put you into the editor and you can change it manually, otherwise check for problems in the original FITS writing software.<br>
<br>
-Mike
