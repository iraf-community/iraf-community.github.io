<br>
The 'invalid filter specification' refers to the parameters of the filter itself, e.g. the cuton and cutoff frequency values. not specifically whether filtering is enabled.  You can get this message if say the cutoff is less than the cuton, all values are zero, fullon less than cutoff, etc.  Check the values in your FILTPARS pset, my guess is they're all zero.<br>
<br>
<blockquote>Furthermore, when in interactive mode i want to go from<br>
xcor mode to fourier mode, or from spectral mode to fourier mode,<br>
by pressing 'f' i get the following error :<br>
ERROR: afftrr: npix not a power of 2<br>
Note that this latter problem only occurs for spectra that have more than 2**15 wavelength bins (merged echelle orders).</blockquote><br>
<br>
The system routine used for the FFT calculation had this 2^15 limit increased earlier this year.  You can get a patched binary from <a href="http://iraf.net/ftp/pub/x_rv.e.RHUX">http://iraf.net/ftp/pub/x_rv.e.RHUX</a>  Download in binary mode, rename 'x_rv.e' and put in your $iraf/noao/bin.linux directory (for Ubuntu).<br>
<br>
Cheers,<br>
-Mike
