**Ivan Ramirez** wrote on Nov 04, 2007

{% raw %}
<div>
I always use "doecslit" to do the final extraction of the spectra. Setting "clean=yes" and "sparams.weights=variance" there removes most of the cosmic rays. I should say I've tested this with bright stars only (S/N&gt;~50) so I'm not sure if this will always work that well.
</div>
{% endraw %}
