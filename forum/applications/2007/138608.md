{% raw %}
<div>
Hi folks,<br>
<br>
I have used crosscor (stsdas.analysis.fourier) for ages in my high speed photometry package to track moving fields of stars.  I only use it when using the previous position or immatch (from ctio) fail.  Crosscor is a lot slower, but it never fails, well, hadn't failed yet.<br>
<br>
I have data from one particular observatory where the crosscorrelation looks really funny.  Whatever I try, no matter how shifted two images are, the cross correlation always comes back with a cross centered at the crosscorrelation image center.  Even copying an image shifting it and then doing cross correlation returns the same zero shift result.<br>
<br>
I have tapered the image (as I always do), I have removed cosmic rays from the images themselves as well as from the crosscorrelation image.  ALways the same result. I have also looked for bad pixels, bad columns, tried different image sections...<br>
<br>
If anyone has some time to take a look at this I would appreciate a suggestion.<br>
