<div>
The 'smw' library comes from ONEDSPEC and should be in the noao$lib directory as a symlink to "../bin/libsmw.a".  Be sure you have IRAFARCH set in your environment (to 'macosx') for cpmpilation, and try adding a "-p noao" to the mkpkg command for guiapps to pick up the NOAO package environment.  I haven't looked at the GUIAPPS stuff in a while but can supply new ppc binaries if there's a problem.<br>
<br>
Cheers,<br>
-Mike

<div>
Ahh, then you also forgot the "-p guiapps" flag.  In general, external package must always be compiled with at least "mkpkg -p &lt;pkgname&gt;".  Some packages will automatically load other environments by adding more -p flags, a good catch-all command is "mkpkg -p &lt;pkg&gt; -p noao -p tables".<br>
<br>
-Mike
