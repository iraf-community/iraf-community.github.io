<div>
The aidpars.rms parameter is described as a "goal" value, not a cutoff filter.  Looking at the code, the computed rms is simply reported in the log file and isn't checked directly for a value.  If you want only those values less than some limit you'd need to extract those lines from the log file afterwards.  Frank may have additional comments.<br>
