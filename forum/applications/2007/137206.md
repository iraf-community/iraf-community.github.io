<div>
This usually means there is a problem in the value of your 'imdir' CL environment variable that says where to put the .pix file for each image.  This is set initially when you run the install script and can be changed by editing the value in your login.cl file.  Be sure that if you edit the file the directory name ends with a trailing '/'.<br>
<br>
Note also that if you're inded running v2.12 then you may be using the original port done by Chris Burke at Ohio.  The v2.13 release from this site is more current and fixes a number of other problems.<br>
<br>
Cheers,<br>
-Mike
