# standard task: ERROR: Cannot convert between selected units

**Nicola Caon** wrote on Oct 05, 2007

{% raw %}
<div>
Hi,<br>
we are trying to create the sensitivity function using the Iraf task "standard" in noao.imred.specred.<br>
<br>
However, we get the error:<br>
ERROR: Cannot convert between selected units<br>
<br>
The spectrum seems to be correctly calibrated in wavelength (nanometers units) as seen with splot.<br>
<br>
There is probably something wrong in the fits spectrum header, or in the standard star data table, however we seem to be unable to find it.<br>
<br>
The command we are executing is:<br>
<pre><code>standard starrbnspec_azul.tot starrbnspec_azul.txt star_name=&quot;cd32d9927&quot; caldir = &quot;./&quot; extinct=&quot;./paranalextinc_n.dat&quot; airmass=1.012 exptime=120.0</code></pre><br>
<br>
We are running Iraf 2.12.2a in a RHEL4 box.<br>
<br>
We have put a tar archive with the relevant files in  <a href="ftp://ftp.iac.es/out/ncaon/standard.tar.gz">ftp://ftp.iac.es/out/ncaon/standard.tar.gz</a><br>
<br>
Thanks very much for your help<br>
Nicola
</div>
{% endraw %}

**Nicola Caon** wrote on Oct 05, 2007

{% raw %}
<div>
The problem was due to the DC-FLAG  keyword missing from the spectrum fits header. We add it manually with value 0 and the task "standard" now works fine.<br>
<br>
These files were produced by the FLAMES ESO pipeline, which apparently does not add the DC-FLAG keyword when doing the wavelength calibration.<br>
<br>
Cheers<br>
Nicola
</div>
