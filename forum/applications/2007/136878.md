Serena,<br>
<br>
The data can be processed by first loading the ``ared'' package in IRAF<br>
and then loading the ``quad'' package.  The data can then be reduced<br>
(i.e., overscan corrected, trimmed, etc) using the task ``quadproc''.  <br>
Quadproc essentially works like ccdproc, but is setup to handle data<br>
that has multi-amp readout.<br>
<br>
After the data are bias-subtracted and trimmed, you can use the standard<br>
IRAF tasks.<br>
