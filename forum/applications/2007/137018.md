# Error in header of echelle/dispcor spectra

**Michael Weber** wrote on Mar 15, 2007

{% raw %}
<div>
I noticed, that whenever I have two calibration frames, the wavelength calibration string in the header gets mixed up a bit: There is no space between the function describing the frist calibration frame and the second one.<br>
<br>
Example<br>
spec1 = "1 51 2 11090.442173559 0.069907943784566 2043 0. 390.55 394.55 0.47011236 0. 1 4 1. 2043. 11162.8227882108 71.3776046374417 -1.00430427491927 -0.01016064638997420.52988764 0. 1 4 1. 2043. 11162.8234571018 71.3867230476937 -1.00553889426357 -0.00311220853411926"<br>
<br>
note the -0.01016064638997420.52988764 beeing the last coefficient of the first function concenated to the weight of the second function. This happens for each order.<br>
<br>
IRAF somehow doesn't mind when reading this, and I managed to also read in the right stuff with python, but it should nevertheless get fixed (maybe it is already in the next release?)<br>
<br>
This is IRAF 2.12.2, functions are Cheb. Polyn.<br>
<br>
Michael
