I suggest you consider the task SBANDS.  This is not interactive like SPLOT but I think is more like what you want to do.<br>
<br>
In SPLOT you could use the 'e' key.  This simply adds up the flux.  You would ignore the equivalent width it computes and only used the "flux" value.<br>
