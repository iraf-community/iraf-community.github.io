Hi,<br>
<br>
To use a mask you need to set regions to "mask" and set the mask parameter to the mask you want or a keyword pointer with the !keyword syntax.  Good pixels have a value of 0.  If this is what you are doing then you are deciding it is not using the mask because the result is the same?  It may be that the bad pixels do not significantly alter the surface fit?  If you want to discuss this further please include a parameter listing.<br>
<br>
As for combining masks that has to be done externally.  The most direct tool to use is imexpr with something like:<br>
<br>
<pre><code>
cl&gt; imexpr &quot;(a==0&amp;&amp;b==0)?0 : 1&quot; out.pl bpm objmask
</code></pre><br>
<br>
Yours,<br>
Frank Valdes
