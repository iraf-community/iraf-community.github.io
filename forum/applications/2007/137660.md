**Mike Fitzpatrick** wrote on Jul 02, 2007

{% raw %}
<div>
If you're using a SciSoft release then check the date of the binaries to be sure you aren't seeing a known problem (that usually showed up as a different error message though).  I.e.:<br>
<br>
<pre><code>cl&gt; dir bin$x_tv.e long+</code></pre><br>
<br>
If the file date is earlier than Nov06 you should reinstall the binaries from the downloads page.<br>
<br>
Otherwise, what version of DS9 is this?  Is the segfault from the DISPLAY task or DS9?  I can't reproduce the error here, does the following work for you:<br>
<br>
<pre><code>cl&gt; display dev$pix[1:32,1:32] 1</code></pre><br>
<br>
Does IMSTAT etc work on these small sections or fail similarly?<br>
<br>
-Mike
</div>
{% endraw %}
