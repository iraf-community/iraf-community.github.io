**Francisco Valdes** wrote on Oct 19, 2007

{% raw %}
<div>
The error is based on a model of the noise in a digital image.  The model is that uncertainty comes from the Poisson statistics of the detected electrons/photons and a constant noise at the sky level.<br>
<br>
The term flux/epadu is the conversion of the background subtracted signal to something representing individual photons.  The Poisson variance is just then number.  Note that epadu is intended to represent the conversion for the image pixel digital units to photons.  For a CCD, assuming processing has not affect the levels significantly, epadu is like the detector gain.  But it is basically a model parameter which you have to set appropriately for the data given your knowledge of the digital data units.<br>
<br>
The next term is the contribution of the error due to the background in the aperture.  And the last term is the uncertainty in the estimate of the sky subtracted to compute the flux.<br>
<br>
So the error is an formal estimate based on a Poisson detection model.<br>
<br>
I hope this help.<br>
<br>
Frank Valdes

Since a user can modify the image values externally task generally rely on the user providing the parameters to take the image values and convert them to electrons (assumed to be the same as detected photons for CCDs).  You can think of the image values as "ADU" and the gain parameter as the number to multiple the image values by to get detected photons/electrons.<br>
<br>
I am probably confusing you...  The gain is the number you multiply your pixel values to get electrons.  This is usually the CCD detector gain expressed in electrons per adu.  In this case phot is expecting data in adu and it uses the gain parameter as you said "FLUX * EPADU" for the Poisson statistics.<br>

<br>
<a href="http://www.phys.vt.edu/~jhs/phys3154/snr20040108.pdf">http://www.phys.vt.edu/~jhs/phys3154/snr20040108.pdf</a><br>

<br>
The IRAF equation for error estimation is an approximation for SNR&gt;&gt;1. If someone doesn't trust that this is valid for all their data, it is better to manually calculate the errors using the SNR (see the first link for a brief explanation and the equations).<br>
