<div>
Hi John,<br>
<br>
It's a good suggestion for an addition to the batch-mode processing I should be able to add fairly easily.  Until then though, writing out the CCF is only available through the colon command.<br>
<br>
You can still automate this however by using a "cursor command file" to drive the task for you.  The format of the file is "&lt;x&gt; &lt;y&gt; &lt;wcs&gt; &lt;cmd&gt;" where I'd picture this using dummy x/y/wcs value and the commands ":wccf somefile" and 'n' to move through the list.  Once you have the file created, you'd run FXCOR with interactive+  and set the 'cursor' parameter to take its input from that file, e.g.<br>
<br>
<pre><code>cl&gt; fxcor *.fits template inter+ cursor=&quot;mycmds&quot;</code></pre><br>
<br>
Note you'll need to setup the list processing for the images and the orders so they happen the way they would in an interactive run.    See "help cursors" for more details on cursor mode files.<br>
<br>
Hope this helps,<br>
-Mike
</div>
