Frank,<br>
<br>
The FITS standard says the DATE-OBS keyword should follow the prescriptions for the DATE keyword, the DATE keyword should be defined in UTC.  However, it also says the DATE-OBS keyword should be in the same time system as the primary header....seems like a conflict to me.  In any case, DATE-OBS is typically in UT so you should probably convert.<br>
