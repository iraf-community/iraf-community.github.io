I think the error is caused by not specifying a 'shiftlist' output filename.  The error message itself it coming from the CL when trying to append to a filename based on the shiftlist param, and from your output this is empty.  It doesn't appear that you can use STDOUT as an option so specify the name of a file to create.<br>

As a workaround, I commented out the steps in xdshifts and xfirstpass where the existence of the shiftlist is checked, and the codes ran fine. But since this problem didn't happen to others, maybe it's my approach to the xdimsum package that's causing the problem...<br>
