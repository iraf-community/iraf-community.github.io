I believe the problem is that the information that is needed for each extension, such as the image type, is in the global header.  There is a convention supported by IRAF that allows keywords in the global (or primary, data-less header) to be automatically attached to each extension.  For this to happen there has to be a keyword INHERIT with value of T in each extension.  I can't tell if the keyword is missing or set to F.  Try<br>
<br>
[/code]imhead WFI.2007-02-24T19:30:21.429.fits[im1,inherit] l+<pre><code>

And see if you see TYPE=&#x27;BIAS&#x27;.  Compare this with leaving out the &quot;inherit&quot; in the command above.  If this is the case you can use

</code></pre>hedit WFI.2007-02-24T19:30:21.429.fits[im1] inherit T  <pre><code>

to update the keyword.  Note you would need to do this for every extension

For more help send the actual command you type (the CCDLIST command) and image headers listed with the IRAF imhead command.
