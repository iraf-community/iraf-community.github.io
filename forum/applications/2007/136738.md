<div>
Type 'ab' implies a boolean array, which was only added to Pyraf in the last year or so (current release is 2.4).  I think you need to either update to a more recent Pyraf or else use the standard CL, GEMINI apparently doesn't make mention of required versions for Pyraf but the package is switching over to use that in the future.<br>
