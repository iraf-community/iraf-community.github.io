<div>
The message is basically saying that the x_longslit.e binary doesn't contain a LSCOMBINE task.  You can verify this by starting the command outside of the CL to check, e.g.<br>
<br>
<pre><code>
prompt%  /iraf/iraf/noao/bin.redhat/x_longslit.e
&gt; ?
    extinction     fitcoords      illumination   response       
    fceval         fluxcalib      lscombine      transform      
&gt; bye
</code></pre><br>
<br>
The '&gt;' in this case is the prompt you get from the binary.<br>
<br>
Since this task was new to V2.12.2a, if I had to guess I'd say the 2a patch was applied but the binaries weren't updated (i.e. you patched the source so the param file etc appears, but not the binaries).<br>
<br>
Cheers,<br>
-Mike
</div>
