**Valeev Azamat** wrote on Jul 04, 2007

{% raw %}
<div>
Use default value. (5.0) <br>
This value depent on matrix/instrument properties (read noise, gain, <br>
scale...) and seeing in observing moment (I think), S/N value and so....<br>
<br>
You may find the best value using this method: <br>
setup apall.format="strip"<br>
change width and see how change 2D-profile of spectra.<br>
select the best value.<br>
<br>
Cheers, Azamat :)
</div>
