I'd first check to see that you're using the latest version of DS9 (you can get it from <a href="ftp://sao-ftp.cfa.harvard.edu/pub/rd/ds9)">ftp://sao-ftp.cfa.harvard.edu/pub/rd/ds9)</a>.  I believe this error came back briefly in one release but has since been fixed.  <br>
<br>
By "ESO website" are you referring to the SciSoft release?  You can determine the exact version of IRAF you're using with the command<br>
<br>
<pre><code>cl&gt; head hlib$motd nl=2</code></pre><br>
<br>
Please post this if you still have problems.  Also, are you using DS9 to load the image in standalone more or the DISPLAY/MSCDISPLAY task?<br>
<br>
Cheers,<br>
-Mike
