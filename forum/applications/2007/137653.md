**Francisco Valdes** wrote on Jun 28, 2007

{% raw %}
<div>
You should do the extraction on one, or go through the steps up to extraction, and save the aperture definitions.  Normally this is automatic and it is saved with the same name as the image (without the .fits).<br>
<br>
To apply the same aperture definitions on another image set the "reference" parameter to the name of the image.  Be sure to turn off all the steps except the extraction so that it doesn't change the definitions; e.g. you don't want to retrace.<br>
<br>
This should apply the exact same aperture definitions (centering, trace, aperture ids, etc.)<br>
<br>
Yours,<br>
Frank Valdes
</div>
