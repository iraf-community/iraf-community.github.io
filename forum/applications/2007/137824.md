# IRAF TFINDER problem

**Sangmo Tony Sohn** wrote on Jul 19, 2007

{% raw %}
<div>
Hi,<br>
<br>
I'm using the TFINDER task in the FINDER package to get astrometric solutions for my CCD frames.  I pull out the reference stars from the USNO-B1 catalog, convert the ASCII RA and DEC to IRAF table format using MKGSCTAB task, and then use TFINDER to get a solution.  <br>
<br>
Everything is working fine except for one thing.  When I use the "e" keystroke in TFINDER to get a "rough" solution (after matching a few stars that are spread out over the entire field) and hit "q" from the graphic terminal, only the stars that I've selected in the previous step (using either "l" or "k" keystrokes) appears on the display.  As I understand, the stars I did NOT selected are supposed be marked with red circles with the X/Y coordinates calculated from the rough solution.<br>
<br>
I tried to track down what may be the problem by looking at the overwritten table file, and figured out that the calculated coordinates (X_CENTER and Y_CENTER in terms of table column names) are nowhere near the actual stars -- they are &gt;60000 and &gt;100000 in pixel coordinates! which doesn't make sense.<br>
<br>
I wonder if anyone else has experienced the same problem?<br>
<br>
Thanks.
</div>
{% endraw %}

**Rob Seaman** wrote on Jul 19, 2007

{% raw %}
<div>
1) Do you have the RA units right in mkgsctab?<br>
<br>
2) Perhaps tfinder parameters like scale, north or east are wrong?<br>
<br>
3) How many stars is a "few"?  You might try a few more.  Note that nothing requires that you fit a solution to every source from the catalog.<br>
<br>
4) Are you convinced your eyeball matching of sources is correct?  If the pixel coordinates are that far off you likely wouldn't be able to find any to match in the first place.<br>
<br>
5) Note that the catalog may contain sources that don't lie within the field of view of your image.
</div>
{% endraw %}
