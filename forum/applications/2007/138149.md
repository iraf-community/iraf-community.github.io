This problem concerns the "%" key in splot to display a different band of a 3D image. When parameters line and band are given on command line it doesn't work.<br>
So typing<br>
cl&gt; splot images=myImage.fits line=1 band=1<br>
will cause the "%" keystroke to have no effect.<br>
Whereas typing<br>
cl&gt; splot images=myImage.fits<br>
and then giving the line and band when asked for will work.<br>
