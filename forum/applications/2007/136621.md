**Mike Fitzpatrick** wrote on Jan 15, 2007

<div>
The defpac() function is expecting only the package name, not the path to the package, e.g. "if (! defpac('imutil')" should do what you want.  Note that packages are loaded by default both in your login.cl file and perhaps in other package loading scripts (i.e. 'images' is loaded by login.cl, 'imutil' is then loaded automatically when IMAGES is loaded).<br>
<br>
Cheers,<br>
-Mike
