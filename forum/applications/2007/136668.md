How can I correct bad pixels in an MEF using a mask which is also an MEF?   The mask has 36 extensions, each corresponds to an extension in the main image I want to process.  Is  it possible to interpolate bad pixels without splitting the MEF and running fixpix 36 times?

**Mike Fitzpatrick** wrote on Jan 19, 2007

{% raw %}
<div>
Frank can comment further, but I think the MSCRED package task MSCCMD can do this as a way to e.g. run FIXPIX on each on the image extensions where the corresponding mask extension is used for the correction.  Something like<br>
<br>
<pre><code>cl&gt; msccmd &quot;fixpix $input $in2&quot; mefs.fits masks.fits out.fits</code></pre><br>
<br>
Otherwise, the FITSUTIL package is handy for dealing with MEFs.<br>
<br>
Cheers,<br>
-Mike
