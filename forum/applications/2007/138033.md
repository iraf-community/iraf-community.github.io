<div>
The image appears to be 1024x1024x1 so you'll need to set the 'dims' parameter to specify the dimensions as well as the header offset.  The 'format=vicar' only works if the format is the same as that defined by the 'vicar' entry in the format database, but since this is modified you'll need to set the parameters by hand.  If you still have problems please post a sample image and I can say more about the parameters or give you a database entry to use.<br>

Cheers,<br>
-Mike
