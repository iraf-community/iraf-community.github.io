**Mike Fitzpatrick** wrote on May 01, 2007

{% raw %}
<div>
Don't you know patience is a virtue 8-)<br>
<br>
You would probably need to write a small script to do the processing, but as a first step see the DUST service at IPAC: <a href="http://irsa.ipac.caltech.edu/applications/DUST/">http://irsa.ipac.caltech.edu/applications/DUST/</a><br>
<br>
What I'm thinking is you would use the HSELECT task to extract the RA,DEC from each of the images to create the position table for upload, e.g.<br>
<br>
<pre><code>
cl&gt; hselect *.fits ra,dec yes &gt; coords
</code></pre><br>
<br>
You would then need to edit this by hand to put it into the proper format for the upload (see the "service help" link on DUST for the format).  Hit Submit to get the values for all the positions and then "Download Table" to get a text file of results.  This gives you a table of positions and extinction values.  The scripting part is in looping over this list to get the A_v value for the given position.  Or, if you plan to run deredden by hand you've at least got a table of values you can enter quickly.  Hope this helps.<br>
<br>
Cheers,<br>
-Mike
</div>
