<div>
Doug,<br>
<br>
It depends somewhat on the type of the param and what field you're talking about, e.g. list and pset structs are SZ_FNAME (255), strings can be as long as SZ_LINE (1023), but the p_min field used for enumerated lists is limited to 160 chars.   Is there some reason you're not using an @-file for a long list of filenames?<br>
<br>
-Mike
