<div>
<blockquote> So, I was wondering if there is an easy way of checking if a file is blank before inputting it into a task?</blockquote><br>
<br>
You might try the COUNT task, e.g. "count (filename) | scan (nlines)" and see whether 'nlines' is then zero.<br>
<br>
<blockquote>A related question is, is there a way of calling fscan on a file/parameter that is not stored as a list parameter? </blockquote><br>
<br>
If I understand your question correctly, then no.  Could you elaborate on what you're trying to do?<br>
<br>
<blockquote>And finally, also kind of related, is there a way to manually define the scope of your variables in the iraf programming language? I know that it is not possible to define a list variable locally, but is there a way to access a global list variable from inside a local block of code without the list variable being included in the function call that creates the block? </blockquote><br>
<br>
Sort of.  You can use package parameters or the CL 'list' parameter as a type of global variable and use it within the script, but within the script it isn't possible to define a local scope.  Hope this helps.<br>
<br>
Cheers,<br>
-Mike[/quote]

<div>
It may just be your usage but you didn't post the code snippet.  Are you scanning individual words or the entire line?<br>
<br>
In any case, a simpler method is to use the 'logfile' directly, e.g.<br>
<br>
<pre><code> match (&quot;Average&quot;, &quot;logfile&quot;) | fields (&quot;STDIN&quot;, 9) | scan (avg_fwhm)</code></pre><br>
<br>
and the variable 'avg_fwhm' will have the value.<br>
<br>
Cheers,<br>
-Mike
