Hello,<br>
<br>
In the documentation Fnu and f_nu are the same thing and magnitude and m_AB are the same thing.  So the equations are<br>
<br>
m_AB(star) = -2.5 * log10 (f_nu) - 48.60<br>
<br>
f_nu = fnuzero * 10. ** (-0.4 * m_AB)<br>
<br>
I recognize that the description was not as precise as it should be and I have made changes.  Adding to this confusion the statement that with the default fnuzero Vega has an AB magnitude of 0.048 is wrong.  The value is 0.0336.  I have changed the help page to reflect this.  The point of the choice of fnuzero is to produce a value of 3.52e-20 for Vega at 5556A which was what versions of STANDARD did 20 years ago.  This is not saying that this is the current best calibration of Vega.  The reason fnuzero is a parameter is because users can change it to meet current absolute flux standards  using the same historical calibration files.<br>
<br>
