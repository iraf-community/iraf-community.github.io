**Mike Fitzpatrick** wrote on Dec 15, 2008

{% raw %}
<div>
Check your .cshrc or .bashrc/.profile for any recent changes.  The 'ls' is a foreign command and a shell is spawned to run it that will source one of these startup files, if there's something in the shell asking for a prompt, requiring a terminal (e.g. and 'stty' or 'tset' command) or somesuch then it may be a startup problem.  Also, if your path includes an NFS mounted disk and that disk isn't available, foreign commands will appear to hang.  [Note:  'dir' is the native IRAF command]<br>
<br>
-Mike
</div>
