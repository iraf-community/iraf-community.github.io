<div>
I'm not familiar with WMOSAIC specifically, but in general terms you need to use the STRFITS task in TABLES or STSDAS to convert MEF files.  The image you have is a 3-D image 800x800x4, so you'll need to use an image section to create a 2-D slice for each plane, e.g.<br>
<br>
<pre><code>
cl&gt; imhead u47b0301r_c0f[0][*,*,1]</code></pre><br>
<br>
to access extension zero and the first plane of the image.<br>
<br>
There's nothing in particular to create color images as in 'pretty pictures', however see the EXPORT task in the DATAIO package (help page examples) as one way to create e.g. a color GIF with RGB components made up of separate images.<br>
<br>
Cheers,<br>
-Mike
</div>

<div>
I found the problem and my first try was in the right direction, but I have to use the right format <em>c0h</em> not <em>hhh</em>.<br>
<pre><code>wfpc&gt; strfits u5310101r_c0f.fits &quot;&quot; /tmp/test.c0h
wfpc&gt; imheader /tmp/u5310101r.c0h 
/tmp/u5310101r.c0h[1/4][800,800][real]: U5310101R[1/4]
</code></pre><br>
After that, everything works as expected.<br>
<br>
I use the following code, which may be helpful for other people:<br>
<pre><code># Converting Fits files
strfits u531010er_c0f.fits &quot;&quot; u531010er.c0h
strfits u531010fr_c0f.fits &quot;&quot; u531010fr.c0h
strfits u531010gr_c0f.fits &quot;&quot; u531010gr.c0h

# Creating Image List
files u531010er.c0h  &gt; list
files u531010fr.c0h &gt;&gt; list
files u531010gr.c0h &gt;&gt; list

# Removing cosmic rays
crrej @list combine.c0h &quot;&quot; &quot;4,4,3,2&quot;

# Creating Mosaic
wmosaic combine.c0h mosaic.c0h

# Converting to FITS file
stwfits mosaic.c0h u531010e_10f_10g.fits
</code></pre><br>
Best regards and thank you for your answer.<br>
