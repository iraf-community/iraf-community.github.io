**Mike Fitzpatrick** wrote on Jun 08, 2008

{% raw %}
<div>
The message you report often means the files are failing to identify<br>
themselves as "zero" exposures.  You can work around this by setting<br>
"ccdtype" in ZEROCOMBINE to "".  However you can check how the<br>
exposures are being identified using CCDLIST.  <br>
<br>
Note that ZEROCOMBINE calls CCDPROC so you'll need to check the CCDPROC parameters to do only the processing you need or set zerocombine.process=no to combine only the raw data).  Hope this helps.<br>
<br>
Cheers,<br>
-Mike
</div>
