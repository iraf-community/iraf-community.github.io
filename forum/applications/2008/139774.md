<div>
A task like QPHOT uses both it's own parameters and inherits params from the APPHOT package itself, so to be complete you need to also dump the package parameters.  A lot also depends on how you're running from the shell:  You should normally 'dpar' the parameters to a file (and append the package parameters) and execute as e.g.<br>
<br>
<pre><code> 
cl&gt; dpar qphot &gt;qphot.dpar
cl&gt; dpar apphot &gt;&gt; qphot.dpar                # appends the params

and at the linux shell execute as

% /path/x_apphot.e qphot @qphot.par
</code></pre><br>
<br>
In the long run the simplest thing may be to create a "#!cl" script that let's you run the QPHOT command as a standalone unix command but still use the CL facilities for parameter, graphics, etc.  See <a href="http://iraf.noao.edu/iraf/web/new_stuff/cl_host.html">http://iraf.noao.edu/iraf/web/new_stuff/cl_host.html</a> for more information.<br>
<br>
-Mike
</div>
