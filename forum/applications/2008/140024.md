Hi,<br>
<br>
I'm sorry if this is confusing.  I thought the task gave you a prompt.  The interactive fitting is just to set appropriate parameters such as the order and any sample regions.  When you are happy you type 'q'.  Then it will prompt you for a new line.  You can pick another line to check how well the parameters work on that line.  When you are satistified with the parameter you hit return when prompted for a line.  At that point the task will go through every line using the last set of fit parameters to produce the response result.  Note when I say line this really means line or column depending on the setting of the DISPAXIS in the header or package parameters.<br>
