<div>
I am not an experience photometrist or fully knowledgable about the tasks.  The one thing I am certain about is that phot does not remove contaminating stars in the aperture.  The only way to do that is with a PSF fitting photometry task such as in the DAOPHOT package.  Normally you need to use an aperture that will not include more than one source.  You would need to do things more manually if you want to use different size apertures for different stars.<br>
<br>
The INDEF values are due to a failure of the photometry.  You would need to read the help and figure out what exactly is resulting in the INDEF values.<br>
<br>
Good luck.<br>
