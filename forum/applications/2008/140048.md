<div>
Scombine is designed to work in wavelength space; which really means whatever the world coordinates for the first axis are set to.  For uncalibrated data this would be pixels.<br>
<br>
Anyway, if all you want to do is "tile" the images end-to-end then I suggest you use imcombine with the offsets parameter.  In the help you will find that one of the forms of the offsets parameter is a string describing a grid.  In you case it might be something like "grid 5 1000 1 1".   If they are of different sizes then the more general offsets file could be used whose contents are something like<br>
<br>
<pre><code>
0 0
1000 0
1900 0
</code></pre><br>
<br>
Note you didn't say if these were 1D or 2D files.  My examples assume 2D images which are tiled end-to-end along the first dimension.<br>
<br>
Yours,<br>
Frank Valdes<br>
[/code]
