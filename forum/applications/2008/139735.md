I was wondering if it was possible to perform different calculations on stars that were out of focus.  The most basic of these tasks would be to find the centroid given the out of focus star's annulus.  Other tasks would be to see intensity plots etc.  Is this possible?

**Mike Fitzpatrick** wrote on Jun 25, 2008

{% raw %}
<div>
Tasks should still all work, although you might get some funny results.  IMEXAMINE for instance has many command to look at radial profiles, contour/surface, a line through the data, etc.   STARFIND and some of the photometry tasks will do centroiding, but if the stars are so out of focus as to look like donuts then they might not converge easily.<br>
<br>
-Mike
</div>
{% endraw %}
