**Mike Fitzpatrick** wrote on Jul 08, 2008

{% raw %}
<div>
You can simply use an image section to copy out the region of interest to a new file, e.g.<br>
<br>
<pre><code>cl&gt; imcopy bigim[500:799,100:399] small.fits</code></pre><br>
<br>
will copy the specified section to a new image.  Note that you need to specify the ".fits" extension explicitly if you're using something earlier than v2.13 or else set your 'imtype' variable to ".fits" in your login.cl file.<br>
<br>
-Mike
</div>
{% endraw %}
