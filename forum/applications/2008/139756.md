The 'ix' variable is filled when scanning the sections file, you're likely seeing the error because there were enough/any values in that file and so it is undefined.<br>
<br>
The sections file in this case should be "S0_fp.corners" which should contain the image name and corner values;  It appears the image name is not valid so you might examine that file to see what's in it.  This file is apparently written by XNREGISTER.  Frank is the current expert on the package and I'm sure will respond when he gets a chance, hopefully this will give you something to look for in the meantime.<br>
