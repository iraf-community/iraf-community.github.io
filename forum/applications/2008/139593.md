It depends on the task and data.  For the most part the IRAF spectral tasks (in the NOAO package) don't handle error information.  The one place where some work was done specifically for your question is in the package guiapps.spt.  This is a complex GUI task with lots of options.  If the data have an uncertainty component, and associated spectrum, then I know it is possible to set parameters to plot error bars.  How you set the uncertainty spectrum is up to you.<br>
