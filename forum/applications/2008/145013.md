**Mike Fitzpatrick** wrote on Dec 01, 2008

{% raw %}
<div>
I've uplaoded an alternative catdb.dat file that contains entries for USNO catalogs (USNO-A2, USNO-B1, NOMAD and ACT), this is available at<br>
<br>
<a href="http://iraf.net/ftp/pub/fitz/catdb.dat">http://iraf.net/ftp/pub/fitz/catdb.dat</a><br>
<br>
You can download this and install in noao$astcat/lib and you should be able to access the catalogs at the alternative site.<br>
<br>
As for getting a rectangular region:  The data queries are based on a radius and in cases where regions are being used but the ra/dec width differ, the max width is used in the query.  If you want a rectangular region you'll need to filter the result table, e.g. using TSELECT from the TABLES package.<br>
<br>
-Mike
</div>
{% endraw %}
