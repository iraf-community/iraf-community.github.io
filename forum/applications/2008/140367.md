<div>
AFAIK, fifos don't work under OSX, but you don't need them.  The default for IRAF is to display using a unix socket which ds9 will also open automatically.  In almost all cases, simply starting ds9 without flags or setting an IMTDEV variable will work as a default.  The message about port 5137 already in use simply means there is another ds9 already running.<br>
<br>
-Mike
