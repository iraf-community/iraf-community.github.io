I've long wanted to support formats with separate wavelength and flux vectors in text or binary tables (is the SPEXTOOL format FITS binary tables?).  But currently the main spectral format for IRAF is an image with a WCS for the wavelengths.  The only other options you could explore are the TABLES package (including the tables graphic task) or maybe the IGI graphics package where you write mongo-like command scripts.<br>
