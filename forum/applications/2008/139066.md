**Francisco Valdes** wrote on Feb 21, 2008

{% raw %}
<div>
Hi,<br>
<br>
My first thought is to use CCTRAN on the text file.  This depends on having access to a correct WCS in headers in the two images.  If they have celestial coordinates the steps are to first transform the x,y column to RA,Dec using the image to be matched and then transform the RA,Dec to logical (pixel) coordinates using the second image.  The task CCMAP may be used to derive a celestial WCS for the headers but this is often tricky and more work than you need.<br>
<br>
The alternative in x,y space is GEOMAP and GEOXYTRAN.  This will generate a "database" with a geometric transformation between the two images and then transform the x,y values in a catalog (similar to CCTRAN but using a database instead of a header WCS).<br>
<br>
If the images have no particular coordinate information associated with them but only the fact you have determined a transformation, it is possible to write a script (again working on text files) that would read the catalog line-by-line, do some computations on the x,y columns and output the new x,y columns leaving the rest unchanged.  This might be more scripting than you are skilled at in which case I could write something for you fairly quickly if you send me the catalog and the equations you believe transforms the coordinates.<br>
<br>
Let me know if you want more information.<br>
<br>
Yours,<br>
Frank Valdes
