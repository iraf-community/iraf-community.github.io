that the '$iraf' that IRAF needs will be /local/iraf/iraf/<br>
<br>
<pre><code>
cd $iraf/iraf

<br>
        I presume that since you're using the redhat binaries you've got some<br>
sort of binary compatability available?  You won't be able to use the system<br>
for compilation, however if you were going to be rebuilding the system<br>
to create an 'openbsd' architecture there are a number of other places<br>
where this would need to be added.  Editing the cl.csh/irafuser.csh/install<br>
script should be good enough to start up though.<br>
<br>
        Otherwise your script looks perfectly reasonable.  You say it doesn't<br>
work, but you don't say what the error is.  Does the script not run, or is it<br>
just that you can't start IRAF afterward?<br>
