<div>
The 'phu' parameter creates a dummy primary header, if what you want is to simply copy out the extension and preserve the PHU, try<br>
<br>
<pre><code>cl&gt; imcopy foo.fits[2,inherit+] bar.fits</code></pre><br>
<br>
or use FXEXTRACT similarly with the 'inherit' flag set.  See <a href="http://iraf.net/irafdocs/fits_userguide/">http://iraf.net/irafdocs/fits_userguide/</a> for more about the FITS kernel parameters.<br>
<br>
-Mike
