**Mike Fitzpatrick** wrote on Dec 18, 2008

{% raw %}
<div>
The error generically means that the task can't find an image display server.  If by 'configured to use ds9' you mean you did something like set the device parameter to be 'ds9' then this won't work, the parameter is meant to specify the overlay color and it is assumed the DS9 is already running.<br>
<br>
A simple test is whether you can display an image at all, DS9 should open the communications socket by default and take input.  I do remember however that a recent release did break IRAF display, you should check that you indeed have the latest version or else try ximtool.<br>
<br>
-Mike
</div>
