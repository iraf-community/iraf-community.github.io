<div>
The first thing to try is to use "ssh -Y" when logging into the remote machine, this enables "trusted X11 forwarding" and other bits of magic that usually fix things like this.  Otherwise, I'd try the latest version of DS9 on the linux box and if you still have problems I'm afraid you'll need to contact SAO to see if they have ideas, this hasn't been reported before.<br>

-Mike
