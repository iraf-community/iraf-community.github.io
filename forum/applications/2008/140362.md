I am a new user ,  this problem troubles me few days ago, fortunately, it has been solved .<br>
  I think if you set the parameters of DARKCOMBINE<br>
<blockquote> (process = no)             Process images before combining?<br>
 (ccdtype = " ")            CCD image type to combine<br>
</blockquote><br>
Maybe the task DARKCOMBINE will run.<br>
I hope this advice is  useful to you.<br>
good luck!<br>

Hi S. K. Li,<br>
thanks for your suggestion. <em>darkcombine</em> worked after setting <br>
<br>
<blockquote>(process = no) Process images before combining? <br>
(ccdtype = dark) CCD image type to combine </blockquote><br>
<br>
I must set <em>ccdtype</em> to <em>dark</em> otherwise all other type of frames will be processed.<br>
<br>
Anyway, I set image type to .fit by<br>
<br>
<pre><code> imtype=fit </code></pre><br>
<br>
then everything go right including  <em>flatcombine</em><br>
