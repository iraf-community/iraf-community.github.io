You can use IRAF for measuring equivalent widths but there is not very much analysis software for the type of later science (other than the nebula package you found).  So you are on your own for doing the atmosphere analysis using IRAF equivalent width measurements.<br>
<br>
Just in case, the SBANDS task might be useful for some kinds of measurements that require standard line indices.<br>

<div>
Hi Siti,<br>
<br>
The sequence of keystrokes are k, k to select the region to fit and do the fit and then - and - to select the region to subtract and do the subtraction.  So it sounds like you did the right thing.  Do you see the graphs and see the fit overplotted.  If you are using xgterm the spectrum and fit should be in different colors.  The other thing that should happen is that fitted data should be erased and the subtracted data plotted.  My one suggestion is you do 'r' after the second '-' to redraw the spectrum.<br>
<br>
A question is that when you type '-' you see "- again:'.  After you type the second '-' does the prompt disappear or do you see it again?<br>
<br>
Frank
