**Mike Fitzpatrick** wrote on Jul 10, 2008

{% raw %}
<div>
The 'apertures' parameter can be used to select specific apertures for each redshift, to apply different redshifts to different apertures you would need to run the task repeatedly for each redshift (possibly in a script).  Note also the SCOPY task can be used to copy out specific apertures to a separate file, you could then apply a redshift to a list of these files as needed.<br>
<br>
-Mike
