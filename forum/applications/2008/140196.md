**Mike Fitzpatrick** wrote on Sep 16, 2008

{% raw %}
<div>
As written, there is no way in the task to save the database (it was viewed as being only temporary).  If you want to keep it you'll need to create a modified version of the script, e.g.<br>
<br>
<pre><code>
cl&gt; copy immatch$wregister.cl home$mywregister.cl 
cl&gt; edit home$mywregister.cl
.....comment out/delete the line that removes the database file
cl&gt; task mywregister = home$mywregister.cl
</code></pre><br>
<br>
When you run the new MYWREGISTER task it will be the version with your changes.  Note that if you plan to re-use the same file you may need to set the 'clobber' environment variable so the file will be overwritten, otherwise a good strategy is to make the database name a parameter you can reset.<br>
<br>
Cheers,<br>
-Mike
</div>
{% endraw %}
