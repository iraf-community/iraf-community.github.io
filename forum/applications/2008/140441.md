**Mike Fitzpatrick** wrote on Nov 18, 2008

{% raw %}
<div>
The 'cannot open connected subprocess' message usually means that either the binaries weren't installed, they were install in the wrong location, or if you built from source that the package wasn't reconfigured for the current architecture before compiling.  The 'mscred' package directory should be defined normally in the hlib$extern.pkg file (be sure it has a trailing '/').  If you defined the package yourself in a login.cl or loginuser.cl file, be sure this was done before the final 'keep' statement in each file.<br>
<br>
-Mike
</div>
