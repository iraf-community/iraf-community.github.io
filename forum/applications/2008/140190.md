Hello Jonathan,<br>
<br>
When you run doecslit it automatically sets several things based on the width parameter:<br>
<br>
<pre><code>
        apslitproc.width = width
        apslitproc.lower = -width / 2.
        apslitproc.upper = width / 2.
        apslitproc.b_sample = \
            str(-2*width)//&quot;:&quot;//str(-width)//&quot;,&quot;//str(width)//&quot;:&quot;//str(2*width)
        apslitproc.t_width = width
        apslitproc.radius = width
        apslitproc.minsep = width
</code></pre><br>
<br>
So anything you set separately, say in apslitproc, will be changed when your run doecslit.  I cannot remember specifically but it must have seemed like a good idea to minimize the number of things a basic user has to worry about.  One has to keep in mind that the DO tasks were targeted at the basic user and not the power user.<br>
<br>
A suggestion for how you can change this for yourself is as follows.<br>
<br>
1.  Copy imred$src/doecslit/doecslit.cl to your home directory.<br>
2.  Edit or comment out the b_sample line.<br>
3.  Load the echelle package<br>
4.  Redefine the task with:  redefine doecslit=home$doecslit.cl<br>
<br>
Yours,<br>
Frank Valdes
