<div>
A simpler approach may just be to create the root part of the filename and concatenate the appropriate extension as needed, e.g.<br>
<br>
<pre><code>
root = &quot;b_&quot; // substr (n,1,strlen(n)-5)
xyxymatch (input=root // &quot;.coo&quot;, ..... )
</code></pre><br>
<br>
Depending on how you create your file list, you could also use the '%' operator to strip the root beforehand, e.g.<br>
<br>
<pre><code>
files (&quot;2008*%.fits%%&quot;, &gt; &quot;imglist&quot;)
</code></pre><br>
<br>
-Mike
