PyRAF is a python command language capable of calling IRAF tasks, but must be installed separately from the rest of the system.  You can download it and get the installation instructions from:<br>
<br>
<a href="http://www.stsci.edu/resources/software_hardware/pyraf">http://www.stsci.edu/resources/software_hardware/pyraf</a><br>
