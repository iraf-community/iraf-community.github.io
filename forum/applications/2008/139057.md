<div>
It looks as if the pixels are wrapping around in the frame buffer.  What is the image size and what stdimage value are you using.  Commands like<br>
<br>
<pre><code>
cl&gt; display dev$pix 1
cl&gt; display  myimage.fits 1 fill+
</code></pre><br>
<br>
I would expect to work because dev$pix is a 512x512 image the same as the default frame buffer, and in the second case the image is scaled to fit whatever the frame buffer size is.<br>
<br>
My guess is the problem is a missing /usr/local/lib/imtoolrc file (which is a link to or a copy of dev$imtoolrc, you can also put this in your unix login directory as '.imtoolrc" to find it.).   A restart of DS9 will be required to use the new file.<br>
<br>
-Mike
</div>
