# daophot psf does not write the psf image in interactive mode

**vrooje** wrote on Sep 16, 2008

{% raw %}
<div>
Hi,<br>
<br>
I need to make about 200 PSFs for individual images. I have, in the past, successfully used the following sequence to create PSF images in noao.digiphot.daophot:<br>
<br>
phot -- starting with just a list of star positions<br>
pstselect<br>
psf<br>
seepsf<br>
<br>
All this works fine if I don't run any of the tasks interactively. If I run psf interactively, I can go through the motions of viewing profiles and adding and deleting stars from the list, but after the program finishes, my *.psf.imh is empty, and so are the opst and group files. However, if I manually remove the deleted stars from the pst file and then run psf non-interactively, everything works fine and I can move on to the last step.<br>
<br>
(I've tried running pstselect interactively, and that goes nowhere -- just selects 0 stars, writes an empty pst file and quits.)<br>
<br>
This was easy to work around when I was only creating a few psfs at a time, but now that I need to do around 200, I really would like to get this working so that I don't have to manually remove bad stars from each list.<br>
<br>
I've searched these forums and I haven't really found anything like this. Any suggestions would be appreciated. Thanks!

2) edited the parameters for pstselect so that it was set to run interactively.<br>
