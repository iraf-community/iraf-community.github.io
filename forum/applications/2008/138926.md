**Mike Fitzpatrick** wrote on Jan 23, 2008

{% raw %}
<div>
Thanks for the data and the report.  This wasn't so much a bug as a bad interaction of interfaces.  The task opens the image and saves the WCS descriptor for later use.  The ZPN driver tries to reference the image in the wcs descritor to get the PV matrix keywords, however the procedure that created that descriptor also closed the image and so the image reference was invalid.  This is outlined in more detail in  Buglog #560 (see <a href="http://iraf.net/article.php/20080123160033255)">http://iraf.net/article.php/20080123160033255)</a>.<br>
<br>
I've put patched binaries for the two platforms you mention at:<br>
<br>
<a href="http://iraf.net/ftp/pub/x_images.e.RHUX">http://iraf.net/ftp/pub/x_images.e.RHUX</a><br>
<a href="http://iraf.net/ftp/pub/x_images.e.MACINTEL">http://iraf.net/ftp/pub/x_images.e.MACINTEL</a><br>
<br>
Write back and I can send you the code change and build instructions if you prefer.<br>
<br>
Cheers,<br>
-Mike
