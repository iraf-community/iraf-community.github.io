<div>
From your INVERTFIT output it appears you've set the parameter object=standard to print only the standard star information.  By using object=program (or 'all') you would get the same information on the program stars which you could use to match against the table with the exposure time.<br>
<br>
There's no direct way to have the task output the OTIME keyword you want, but a small script should be able to merge the tables based on the program star id string (e.g. see the TMERGE task in the TABLES package).<br>
<br>
-Mike
