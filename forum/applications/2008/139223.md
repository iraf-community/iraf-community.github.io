**Francisco Valdes** wrote on Mar 24, 2008

<div>
Hi,<br>
<br>
This is not a very well documented definition of a reference spectrum.  It is defined in the second paragraph of the REFSPEC help page:<br>
<br>
<blockquote><br>
    A  reference spectrum is defined to be a spectrum that has been used<br>
    to calculate a  wavelength  solution  with  the  tasks  IDENTIFY  or<br>
    REIDENTIFY.   These tasks have set the keyword REFSPEC1 in the image<br>
    header equal to the spectrum's own name.<br>
</blockquote><br>
<br>
So in your case you either have to have run IDENTIFY or equivalent task on lamp_four_ap.fits or you have to set the REFSPEC1 keyword with HEDIT.  Note that you can skip REFSPEC if you want to explicitly assign dispersion solutions to images.  REFSPEC is intendend when you have many arc calibrations interspersed in many object spectra and you want an automatic way to assign the arcs to the objects, usually by proximity in time.<br>
<br>
Yours,<br>
Frank Valdes
</div>
