Hello,<br>
<br>
The way I would do this is with imheader piped into match:<br>
<br>
<pre><code>
cl&gt; imhead name.fits l+ | match &quot;SLITX[0-9] OBJ RA&quot;
</code></pre><br>
<br>
Note that match provides a powerful string matching syntax.  The main confusion people have is that * is different from what it means in directory matching.  It is more similar to regular expressions except '?' means any character instead of '.' in regular expressions.<br>
<br>
Yours,<br>
Frank Valdes
