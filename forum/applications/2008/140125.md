# display - bpcolor has no effects

**Kathleen Labrie** wrote on Aug 25, 2008

{% raw %}
<div>
In IRAF 2.14, it seems that the parameter 'bpcolor' is no longer effective.  Only the 'ocolors' parameter is picked up (even for bpdisplay='overlay' and overlay="").<br>
<br>
For example<br>
cl&gt; unlearn display<br>
cl&gt; display myimage 1 bpmask=mymask.fits bpdisplay=overlay bpcolor=red \<br>
        overlay="" ocolors=green<br>
<br>
..will display the bpmask in green.  The bpcolor is completely ignored.<br>
<br>
This becomes a problem when someone, like me, needs to flag the bpmask *and* make use of the 'overlay'.<br>
<br>
Cheers,<br>
Kathleen
</div>
{% endraw %}
