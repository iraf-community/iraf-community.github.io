The contrast box problem I'm aware of but haven't gotten to yet, it's a simple matter of scaling between the frame buffer size and the display window not being set correctly.<br>
<br>

In any case, when I work on the above I'll load up all the memory debuggers to see if there's an obvious problem.  Thanks for the report.<br>
