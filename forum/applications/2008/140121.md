**Albert Domingo** wrote on Aug 25, 2008

{% raw %}
<div>
Dear colleagues,<br>
<br>
I have found this strange behaviour in imextensions task:<br>
<br>
ecl&gt; imextensions Sects_led_cor.fits output="file" index="0-" extname="" extver="1" lindex+ lname+ lver+<br>
ERROR: integer divide by zero<br>
<br>
The problem seems to be related with the extver parameter. If we execute the task with a null list in the extver parameter, then it works:<br>
<br>

Sects_led_cor.fits[0]<br>
Sects_led_cor.fits[1][OMC._LEDF_CCR,1]<br>
Sects_led_cor.fits[2][OMC._LEDF_CCR,2]<br>
<br>
I am running IRAF V2.14 under Fedora Core6. But I have found the same behaviour under Fedora Core8 and Mac OS.<br>
<br>
Any workaround on this problem will be welcome.<br>
<br>
Regards,<br>
Albert.
