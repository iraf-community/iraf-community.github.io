**Mike Fitzpatrick** wrote on Mar 20, 2008

{% raw %}
<div>
You need to specify the display to be the machine you're sitting at and not the remote machine (which a :0.0 implies).  For example, if you're on machine 'fred' and logged into 'barney', you would need to do<br>
<br>
<pre><code>cl&gt; !ds9 -display fred:0.0 &amp;</code></pre><br>
<br>
This assumes that someplace on fred you issued a command like<br>
<br>
<pre><code>% xhost +</code></pre><br>
<br>
so that remote tasks are allowed to connect to fred's X server.<br>
<br>
-Mike
</div>
{% endraw %}

<div>
Is 'paul' a name that's recognized by the other machine (i.e. a static IP address), or is it a laptop using variable DHCP addresses?  A simply test is whether you can "ssh paul" from the remote machine to get back in, otherwise you'll need to specify the '-display' flag using the IP address and not the name, e.g. "-display 140.252.1.1:0.0"<br>
<br>
-Mike
