                The error message pointing to the closing brace makes me think this is being caused by a quick in the CL where an 'if' statement sometimes needs to be terminated with a semicolon to keep the parser from looking for an 'else' statement.  In this case, the statement at the end of your loop should look like:<br>
<br>
<pre><code>
    if (i &gt; 5)
        break
    ;                           # &lt;--- add this
}
 </code></pre><br>
<br>
I'm not sure what the external task produces or what's in the @file created, but post back if this doesn't explain it.<br>
