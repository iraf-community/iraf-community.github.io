<div>
<br>
<br>
The task would have to be fixed by STScI in a future release (you can contact their helpdesk at help@stsci.edu), but you should be able to work around it by removing the options, i.e.<br>
<br>
    cl&gt; pltpar.errtype.p_min="bar"<br>
<br>
    cl&gt; pltpar.errtype="bar"<br>
<br>
Note that to actually see the error bars you need to also set the 'erraxis' parameter.<br>
