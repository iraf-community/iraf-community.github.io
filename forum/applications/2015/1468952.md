<div>
<br>
                The FINDER package is no longer actively maintained and 'redhat' is one of the older architectures.  The specific error you report has to do with the fact you need to define an environment for compilation, e.g.<br>
<br>
    % setenv iraf /iraf/iraf/                # &lt;--- trailing '/' req'd<br>
<br>
    % setenv IRAFARCH redhat        # should be 'linux' on newer systems<br>
<br>
    % source $iraf/unix/hlib/irafarch.csh     # to remaining environment<br>
<br>
In v2.16 systems there are Bash equivalents for these (e.g. 'irafarch.sh').  Even so, there were compilation problems on newer systems due to compiler differences and so I've simply put a compiled package for 32-bit linux at<br>
<br>
    ftp://iraf.noao.edu/pub/finder_221-linux.tar.gz<br>
<br>
Download in binary mode and unpack in the same directory as your other external packages.  Since you can't use the autmated package mechanism with this (just yet, I'll get to it), edit the $hlib/extern.pkg file to declare the package (before the final 'keep' statement) with<br>
<br>
     reset finder = /&lt;path&gt;/finder/                       # replace , trailing '/' req'd<br>
<br>
     task  finder = finder$finder.cl<br>
<br>
Note you'll also need to have the TABLES package installed.<br>
