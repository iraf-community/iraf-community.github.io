<div>
I don't do much imaging myself, but I was wondering if you might use geotran directly to perform any necessary rectification on each individual image (since you already have the solution for that) -- or start with the intermediate images from imcoadd -- and then co-add them yourself with imcombine? It looks at a glance like that's what imcoadd does internally anyway; it's a CL script so you can see what core IRAF tasks it calls with which parameters, though unfortunately it is 2000 lines long... I'm having trouble spotting quickly where the cropping occurs, since imcombine itself is called with outlimits="" and it looks like the full pixel range is also specified when calling geotran. This would need a bit more investigation. If you can't make any headway with that, you could send your question to the Gemini helpdesk and one of my colleagues who has studied imcoadd more may have better insight.<br>
<br>
I suspect the "to do" list you mention is rather old and unless Inger has a renewed interest in imcoadd for some reason, it's more likely that we'll provide greater flexibility in future via our pipeline processing in Python.<br>
