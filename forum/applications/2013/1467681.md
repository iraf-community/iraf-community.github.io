<div>
Without knowing the size of your image lists it's hard to give a specific answer.  You sometimes get the message if e.g. the /tmp partition fills up during processing, it can also happen if you run out of file descriptors.<br>
<br>
Since you're looping over loops one way to "free" a list pointer is to set it to a null string when done, e.g.<br>
<br>
<pre><code>
    list = &quot;somefile&quot;
    while (fscan (list, .....) != EOF) {
       ....something
    }
    list = &quot;&quot;           # release the pointer
</code></pre><br>
<br>
The system level number of descriptors could also be raised outside of IRAF using<br>
<br>
<pre><code>
     % limit descriptors unlimited       # for C-shell
or  % ulimit -n unlimited                 # for Bash shells
</code></pre>
