# PSF subtraction problem

{% raw %}
<div>
<span style="color: red">Note: posted on behalf of user by moderator.</span><br>
<br>
I have a problem with daophot. I can't find any answer on the iraf.net forum. If you or somebody can help, I am much appreciated.<br>
<br>
I am working on images of different filters (same field). It is a very crowded stellar field. I follow the standard daophot handbook instruction: run daofind --&gt; phot --&gt; pstselect (interactively) --&gt; psf --&gt; nstar --&gt; substar. The substar image is used to evaluate the psf model. I delete bad stars from pst file and re-iterate with psf --&gt; nstar --&gt; substar. Once the subtraction is clean, I create the final psf model and run allstar.<br>
<br>
I have no problem for getting reasonable subtracted images after running substar for two images. However, problem arises on the third image. The psf model looks normal but the subtracted image doesn't look clean. The bright star has been subtracted but the grouped neighboring stars haven't (see eg: attached screenshot). No matter how many bad stars I delete from the pst file, the result remains the same. I suspect something goes wrong during the run of nstar because most of the outputs look like this:<br>
<br>
Group:   17 contains  4 stars<br>
        Star 21    has been deleted because it is too faint<br>
        Star 81    has been deleted because it is too faint<br>
        Star 37    has been deleted because it is too faint<br>
        ID:    50  XCEN:   138.25  YCEN:    16.40  MAG:    18.34<br>
        ID:    37  XCEN:   155.07  YCEN:    12.41  MAG:    INDEF<br>
        ID:    81  XCEN:   134.32  YCEN:    27.19  MAG:    INDEF<br>
        ID:    21  XCEN:   131.37  YCEN:     7.39  MAG:    INDEF<br>
<br>
I check the magnitude file. Star 21, 37 and 81 have valid magnitude. They are faint in other filters as well. Thus, it doesn't explain to me why it claims to be faint in this filter but not the other. Any idea of why neighboring stars aren't subtracted even though the psf model looks fine? I exercise the same procedures as I did for other two images. I try to change psfrad and fitrad, nothing seems to help.<br>
<br>
Some important parameters that I use.<br>
<br>
datapars:<br>

<br>

<br>
