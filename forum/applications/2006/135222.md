<div>
Package environments are only picked up from either the hlib$extern.pkg file or the unix environment.  Defining the package in your login.cl is sufficient to run it (so long as it is before the final 'keep' statement), however to build it you should do something like<br>
<br>
<pre><code>
unix%  setenv color /data/color/    # trailing &#x27;/&#x27; required
unix%  mkpkg -p color               # assuming you&#x27;re in the color dir
</code></pre><br>
<br>
Be sure the package is first configured for your architecture before building and note that the EXPORT task may already do what you want.<br>
<br>
-Mike
