# PANIC in \`x\_tv.e': Memory has been corrupted

**Stefano Zibetti** wrote on Jan 19, 2006

{% raw %}
<div>
Dear all,<br>
I have the following problem ovarlaying a mask on a displayed image.<br>
When I run a command like this:<br>
display (image=image.fits[0], frame=1, bpmask=, bpdisplay=none, overlay=tmp$mask.pl, ocolors=green, zscale=no, zrange=no, z1=475., z2=712.)<br>
the image displays correctly and the mask is also overlayed, but the process hangs and issues the error message:<br>
PANIC in `[path]/x_tv.e': Memory has been corrupted.<br>
The cl must be killed then.<br>
<br>
Note that the image is a multi-extension fits image that correctly displays without any problem if no mask overlay is requested.<br>
<br>
I am running IRAF V12.2.2 on a customized debian Linux distribution for pc, with kernel 2.6.8-2-686. ds9 is version 3.0.3<br>
<br>
Any hint?<br>
Thanks!<br>
   Stefano
</div>
{% endraw %}

{% raw %}
<div>
This has come up before in cases where the mask is not the same dimension as the image.  While the pixel dimensions may be the same, magnification or the extraction of an image section can affect the logical dimension of the image.<br>
If that's not it, try explicitly saying<br>
<br>
     bpmask=""   instead of just    bpmask=<br>
<br>
especially if you have a BPM keyword in the header.  Since the task is failing at the end (i.e. when pointers are being freed) it likely means memory was corrupted/overrun earlier someplace.  If you've got ElectricFence installed you can use that to better trap the error at the point of the corruption.<br>
<br>
-Mike
</div>
