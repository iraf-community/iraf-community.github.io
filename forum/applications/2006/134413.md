<br>
<pre><code>hselect *.fits $I, expr=&quot;imagetyp == &#x27;object&#x27;&quot; &gt; object_list

**Mike Fitzpatrick** wrote on Feb 07, 2006

{% raw %}
<div>
Just set the 'clobber' CL variable, e.g.<br>
<br>
cl&gt; show clobber     <br>
no<br>
cl&gt; type hlib$motd &gt; foobar<br>
cl&gt; type hlib$motd &gt; foobar<br>
ERROR: cannot open `foobar' for writing<br>
cl&gt; reset clobber = yes<br>
cl&gt; type hlib$motd &gt; foobar<br>
<br>
There is an analogous 'imclobber' var.  Use both with care.<br>
<br>
-Mike
