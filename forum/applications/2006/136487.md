I'll admit I'm not quite sure what it is you're after (visually anyway).  The FIELDS task can extract columns from the output files, and from these you can create a region specification you can input to the MSKREGIONS task in the PROTO package to create a pixel mask.  From there, the DISPLAY task has an 'overlay' paramter that will overlay this mask on the displayed image?  You would need to write a small script to tie all this together, but I think these are the major pieces you need.  Hope this helps.<br>
