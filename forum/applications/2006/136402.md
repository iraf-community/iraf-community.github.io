# Ratio maps for Spitzer spectral maps

**Brian O'Halloran** wrote on Nov 28, 2006

{% raw %}
<div>
Hi there.<br>
<br>
I have some Spitzer IRS mapping data, and I wish to make a ratio map for certain lines - the two maps cover the same physical area (23" x 15") but have different pixel sizes (2.26" vs 4.46"). Does anyone know of an IRAF routine that would allow me to put together a ratio map despite the different pixel sizes?<br>
<br>
Thanks.<br>
<br>
Brian
</div>
{% endraw %}

---

**Mike Fitzpatrick** wrote on Nov 28, 2006

{% raw %}
<div>
I don't know of a single existing task to do this, however the MAGNIFY task can interpolate an image with flux conservation such that an IMARITH/IMEXPR of the new images would produce a ratio image.  Does this help?<br>
<br>
-Mike
</div>
{% endraw %}
