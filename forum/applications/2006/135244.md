<div>
What is your starting point?  HJD is the JD plus the light travel time to the Sun, but to compute that you need an ra and dec.  The equations and code can be found in astutil$asttools/asthjd.x which you could recode as a CL script to find the light time and then just subtract.  If you've got an image with RA and DEC (or just the information) the SETJD task will compute the JD for you.<br>
