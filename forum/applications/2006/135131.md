<div>
Hi Josh,<br>
<br>
I can't tell what is wrong without reproducing this.  My guess is that something is happening when getting the coordinates by executing a command.  What might work better for you is to turn you single command over a list of files into a script loop where in each loop one image is done at a time.  In this loop you could call mscgetcat separately and pass the file to msccmatch or may just doing<br>
what you are doing one exposure at a time with a flpr would be a convenient workaround.  An example of what the loop would look like is<br>
<br>
<pre><code>
list = &quot;list_obj2&quot;
while (fscan (list, s1) != EOF) {
    msccmatch (s1, coords=&quot;!mscgetcat $I $C magmax=20&quot;, nsearch=60,
       search=40, rsearch=1.0, nfit=200, rms=1.0, maxshift=5, verbose+, 
       listcoords-, reject=3, int-)
    flpr
}
list = &quot;&quot;
</code></pre><br>
<br>
Frank Valdes
