<div>
The STSDAS package (and TABLES package) are available from STScI at <a href="ftp://ftp.stsci.edu/pub/sofware/stsdas/stsdas_v3.5">ftp://ftp.stsci.edu/pub/sofware/stsdas/stsdas_v3.5</a> (and .../tables_v3.5).  You'll need to get at least the source distribution in any case, prebuilt binaries for some platforms are available from their archive, binaries for macintel/cygwin are available from the downloads page on this site.  See the installation docs,  you might also just type 'fourier' into the search box on the banner bar to read the package help pages before beginning.<br>
<br>
Cheers,<br>
-Mike
