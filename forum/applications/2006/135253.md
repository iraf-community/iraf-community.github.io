**Mike Fitzpatrick** wrote on Jun 16, 2006

{% raw %}
<div>
<blockquote>Indeed. I did my best; but when I add the following line<br>
,rvsao$lib/helpdb.mip\<br>
to hlib$extern.pkg and try to start IRAF, I get.....</blockquote><br>
<br>
This sometimes means there is a space following the '\' newline escape, or you've added the line in-place-of/outside the quotes of the 'helpdb' string.  The 'reset helpdb...' is all one line of comma-delimited files, be sure there is both an opening/closing quote and no blank lines in between.<br>
<br>
<blockquote><br>
which again I did, so my hlib$extern.pkg now contains:<br>
reset rvsao = /home/iraf/iraf/local/rvsao/rvsao-2.5.0/<br>
task rvsao.pkg = rvsao$rvsao.cl <br>
</blockquote><br>
<br>
This looks fine as long as the path is correct for your system.  From within the CL can you <br>
<br>
<pre><code>
cl&gt; type rvsao$rvsao.cl          or
cl&gt; show rvsao
</code></pre><br>
<br>
without error?  If so the path is correctly defined, if not then be sure these definitions come before the final 'keep' statement which should be the last line in the file.  I just downloaded the 2.5 version to make sure it compiles properly (on RH9 anyway).<br>
<br>
Doug Mink reads this site occassionally and may also comment, note there is also an RV package in the core system that may do what you need.<br>
<br>
Cheers,<br>
-Mike[/quote]
</div>
