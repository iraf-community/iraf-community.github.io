**Francisco Valdes** wrote on Jul 03, 2006

{% raw %}
<div>
Hello Danila,<br>
<br>
Your flat field must have low response (low counts) at some wavelengths.  The only task that does anything special for flat fields is CCDPROC which will limit the values of the processed flat field to be greater than some value set by a parameter and usually defaults to 1.<br>
<br>
RESPONSE does not do this, though you could argue that it should.  What I believe is happening is that when the average flat field spectrum is extracted it<br>
has values near zero.  The process that fits this spectrum to smooth it, in your case a cubic spline of 6 pieces unless you changed the values interactively, will normally including some "wiggles" as it tries to approximate the shape of the spectrum.  These wiggles can cause the fit to go negative where the signal is very low.<br>
<br>
My suggestion is that you apply IMREPLACE after RESPONSE.  This task lets you replace all values below some amount, such as 1, by a constant value, such as 1.<br>
<br>
I hope this explains your problem and gives a good solution.<br>
<br>
Yours,<br>
Frank Valdes
</div>

**Francisco Valdes** wrote on Jul 03, 2006

<div>
Only if the output of RESPONSE contains values less than or equal to zero.  You only get low signal when your spectrum has wavelengths where the CCD is not sensitive or if there is a filter that cuts off before the spectrum goes off the edge of the CCD.<br>
<br>
If you want a simple answer then it is ok to aways use IMREPLACE after response even if it is not needed.<br>
