I believe the usual cause of this behavior is data which has negative values.  In order to calculate errors with the uncertainty model used by splot it assumes the data are in positive counts.  It is true that there is no error message.<br>
<br>
If this is not the cause try searching the forums on this site for similar questions.<br>
