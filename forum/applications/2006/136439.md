**Jacob Albretsen** wrote on Dec 02, 2006

{% raw %}
<div>
Make sure darkcombine.scale = exposure so it uses the exposure time.<br>
<br>
Now, if it REALLY works on your CCD is a different question.  I have a reference in front of me that says their experience is that dark current seldom scales linearly.  <br>
<br>
So before you assume it works for your CCD, I've been told to try a few things.  For example, take 180 second darks and 90 second darks.  Divide by the 180 second by 2, then subtract from the 90 second dark and see if you have anything significant left.<br>
<br>
I have yet to do this myself, but I will probably this week, possibily with a chip that was used on data for your summer project.  :wink:

If "By displaying..." you mean you used the DISPLAY task, remember that the pixel readouts you'll get from DS9 are an approximation based on the z1/z2 scaling and not real values.  This is a limitation in DS9, but if you load the image standalone you'll see real values.  Note that IMEXAM can also be used to access the real pixel values if you DISPLAY the image.  Knine may still be right, don't let the display values fool you though.<br>
