<div>
Scan-from-pipe to an array variable isn't really supported so unless you run IMHIST with a single bin, the answer is no.   You could possibly convert all the values to a single string by removing the newlines from the output, but you'd then be limited by the length of a string variable (1024 char) in how many bins you could use, output to a file is the most general.<br>
<br>
-Mike
