<div>
The .pl file can be treated as an image and so tasks like IMHEAD, HEDIT, etc can manipulate the header to find/create a WCS in the header.  Assuming the file has a WCS something like "cl&gt; listpix test.pl wcs=world" will print the pixels with the WCS coordinates, IMEXAMINE can display the WCS, etc.  Post back if you still have questions.<br>
<br>
-Mike
