# Solution for dispcor having no effect

{% raw %}
<div>
Hello,<br>
<br>
Just wanted to post a non-obvious solution to a dispcor problem I had recently.  I was having trouble gettijng dispcor to do anything to my spectra.  It would run without error, and set the DCLOG keyword properly, but would not apply any wavelength solution.  <br>
<br>
The problem was simply that the image headers had WCSDIM and WAXMAP01 keywords.  I removed these with hedit, and then dispcor worked as expected.<br>
<br>
It would be nice if dispcor gave some feedback that it was going to do nothing because these keywords are present.  <br>
