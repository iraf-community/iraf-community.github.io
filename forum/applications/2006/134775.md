**Mike Fitzpatrick** wrote on Mar 30, 2006

<div>
Sounds like you're executing the 'mkpkg' file itself rather than the command.  Since this is defined as a foreign task be sure that the mkpkg file is not executable and that your .cshrc/.bashrc file defines a path that picks up the mkpkg command first.  This is installed in the same directory as the 'cl' command, do a "which mkpkg" or "cl&gt; !which mkpkg" to find out where it is on your machine.<br>
<br>
Also, I'm assuming you're doing this from the digiphot$phot directory?  Be sure to include the "-p noao -p tables" flags to pick up the needed package environments, that you've defined a $iraf and $IRAFARCH in your .cshrc file, and that you've reset the NOAO package architecture first, e.g.<br>
<br>
cl&gt; cd noao$<br>
cl&gt; mkpkg -p noao redhat        # reset architecture<br>
cl&gt; cd digiphot/apphot              # go to package dir<br>
cl&gt; mkpkg -p noao -p tables update<br>
<br>
The "relink" target doesn't  exist in the phot$mkpkg file,  you'll need to compile from the main apphot dir and use 'update' to install a new binary.  Hope this helps.<br>
<br>
Cheers,<br>
-Mike
</div>

**Mike Fitzpatrick** wrote on Mar 30, 2006

{% raw %}
<div>
All users should be able to run the MKPKG command assuming the permissions on the file aren't restriciting it.  The command is in the same directory as the 'cl' command so first find that directory and the 'mkpkg' symlink.  The link will point t o $iraf/unix/bin.&lt;arch&gt;/mkpkg.e, if the link is wrong or the permissions on this file are restrictive you'll get an error message.  Next is the matter of whether you can modify the iraf installation itself:  I've been assuming you were doing this as 'iraf' or 'root' or whoever owns the iraf files.  If not you should still be able to copy the entire directory tree and recompile it for personal use, but note the package will need to be redeclared to fiind your copy, e.g.<br>
<br>
    % cp -rp $iraf/noao/digiphot/apphot /tmp/apphot<br>
    % cd /tmp/apphot<br>
    % mkpkg -p noao -p tables relink<br>
<br>
and once logged into the CL do<br>
<br>
    cl&gt; task phot = /tmp/phot/xx_apphot.e<br>
<br>
You should then be using the modified version.<br>
<br>
-Mike
</div>
