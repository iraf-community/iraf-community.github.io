Hi,<br>
<br>
The ccdtype parameter maps through the instrument translation file, specified by the parameter "mscred.instrument", to a keyword.  The translation file also provides the mapping between the keyword values and the list of types understood by ccdlist.  Note that in the absence of a translation file the task uses certain defaults which may not be appropriate for your data.<br>
<br>
