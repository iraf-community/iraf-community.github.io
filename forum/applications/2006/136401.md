<div>
This is a bug when the spectrum is log sampled and an image section has been extracted.  The bug log is below.  I don't see an easy workaround.  The user should find an alternative means for modifying the spectrum than using SPLOT.<br>
<br>
Frank Valdes<br>
<br>
<blockquote><br>
NUMBER: 557<br>
MODULE: splot<br>
SYSTEM: -V2.13beta<br>
DATE:   Mon Dec  4 15:29:44 MST 2006<br>
FROM:   valdes<br>
<br>
BUG:    When the dispersion function for a spectrum is log sampled,<br>
        e.g. DC-FLAG=1, and there is also a logical/physical pixel offset,<br>
        i.e. LTV1 is not zero, then writing out a new spectrum with the<br>
        'i' key the results in a wrong WCS.  There is no workaround.<br>
<br>
STATUS: Fixed for a future release.<br>
</blockquote>
