**Guest** wrote on Mar 08, 2006

{% raw %}
<div>
Hi Phil,<br>
<br>
The mkgscindex task uses strfits.  Am wondering if this is picking up on imtype.  Do you have imtype set to "fits"?  Also, if this is a new installation, an unlearn strfits probably won't help - but won't hurt, either.<br>
<br>
&gt; ERROR on line 272: Parameter not a legal character constant (datatype)<br>
<br>
On the other hand, this is coming from cdrfits.  The parameter is question is not used by tfinder, but is rather hardwired to a null string.  Try an "unlearn cdrfits" - this won't work, but try it anyway.  Then edit the tfinder.cl file and delete the datatype="" specification from the cdrfits command line.<br>
<br>
Rob
</div>
