Try doing an "unlearn daofind" (or a new MKIRAF to reinitialize your whole uparm directory).  The clgwrd() func is used in getting parameter values and a corrupt uparm file (or inadvertant edit) could explain it.  In this case the 'boundary' and 'wcsout' parameters use this particular function.<br>

-Mike
