The EXTVER message is bogus due to the way the error recovery is done (this should have been cleared up for TELLURIC in V2.12.2a and later systems).  In any case, the trick is to define an EXTVER header parameter and run the task again, you'll see the real error message which will likely be some other missing keyword.  Hope this helps.<br>
