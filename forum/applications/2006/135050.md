<div>
The epoch returned by the 'a' key is simply the x-axis value of the extreme point in the curve, it is not fit at all to find a more precise value (the amplitude is the<br>
(max-min) value in the data).  I'm not aware of any other tasks that will do this but you might check the list of external packages for ideas (i.e. <a href="http://iraf.net/article.php/20051211115253923)">http://iraf.net/article.php/20051211115253923)</a>.  Others might have suggestions as well.<br>
