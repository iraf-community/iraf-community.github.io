See Section 3.3 of the "CL User's Guide" (<a href="http://docs.iraf.net/cluser/">http://docs.iraf.net/cluser/</a> at about page 18).  It's an old doc but parts of it are actually correct.<br>
<br>
As for the rest, GFIT1D doesn't allow custom axis labels or link with something like the gtools lib that does.  The 'T' command is part of the standard cursor interface (see "help cursors").  You might have a look at CURFIT in the UTILITIES package, it fits the same functions but does link to gtools (and see "help gtools" for more about those commands).  Hope this helps.<br>
<br>
