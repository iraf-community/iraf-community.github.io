What you need to do is create a file to specify for the "graphcur" parameter.  It can just be a file with a single line containing just the letter q.  So you specify the input coordinates with the "imagecur" parameter and graphics command with the "graphcur" parameter.  The last thing you may or may not want to do is to have the graphics appear (do nothing), throw it away (psfmeasure ... G&gt;&gt; dev$null), or capture the graphics in an IRAF metacode file (psfmeasure ... G&gt;&gt; myfile.mc).  In the last case you can then use tools in the plot package to later plot the graphs.<br>
