**Mike Fitzpatrick** wrote on Mar 20, 2006

{% raw %}
<div>
For MSCRED.CCDPROC it is mscred$src/ccdproc.cl, for the NOAO.IMRED.CCDRED.CCDPROC it is ccdred$ccdproc.par (which has a 'max_cache' param your listing doesn't mention so I'm assuming you're listing the mscred version).  The ZEROCOMBINE task is a script wrapper calling the tasks.<br>
<br>
If you get the error from an initialized uparm then there may have been an error in your IRAF or MSCRED install, e.g. the binaries were updated but the source tree wasn't.  The 'bpmasks' param was added for MSCRED V4.3 (Feb01).  Double-check your mscred version and update to the latest if you don't see the parameter list in the source.<br>
<br>
-Mike
</div>
