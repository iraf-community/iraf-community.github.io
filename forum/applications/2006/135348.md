<div>
I think the error is in the last line, i.e.<br>
<br>
<blockquote><br>
KeyError: "Undefined environment variable `crrefer'" </blockquote><br>
<br>
The 'crrefer' is a logical directory used for reference data (e.g. I know it is used for SYNPHOT) and should be defined in the hlib$extern.pkg file along with the STSDAS declaration.<br>
<br>
I'll admit total ignorance about MULTIDRIZZLE so you might also ask the STScI Help Desk at help@stsci.edu since this is their software.  Hope this helps.<br>
<br>
Cheers,<br>
-Mike
