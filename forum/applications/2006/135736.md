<div>
Hi Karen,<br>
<br>
Try starting as "/usr/X11R6/bin/xterm" and see if that makes a difference, if so then you probably just don't have /usr/X11R6/bin in your path.  Command-N does nothing under X by default but you should be able to open as many X apps as you like.  Check also for a DISPLAY environment variable set in your .cshrc/.login file that may be sending the window someplace else.  Do you get an error message when starting on the cmdlin (if so, what?), do you get the prompt back right away, or is it that no window ever shows up?<br>
