**Mike Fitzpatrick** wrote on Jul 31, 2006

{% raw %}
<div>
In your first example:  nclip=0<br>
In your second example: nclip=3<br>
<br>
The 'nclip' parameter controls the number of iterations performed and if non-zero will cause the lower/upper limits to be adjusted.<br>
<br>
If you really want to do statistics through masks, see the MIMSTATISTICS task.  See also the examples in the help page for IMEXPR for ways to create pixel masks based on pixel value.<br>
<br>
Cheers,<br>
-Mike
