<div>
Hi Paula,<br>
<br>
The problem is due to the presence of the diagonal elements of the CD matrix.  Initially the GMOS data had an RA/DEC system.  After processing it is creating a longslit system (wavelength and spatial) where the axes are expected to be independent.  I'm not sure if the fact the CD1_2 and CD2_1 keywords are not removed is a problem in the gemini package or the NOAO/IRAF task which it calls.  The solution is to use HEDIT to remove CD1_2 and CD2_1.<br>
<br>
Yours,<br>
Frank Valdes
