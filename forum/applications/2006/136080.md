<br>
Are you sure the message isn't more like "Warning: OBSGETD: Observatory parameter not found"?  OBSGETD is the name of a procedure used by the task and not a parameter itself, if you're getting an error message from it then there is some error like a missing OBSERVAT keyword in the image, an invalid type for a parameter (e.g. a space in a string, a string where a double belongs, etc).    You can unlearn the OBSERVATORY and ASTUTIL task/packages to reset to the defaults, otherwise check the header and values.<br>

Also, what do you mean by 'confused' about the tek terminal or cl terminal?  Are you in epar or running the task at the time?<br>
