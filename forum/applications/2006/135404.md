**Mike Fitzpatrick** wrote on Jun 29, 2006

{% raw %}
<div>
"$home/foo" is a unix shell variable pathname, "home$foo" is an iraf logical pathname where 'home$" refers to your iraf login directory (i.e. the directory with the login.cl).  You'll need to use the latter syntax if you don't give a full pathname.<br>
<br>
Note the '$' before the taskname on the left of the '=' indicates the task has no parameters,  all task definitions belong before the final 'keep' statement in the login.cl but more properly things like this belong in a loginuser.cl file (again w/ keep as the last line) and will automatically become part of the 'user' package defined in the login.cl along with foreign commands like 'ls'.<br>
<br>
-Mike
</div>
