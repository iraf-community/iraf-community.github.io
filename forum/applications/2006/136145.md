Hello Julia,<br>
<br>
MSCRED is designed to work with multiextension files (MEF) which is a different thing than a multidimensional format.  However, there are tools which can be used to convert between formats.  You might find useful the FITS Kernel document in the Docs section.<br>
<br>
I have never heard of an observatory format for a mosaic such as you describe.  The most common alternative to an MEF is a 2D image where the pieces are pasted into different parts of the image.<br>
<br>
There is a task in MSCRED called MKMSC that was designed for converting the 2D image composite I just mentioned.  However, I believe it could be used with a 3D image since you give arbitrary sections.  So instead of describing the mosaic pieces as [nnn:nnn,nnn:nnn] you might be able to use [*,*,n] where n is a number.  It would also be possible to build an MEF with low level imcopy commands:<br>
<br>
cl&gt; imcopy a[*,*,1] mef.fits[im1]<br>
cl&gt; imcopy a[*,*,2] mef.fits[im2,append]<br>
etc<br>
<br>
You might find getting the headers correct for MSCRED would then be a challenge.<br>
<br>
As far as MSCRED documentation, many of the task are, unfortunately, without help pages.  There is old users kind which is still probably fairly correct.  If you have the mscred package installed then "phelp mscguide".  There are also some useful help pages for setting up the astrometry and a generic mosaic header.<br>
<br>
See<br>
<br>
<a href="http://iraf.noao.edu/projects/ccdmosaic/generic/generic.html">http://iraf.noao.edu/projects/ccdmosaic/generic/generic.html</a><br>
<a href="http://iraf.noao.edu/projects/ccdmosaic/astrometry/astrom.html">http://iraf.noao.edu/projects/ccdmosaic/astrometry/astrom.html</a><br>
<a href="http://iraf.noao.edu/projects/ccdmosaic/mscguide.html">http://iraf.noao.edu/projects/ccdmosaic/mscguide.html</a> (same as mscguide)<br>
<br>
NOAO is finishing a pipeline for data from our Mosaic Imager.  However, this is a complex facility system and is not something for users.<br>
<br>
Good luck,<br>
Frank Valdes
