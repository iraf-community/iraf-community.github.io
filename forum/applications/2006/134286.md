 Dear Janaka,<br>
The "line" parameter in apall refers to the line or column which crosses the dispersion axis at which display (as in the aperture editing) and tracing starts.<br>
<br>
So if dispaxis = 1 the the line parameter is the column for aperture editing and for tracing to start.<br>
