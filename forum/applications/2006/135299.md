<div>
The 'imtgmos' frame buffer is 6400x4644, but from the error messages it looks like you're using the imtgmos4 buffer which is 1600x1161 and was set up for binned images.  With the mscimage fill parameter the display will scale up or down to fit the frame buffer, however GDISPLAY looks for a binning parameter and adjusts the magnification itself.<br>
<br>
Double check your stdimage setting (I think it is an output of the task anyway) as well as binning keywords in the header.  Another possibility is that the frame buffer configuration file being used (/usr/local/lib/imtoolrc is a symlink to iraf$dev/imtoolrc) doesn't have this configuration.  Have a look at the file and check that imtgmos is there and that you're using at least the V2.12.2a release.<br>
<br>
Cheers,<br>
-Mike
</div>
