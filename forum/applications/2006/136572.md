Hi everyone,<br>
I'm a student working on a senior undergraduate thesis, which relies pretty heavily on the xregister routine in IRAF.  I have a few questions on the exact algorithm used, I want to understand it well so that I can talk intelligently about it.<br>
<br>
I'm using the "discrete" correlation function, which has the equations given as:<br>
<br>
correlation = discrete<br>
    <br>
            &lt;I&gt; = SUMj SUMi { I[i+xlag,j+ylag] } / (Nx * Ny)<br>
            &lt;R&gt; = SUMj SUMi { R[i,j] } / (Nx * Ny)<br>
         sumsqI = sqrt (SUMj SUMi { (I[i+xlag,j+ylag] - &lt;I&gt;) ** 2 })<br>
         sumsqR = sqrt (SUMj SUMi { (R[i,j] - &lt;R&gt;) ** 2 })<br>
    <br>
              X = SUMj SUMi { (I[i+xlag,j+ylag] - &lt;I&gt;) * (R[i,j] - &lt;R&gt;) }<br>
                          ----------------------------------------------------<br>
                                       sumsqI * sumsqR<br>
<br>
(from the IRAF help for xreigster).<br>
<br>
My questions are: What are the functions I[i,j] and R[i,j]?  What do the iterators i and j represent?  I assume that xlag and ylag are the shifts computed for each region.<br>
<br>
Also, does "** 2" mean "squared" or "times two"?  It seems like it should mean "squared" to me.  <br>
<br>
Any help you can give me or point me towards is more than appreciated.  Thank you, and have a happy new year.<br>

<div>
Karl,<br>
<br>
If 'I' and 'R' are the input and reference images respectively, then I[i,j] is just the pixel value at (i,j) in the input image.  You can see from the equation for &lt;R&gt; (which is just the mean of the reference image) that the equation is looping over the image dimensions.  The '**2' does indeed refer to 'value squared'.<br>
<br>
If you want to look at the source code for this, see the rg_xconv() procedure at about line 937 of images$immatch/src/xregister/rvxcorr.x   Hope this helps.<br>
<br>
Cheers,<br>
-Mike
