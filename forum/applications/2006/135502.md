<div>
In general a newer external package can be defined in a (really) old IRAF with no problems.  You'll probably want to use pre-compiled binaries if they're available, and I'm assuming it isn't also a really old OS where you might have shared library version issues,  newer code may make use of newer IRAF interfaces/changes and may not always build from source under an old version.  If all of this is pre-1998 then you should have been dealing with Y2K issues for a few years now, upgrading everything should be seriously considered. <br>
<br>
Cheers,<br>
-Mike
