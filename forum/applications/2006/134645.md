**Mike Fitzpatrick** wrote on Mar 10, 2006

{% raw %}
<div>
Most commonly it means that there is an RA/DEC wcs in the image header which the spectral tasks like IDENTIFY can't handle.  It can also happen when there is a dimension mismatch, e.g. the WCSDIM header keyword is '2' for a 1-D image or somesuch.  <br>
<br>
The solution is to remove the coordinate system from the header.  You do this with<br>
<br>
cl&gt; wcsreset &lt;images&gt; wcs=world<br>
<br>
Since the end result of most spectral data reductions is to dispersion calibrate the data the initial RA/DEC system is not needed.  Hope this helps.<br>
<br>
Cheers,<br>
-Mike
</div>
{% endraw %}
