**Mike Fitzpatrick** wrote on Aug 21, 2006

{% raw %}
<div>
Dave,<br>
<br>
Please send me or post your catdb.dat file.  Also note that the ASTCAT package parameter 'catdb' is where you would set the filename, the rest of the tasks inherit that value in their parameters.  To be explicit you could use<br>
<br>
<pre><code>cl&gt; aclist catdb=/tmp/foo</code></pre><br>
<br>
where /tmp/foo is a copy of the catdb.dat with the new change.  If you don't see it that way it may be some silly syntax error in your file.<br>
<br>
Also, from the earlier posting for the entry ( <a href="http://iraf.net/phpBB2/viewtopic.php?t=84843">http://iraf.net/phpBB2/viewtopic.php?t=84843</a> for interested people) you should note that a copy-n-paste directly from there to the dat file won't work.  Specifically, the line beginning with 'query' should include the 'GET', the path, and the 'HTTP' string all on the same line (these were broken out in the posting to separate lines).  Once that was fixed I was able to use it with no problem.<br>
<br>
BTW, related work has been going on in this area.  Expect an announcement in the next few weeks that will make <strong>many</strong> more catalogs available in the system.<br>
<br>
Cheers,<br>
-Mike
</div>

There are two tasks to consider:  mscgetcat uses a different interface and can ONLY access the USNO-A2 catalog servers at noao or cadc.  On the other hand, the mscagetcat (note the 'a') is the one that uses the ASTCAT package but in this case the catdb is hardwired to be astcat$lib/catdb.dat.<br>
