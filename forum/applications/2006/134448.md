Hi Andrew, <br>

Sorry for taking so long to reply... I am the developer of the Nebular package and I'd like to help if I can. I will need a little more to go on, though because the examples I try seem to work for me. If you are just starting to use the <em>temden</em> task, may I suggest that you first use <em>ionic</em> to get an idea of what line emissivities to expect. Then try reproducing the result with <em>temden</em>. <br>
<br>
For example, try <br>
<br>
<pre><code>cl&gt; ionic sulfur 2 temper=10000., dens=1000.</code></pre><br>
<br>
The result will give volume emissivities for a large number of lines, but the relevant ones are: <br>
<br>
6730.78 (2-&gt;1): 2.459E-20<br>
6716.42 (3-&gt;1): 2.157e-20<br>
4076.35 (4-&gt;1): 1.522e-21<br>
4068.60 (5-&gt;1): 4.153e-21<br>
<br>
Taking the ratio of the emissivities from the line pair near 6725 to that for the line pair near 4072 gives 7.6487. Now plugging that into the temden task: <br>
<br>
<pre><code>cl&gt; temden temperature 7.6487 atom=sulfur spec=2 assume=1000</code></pre><br>
Temperature ratio S II: I(6725)/I(4072) = 7.6487<br>
Temperature = 10000.2 K<br>
<br>
Then if you try ratios near that value (e.g., 10.0, 6.0) you will see that you get convergent results. Where, you may ask, do you find out what ratios to use? Try the <em>temden</em> help page, Table 2 (for temperatures). <br>
<br>
Hope this helps. If there are specific examples that should work but do not, please post a reply.<br>
<br>
Regards,<br>
Dick Shaw
