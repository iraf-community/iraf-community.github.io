Most generally, it means there was likely an error with your iraf installation and the x_tv.e binary is not in the right place.  It can also be caused by a permissions problem, e.g. the iraf files aren't generally readable or some directory in the iraf path isn't readable, however these would normally affect the CL binary as well.  Write back if you still have problems.<br>
