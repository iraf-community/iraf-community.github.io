Hello,<br>
<br>
I can help you if you can provide an example for me to reproduce the behavior.  If the files are small you can attach them otherwise you can put them at <a href="ftp://iraf.noao.edu/pub">ftp://iraf.noao.edu/pub</a> and notify me.  Your description seems clear enough and there is not interpolation buffer.  Interpolation is done between the nearest good pixels identified in the mask.  While using the text file is reasonable the bad pixel mask is easier and understood by fixpix.  One suggestion is that you can try to force interpolation along rows or columns to see what difference that makes.  In the mask you do that using mask values of 2 or 3.<br>
<br>
So let me know if I can help you by looking a case or if you have other questions.<br>
