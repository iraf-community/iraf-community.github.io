**Mike Fitzpatrick** wrote on Aug 18, 2006

{% raw %}
<div>
I've verified the file is in the distribution so it must be in the way you installed it.  If none of the NOAO package tasks work the the NB distribution file may have been unpacked in the wrong place, if it's just this one task then may you unpacked using 'winzip' instead of the cygwin unzip (another user earlier reported this produces a  corrupted installation)?  In any case, the file should be in<br>
<br>
/iraf/iraf/noao/bin.cygwin &lt;==&gt; /iraf/irafbin/noao.bin.cygwin<br>
<br>
If it's missing try unpacking the NB distribution again using unzip or<br>
<br>
tar zxvf nb.cygw.tar.gz<br>
<br>
(the 'z' flag uncompresses for you).<br>
<br>
Cheers,<br>
-Mike
</div>
{% endraw %}
