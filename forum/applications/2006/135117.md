<div>
It means either TABLES is not installed, has been defined with an incorrect path (e.g. a missing trailing '/'), or the binaries are missing from tables$bin.macosx/ (or bin.macintel for an OSX Intel system).  Rarely, the file exists but is not executable.<br>

-Mike
