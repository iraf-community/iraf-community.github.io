Hello Christina,<br>
<br>
I am not sure what is causing your problem.  It can be a little confusing because when there are long file names IRAF error messages sometime truncate the name.  So you can't tell if the file name is really being truncated or just the error message.  In any case my suggestion would be to try renaming your data to shorter names and seeing if that solves the problem.  If you can do this that would have two benefits.  One is that you would be able to reduce your data.  The other is that by telling me that long names was the source of the problem the code could be potentially fixed and we would also have a record for other users.<br>
