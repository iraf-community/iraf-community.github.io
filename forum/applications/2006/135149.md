**Mike Fitzpatrick** wrote on Jun 03, 2006

{% raw %}
<div>
Depends, but probably not considering the error is 100 deg^2. How big is the field of view?  How deep is the image?<br>
<br>
The WCSFIXER task (search the site here for information or <a href="http://nvo.noao.edu/wcsfixer">http://nvo.noao.edu/wcsfixer</a> for a direct link) is meant to do this but needs at least an approximate (+/- half the field width) center and scale.  If your FOV is 5 deg or so the algorithm would work but the current reference catalogs would be much too dense.  You could use something like the Yale Bright Star Catalog to identify the field a bit better and manually enter that position, but again it depends on the depth of the field as to whether you have enough stars to match.<br>
<br>
On the non-IRAF side, the IMWCS task in the WCSTOOLS package from SAO does something similar although I've never used it.  Google for a link and similar results or see <a href="http://tdc-www.harvard.edu/wcstools/">http://tdc-www.harvard.edu/wcstools/</a>.<br>
<br>
The idea is either case is the same -- match a reference catalog to a catalog of objects created from the image, compute a plate solution and update the header.  There are tools to help with these steps, but the closer the image catalog is to the portion of the reference catalog you select the better luck you'll have.  Matching 100 image stars to 1,000,000 catalog stars produces too many false solutions (and takes forever to run).  Hope this helps.<br>
<br>
Cheers,<br>
-Mike
</div>
{% endraw %}
