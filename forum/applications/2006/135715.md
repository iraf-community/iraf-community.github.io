<div>
It means you're either not using a graphics terminal (Xterm or XGterm), or you're using an Xterm but told IRAF it was an XGterm (or vice versa).  All graphics tasks (e.g. IMPLOT) should fail similarly.<br>
<br>
Be sure you start IRAF from either an Xterm or XGterm window and set the appropriate terminal type when you do a MKIRAF.  You can reset on the cmdline w/ either<br>
<br>
<pre><code>
cl&gt; stty xgterm
cl&gt; stty xtermjh</code></pre><br>
<br>
(The 'xtermjh' puts the status line in the text window instead of overwriting graphics).  Desktop terminals, e.g. Terminal.app in OSX and gnome-term, kdeterm, rxvt etc for linux, don't normally support graphics and cannot be used.<br>
<br>
Cheers,<br>
-Mike
</div>
