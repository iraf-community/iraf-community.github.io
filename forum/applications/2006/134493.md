# daophot.addstar problem

**Jens Melinder** wrote on Feb 23, 2006

{% raw %}
<div>
Hi,<br>
I'm using addstar in the daophot package to simulate stars (based <br>
on a psf model computed with the psf task).<br>
<br>
The task runs ok, I get no error messages and the resulting <br>
simulated images look nice. I'm adding ~1000 stars to a <br>
~2000*2000 pixel image and the psf model is computed with a <br>
varorder of 2 (i.e. the psf can vary over the frame).<br>
<br>
When I run addstar I add all of the stars using the "simple file"<br>
 option as input (i.e a list with xcoord, ycoord, mag, id) and with all <br>
stars set to the same magnitude. The problem I have appears when<br>
 I do photometry of the simulated stars. I measure the magnitudes <br>
of the stars using aperture photometry (with a radius of ~5FWHM) <br>
and then compare the mean estimated errors to the scatter of the <br>
magnitude distribution. Two things then stand out as being a bit <br>
strange:<br>
1. The mean/median magnitude of the sample is not the magnitude<br>
 I specified in the input file (the measurements give magnitudes <br>
about ~0.3 mags fainter than the input, this increases slightly when<br>
 going towards the noise limit).<br>
2. The scatter of the magnitude distribution is about two times the <br>
mean photometric errors. I would expect the scatter to be the same<br>
 as the mean error more or less.<br>
<br>
Have anyone encountered these problems before? I need to be <br>
able to control the brightness of my simulated sources for the work <br>
I'm doing, so point 2 is really the most problematic thing (1. can be <br>
solved by just remeasuring in the simulated image).<br>
<br>
Would be grateful for any help,<br>
cheers Jens
</div>
{% endraw %}

Hi Jens,<br>
<br>
I'm really not sure how to answer your question.  But, perusing the<br>
source and the docs brings up some questions which you may<br>
consider.  I apologize if the following seems obvious/elementary.<br>
<br>
Using varorder=2 may be the cause of some of your results, e.g.,<br>
while phot'ing, the larger spread would give you less flux.  Hence the<br>
median/mean magnitude of the sample would end up being fainter,<br>
particularly due to those that are affected by the psf variability<br>
order.<br>
<br>
Have you tried with varorder=-1 or 0 to see if you get results that<br>
are closer to what you expect?<br>
<br>
It seems that varorder=2 would also increase the scatter in the<br>
magnitude distribution as a result of decreasing flux for a given<br>
aperture size.  On the other hand, increasing the aperture will give<br>
you more flux, but may end up including nearby stars.<br>
<br>
Hope that helps.<br>
<br>
Phillip Warner<br>
NOAO
