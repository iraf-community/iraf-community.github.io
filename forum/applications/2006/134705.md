<br>
Tracing is the process of centroiding a profile repeatedly at a =20<br>
number of places along the spectrum and then fitting a curve to those =20=<br>
<br>
centroids.  The number of places is set by a t_step parameter while =20<br>
the number of rows or columns averaged before centroiding is given by =20=<br>
<br>
t_nsum.  For the starting point in the centroiding it used the =20<br>
position found in the previous step.  It is required that the next =20<br>
center be within radius of the previous value to avoid jumping to a =20<br>
neighboring profile or noise.  If the centroid is not found in one =20<br>
step it tries going on to the next step to see if it can "recover" =20<br>
the profile.  The number of times it does this before deciding it =20<br>
cannot find the profile is set by t_nlost.<br>
<br>
The curve fitting is used to minimize the noise of the individual =20<br>
centroids and because profiles should generally be a smooth =20<br>
continuous path in the image set by camera and detector distortions =20<br>
and alignment.  Once the curve is found the software can then =20<br>
evaluate where the profile is at every point along the spectrum.<br>
