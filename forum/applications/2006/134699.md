Hi Scott,<br>
<br>
Try resetting your 'stdimage' environment variable so you're using a frame buffer large enough for the image, e.g.<br>
<br>
cl&gt; reset stdimage = imt4096<br>
<br>
will create a 4k x 4k frame buffer when you display, you can then pan/zoom around in the ds9 as needed.  Use the GDEVICES command to list the available frame buffers.<br>
<br>
Cheers,<br>
-Mike
