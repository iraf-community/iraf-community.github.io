The situation gets a little confused because of different versions of  <br>
XImtool and DS9 that people use.  The cursor readback depends on  <br>
certain behaviors of the display servers.  It is likely you are using  <br>
DS9 which does not correctly implement a response to IRAF about its  <br>
capabilities.  There is an easy fix:<br>
<br>
   cl&gt; set disable_wcs_maps=""<br>
   cl&gt; flpr<br>
<br>
You can also put the set command in your login.cl or loginuser.cl.<br>
<br>
Let me know if this does not fix your problem and at the same time<br>
tell be what display server you are using.  For DS9 it is a recent<br>
version that has the problem.<br>
<br>
Yours,<br>
Frank<br>
