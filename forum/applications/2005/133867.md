<br>
Have you looked at pselect?  You can use it to select a subset of the<br>
records using various expressions/constraints (see 'phelp pselect').<br>
<br>
Another task you can use is pexamine.  This task is typically<br>
interactive, though you could probably reduce (and maybe eliminate) the<br>
interactive nature through the use of an image display cursor file or<br>
graphics cursor file.  From the documentation, this seems to write to<br>
two files, one which is an accepted list, while the other is the<br>
deletions list (though you need to specify the name in the<br>
parameters).  See 'phelp pexamine' for more details.<br>
<br>
Once you have a good psf model, you can use substar to subtract the<br>
close neighbors from the image.  This is probably more 'manual' than<br>
you would like, however.<br>
<br>
Another suggestion is to take a look at the version of DAOPHOT written<br>
by Peter Stetson (IRAF/NOAO's daophot is derived from an earlier<br>
version).  I'm not sure how useful it would be in pipelines, but it<br>
may be worth a look.  He's at DAO in Canada; his contact information<br>
can be found at the following URL:<br>
<br>
<a href="http://www.hia-iha.nrc-cnrc.gc.ca/staff/stetson_e.html">http://www.hia-iha.nrc-cnrc.gc.ca/staff/stetson_e.html</a><br>
<br>
Finally, and in case you haven't read it already, there is a DAOPHOT<br>
manual written by Lindsey Davis, which can be found at:<br>
<br>
<a href="http://iraf.noao.edu/iraf/ftp/iraf/docs/daorefman.ps.Z">http://iraf.noao.edu/iraf/ftp/iraf/docs/daorefman.ps.Z</a><br>
<br>
I hope that helps.  Let me know if you have further questions.<br>
