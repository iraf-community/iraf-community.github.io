Hi Venkat,<br>
	The message means exactly what is says:  one or more of your <br>
input images is a different size.  You can use the IMHEAD to verify<br>
the images are all the same size and sections to cutout the same<br>
size region directly, e.g.<br>
<br>
   cl&gt; rgbsun red[1:1282,1:1269] green[1:1282,1:1269] .......<br>
<br>
The task would have died with a different message if the images weren't<br>
2-D.  See also the EXPORT task in the DATAIO package, however it also<br>
requires images to be the same size.  Hope this helps.<br>
