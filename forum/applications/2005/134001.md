Hi Pat,<br>
	The GUIAPPS tasks use the same Gterm graphics/imaging widget as<br>
XImtool and so you're seeing the 8-bit limitation of the widget (i.e.<br>
you're probably using a 24-bit display).  In this case there is no <br>
workaround other than to use an 8-bit display (or put the GUI on a<br>
VNC window running 8-bits).  The XGPHOT task *should* still be usable<br>
with only an xgterm graphics display or noninteractively, but for the<br>
GUI version you'll need an 8-bit visual.  Hope this helps, let us know<br>
if you still have problems.<br>
