Hi Sven,<br>
    The message is bogus and is usually masking another error message.  <br>
To find out what this real error is, define 'isodates' and rerun the task, <br>
e.g.<br>
<br>
    cl&gt; reset isodates = 1<br>
    cl&gt; telluric .......<br>
<br>
most likely you're missing a header keyword of some kind.  Hope this <br>
helps, let us know if you still need help fixing the error.<br>
