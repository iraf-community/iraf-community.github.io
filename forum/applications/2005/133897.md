<br>
The "mean isophotal intensity" values output by task 'ellipse'<br>
are expressed in whatever units the input image pixels are. Say,<br>
if you image has a raw count values tored in each pixel, the INTENS<br>
output value will be an average of raw values computed over the <br>
elliptical isophiote. In other words, you have to calibrate the <br>
values yourself, either before or after you run ellipse your data.<br>
 <br>
Hope this helps. Please feel free to write back directly to me<br>
if you have any questions.<br>
