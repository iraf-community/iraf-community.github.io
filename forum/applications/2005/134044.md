Hi David,<br>
<br>
There were significant changes in the parameters for mscred.combine  <br>
(as well as immatch.imcombine) where the old "plfile" parameter  <br>
disappeared and others were added.  Combine is the core task used in  <br>
other scripts such as zerocombine and mscstack.  You have found a  <br>
mistake in sflatcombine where things were not updated.  mscdither is  <br>
an obsolete task which is not actually in the package at this time.<br>
<br>
The problem you are having must be some mismatch between the mscred  <br>
source installation, the binaries, and your uparm directory.  One  <br>
occasional error people make is in installing a new version of the  <br>
source but not of the binaries.  In this case the binary will request  <br>
a parameter like "plfile" but the source, which has the expected  <br>
parameters as well as scripts, will not have the parameter.  So check  <br>
that you have the right binaries.  The other problem with the uparm  <br>
contents is solved either by doing a "mkiraf" (from Unix) to recreate  <br>
the directory or doing unlearns of tasks and packages.  It seems you  <br>
have at least tried the unlearn route.<br>
<br>
Let me know if you have questions or can't resolve the problem from  <br>
these thoughts.<br>
