Q:	I have a question concerning the colbias command in the noao.bias<br>
	package of IRAF. I am working with a telescope which uses columns<br>
	1-48 and 2096-2158 as overscan regions. The bias is found by the<br>
	colbias command. I was wondering if it is poissible to set up the<br>
	parameters in such a way that both sections (so 1-48 and 2096-2158)<br>
	are used for this purpose. Could you help me with this question?<br>
<br>
A:	It is not common to use both the prescan and overscan columns at<br>
	the same time.	The standard IRAF tasks for handling bias (colbias<br>
	and ccdproc) do not allow use of more than one contiguous region<br>
	for bias.  However, if you wish to do so you can use FIT1D to do<br>
	what you want.	The parameters I recommend are:<br>
<br>
					   I R A F<br>
			    Image Reduction and Analysis Facility<br>
	PACKAGE = imfit<br>
	   TASK = fit1d<br>
<br>
	input   =                       Images to be fit<br>
	output  =                       Output images<br>
	(axis   =                    1) Axis to be fit<br>
	type    =           difference  Type of output (fit, difference, ratio)<br>
	(interac=                   no) Set fitting parameters interactively?<br>
	(sample =       1-48,2096-2158) Sample points to use in fit<br>
	(naverag=                 -100) Number of points in sample averaging<br>
	(functio=            chebyshev) Fitting function<br>
	(order  =                    2) Order of fitting function<br>
	(low_rej=                   0.) Low rejection in sigma of fit<br>
	(high_re=                   0.) High rejection in sigma of fit<br>
	(niterat=                    1) Number of rejection iterations<br>
	(grow   =                   0.) Rejection growing radius in pixels<br>
	(graphic=             stdgraph) Graphics output device<br>
	(cursor =                     ) Graphics cursor input<br>
	(mode   =                   ql)<br>
<br>
	The type of "difference" subtracts the bias, the "sample"<br>
	parameter defines the data to use for the bias.  The value of<br>
	-100 says to take the median of each bias region (a median is<br>
	good to avoid bad pixels and cosmic rays), and the function and<br>
	order fit a line between the two regions.  The value of the fit<br>
	is subtracted from each pixel in the image.   Read the help page<br>
	for this task for the various options.<br>
<br>
	To later trim away the bias regions you would use imcopy with image<br>
	sections.<br>
<br>
	cl&gt; imcopy &lt;image&gt;[49:2095,*] &lt;newimage&gt;<br>
