Venkat,<br>
	The Sun rasterfile format has an assumed byte order.  I'm<br>
guessing you're running this on a linux PC of some kind?  If so<br>
you can correct the file for the local byte order using the REBLOCK<br>
task as in<br>
<br>
	cl&gt; reblock orig.ras fixed.ras byte- word+<br>
<br>
XV should then be able to handle the rasterfile.<br>
