Hello Yan,<br>
<br>
It is not common to use both the prescan and overscan columns at the  <br>
same time.  The standard IRAF tasks for handling bias (colbias and  <br>
ccdproc) do not allow use of more than one contiguous region for  <br>
bias.  However, if you wish to do so you can use FIT1D to do what you  <br>
want.  The parameters I recommend are:<br>
<br>
                                    I R A F<br>
                     Image Reduction and Analysis Facility<br>
PACKAGE = imfit<br>
    TASK = fit1d<br>
<br>
input   =                       Images to be fit<br>
output  =                       Output images<br>
(axis   =                    1) Axis to be fit<br>
type    =           difference  Type of output (fit, difference, ratio)<br>
(interac=                   no) Set fitting parameters interactively?<br>
(sample =       1-48,2096-2158) Sample points to use in fit<br>
(naverag=                 -100) Number of points in sample averaging<br>
(functio=            chebyshev) Fitting function<br>
(order  =                    2) Order of fitting function<br>
(low_rej=                   0.) Low rejection in sigma of fit<br>
(high_re=                   0.) High rejection in sigma of fit<br>
(niterat=                    1) Number of rejection iterations<br>
(grow   =                   0.) Rejection growing radius in pixels<br>
(graphic=             stdgraph) Graphics output device<br>
(cursor =                     ) Graphics cursor input<br>
(mode   =                   ql)<br>
<br>
The type of "difference" subtracts the bias, the "sample" parameter  <br>
defines the data to use for the bias.  The value of -100 says to take  <br>
the median of each bias region (a median is good to avoid bad pixels  <br>
and cosmic rays), and the function and order fit a line between the  <br>
two regions.  The value of the fit is subtracted from each pixel in  <br>
the image.   Read the help page for this task for the various options.<br>
<br>
To later trim away the bias regions you would use imcopy with image  <br>
sections.<br>
<br>
cl&gt; imcopy &lt;image&gt;[49:2095,*] &lt;newimage&gt;<br>
<br>
