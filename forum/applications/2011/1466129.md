Hello,<br>
I'm doing aperture photometry with phot on iraf. I want to do the following:<br>
<br>
phot &lt;images&gt; &lt;coordfile&gt; fwhm=&lt;""&gt; ann=&lt;""&gt; dann=&lt;""&gt; aper=&lt;""&gt;<br>
<br>
I know it is possible to do this with a list of images with ll the same values of fwhm,ann, dann,and apper. I was wondering if there was a way I could do this with a list to have different value of fwhm,ann,dann,and aper for each image. <br>

{% raw %}
<div>
To do what you want you would need to write a script that processes a list of the filenames and values.  For example,  if you have a file containing lines such as<br>
<br>
<pre><code>image.fits coords.txt  2.5 5.0 1.0 3</code></pre><br>
<br>
You could loop over a list of these with something like<br>
<br>
[cpde]<br>
string   img, coord, aper<br>
real      fwhm, ann, dann<br>
<br>
list = "values.txt"<br>
while (fscan (list, img, coord, fwhm, ann, dann, aper) != EOF) {<br>
   phot (img, coord, fwhm=fwhm, ann=ann, dann=dann, aper=aper)<br>
}<br>
[/code]<br>
<br>
For more on scripts see <a href="http://iraf.net/irafdocs/script/">http://iraf.net/irafdocs/script/</a>
</div>
{% endraw %}
