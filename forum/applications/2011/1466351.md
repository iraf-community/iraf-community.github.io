**Mike Fitzpatrick** wrote on Mar 28, 2011

{% raw %}
<div>
I was able to reproduce the problem on a v2.15 32-bit linux system and tracked it down to a likely cause.  The key thing missing was that the 'grow' parameter had to be set to non-zero in order to trigger the error.<br>
<br>
Frank is looking into a solution now and we should have a patched binary soon.  Until then, if you don't need to set the 'grow' parameter then it appears to work fine.
</div>
{% endraw %}
