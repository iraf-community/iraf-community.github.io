<div>
When you use the <pre><code>cl&gt; reset stdimcur=text</code></pre> trick you need to remember that even though you are entering the input from the terminal window, it must still be in the format of a cursor read, i.e.<br>
<br>
<pre><code>x y wcs key</code></pre><br>
<br>
For example,<br>
<br>
[quote]<br>
<br>
ecl&gt; reset stdimcur=text<br>
ecl&gt; imexam dev$pix 1<br>
image display cursor input: 100 100 1 z<br>
[/code]<br>
<br>
As for why DS9 doesn't read this directly:  Some versions of DS9 had cursor reads broken so you should check that you're using the latest version and/or that you ran the iraf install script on the machine.  If you're sure it's not an input focus issue, then you might also try restarting DS9 and the CL since there are time where it "loses sync" with the cursor read pending.
</div>
{% endraw %}
