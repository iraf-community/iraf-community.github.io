# Copying Headers in Mosaic1.1 Files

**RLBeaton** wrote on May 27, 2011

{% raw %}
<div>
Hello, <br>
<br>
On a recent KPNO+Mosiac1.1 run, many of my exposures did not have headers. I have been attempting to copy the header from one file to the pixels for another file and then edit the required fields with mscred.ccdhedit<br>
<br>
My first attempt was to use stsdas.toolbox.imgtools.moveheader <br>
It worked - but also copied the ext1 pixel file to the ext0 header file, which is causing problems in image processing in mscred. <br>
<br>
I'm looking for a solution that could take one of the following forms:<br>
(i) remove extra pixel information from ext0;<br>
(ii) a more effective means at copying the header.<br>
<br>
I could also use a combination of mscsplit and mscjoin to copy ext0 -- but I was trying to avoid having to split up the files in case that might have other consequences.<br>
<br>
Any help would be appreciated!<br>
-Rachael Beaton<br>
UVA Astronomy
</div>
{% endraw %}

<div>
For what its worth, here is the solution we found: <br>
<br>
This will copy the header from n204251 into n204252_nohead.<br>
Of course, you'll want to make a copy of n204252_nohead first.<br>
<br>
&gt; msccmd "mkheader $input $in1 append- verbose+"<br>
Input files: n204252_nohead<br>
Second list of input files: n204251<br>
