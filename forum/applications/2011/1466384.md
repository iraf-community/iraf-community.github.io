<div>
The ambiguous parameter message usually means that you are using an undeclared variable which matches with something in the package or the cl.  This could also happen when you accidentally have a typo such that a variable is an abbreviation that matches a variable in your script and in the cl.<br>
<br>
However, the error you show doesn't seem to be naming a real variable so maybe a comment marker is missing in a comment.  If you want to send the script (valdes@noao.edu) I might be able to deduce the source of the error.<br>
<br>
The failure trace you should is probably not really relevant to the error you are showing.<br>
<br>
Frank Valdes
