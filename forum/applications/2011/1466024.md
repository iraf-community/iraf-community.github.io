Typing 'd_trace' before executing a script task will produce lots of output telling you exactly what command is being executed, you can use this to track down the floating point error.  This could be either a bug in a task or something data-related but its impossible to say without even knowing what task is failing.<br>

There have been several other questions about the WIFES package posted recently, use the search box on the banner bar to find them.  Hopefully one of those users can post a solution, but your best bet may be to contact the WIFES project or the original script developers.
