{% raw %}
<div>
Dear all,<br>
<br>
is IRAF splot supposed to be able to read log-resampled spectra properly? I created some with my own software and found that splot displays what I think are wrong wavelengths. It could be that I understood the FITS WCS papers (especially "Representations of spectral coordinates in FITS") wrongly but I'm not sure...<br>
<br>
An example spectrum is at <a href="http://www.aip.de/People/PWeilbacher/spec_log.fits">http://www.aip.de/People/PWeilbacher/spec_log.fits</a>, the relevant header keywords are<br>
<br>
<pre><code>NAXIS   =                    1
NAXIS1  =                 1036
CRPIX1  =                   1.
CD1_1   =              0.78125
CTYPE1  = &#x27;AWAV-LOG&#x27;
CUNIT1  = &#x27;Angstrom&#x27;
OBJECT  = &#x27;Test (DATA)&#x27;
CRVAL1  =                5530.</code></pre><br>
<br>
Any hints?<br>
   Peter.

As you surmised, the IRAF spectroscopy system predates the FITS work on spectral coordinate system by decades and updates to the IRAF coordinate systems is, unfortunately, pretty low priority in such a stable system.  Logarithm coordinates are supported.  In your example you need to<br>
<br>
<pre><code>
DC-FLAG =                    1
CRVAL1  =      3.7427251313047   (log10(5530.))
CD1_1   =   6.1350560486062E-5 (log10(5530.+0.78125)
</code></pre><br>
<br>
This could certainly be automated easily in IRAF if there is a lot of data.<br>
<br>
Yours,<br>
Frank Valdes
