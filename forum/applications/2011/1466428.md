Hi Pat,<br>

What you want to do is very easy with newfirm.combine.  This task was designed with the concepts of multiple extensions.  The default parameters will combine each matching extension in an MEF into an output MEF with the same set of extensions.  This is what you are wanting to do.  I realize that the full description of combine can be daunting because it has so many ways to do things but that is what allows it to address the various data reduction applications.<br>
<br>
Msccmd and imcombine could be used to do what you want but it was not really intended for this use.<br>
