<div>
You didn't say specifically what you've been reading, but see section 3.7 of "cl&gt; help cursors" for the description of a coordinate input file.  This is what you would use to pass in e.g. the 'a' command to imexam in a batch mode.<br>
<br>
Note that many of the functions in imexam have task equivalents (e.g. the 'a' key could be done with apphot tasks).  If you still have questions, please post an example of what you're trying to do.

**Mike Fitzpatrick** wrote on Jan 21, 2011

{% raw %}
<div>
Host programs can be used in scripts by declaring them as 'foreign tasks', e.g. in your login.cl you would declare a task as e.g.<br>
<br>
<pre><code>task $fixit = /path/fixit.sh</code></pre><br>
<br>
Otherwise I'm not clear on exactly how you're creating the coords files, but I can imagine a loop that get the coords and write out the new coord file each time it is needed.

<div>
Do you mean you set the 'stdimcur' environment variable to the name of a cursor file, or actual text values?  A task like IMEXAM has it's own 'imagecur' parameter which must also be set to a cursor file.<br>
<br>
A cursor file contains simply "x y wcs key" values one per line, how you convert your coordinate lists into this format is up to you.
</div>
