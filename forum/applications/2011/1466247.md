<div>
The key step is modifying the wavelength solution to account for the geocentric velocities.  The task RVCORRECT can be used to calculate a correction and DOPCOR can be used to modify the wavelength solution (without actually rebinning).  What you need to do is correct to the same standard of rest (say to heliocentric).  The last step for coadding is to use SCOMBINE.  This will use the corrected wavelength solutions to resample to a common pixel sampling before coadding.<br>
