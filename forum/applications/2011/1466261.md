# Ellipse cursor command in non-interactive mode

**Juan Carlos** wrote on Mar 09, 2011

{% raw %}
<div>
Hi,<br>
<br>
I've just emailed this question to the STS helpdesk, but I thought I would also post it here as well, in case anyone can help me.<br>
<br>
Problem summary<br>
-------------------------<br>
ellipse doesn't seem to read the image cursor command file when run<br>
non-interactively<br>
<br>
Full description<br>
--------------------<br>
I am using the Iraf task ellipse to perform surface photometry in a<br>
large set of images of nearby galaxies. The task is run<br>
non-interactively within a cl script, which basically reads initial<br>
guesses for the ellipticity and position angle for each galaxy from a<br>
catalog, and then uses those values as initial values for the ellipse<br>
fit (the ellipticity and PA are then left as free parameters during<br>
the fit). The intial semimajor axis is set to an intermediate value,<br>
to ensure that there's enough S/N but without going too close to the<br>
galaxy center.<br>
<br>
In many cases -especially in galaxies with very large apparent sizes-,<br>
ellipse seems to become quite sensitive to the initial values, so that<br>
very slight variations will quickly yield an error code 4. Increasing<br>
the number of iterations and maxgerr helps sometimes, but in general<br>
the problem persists. If I run ellipse interactively and re-fit the<br>
first ellipse, then the fit goes on correctly from there. Since I need<br>
to run this task in batch mode for a large number of images, I created<br>
a simple text file with the re-fit command "f", and used it as an<br>
image cursor command file. However, I've noticed that ellipse will<br>
only read that file when run interactively. If I do so, it will read<br>
the command file and re-fit the first ellipse as indicated, and then<br>
proceed from there. But if I set "interac" to "no", the command file<br>
will be ignored and the first ellipse won't be re-fitted.<br>
<br>
Of course, running ellipse interactively increases the execution time,<br>
even with a small display buffer size. I've tried adding "c" below "f"<br>
in the command file to prevent ellipse from plotting subsequent<br>
ellipses, but I still have to wait for the image and the bad pixel<br>
mask to be loaded, which takes a while. I would therefore appreciate<br>
any help on how to make ellipse read the cursor command file when run<br>
non-interactively.<br>
<br>
Thanks!<br>
Juan Carlos
