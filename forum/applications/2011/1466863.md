**Mike Fitzpatrick** wrote on Jul 14, 2011

{% raw %}
<div>
The message generally means that either you don't have write permission in the current directory to create a new file, or else 'shifts.dat' already exists and you are trying to overwrite it.  If you meant to append, use the "&gt;&gt;" operator (I realize you didn't write the script), otherwise you can set the 'clobber' variable to allow overwriting existing files.
</div>
{% endraw %}
