<div>
It doesn't sound like you want to "normalie" the spectra (i.e., divide by the continuum); rather what you want to do is just scale each spectrum using the flux around 5100.  <br>
<br>
If I were doing this, I would first use "sbands" with a constant filter function<br>
from 5000-5200.  Once you have the average flux, you could easily write a script that grabbed the numerical value and divided that into each spectrum using sarith.
