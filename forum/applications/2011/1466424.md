<div>
In case you haven't discovered the answer to lists ...<br>
<br>
Many programs ask for a list of images/files.  What this means is either<br>
<br>
- a comma separated list: a,b,c<br>
- a wildcard template: f*fits<br>
- a file containing the names of the files:  @list.dat<br>
- or some combination of these: a,b,@c.dat,d*<br>
<br>
Note that you use the character @ to indicate that the file names are contained in the specified file.<br>
<br>
This applies to more than 90% of tasks.  There are a few oddballs, usually written by a novice, where the argument is expected to be the file itself (e.g. list.dat).  Those are rare and, hopefully, the parameter prompt or help is clear.<br>
<br>
