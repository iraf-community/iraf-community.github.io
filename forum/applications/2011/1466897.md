{% raw %}
<div>
It means you're not actually using an XGterm window to run iraf.  If you're using an XTerm then you can do a MKIRAF and change the terminal type, or do<br>
<br>
<pre><code>cl&gt; stty xtermjh ; gflush</code></pre><br>
<br>
on the commandline to change it.  Terminals like rxvt, gnome-terminal, Terminal.app, etc do not support graphics and cannot be used for plots.
</div>

{% raw %}
<div>
You can do a MKIRAF and reset the default terminal type at any time, this just recreates the login.cl file.  Keep in mind however, this does NOT install xgterm for you or cause one to be started, it is simply your way of telling IRAF that you have logged in using an XGterm teminal window, but installing xgterm on your machine and starting it are up to you.

**Mike Fitzpatrick** wrote on Jul 19, 2011

{% raw %}
<div>
<blockquote>Is there anyway of having the Xterm automatically start when one starts iraf?</blockquote><br>
<br>
Not really, since the point is that you start iraf from within the xterm/xgterm window they need to be running first.  You can however do<br>
<br>
<pre><code>xterm -e cl</code></pre><br>
<br>
(or with 'xgterm') and have the xterm/xgterm window startup IRAF for you (assuming you do this from a directory with a login.cl file).[/quote]
</div>
