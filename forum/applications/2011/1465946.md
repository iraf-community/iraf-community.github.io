The message basically means there was an error in the COPY task and communication with the CL was terminated.  You can type 'd_trace' before running the task (or insert a print statement in the script) to find out exactly what the parameters are, if you can then reproduce this behavior outside the script then I'll need to know more about the file (or have access to it) to reproduce and debug the problem.  If it only happens in the script then it could be an error in the script of some kind.<br>
