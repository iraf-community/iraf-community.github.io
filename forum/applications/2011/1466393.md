The DATE-OBS keywords are correct (it includes the correct date and time) but the RA,DEC,EPOCH,ZD,HA,ST and airmass are wrong. I was able to use hfix to fix the EPOCH,RA and DEC but I need to fix the remaining headers. Is there any way to correct the airmass but by only using the information from DATE-OBS? <div>
Assuming that by "fix the HA and ST" you mean you need to compute these values for the given DATE-OBS and observatory, then have a look at the ASTHEDIT task.  You can setup an expression file using the builtin functions to compute these values as well as the airmass.
