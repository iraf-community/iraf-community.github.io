Hello Sebastian,<br>

I don't have much experience with the photometry tools I think you need nor did I write them.  What I think you need is the digiphot.polyphot task which allows you to define special apertures for aperture photometry.  The "experimental" graphical photometry xapphot can be used for this type of photometry as well.<br>
<br>
What I don't know is how easy it is to apply these tools to larger volumes of data (number of sources and number of frames).<br>
<br>
I hope this helps.<br>
