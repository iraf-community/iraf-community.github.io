<blockquote><br>

MODULE: apall,<br>
SYSTEM: V2.15<br>
DATE:   Mon Mar  5 08:51:03 MST 2012<br>
FROM:   valdes<br>
<br>
BUG:    The optimal extraction for significantly tilted spectra, the Marsh<br>
        algorithm, has bug which manifests only under 64-bit architectures.<br>
        The symptom is a crash, usually a memory or segmentation panic.<br>
        The only workarounds are 1) go to an 32-bit system or 2) don't<br>
        use the optimal extraction option.<br>
<br>
STATUS: Fixed for V2.16.<br>
</blockquote>
