It's probably just a case of I/O buffering not syncing to disk before task exits (abnormally).  I've added a flag in the next update so the log file gets flushed each time it is written to, until then you would need to periodically use ":nolog" and ":log" to close (and flush) the file then reopen it for appending, i.e. to checkpoint the results written so far.<br>
