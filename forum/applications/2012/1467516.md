<br>
<blockquote>Also something confusing is going on with the help databases for this task. Using ctio's apropos task, you get</blockquote><br>
<br>
The CTIO package has been orphaned for a while and the APROPOS task hasn't been touched since 1991.  You can try using MKAPROPOS to rebuild the database it uses, otherwise I'd chalk it up to changes in the help code over the last two decades.  The core system provides a REFERENCES task that serves the same purpose.<br>
<br>
Tasks are often included in multiple packages, duplicate help pages come about when a task used to live in an external package and then gets moved to the core system.  Differences in the help page may reflect differences in the code itself (e.g. the old extpkg version has a special parameter for some reason), but it doesn't necessarily mean it is an error.
