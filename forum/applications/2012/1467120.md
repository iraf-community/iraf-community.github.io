# New version of the Gemini IRAF package released (v1.11)

**emma** wrote on Jan 05, 2012

{% raw %}
<div>
A new version of the Gemini IRAF package (v1.11) has been released.<br>
<br>
The package is available for download at:<br>
<br>
    <a href="http://www.gemini.edu/sciops/data-and-results/processing-software">http://www.gemini.edu/sciops/data-and-results/processing-software</a><br>
<br>
Please note that this version of the Gemini IRAF package does NOT support the<br>
new GMOS North e2v CCDs. However, this release is the foundation for the<br>
upcoming patch that will provide full support for the new GMOS North e2v CCDs.<br>
PIs with new GMOS North e2v data should install v1.11 of the Gemini IRAF<br>
package in preparation for the upcoming patch. Due to the unexpected use of<br>
6-amp mode, the gmos package has undergone many changes to ensure compatibility<br>
with 6-amp data. Characterization of the new CCDs (e.g., accurately measuring<br>
the gain) is still to be completed, along with the scientific verification of<br>
the code for the new GMOS North e2v CCDs.<br>
<br>
The highlights of this release are:<br>
<ul><br>
- Support for the re-built GNIRS that is now installed at Gemini North<br>
- Removed compatibility constraints on fitsutil<br>
- Removed the dependency on the external package nmisc<br>
- Full compatibility with IRAF v2.15<br>
</ul><br>
A detailed list of the changes relative to v1.10 can be found in the release<br>
note:<br>
<br>
    <a href="http://www.gemini.edu/sciops/data/software/gemini_v111_rev.txt">http://www.gemini.edu/sciops/data/software/gemini_v111_rev.txt</a><br>
<br>
Many thanks,<br>
<br>
Emma :)
