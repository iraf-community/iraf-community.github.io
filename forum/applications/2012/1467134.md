<div>
The RVSAO package has been around quite a while and the version installed by the "make rvsao" in v215 is the 32-bin binary distributed by SAO for the latest release (and so can't be a 64-bit issue).  If other tasks in the core system (e.g. IMSTAT or IMPLOT) have similar problems then it may be data-related and you should upload the image to <a href="ftp://iraf.noao.edu/pub">ftp://iraf.noao.edu/pub</a> and I'll have a look, otherwise it may be a bug in RVSAO itself and you should contact SAO (dougmink@cfa.harvard.edu) with the parameters you used and the data file so they can investigate.
