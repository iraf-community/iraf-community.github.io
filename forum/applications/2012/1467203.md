**Mike Fitzpatrick** wrote on Feb 28, 2012

{% raw %}
<div>
This problem was fixed just recently for the upcoming release, you can get a patched v2.15 IMAGES binary and library from<br>
<br>
<a href="ftp://iraf.noao.edu/iraf/v215/support/macintel/x_images.e">ftp://iraf.noao.edu/iraf/v215/support/macintel/x_images.e</a><br>
<a href="ftp://iraf.noao.edu/iraf/v215/support/macintel/libex.a">ftp://iraf.noao.edu/iraf/v215/support/macintel/libex.a</a><br>
<br>
Download these in binary mode and install in your $iraf/bin.macintel directory.  The images binary will fix the imtranspose problem immediately, however since this problem affects all tasks you'll also want to get the libex.a file so you can relink your system and external packages.<br>
<br>
To relink:<br>
<br>
<pre><code>
% cd /iraf/iraf/         # go to the iraf root
% make macintel      # reset the architecture
% make update        # relink
</code></pre><br>
<br>
External packages will need to be updated as well, let me know if you have questions about how to do that for a particular package (the details will vary).
</div>
