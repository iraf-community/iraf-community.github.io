# imexpr question

**svensk** wrote on Jul 08, 2010

{% raw %}
<div>
IRAF newbie here.<br>
<br>
I am trying to use imexpr to do some pixel replacements.<br>
<br>
My function:<br>
<br>
cl&gt; imexpr "(a &gt; 70000) ? 10*b : a" c<br>
<br>
simply replaces an overexposed pixel from "a" with a properly exposed and scaled pixel from "b". This works as expected on a single image set, assuming they are named "a" and "b" but I'd like imexpr to do this to a list of files.<br>
<br>
So I thought:<br>
<br>
cl&gt; imexpr "(a &gt; 70000) ? 10*b : a" @final<br>
operand a: @long<br>
operand b: @short<br>
<br>
but I get an error after the operand a prompt that says<br>
<br>
ERROR: Cannot open image (@long)<br>
<br>
Can operands not be lists? How should I be rethinking this? Any help is greatly appreciated.<br>
<br>
Thanks!
</div>
{% endraw %}

**Mike Fitzpatrick** wrote on Jul 08, 2010

{% raw %}
<div>
Right, operands must be single images or values.  To work on lists you'll need to write a small script to process the list with repeated calls to imexpr, e.g.<br>
<br>
<pre><code>
cl&gt; list = &quot;myfile.txt&quot;
cl&gt; while (fscan (list, s1) != EOF) {
&gt;&gt;      imexpr ( ....., a=s1, .... )
&gt;&gt; }
</code></pre>
</div>
{% endraw %}
