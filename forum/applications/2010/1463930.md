**Mike Fitzpatrick** wrote on Mar 23, 2010

<div>
The answer depends on which SDSS catalog you want to access, and specifically whether there is a simple http GET url to access it.  The database of services is defined by the ASTCAT 'catdb' and 'imdb' package parameters, see "help catalogs" and "help surveys" for a description of the format.  In the longer term, access to all VO data services is planned.
