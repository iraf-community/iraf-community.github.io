<div>
The 'apertures' parameter can be specified as a command delimited list of range strings, e.g.<br>
<br>
<pre><code> &quot;1,3,5-9,11,13-17&quot;</code></pre><br>
<br>
and needn't be just a single value.  When you do it like this you can use the 'n' keystroke to move to the next aperture in the list automatically, and when the aperture list reaches its end you move to the next image with a fresh list.<br>
<br>
Using the ":apertures" command with an argument causes the list to be reset and the image re-opened.  I'm not sure why you'd see an image name prompt, but let me know if the above doesn't solve your problem.<br>
<br>
-Mike
</div>
{% endraw %}
