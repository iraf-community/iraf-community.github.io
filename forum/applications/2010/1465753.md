Hi Ed,<br>
<br>
This (changing what goes into the header) is something that someone at CTIO must have done.  I don't know about the file you reference or where it might be located.   As you say it is not in the mscdb$ files.  I'm not sure who to ask but it might be Andrea Kunder or Tim Abbot.  I've not have anything to do with the data taking system at CTIO for many years.<br>
<br>
It is certainly reasonable to do what you did to "fool" the code.  You can also just tell ccdproc to use a particular file rather than referencing the value of a keyword in the header.  Since the crosstalk file is independent of the extension there is no real need to use the header keyword to get different values for different extensions.  Or you could edit the header of course.<br>
<br>
But there must be a good reason for the alternate file.  In particular, the crosstalk for 16 vs 8 is definitely different.<br>
<br>
Good hunting,<br>
Frank<br>
<br>
If you find out anything I would be interested though it seems I ought to make an inquiry myself.
