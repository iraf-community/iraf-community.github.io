# tiltpars (fortran executable in iraf)

**ebubar** wrote on Sep 14, 2010

{% raw %}
<div>
I wonder if anyone can help with this.  I am reducing some MIKE echelle spectra using the mike_tools packages.  I've reached the point where I am correcting for the tilt of the slit using a fortran program called tiltpars.  It is compliled and I have linked to it using:<br>
task tiltpars=location/./tilpars<br>
<br>
This gives me an error:<br>
ERROR: task 'tiltpars' has no param file<br>
<br>
I assume I need to link somehow so that IRAF knows its a fortran executable, not an IRAF package.  Any insight?
</div>
{% endraw %}

**ebubar** wrote on Sep 14, 2010

{% raw %}
<div>
If anyone else runs into this, I seem to have fixed the problem.  I needed to first include the path to my tiltpars executable in my .bashrc:<br>
In my case:<br>
PATH=$PATH:/Applications/scisoft/all/Packages/iraf/mike_tools/iraf/:$PATH<br>
<br>
I also added an alias to my executable:<br>
alias tiltpars='/Applications/scisoft/all/Packages/iraf/mike_tools/iraf/./tiltpars'<br>
<br>
Finally, I loaded this into IRAF using the $foreign option...<br>
<br>
task $tiltpars=$foreign <br>
<br>
which I believe tells IRAF that the command tiltpars isn't an IRAF script.
</div>
{% endraw %}
