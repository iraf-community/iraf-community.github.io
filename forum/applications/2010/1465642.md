I don't understand this last command, there is already a iraf$bin.redhat symlink pointing to bin.linux.<br>
<br>
The proiblem with building a static binary for ECL is that the readline library used (which required ncurses/termcap) makes other system calls that newer GCC versions say can only be used in a dynamic binary.  If you ignore the compilation warnings, a static binary can be built, but I haven't tested whether it actually works.
