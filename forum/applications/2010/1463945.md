<div>
I don't really have anything further to add.  As the references point out, once an aperture is defined it may be adjusted in various ways -- shift it, change the width, shift the edges without moving the center, etc.   This is done interactively in the aperture editing stage or, if you want to by-pass the graphical mode, you can edit the text file database that contains the aperture descriptions.  The definition of an aperture is pretty straightforward.<br>
