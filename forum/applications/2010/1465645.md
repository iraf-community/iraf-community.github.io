I've been using nfit1d to carry out fits to galaxy light profiles (galprof parameter), but I will most likely have to carry out about 120,000 fits. Does anyone know of how I can speed up this process, say by telling Iraf to accept the second iteration for each fit and move onto the next? I did the first 4000 fits last night, where each one had the same name except for a number so I could read them in one after the other with the * symbol, but it still took several hours of manually pressing two buttons. I've set the initial parameters close enough to the true values that in all cases so far the best fit has been obtained after the first iteration.<br>
<br>
I'm still quite new to iraf, and haven't written any scripts for it yet.<br>
<br>

Aquila

**Mike Fitzpatrick** wrote on Nov 30, 2010

{% raw %}
<div>
Try setting the 'maxit' and 'restart' parameters in the CONTROLPARS pset used to limit the number of iterations and restarts used in the fitting method.  Turning off the nfit1d.interactive parameter should suppress any prompts required.
</div>
{% endraw %}
