**Mike Fitzpatrick** wrote on Nov 20, 2010

{% raw %}
<div>
Primarily, the IMUTIL version has a 'rename' parameter and the 'comfile' parameter expects a null string value (i.e. "") instead of the string "NULL" as is used in the GEMINI package.  You can diff the code the see what else might be different.<br>
<br>
Note that for v2.15 the FITSUTIL.NHEDIT task was moved to GMISC since that version is needed only for gemini support and the differences were causing problems for other packages when FITSUTIL was loaded.
</div>
{% endraw %}
