Hello ginger,<br>
<br>
In the helpfile for xnregistar, it says that the sections parameter is 'The optional output sections or corners file suitable for input to the maskdereg task. If defined sections contains the name of the input images in sinlist if it is defined or inlist, the x and y coordinates of the lower left corner of the input image in the combined output image, and the x and y coordinates of the upper right corner of the input image in the output image in columns 1 through 5 respectively.' while the sinlist parameter is 'The list of image names that will be written to the sections file. If sinlist is undefined then the input image names in inlist are used.'<br>
<br>
I notice that you have the sinlist parameter set to 'demo.list'. What is contained in this file? Does it exist? I think that if you set sections="" <em>and</em> sinlist="" then the task should run without complaining ;)<br>
<br>
Hope that helps?<br>
