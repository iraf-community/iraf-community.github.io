<div>
The file type is defined by the 'imtype' environment variable, i.e. if you do a "cl&gt; show imtype" does it say 'imh' or 'oif'?   In recent versions the default imtype should be "fits" so new images will be written in FITS, you can reset this in your login.cl.
</div>
{% endraw %}
