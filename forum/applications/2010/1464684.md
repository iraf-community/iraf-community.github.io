I can't think of what is the most appropriate help page describing the image cursor format.  For graphics it would be "cursors".  The help for "rimcur" is somewhat appropriate.<br>
<br>
But it is easy enough to tell you that an image cursor input has the format<br>
<br>
&lt;x&gt; &lt;y&gt; &lt;frame/subframe&gt; &lt;key&gt;<br>
<br>
The frame/subframe is like 101, 201 but it many cases it doesn't matter and you can use just use 101.  So you can create  a coordinate file with some script with the appropriate 'q' key values between each image.<br>
<br>
I can give a more complete example with psfmeasure if you wish.<br>
