**Mike Fitzpatrick** wrote on Jun 03, 2010

{% raw %}
<div>
The IDENTIFY task, assuming you saved the fitted results, only generates the database with the dispersion solution.  You need to then use the DISPCOR task to apply the solution to the image so it has a proper WCS.<br>
<br>
If you're just getting pixel values out instead of wavelengths you may have skipped this last step.
</div>
{% endraw %}

**Mike Fitzpatrick** wrote on Jun 03, 2010

{% raw %}
<div>
Be sure you did a MKIRAF to create a login.cl file, and that you typed 'cl' to login to iraf from the directory with that login.cl file.  This is what loads the default packages that include HSELECT.<br>
<br>
Otherwise, type 'images' and 'imutil' to load the proper package (but note you'll be missing the proper package for many other tasks).
