<div>
First, you should be installing the v2.0 release as described in <a href="http://iraf.net/article.php/20081118030715468">http://iraf.net/article.php/20081118030715468</a><br>
<br>
The message basically means the X11 app-defaults directory wasn't found in one of the "normal" locations.  You only need this file for the XGterm menu options and some default color settings.  I don't have a SuSE system but try to find the 'app-defaults' directory under e.g. /usr/X11R6 somewhere, the manually copy the 'XGterm' file in x11iraf$app-defaults to this directory to restore that functionality.  You can ignore the message from the install script then.<br>
<br>
-Mike
