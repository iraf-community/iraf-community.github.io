<div>
This is either an issue with your window manager or DS9 itself.  Changing your focus policy to 'focus follows mouse' might be another solution.<br>
<br>
A cursor read is simply a command sent from IMEXAM to the display server (ds9 here), the server then goes into "read mode" and you get a blinky cursor but interactions with the focus and panner are at that point entirely between the server application and the window system.  If you contact SAO they'll probably need to know more details about your system (OS version, window manager, etc).
