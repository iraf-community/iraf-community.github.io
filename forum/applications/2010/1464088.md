**Mike Fitzpatrick** wrote on Apr 21, 2010

{% raw %}
<div>
Try something like<br>
<br>
<pre><code>cl&gt; stdplot foo.gki dev=psdump
cl&gt; gflush</code></pre><br>
<br>
This will create a file called 'irafdmpXXXX.ps' in the current directory (where 'XXXX' is some process id) that will be a B&amp;W postscript. The 'psdump' device uses the Simple Graphics Interface (SGI) to make the plot, if you were using the STSDAS postscript kernel then this is a full graphics kernel and colors are preserved.<br>
<br>
-Mike
</div>
