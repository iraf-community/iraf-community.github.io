**Mike Fitzpatrick** wrote on Mar 23, 2010

{% raw %}
<div>
Try unlearning the ALLSTAR parameters.  The error basically means the task was trying to get a 'version' parameter, and instead of getting the task's 'version' parameter (with a default value of 2) it instead found something like the DAOPHOT 'version' parameter (value something like 'May00').  Unlearning daophot as well might necessary so you go back to using the default parameters instead of what might be a corrupted file in your uparm directory.
</div>
{% endraw %}
