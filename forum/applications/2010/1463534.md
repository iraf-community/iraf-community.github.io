**Mike Fitzpatrick** wrote on Feb 04, 2010

{% raw %}
<div>
MSCRED is a true external package that must have been installed separately.  Packages are defined in the hlib$extern.pkg file (e.g. "cl&gt; type hlib$extern.pkg"), however you can define a package without having actually unpacked the source files/binaries so this isn't reliable, you need to see whether the files exist where they are declared.<br>
<br>
You can download MSCRED from the download link on the banner bar under 'External Package', see the README file for installation instructions.
</div>
{% endraw %}
