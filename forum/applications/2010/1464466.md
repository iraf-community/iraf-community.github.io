That means it's not finding the results from identify for your input file. Either you need to run identify beforehand on the same file in the same directory or you need to specify a matching reference file that you've already run identify on, by setting REFSPEC1 in the input file header, eg. with the task refspectra (see the second manual on the page I sent a link for). <br>
