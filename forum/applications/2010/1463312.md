<div>
The thing to remember is that the backslash is used as an escape, and so it needs to be escaped itself.  Its a kludge, but try something like<br>
<br>
<pre><code>
begin
    char ch

    while (yes) {
        ch = cl.ukey

        if (substr(ch,1,4) == &quot;\\015&quot;) {
            print (&quot;do newline&quot;)
        } else if (substr(ch,1,4) == &quot;\\040&quot;) {
            print (&quot;do spacebar&quot;)
        } else {
            switch (ch) {
            case &quot;q&quot;:   break
            case &quot;a&quot;:   print (&quot;got an &#x27;a&#x27;&quot;)
            case &quot;?&quot;:   print (&quot;do help&quot;)
            case &quot;\\&quot;:  print (&quot;do backslash&quot;)
            }
        }
    }
end
</code></pre><br>
<br>
-Mike
</div>
