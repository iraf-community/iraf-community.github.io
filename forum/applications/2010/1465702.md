**Mike Fitzpatrick** wrote on Dec 07, 2010

{% raw %}
<div>
It means the TABLES package is defined, but not actually installed.  Either you installed only the source, the wrong binaries, built from source but it didn't put the binaries in the right place, or the extern.pkg file simply defines the package so it shows up in the menu but you didn't actually install TABLES in any way yourself.  There are more obscure reasons for the error but check the above first and make sure TABLES is installed.
</div>

<div>
Problem solved. It was because the installation instructions I<br>
followed for tables told me to place the binary files inside a folder<br>
called bin.linux, whereas I should have placed them inside a folder<br>
called bin.redhat, because my system architecture (shown by typing<br>
"show arch" at the iraf command prompt) is redhat. I placed the binary<br>
files inside the correct folder and now it works.<br>
