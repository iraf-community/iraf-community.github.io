Did the file link correctly or were there any error messages when compiling?  "No file" doesn't look like a normal error message, was it 'no such file' or 'command not found'?  If so then you might just need to execute it as "./program.e" and adjust your path to include the '.' directory.  Otherwise, please post more information (IRAF and OS version, 32- or 64-bit system, etc).  Note there are tasks in $iraf/sys/imfort/tasks directory you can use to verify that FC work on your system.<br>
