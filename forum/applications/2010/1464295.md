Use the slist task.  You can select a single aperture and pipe the output to scan or you can dump the information into a file and then a loop over each line of the file. <br>
<br>
For the SNR I assume you mean finding the mean and rms of the continuum.  It depends on whether you want to do this interactively or automatically and whether you have specific wavelength regions.  Interactively this is usually done with splot though you need to do a continuum normalization or subtraction if there is any slope to the continuum.  If you have specific wavelength ranges then you can use bplot and put the wavelengths into a cursor file.  For echelle the logic is a bit tricky because each order has a different wavelength coverage.  Finally to do things automatically you would probably use continuum to produce the data output minus the lines and then use imstat.  Again you would need to use image sections or scopy to keep the orders separate if you have them all in a single .ec file.<br>
<br>
I hope this helps,<br>
Frank Valdes<br>
