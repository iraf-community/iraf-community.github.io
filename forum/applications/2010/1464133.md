<div>
A floating point error is sometimes a coding bug, and sometimes an error caused by the data (e.g zero-valued pixels).  The DAOFIND executable is actually the same between DAOPHOT and APPHOT and the default parameters are the same for both so I don't fully understand why it would work in one case and not the other.<br>
<br>
There are no known bugs in the task and not much more I can say without being able to reproduce the problem.  To do the latter, i would need to know the IRAF version, what platform you're using, the parameters for the task and you'd need to upload the problem image to the anonftp at <a href="ftp://iraf.noao.edu/pub">ftp://iraf.noao.edu/pub</a>.<br>
<br>
-Mike
