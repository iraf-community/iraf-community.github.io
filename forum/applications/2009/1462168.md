Seems that I managed to fix my problem as described in <a href="http://iraf.net/phpBB2/viewtopic.php?t=88799">http://iraf.net/phpBB2/viewtopic.php?t=88799</a> thread. EXTNAME keywords in my FITS files containing dashes (e.g. EXTNAME = 'CCID20-14-5-6') caused this error:<br>
<br>
<pre><code>
ERROR: FXF: numeric value only allowed as second term in ksection
</code></pre><br>
<br>
which is a bit different from what described in that case but anyway related to the FITS kernel parser. Replace dash with underscore fixes the problem.
</div>
