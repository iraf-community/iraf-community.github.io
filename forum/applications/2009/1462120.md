The command you have used is correct in order to extract just one aperture. However, it seems the apertures need to be renumbered. To do the renumbering you will need to change the parameter in scopy. Do the following: <br>
<br>
cl&gt; epar scopy<br>
<br>
Under renumber choose "yes". Try this out to see if it works the way you want it.
