This sounds like a fairly basic though important problem.  First make sure you are running IRAF in an xterm or xgterm window!  The try a simpler task that makes a plot (say "implot dev$pix").  If that works, and you say you are an experience IRAF user so you probably know what the graphics system should do, then I would be at a loss.  Oh,  you could try and call CCMAP directly (make up some dummy data if necessary) and see if that works.  There is really nothing mysterious in MSCTPEAK since it simply executes CCDMAP.<br>
<br>
If this doesn't point you to a solution let us know and we will have to try and figure out what is wrong with your installation.<br>

Frank Valdes<br>
