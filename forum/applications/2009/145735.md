I believe you are asking about the standard star files used by IRAF and the STANDARD task?  If you read the help page you will find a section describing the format and content of the standard star files, basically a text file with three columns.  The key thing is the second column must be m_AB values over some wavelength interval.  The intervals can be as find as single pixels in a flux calibrated spectrum or some wider bins where you integrate the spectrum.<br>
