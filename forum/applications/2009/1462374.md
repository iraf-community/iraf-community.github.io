**Mike Fitzpatrick** wrote on Aug 29, 2009

{% raw %}
<div>
If you're sure the path to the file is e.g. /usr/local/bin/xgterm, then check to be sure the file is executable, e.g.<br>
<br>
<pre><code>
iraf-nvo&gt; ls -l /usr/local/bin/xgterm
-rwsr-xr-x    1 fitz     users     1179181 Dec 10  /usr/local/bin/xgterm
</code></pre><br>
<br>
Where the 'x' in the permissions string means executable.  If not, use the command "sudo chmod 755 /usr/local/bin/xgterm" to set the permissions.  If they appear okay, you can check for missing shared libraries with e.g.<br>
<br>
<pre><code>% ldd /usr/local/bin/xgterm</code></pre><br>
<br>
It's possible the ecl.e binary is missing a libncurses.so,  if so get the statically linked version from <a href="http://iraf.net/ftp/pub/fitz/ecl.e">http://iraf.net/ftp/pub/fitz/ecl.e</a> and replace the binary in your /iraf/iraf/bin.linux directory.
</div>
