<div>
SCOMBINE is normally used to combine spectra.  I assume you mention the time difference because you need to remove some the velocity components, see the RVCORRECT task to compute the heliocentric velocity for the time of observation and the DOPCOR task to apply a correction so the data are both in the rest frame.
