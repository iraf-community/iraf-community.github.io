**Mike Fitzpatrick** wrote on Apr 09, 2009

{% raw %}
<div>
I don't think the database name is able to correctly handle the directory prefix, try running it from the 'Feb14' directory itself.  You might also try creating an iraf logical directory and use that instead, e.g.<br>
<br>
<pre><code>
cl&gt; set data  = &quot;Feb14/&quot;                     &lt;--- trailing &#x27;/&#x27; required
cl&gt; doslit data$c0030master-iraf.fits arcs=data$c0030masterwavelength-iraf.fits
</code></pre><br>
<br>
This may fail in a similar manner, however.  Frank will comment if I'm too far off.<br>
<br>
-Mike
</div>
{% endraw %}
