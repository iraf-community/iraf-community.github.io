<div>
I uploaded a Mac universal binary for CFITSIO to  <a href="http://iraf.net/ftp/pub/libcfitsio_mac.a">http://iraf.net/ftp/pub/libcfitsio_mac.a</a><br>
<br>
According to the CIRRED instructions you should be able to simply copy this to the cirred directory and compile with e.g.<br>
<br>
<pre><code>cl&gt; fc  fixfits.f ./libcfitsio_mac.a</code></pre><br>
<br>
Note that for compilation your will need to define a 'iraf' and 'IRAFARCH' environment variable in your .cshrc file (the 'fc' command is a C-shell script) as e.g.<br>
<br>
<pre><code>
setenv iraf /iraf/iraf/                      &lt;-- trailing &#x27;/&#x27; required
setenv IRAFARCH macintel           &lt;-- or &#x27;macosx&#x27; for PPC systems
</code></pre><br>
<br>
If you stil have problems please post the error message.<br>
<br>
-Mike
</div>
