<div>
The main thing that is special about SCOMBINE is that it works in wavelength space.  Hence it can take spectra with different wavelength sampling and combine them.  As you note, it does not handle the associated band data.  There are two possiblities.  If the data have a common wavelength sampling then you could use IMCOMBINE.  Note that combining of any error bands will not be statistically correct.  The other, which I haven't verified, is that it may be possible with image sections to have it treat the bands as the spectra.  There might be some gotchas but I would try that.  To rebuild the format from the output combines one could use imstack.<br>
<br>
This is just a quick answer which I hope might be of use.<br>
<br>
Frank Valdes
