Um, display from the shell 8-)<br>

Seriously,  when you display from IRAF the scaling is done in the client, DS9 is acting as a server and so doesn't have direct access to the pixels and so scaling doesn't make sense (i.e. taking the 95% histogram scaling of the IRAF z-scaled display pixels probably isn't what you want anyway).  This could be made to work in the future, but it would have to be a change on the DS9 side.<br>
