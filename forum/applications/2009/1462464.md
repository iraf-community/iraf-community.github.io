What I understand is that you have all the coordinates in a single file, say the first 3 lines for the first image, the next three lines for the second image, and so on.  I confirm my reading of the help page that if you want separate coordinates for each image then the coordinates have to be in separate file.  So you have to break up the file and the possible ways are with your favorite editor, with some Unix script or whatever is you best scripting language, or with an IRAF script.  An IRAF script is just one option but this is job of breaking up a file doesn't have to be done with IRAF.<br>
