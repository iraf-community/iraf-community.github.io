# Strange behaviour in procedure script?

**Gabriel** wrote on Mar 11, 2009

{% raw %}
<div>
Hi,<br>
I'm writing a procedure script that looks like this:<br>
<br>
procedure test1 (query parameters)<br>
<br>
#declaration of parameters<br>
real fwhm  {prompt = "Ingrese el valor de FWHM"}<br>
<br>
begin<br>
<br>
    #declaration of variables<br>
    string variable1<br>
<br>
#if structure<br>
if (xxxxx) {<br>
xxxx<br>
xxx<br>
}<br>
else {<br>
xxx<br>
}<br>
<br>
etc... (more script commands)<br>
<br>
end<br>
<br>
The thing is that when I run this script, it FIRST runs the 'if structure' and THEN it asks for the 'query parameters' (defined before 'begin').<br>
Am I doing something wrong? Is this the way it should work?<br>
In any case I want it to do this (I'm happy with the way the script runs), I just don't know if this is a sign that something is not working properly (in that case I'd rather fix it now that the script is small) or just normal behaviour.<br>
<br>
Thanks!
</div>

<div>
The query is made when the parameter is first accessed in the script, if this is after your 'if' statement then that would explain it.  A common practice is to first get all the parameters at the top of your script and save them to local variables, this will avoid the query each time the parameter is accessed (i.e. a query parameter in a loop may prompt each time).<br>
<br>
-Mike
</div>
