<div>
The task APMASK can be used to make a mask from the aperture definitions.  There are features in TV.DISPLAY to overlay masks on a display.  This would work with DS9 or XImtool.   As noted in the help, the mask (or the overlay color mapping) can be set to either cover the apertures or the areas outside the apertures.<br>
<br>
I think what might also be desired is to draw a single overlay line of the trace.  The only thing I can think of is a vague memory that an outside group (Lick Obs I think) developed some task to output the trace.  But this was many years ago (&gt; 10 years).  User's may search the forum to try and find this discussion.<br>
<br>
Frank Valdes
