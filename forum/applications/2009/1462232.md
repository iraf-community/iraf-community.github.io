<div>
The SPLOT 's' keystroke does a simple boxcar smoothing of the spectra.  If you want to treat the data as simply a pixel array, you can do pretty much the same thing using the BOXCAR task directly.  Note for extracted echelle spectra you'll want to set the 'ywindow' parameter to be a single row.<br>
<br>
-Mike
