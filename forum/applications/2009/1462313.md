<div>
The answer depends on whether this is a single 2-D image with four separate image areas, or if the four images are in different FITS extensions and it was simply by displaying it that you saw the gaps.<br>
<br>
In the latter case programs like DS9 can be used to display a mosaic MEF image and the 'white bar' is an effect of how the image is displayed in the frame.  In IRAF, you can try something simple like<br>
<br>
<pre><code>cl&gt; imstat image.fits</code></pre><br>
<br>
If you get a complaint about 'must provide image extension', then you have an MEF file (i.e. multi-extension FITS) and you can use a task like FXSPLIT in the FITSUTIL package to separate the extensions to new images.  If you don't get a complaint, or the IMHEAD task says this is a 2-D file then you'll need to use image sections to copy out the pixel areas.  For example,<br>
<br>
<pre><code>
cl&gt; imcopy image.fits[1:1024,1:1024] q1.fits
cl&gt; imcopy image.fits[1034:2049,1:1024] q2.fits
   .... and so on
</code></pre><br>
<br>
Presumably for this type of image the sections would be the same for all images so you could create a script to automate this.<br>
<br>
As for combining these to remove the gaps:  The ARTDATA package has a MKPATTERN task you can use to create a blank image of a certain size, you can then just IMCOPY the pixels directly using an image section, e.g.<br>
<br>
<pre><code>cl&gt; imcopy q1.fits blank.fits[1:1024,1:1024]

or

cl&gt; imcopy image.fits[1034:2049,1:1024] blank[1025:2048,1:1024]
</code></pre><br>
<br>
Likewise, you can copy within the image to remove the gaps and then trim the excess, e.g.<br>
<br>
<pre><code>cl&gt; imcopy image.fits[1034:2049,1:1024] image[1025:2048,1:1024]</code></pre><br>
<br>
There isn't a task to do this automatically since this isn't really a standard format.  If you'd care to post the image somewhere I'll have a look to see if there are other sugestions for you.<br>
<br>
-Mike
</div>

<br>
I think you are talking about what is called "quadformat".  Some observatories, including NOAO, sometimes used multiple amplifiers to readout a CCD and store each amplifier as a quadrant in a "flat image" (as opposed to extensions in a multiextension format).  The overscan for each amplifier is placed next to the piece being read out which often means it ends up in the middle causing what appears as a stripe.<br>
<br>
Calibrating such a format is done with the quadred package.  You can type<br>
<br>
cl&gt; help quadred<br>
cl&gt; help quadformat<br>
<br>
to get more information.<br>
<br>
Yours,<br>
Frank Valdes
