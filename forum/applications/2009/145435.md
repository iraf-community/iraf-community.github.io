**Mike Fitzpatrick** wrote on Jan 27, 2009

{% raw %}
<div>
Check the CCDRED package parameters 'verbose' and 'logfile'.  If verbose is off you won't get some output, if logfile is non-null (be sure it isn't just a space character) the output will be written there.<br>
<br>
-Mike
