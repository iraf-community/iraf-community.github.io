There is no specific IRAF task for SBIG images, however the IMPORT task in the DATAIO package can probably read the data assuming you can parameterize the header offset, raster size, etc.  If you can supply me with a sample image I can give you a database entry for IMPORT to convert this automatically, otherwise a Google search will turn up a number of conversion programs to produce FITS (not all are linux, though).<br>
