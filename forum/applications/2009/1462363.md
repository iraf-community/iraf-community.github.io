**Mike Fitzpatrick** wrote on Aug 28, 2009

{% raw %}
<div>
DS9 physically opens the image to determine what type of file it is, IRAF relies on the filename extension to use the appropriate image kernel.  If the filenames have no extension but you know they are e.g. FITS files, you can add an extension automatically using<br>
<br>
<pre><code>cl&gt; rename foo* fits field=extn</code></pre><br>
<br>
You should then be able to use DISPLAY (or MSCDISPLAY for multi-extension files) to display the image.<br>
<br>
-Mike
</div>
{% endraw %}
