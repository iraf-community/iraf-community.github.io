<br>
IRAF is distributed as three compressed tarballs: the as.pcix.gen.gz (AS = All sources), ib.cygw.x86.gz (IB=core IRAF binaries) and nb.cygw.x86.gz (NB=NOAO binaries).  The 'cygw' indicates Cygwin binaries.  You would normally download these files from the Downloads link above, unpack and install according to the directions in the installation guide (<a href="http://iraf.net/irafdocs/pciraf)">http://iraf.net/irafdocs/pciraf)</a>.  The example given in the guide refers to 'redhat' as the architecture, the process is the same if you instead use 'cygwin' for your system.<br>

<div>
Cygwin must be installed first and is independent of IRAF.  You can get what you need from cygwin.org but be sure you have this installed before trying to install IRAF.  If a connection times out when installing Cygwin, try using a different mirror site.<br>
<br>
The download link on this site gets you ONLY the three iraf distribution files I mentioned.  There are no specific instructions for a Cygwin install, the process is basically the same on all systems so while the guide may specifically mention 'redhat', you can just as easily use 'cygwin'.<br>
<br>
-Mike
