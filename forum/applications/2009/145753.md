# Writing to file from a procedure script

**Gabriel** wrote on Mar 12, 2009

{% raw %}
<div>
I need a way to automatically (i.e. from a script) create a file and write the following text into it:<br>
<br>
char : text1 text2 text3<br>
char2 : text4 text5 text6<br>
<br>
something along those lines (it's the 'imsets' file from 'mknobsfile'). Can this be done with a script or do I have to do it manually?
</div>

---

**Mike Fitzpatrick** wrote on Mar 12, 2009

{% raw %}
<div>
Use a print statement and redirect it to a file, e.g.<br>
<br>
<pre><code>
print (&quot;char : text1 text2 text3&quot;,  &gt; &quot;imsets&quot;)
print (&quot;char2 : text4 text5 text6&quot;, &gt;&gt; &quot;imsets&quot;) 
</code></pre><br>
<br>
Note the filename 'imsets' is quoted as a literal string, the &gt;&gt; operator is used to append a file.<br>
<br>
-Mike
</div>
{% endraw %}
