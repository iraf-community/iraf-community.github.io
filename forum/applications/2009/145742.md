**Mike Fitzpatrick** wrote on Mar 11, 2009

{% raw %}
<div>
A new MKIRAF will recreate your login.cl file and uparm directory.  The location of your uparm directory is defined in the login.cl, if you simply copied this from another machine then the path is likely to be different and would explain the error.  The other common cause is a permissions problem, e.g. you logged in through somebody else's login.cl or updated the machine and changed the user-id so can't update the files.<br>
<br>
In any case a new MKIRAF is the recommended fix.<br>
<br>
-Mike
</div>
{% endraw %}
