# Incorrect compass annotation in ximtool?

**James Turner** wrote on Jan 12, 2009

{% raw %}
<div>
I think the N-E compass annotation in ximtool is rotated incorrectly. This is the annotation enabled by pressing "coords" from the toolbar and selecting the "compass" check box. It seems to me that the sense of the rotation is back to front when there are CD1_2 and CD2_1 elements.<br>
<br>
For example, with the following WCS elements, ximtool (v1.3 or v2.0beta) shows North down-left and East up-left, whereas ds9 shows North down-right and East down-left, which is what I'd have expected from sketching it:<br>
<pre><code>CD1_1   = -2.86791518040212E-05 / WCS matrix element 1 1
CD1_2   = -2.86977296724552E-05 / WCS matrix element 1 2
CD2_1   = 2.87179100916065E-05 / WCS matrix element 2 1
CD2_2   = -2.86749200926711E-05 / WCS matrix element 2 2
</code></pre><br>
I also notice that in ximtool 2 beta, when I display an image after resizing the ximtool window, the panner image is redrawn on top of the compass annotation, making it no longer visible.<br>
