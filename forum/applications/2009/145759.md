I'm not quite sure what effect you are seeing and asking about.  Scale, rotate and translate are separate operations that can be done individually by tasks like MAGNIFY, ROTATE or IMSHIFT...or as a combined operation in IMLINTRAN.  You might try separating the operations so that the scale change is done first so the center is preserved, then try translating with IMLINTRAN or IMSHIFT as a second step.<br>
