# Recommended tweaks for combine and imcombine help files

**Jason Quinn** wrote on Nov 19, 2009

{% raw %}
<div>
Couple of recommended help file tweaks for <strong>combine</strong> and <strong>imcombine</strong>.<br>
<br>
1) When scaling by exposure, <strong>combine</strong> seems to scale relative to the <em>average</em> exposure time while <strong>imcombine</strong> seems to scale relative to the <em>first image</em> in the input list. This should be explicitly mentioned in the scaling section of the documentation. And perhaps with a note that the two act differently. (I always use <strong>imcombine</strong> but some other group members use <strong>combine</strong>.... is <strong>imcombine</strong> the more "fundamental" of the two? It says in the help that <strong>combine</strong> is derived from <strong>imcombine</strong> but I don't know how much code they share.)<br>
<br>
2) The help files for both <strong>imcombine</strong> and <strong>combine</strong> in the explanation of the minmax algorithm both talk about <br>
<br>
<blockquote>As an example with 10 input images and specifying nlow=1 and nhigh=2 the fractions to be rejected are <span style="color: red">nlow=0.1</span> and <span style="color: red">nhigh=0.2</span> and the number rejected as a function of n is:<br>
</blockquote><br>
This should be changed because the variables nlow and nhigh are being used inconsistently leading to possible confusion. Perhaps:<br>
<br>
<blockquote>As an example with 10 input images and specifying nlow=1 and nhigh=2 the fractions to be rejected are 0.1 and 0.2, respectively, and the number rejected as a function of n is:<br>
</blockquote><br>
<br>
Somehow I only just yesterday even realized that the combine tasks change my choices for how many pixels get rejected according to a dynamic formula. Ugh.<br>
<br>
3) When exposure scaling is used by <strong>combine</strong>, by default it seems to look for an "exptime" keyword and there is no way to change it (there is the !keyword mechanism but it acts differently). By contrast, <strong>imcombine</strong> allows the specification of a exptime keyword.  It should say in the documentation, what keyword is used with <strong>combine</strong> when exposure is chosen.
</div>
{% endraw %}
