<div>
A 'memory corrupted' error is normally a coding error (e.g. an array overflow), but it can be triggered by anything from data values to specific combinations of parameters.  Without your image and a list of the parameters (and the IRAF and OS versions) to reproduce the problem any comments are pure speculation.<br>
<br>
The fact the task seems to 'think' for a little while makes me think the fit might not be converging for some reason and the task eventually dies.  You might try resetting some of the 'controlpar' parameters to change the fit behavior, or perhaps try a (slightly) different guess for the centroid to see if the behavior changes.   Otherwise, if you're running an older version of STSDAS you might try getting the latest.<br>
<br>
If you don't get an answer here, the STScI help desk can be reached at help@stsci.edu   Hope this helps.<br>
<br>
-Mike
