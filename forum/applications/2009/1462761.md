**Mike Fitzpatrick** wrote on Oct 24, 2009

{% raw %}
<div>
Some of each:  Basic CCD reductions, cosmic ray removal, image registration and such are done with things like IRAF, but the pretty-picture things like color balance and visual manipulation are done in PhotoShop/GIMP-like tools.<br>
<br>
A very basic form of color combination can be done in IRAF using the EXPORT task to combine e.g. RGB images into a color GIF (see the help page examples for details), but these usually aren't going to be press-release type images.<br>
<br>
-Mike
</div>
{% endraw %}
