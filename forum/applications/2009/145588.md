**Mike Fitzpatrick** wrote on Feb 17, 2009

{% raw %}
<div>
<blockquote><br>
Warning: cannot open /dev/imt10 </blockquote><br>
<br>
The fifo pipes aren't necessary for display and I missed the case for Cygwin that tells the code to ignore them (fixed for next release).    For the moment you can just use<br>
<br>
<pre><code>vximtool -unix_only</code></pre><br>
<br>
to avoid this, but note that VXIMTOOL is generally only used by developers.  XImtool should  complain but keep running.<br>
<br>
As for the X error:  This v2.0 version supports 24-bit displays but is a little weak in 8-bit support ironically.  Be sure you aren't using just 256 colors for the main display.<br>
<br>
-Mike
</div>
