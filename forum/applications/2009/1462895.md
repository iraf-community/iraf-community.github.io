<div>
RVSAO requires that you compile with "mkpkg -p rvsao update" in order to install the binary in the proper place.  If there was an error in the compilation, you'll need to take it up with the author.  Pre-built macintel binaries of the latest version are in the download area (<a href="http://iraf.net/ftp/iraf/extern/rvsao-2.7.8-bin.macintel.tar.gz)">http://iraf.net/ftp/iraf/extern/rvsao-2.7.8-bin.macintel.tar.gz)</a><br>
<br>
-Mike
