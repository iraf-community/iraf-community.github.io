<div>
Assuming your file is called 'test' and you don't care whether there is a newline at the end try:<br>
<br>
<pre><code>cl&gt; type test | tr STDIN &quot;\n&quot; &quot; &quot;</code></pre><br>
<br>
Otherwise, you could write a little loop:<br>
<br>
<pre><code>
list = &quot;test&quot;
while (fscan (list, line) != EOF) {
    printf (&quot;%s&quot;, line, &gt;&gt; &quot;newfile&quot;)
}
print (&quot;&quot;, &gt;&gt; &quot;newfile&quot;)
</code></pre><br>
<br>
This will create the new file called 'newfile' with a terminating newline.  You could similarly redirect using the one-liner above and then add a newline the same way.<br>
