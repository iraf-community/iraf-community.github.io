I have a list of 1990 stars that I've run phot on, and now I need to do aperture corrections. Not all these stars are suitable for aperture photometry, due to mild crowding, bad pixels, etc. But I don't cull the list since I want the photometry to be as automatic as possible. When I run mkapfile, I go through and delete obviously errant data points. Once I'm done, I notice that a lot of the stars from the input list do NOT appear in the output magnitude file, or the log file. In fact, the log file renumbers the objects such that it is impossible to tell which stars are missing. So for example if I input stars 1,2,3, and 4 and #2 has bad photometry, the log file shows stars 1,2, and 3 output, whereas in reality they correspond to 1,3, and 4. And the magnitude file does not have id numbers at all.<br>
<br>
 I would really like to know which of the input stars are missing from the output. I cannot find any record of this, and then only way to find out is to go through and manually match up the coordinates of the input with the output (annoying, because they've been recentered and hence are not exactly the same). Is there some way I can get mkapfile to tell me what objects it has failed to produced photometry for?<br>
Or better yet, to perform aperture corrections on *all* input stars, even if the answer is erroneous?
