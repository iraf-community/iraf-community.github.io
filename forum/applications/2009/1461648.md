# dispcor not working with ecidentify

**astronick** wrote on May 29, 2009

{% raw %}
<div>
Hello all,<br>
<br>
I'm trying to reduce some echelle spectrograph data, but I'm hitting a problem applying my wavelength solution using DISPCOR.<br>
<br>
I've identified the ThAr lines using ECIDENTIFY, and got a good solution for all the orders. I applied this to a test image using REFSPECTRA; the reference spectrum was accepted and the correct value for REFSPEC1= appeared in the test file's header.<br>
<br>
However, running DISPCOR on the test file produces the following error:<br>
<br>
Warning: Cannot open file (database/idthar_df.ec)<br>
<br>
and no processing is done. The actual filename it should be looking for (and which has the wavelength solution in it) is database/ecthar_df.ec - it looks like DISPCOR is trying to use an IDENTIFY solution rather than ECIDENTIFY.<br>
<br>
Any ideas? Thanks!
</div>
{% endraw %}

Problem solved - turns out due to a typo I was running DISPCOR on the spectrum image rather than the extracted spectra. Works fine now.
