**Mike Fitzpatrick** wrote on Apr 01, 2009

{% raw %}
<div>
I think the command you are looking for is<br>
<br>
<pre><code>cl&gt; hselect d*ms.fits OBJECT,EXPTIME,AIRMASS &quot;object ?= &#x27;eg274&#x27;&quot;</code></pre><br>
<br>
The IMHEAD task dumps the entire header with the 'long' option, but HSELECT is used to print only certain header fields.  In this case we give it a list of images to search, the keywords to print out, and a conditional expression that must be true to print the value (in this case only print when the OBJECT keyword is 'eg274', the "?=' is a string-comparison operator).  See the help page for HSELECT (and HEDIT) for additional details.<br>
<br>
-Mike
</div>
{% endraw %}
