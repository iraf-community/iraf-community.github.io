I haven't personally reduced NIFS science data, but as far as I can tell this is harmless. The task nsreduce is used by several instruments, hence the "slit" terminology. In this case, you would expect a different focal plane mask for the Ronchi flats and the normal flats (only one of them has the Ronchi screen), but more generally when reducing spectroscopic data you'd expect to have the same thing(s) in the focal plane for the flats and the file you're reducing.<br>
