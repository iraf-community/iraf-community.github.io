<div>
ARED is a fairly old package and we're recommending you use the QUADRED package (based on ARED) that's already part of the core system.  For the error message you mention, the usual cause is that the 'ared' variable isn't defined in the hlib$extern.pkg file (or isn't defined with a trailing '/', or isn't defined before the finall 'keep' statement).<br>
<br>
-Mike
