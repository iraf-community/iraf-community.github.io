**Mike Fitzpatrick** wrote on Dec 12, 2009

{% raw %}
<div>
<blockquote><br>
txdump (s1, "otime,id,xcenter,ycenter,mag,merr,image", "id="//j &amp;&amp; "merr&lt;"//e , &gt;&gt; s2) </blockquote><br>
<br>
The thing to remember is that you are trying to create a string of the whole expression;  you can do this by concatenating actual strings with variables or else us a printf() to format the string.  For example<br>
<br>
<pre><code>
&quot;id = &quot; // j // &quot; &amp;&amp; merr &lt; &quot; // e

or 

printf (&quot;id = %d &amp;&amp; merr &lt; %.2f\n&quot;, i, e) | scan (line)
</code></pre><br>
<br>
The first case is straightforward.  In the second case, the newline is required to properly terminate the scan, and you need to use the 'line' CL parameter (or some parameter of type 'struct') to capture the whole string.  You can use a simple string variable as well but need to remove the spaces from within the expression.<br>
<br>
-Mike
