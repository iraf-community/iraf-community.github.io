<div>
There are two error messages here:  The 'memory corrupted' usually indicates a coding problem of some kind, i.e. an array overflow that corrupted memory.  STScI would have to debug this and might need your parameters or some way to reproduce the problem to properly track it down.<br>
<br>
The second error is "out of memory" and I think is really the issue:  Your image is ~768MB and the ADAPTIVE task allocates 5 full images (&gt;3.5GB) as work space.  So, not only does this exceed the 32-bit restriction currently in the system, but may also be more than your process limit allows.  There are workarounds for the second thing, but the task would need to be rewritten to use less memory.  I don't really know of an equivalent filtering task, sorry.<br>
<br>
My only suggestion is to try to process the image in smaller pieces and then recombine it later.  Hope this helps.<br>
<br>
-Mike
