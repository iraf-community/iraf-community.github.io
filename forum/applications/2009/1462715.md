<div>
The EXTVER keyword should be an integer value, but the complaint about it is probably masking the real problem due to error cascading.  Try deleting the keyword and adding it again with a value of 1 (one), when you run the task again you should see the real error.  This will likely be something like a missing header value or e.g. mask file.<br>
<br>
-Mike
