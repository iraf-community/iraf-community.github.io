**Mike Fitzpatrick** wrote on Aug 16, 2009

{% raw %}
<div>
Firstly, if you're using SuSE then the IRAF architecture you need to remember is 'linux'.<br>
<br>
When resetting the package architecture or compiling, you also need to remember to use the '-p &lt;pkgname&gt;' flag to load the package environment.  In this case, resetting the package architecture is done with:<br>
<br>
<pre><code>mkpkg -p stsdas suse</code></pre><br>
<br>
That said, compiling anything in IRAF requires that you define certain environment variables, e.g.<br>
<br>
<pre><code>
setenv  iraf  /iraf/iraf/              &lt;-- trailing &#x27;/&#x27; required
setenv IRAFARCH linux            &lt;--  for v2.14, earlier systems use &#x27;suse&#x27;
source $iraf/unix/hlib/irafuser.csh    &lt;-- picks up other variables
</code></pre><br>
<br>
These are for C-shell users and should be put in your .cshrc file, let me know if you need the equivalent Bash shell commands.  For major packages like STSDAS/TABLES, it may be simplest to just download and unpack the pre-built binaries.<br>
<br>
As for the error when starting the CL:  This looks like a problem in the hlib$extern.pkg file which you must edit to define the package, e.g. you forgot a closing quote char or didn't escape a newline in the 'helpdb' definition.  Post this file if you aren't sure what went wrong, in any case please review the STSDAS/TABLES installation docs and be sure you've followed all the steps.<br>
<br>
-Mike
</div>
{% endraw %}

**Mike Fitzpatrick** wrote on Aug 16, 2009

{% raw %}
<div>
<blockquote><br>
reset   helpdb      = "lib$helpdb.mip\<br>
           ,noao$lib/helpdb.mip\<br>
#           ,tables$lib/helpdb.mip\<br>
           "stsdas$lib/helpdb.mip\<br>
<br>

<br>
This is supposed to be a quoted string, where the '\' at the end escapes the newline.  Your definition for stsdas follows the closing quote and is a syntax error, try instead<br>
<br>
<pre><code>
reset   helpdb      = &quot;lib$helpdb.mip\
           ,noao$lib/helpdb.mip\
          ,tables$lib/helpdb.mip\
          ,stsdas$lib/helpdb.mip\

</code></pre>
