Yes, display has the "overlay" feature that was designed for masks.  You can chose to set the overlay colors based on the (non-zero) mask values if you want to discriminate various types of mask values.  It takes a little learning but once you do the visualization that the overlay feature provides can be quite powerful and useful.<br>
