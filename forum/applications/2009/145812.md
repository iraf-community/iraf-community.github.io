<div>
You need commas after each argument and a value of some sort for the 'append' param, i.e.<br>
<br>
<pre><code>tmerge (file1, file2, file3, append+)</code></pre>

**James Turner** wrote on Mar 23, 2009

{% raw %}
<div>
If the files are actually called "file1" etc. (rather than being stored in variables of those names), you need to do this:<br>
<pre><code>tmerge (&quot;file1,file2&quot;, &quot;file3&quot;, &quot;append&quot;)</code></pre><br>
I'd suggest reading the guide to IRAF scripting, to understand where this syntax comes from:<br>
<br>
<a href="http://iraf.net/irafdocs/script.pdf">http://iraf.net/irafdocs/script.pdf</a><br>
<br>
Cheers,<br>
<br>
James.
</div>
{% endraw %}
