**Mike Fitzpatrick** wrote on Jul 23, 2009

{% raw %}
<div>
Trying to do surface photometry from data derived from a contour plot rather than the original FITS file probably isn't the best thing.  The ISOPHOTE package in STSDAS is meant to work on the FITS file itself and is probably what you're after.  You'll need to install STSDAS and read the package documentation, but in short there really isn't a way to create data from an IRAF graphic like a contour plot.<br>
<br>
-Mike
</div>
