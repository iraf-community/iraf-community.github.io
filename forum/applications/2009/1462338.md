**Mike Fitzpatrick** wrote on Aug 25, 2009

{% raw %}
<div>
It is the 'scrollBar' resource, or else use the "-sb" command-line flag.  In general, XGterm allows the same resources and options as XTerm (at least for text windows) so see the xterm man page if you haven't specifically got the xgterm man page installed.<br>
<br>
-Mike
