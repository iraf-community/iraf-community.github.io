**Mike Fitzpatrick** wrote on Feb 26, 2009

<div>
The "out of space in image header" message typically means you have<br>
exceeded the size of your "min_lenuserarea" environment variable. <br>
You can increase this beyond the default value of 64000, in the cl:<br>
<br>
       cl&gt; reset min_lenuserarea = 200000<br>
       cl&gt; flpr <br>
<br>
Alternatively, you can reset the min_lenuserarea in your login.cl     <br>
(or loginuser.cl) file and start a new IRAF session.<br>
<br>
If you stil have problems, post back.<br>
<br>
Cheers,<br>
-Mike
</div>
{% endraw %}

<div>
The basic cause is indeed trying to create a header with too many keywords.  This seems to be because IMCOMBINE tries to document the data that went into the combination.  There is a maximum number of IMCMB keywords it will try and create.  I can't recall if it is in the current or next version of IMCOMBINE but there is an option to turn off or better control this record keeping.  As a workaround, increasing the min_lenuserarea should solve the problem.<br>
<br>
Yours,<br>
Frank Valdes
