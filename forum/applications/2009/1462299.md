<div>
It means you told IRAF you were using an XGterm window, but you're running from a normal Cygwin window and so can't do graphics.  You'll need to be sure you have the X11 stuff installed as well, then be sure to type 'startx' to start X.  This normally brings up an XTerm window which *can* be used so long as that's what you've told IRAF to expect.<br>
<br>
If you really wan to use an XGterm, you'll need the X11 stuff as well as the X11IRAF distribution on the main page for the Cygwin binaries.<br>

-Mike
