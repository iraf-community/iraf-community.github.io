<div>
See the IMEXPR task help page.  You can create an expression that uses the pixel position in some way, and you can create a pixel mask by specifying the output image as a .pl file.  You might also use the REFERENCES task to search for other mask-making tasks e.g. text2mask, mskexpr, etc.<br>

-Mike
