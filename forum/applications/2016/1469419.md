**Mike Fitzpatrick** wrote on Jul 19, 2016

{% raw %}
<div>
<br>
                Please post a header for the file or a link to the data so I can have a look.  I suspect the header contains an inappropriate WCS (e.g. an RA/DEC WCS) or perhaps multiple WCS keywords that can be causing the problem.  One thing you might try (on a <strong>copy</strong> of the file!) is to use the WCSRESET command (e.g. "cl&gt; wcsreset lwr06483mxlo_vo.fits wcs=world") to reset the WCS, but this may destroy everything where a simple keyword edit might fix it as well.<br>
<br>
I remember there being some problems with IUE data but don't remember the particulars, and don't have any experience with the MAST-distributed data.  Be sure to read up on the particulars of IUE data reduction and analysis at https://archive.stsci.edu/iue/analysis.html for additional pointers.<br>
</div>
