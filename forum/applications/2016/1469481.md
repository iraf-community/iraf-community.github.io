{% raw %}
<div>
<br>
                For each of the features, the values are:<br>
<br>
    - feature pixel coordinates<br>
<br>
    - feature fit coordinates<br>
<br>
    - feature user coordinates<br>
<br>
    - weights<br>
<br>
    - width<br>
<br>
    - type (emission=1, absorption=2)<br>
<br>
    - label string<br>
<br>
where the width and type come from the parameter settings and are not computed.<br>
</div>
{% endraw %}
