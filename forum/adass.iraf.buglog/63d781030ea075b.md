        You&#x27;re seeing a classic Y2K imheader problem found on older IRAF
versions.  The only workaround is to upgrade to V2.11.3 which is now 
available for all platforms from our archive.  RedHat 5.2 is still 
supported but you&#x27;ll need special binaries from the /iraf/v211/PCIX
directory, see the end of the README file for installation instructions.
        If you still have problems or questions feel free to followup to
the adass.iraf.system newsgroup or contact us at iraf@noao.edu.
