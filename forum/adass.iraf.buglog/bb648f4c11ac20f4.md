# Updated data file for O IV; NEBULAR package; all tasks

**Dick Shaw** wrote on Feb 20, 1998

<pre style="background: transparent; box-shadow: none; border: none;">

STSDAS Bug Report
MODULE: analysis.nebular, tasks: abund, ionic, temden, zones
SYSTEM: STSDAS V2.0
DATE:	20-Feb-98
FROM:	Shaw

BUG:  The statistical weight for level 5 for O IV was incorrectly 
recorded in the atomic data file as 5 instead of 6. The effect is 
that the level populations and emissivities for transitions to and 
from this level for this ion will be incorrect by about 20%.  
Diagnostics and abundances drived using these levels will be 
similarly affected. 

STATUS: The repaired data file has been included in the NEBULAR 
source distribution at ftp://ra.stsci.edu/pub/nebular/), and is 
fixed for the next release of STSDAS, due out soon.  There is 
no work-around.  A simple fix (without re-installing nebular) 
is to download the revised atomic data file from the ftp address 
above.  This file is in the subdirectory atomic_data, and is 
called o_iv_atom.fits.  After placing this file in the 
nebular$atomic_data directory, all futher calculations for this 
ion will be correct.
</pre>
